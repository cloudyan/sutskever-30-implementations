## Day 31

**知识点**：最大似然估计 (MLE)

**一句话**：MLE 选择让观测数据"最可能出现"的参数值。

**前置知识**：Day 22（贝叶斯定理）、Day 24（概率分布）、Day 25（期望与方差）
**后续应用**：Day 32（MAP）、Day 47（高斯分布与最小二乘）、Day 50（EM 算法）
**关联回顾**：Day 46（交叉熵 = 负对数似然）

**核心定义**：
- 似然函数：L(θ|D) = P(D|θ)，参数θ下数据 D 的概率
- MLE：θ̂ = argmax L(θ|D) = argmax log L(θ|D)
- 对数似然：连乘变连加，便于计算
- 频率派观点：参数是固定但未知的常数

**几何直观**：
- 似然函数：参数空间中的"山峰"
- MLE：找到山峰的最高点
- 多峰：可能有多个局部最优
- 曲率：峰越陡，估计越确定

**AI 中的应用**：
- 线性回归：MLE 等价于最小二乘 (假设高斯噪声)
- 逻辑回归：MLE 最大化对数似然
- 语言模型：MLE 最大化训练数据概率
- 高斯混合模型：EM 算法求 MLE
- 神经网络：交叉熵损失 = 负对数似然

**关键公式**：
```
似然函数：
L(θ|D) = P(D|θ) = ΠᵢP(xᵢ|θ) (独立同分布)

对数似然：
ℓ(θ) = log L(θ) = Σᵢlog P(xᵢ|θ)

MLE：
θ̂_MLE = argmax ℓ(θ)

高斯分布 MLE：
μ̂ = (1/n)Σxᵢ (样本均值)
σ̂² = (1/n)Σ(xᵢ-μ̂)² (样本方差，有偏)
```

**思考题**：为什么 MLE 在高斯分布下方差估计是有偏的？如何修正？

## Day 32

**知识点**：最大后验估计 (MAP)

**一句话**：MAP 在 MLE 基础上加入先验，是"正则化的 MLE"。

**核心定义**：
- 贝叶斯派观点：参数是随机变量，有先验分布
- 后验：P(θ|D) ∝ P(D|θ)P(θ)
- MAP：θ̂ = argmax P(θ|D) = argmax [log P(D|θ) + log P(θ)]
- 先验 P(θ)：编码对参数的先验信念

**几何直观**：
- MLE：只看似然函数的峰值
- MAP：似然 × 先验，被先验"拉向"先验均值
- 先验越强：后验越接近先验
- 数据越多：似然主导，先验影响减弱

**AI 中的应用**：
- L2 正则化：等价于高斯先验的 MAP
- L1 正则化：等价于拉普拉斯先验的 MAP
- 贝叶斯方法：MAP 是贝叶斯推断的近似
- 小样本：先验提供额外信息，防止过拟合
- 迁移学习：预训练权重作为先验

**关键公式**：
```
MAP 估计：
θ̂_MAP = argmax [log P(D|θ) + log P(θ)]

高斯先验：
P(θ) = N(0, σ₀²I)
log P(θ) ∝ -||θ||²/(2σ₀²)
MAP = MLE - λ||θ||² (L2 正则化)

拉普拉斯先验：
P(θ) ∝ exp(-λ||θ||₁)
MAP = MLE - λ||θ||₁ (L1 正则化)
```

**思考题**：MLE 和 MAP 的区别是什么？什么时候两者等价？

## Day 33

**知识点**：贝叶斯推断

**一句话**：贝叶斯推断计算参数的完整后验分布，而非单点估计。

**核心定义**：
- 贝叶斯推断：计算 P(θ|D) 的完整分布
- 后验预测：P(x_new|D) = ∫P(x_new|θ)P(θ|D)dθ
- 共轭先验：后验与先验同族，计算简化
- MCMC：用采样近似后验分布

**几何直观**：
- 点估计 (MLE/MAP)：一个点
- 贝叶斯：整个分布，包含不确定性
- 后验方差：参数估计的不确定性
- 预测分布：考虑参数不确定性的预测

**AI 中的应用**：
- 贝叶斯优化：超参数调优，平衡探索与利用
- 贝叶斯神经网络：权重是分布，输出不确定性
- 主动学习：用不确定性指导样本选择
- 贝叶斯深度学习：近似推断 (变分推断、MC Dropout)
- 因果推断：贝叶斯因果网络

**关键公式**：
```
贝叶斯定理：
P(θ|D) = P(D|θ)P(θ) / P(D)

后验预测分布：
p(x_new|D) = ∫p(x_new|θ)p(θ|D)dθ

共轭先验示例 (高斯 - 正态)：
先验：θ ~ N(μ₀, σ₀²)
似然：x|θ ~ N(θ, σ²)
后验：θ|x ~ N(μₙ, σₙ²)
其中：
μₙ = (σ²μ₀ + nσ₀²x̄)/(σ² + nσ₀²)
σₙ² = (σ²σ₀²)/(σ² + nσ₀²)
```

**思考题**：为什么贝叶斯推断在深度学习中不常用？计算难点是什么？

## Day 34

**知识点**：假设检验

**一句话**：假设检验判断观察到的差异是否"统计显著"。

**核心定义**：
- 零假设 H₀：默认假设（如"无差异"）
- 备择假设 H₁：想要证明的假设
- p 值：在 H₀成立下，观察到当前或更极端结果的概率
- 显著性水平α：拒绝 H₀的阈值（通常 0.05）
- 第一类错误：H₀为真但拒绝（假阳性）
- 第二类错误：H₀为假但接受（假阴性）

**几何直观**：
- H₀下的分布：中心在 0
- 观察到的统计量：落在尾部
- p 值：尾部面积
- p < α：落在拒绝域，拒绝 H₀

**AI 中的应用**：
- A/B 测试：比较两个模型的效果
- 特征选择：检验特征与目标的相关性
- 模型比较：新模型是否显著优于基线
- 消融实验：某个组件是否有显著贡献
- 因果推断：干预效果是否显著

**关键公式**：
```
z 检验 (大样本，方差已知)：
z = (x̄ - μ₀)/(σ/√n)
p 值 = P(|Z| > |z|) (双侧检验)

t 检验 (小样本，方差未知)：
t = (x̄ - μ₀)/(s/√n)
自由度：n-1

第一类错误：P(拒绝 H₀|H₀为真) = α
第二类错误：P(接受 H₀|H₀为假) = β
统计功效：1-β = P(拒绝 H₀|H₀为假)
```

**思考题**：p 值 < 0.05 意味着什么？p 值能告诉我们 H₀为真的概率吗？

## Day 35

**知识点**：置信区间

**一句话**：置信区间给出参数估计的"范围"，而非单点。

**核心定义**：
- 置信区间：[θ_lower, θ_upper]
- 置信水平 1-α：重复抽样下，区间包含真值的比例
- 95% CI：重复 100 次，约 95 次包含真值
- 宽度：样本量越大，区间越窄

**几何直观**：
- 点估计：一个点
- 置信区间：一个区间，包含不确定性
- 宽区间：估计不确定
- 窄区间：估计精确

**AI 中的应用**：
- 模型评估：准确率的置信区间
- A/B 测试：效果提升的置信区间
- 误差分析：模型误差的范围
- 超参数调优：报告最优值的置信区间
- 贝叶斯方法：可信区间 (Credible Interval)

**关键公式**：
```
均值的置信区间 (方差已知)：
x̄ ± z_(α/2) × (σ/√n)

均值的置信区间 (方差未知)：
x̄ ± t_(α/2,n-1) × (s/√n)

比例的置信区间：
p̂ ± z_(α/2) × √(p̂(1-p̂)/n)

样本量计算：
n = (z_(α/2) × σ / E)² (E 是允许误差)
```

**思考题**：95% 置信区间的正确解释是什么？"真值有 95% 概率在区间内"对吗？

## Day 36

**知识点**：回归分析

**一句话**：回归分析建模变量间的关系，预测连续输出。

**核心定义**：
- 线性回归：y = wᵀx + b + ε
- 最小二乘：最小化残差平方和
- 决定系数 R²：模型解释的方差比例
- 残差：观测值 - 预测值
- 假设：线性、独立性、同方差、正态误差

**几何直观**：
- 线性回归：拟合一条直线（或超平面）
- 最小二乘：最小化垂直距离的平方和
- R²=1：完美拟合；R²=0：不优于均值预测
- 残差图：检验模型假设

**AI 中的应用**：
- 基线模型：简单的线性回归基线
- 特征重要性：回归系数的大小和符号
- 时间序列预测：线性趋势 + 季节性
- 因果推断：回归控制混杂变量
- 神经网络：最后的输出层常是线性回归

**关键公式**：
```
线性回归模型：
y = Xw + ε

最小二乘解：
ŵ = (XᵀX)⁻¹Xᵀy

预测：
ŷ = Xŵ

残差：
e = y - ŷ

R² (决定系数)：
R² = 1 - SS_res/SS_tot = 1 - Σ(yᵢ-ŷᵢ)²/Σ(yᵢ-ȳ)²

假设检验：
t = ŵⱼ/SE(ŵⱼ) ~ t_(n-p-1)
```

**思考题**：线性回归的假设不满足时会怎样？如何诊断和修正？

## Day 37

**知识点**：过拟合与欠拟合

**一句话**：过拟合是模型太复杂记住了噪声，欠拟合是模型太简单没学到规律。

**前置知识**：Day 25（期望与方差）、Day 31-36（统计推断基础）
**后续应用**：Day 38（正则化）、Day 39（交叉验证）、Day 59（初始化）
**关联回顾**：Day 10（L1/L2 范数）、Day 20（Adam 优化器）

**核心定义**：
- 过拟合：训练误差低，测试误差高（泛化差）
- 欠拟合：训练误差高，测试误差高（没学好）
- 偏差 - 方差权衡：模型复杂度与泛化能力的平衡
- 期望测试误差 = 偏差² + 方差 + 噪声

**几何直观**：
- 欠拟合：直线拟合曲线，太简单
- 合适：曲线平滑，抓住主要趋势
- 过拟合：曲线穿过每个点，包含噪声
- 甜区：偏差和方差的平衡点

**AI 中的应用**：
- 模型选择：选择合适复杂度的模型
- 正则化：L1/L2/Dropout 防止过拟合
- 早停：验证集误差上升时停止训练
- 数据增强：增加有效数据量
- 集成方法：降低方差，提高泛化

**关键公式**：
```
偏差 - 方差分解：
E[(y - f̂(x))²] = Bias[f̂(x)]² + Var[f̂(x)] + σ²

偏差：Bias[f̂(x)] = E[f̂(x)] - f(x)
方差：Var[f̂(x)] = E[(f̂(x) - E[f̂(x)])²]
噪声：σ² (不可约误差)

学习曲线：
训练误差 vs 训练集大小
验证误差 vs 训练集大小
```

**思考题**：如何判断模型是过拟合还是欠拟合？分别有什么解决方案？

## Day 38

**知识点**：正则化 (L1/L2)

**一句话**：正则化通过惩罚复杂模型来防止过拟合。

**前置知识**：Day 10（范数定义）、Day 37（过拟合）、Day 18（凸优化）
**后续应用**：Day 59（初始化）、Day 60（学习率调度）
**关联回顾**：Day 32（MAP = MLE + 先验 = 正则化）
**重要**：Day 10 已介绍 L1/L2 范数，此处深入讲解正则化原理

**核心定义**：
- L2 正则化 (Ridge)：λ||w||₂²，权重衰减
- L1 正则化 (Lasso)：λ||w||₁，产生稀疏解
- Elastic Net：αL1 + (1-α)L2，两者结合
- 正则化强度λ：控制惩罚力度

**几何直观**：
- L2：圆形约束区域，最优解在边界
- L1：菱形约束区域，最优解在坐标轴（稀疏）
- 正则化路径：λ从大到小，权重从 0 逐渐增大
- 约束视角：带约束的优化问题

**AI 中的应用**：
- 神经网络：权重衰减 (Weight Decay)
- 特征选择：L1 自动选择重要特征
- 逻辑回归：防止过拟合的标准配置
- 多任务学习：共享表示的正则化
- Dropout：隐式的正则化方法

**关键公式**：
```
带正则化的损失函数：
L_reg(w) = L(w) + λR(w)

L2 (Ridge)：
L(w) + λ||w||₂²
解析解：ŵ = (XᵀX + λI)⁻¹Xᵀy

L1 (Lasso)：
L(w) + λ||w||₁
无解析解，用坐标下降或近端梯度

Elastic Net：
L(w) + λ₁||w||₁ + λ₂||w||₂²
```

**思考题**：为什么 L1 正则化产生稀疏解而 L2 不产生？从几何和优化角度解释。

## Day 39

**知识点**：交叉验证

**一句话**：交叉验证用有限数据更可靠地评估模型泛化能力。

**核心定义**：
- 训练集：训练模型
- 验证集：调超参数、模型选择
- 测试集：最终评估（只用一次）
- k 折交叉验证：数据分 k 份，轮流做验证集
- 留一法 (LOOCV)：k=n，每次留一个样本

**几何直观**：
- 单次划分：可能运气好/坏
- 交叉验证：多次平均，减少方差
- k 的选择：k 越大偏差越小，方差越大，计算越贵
- 典型值：k=5 或 k=10

**AI 中的应用**：
- 模型选择：比较不同模型的性能
- 超参数调优：网格搜索 + 交叉验证
- 小数据集：最大化利用有限数据
- 特征选择：评估特征子集的效果
- 嵌套交叉验证：外层评估，内层调参

**关键公式**：
```
k 折交叉验证：
1. 随机分数据为 k 份
2. 对每份 i：
   - 用其他 k-1 份训练
   - 用第 i 份验证
3. 平均 k 次的验证误差

CV 误差估计：
CV = (1/k)Σᵢ₌₁ᵏ L(D_valⁱ, fⁱ)

分层交叉验证：
每份中各类别比例与整体相同
```

**思考题**：为什么测试集只能用一次？多次使用会有什么问题？

## Day 40

**知识点**：Bootstrap 方法

**一句话**：Bootstrap 用重采样估计统计量的分布，无需假设分布形式。

**核心定义**：
- Bootstrap：有放回地从原数据采样
- Bootstrap 样本：与原数据同大小，可能有重复
- Bootstrap 分布：多次 Bootstrap 得到的统计量分布
- 应用：估计标准误、置信区间、偏差

**几何直观**：
- 原数据：一个样本
- Bootstrap：从原数据"模拟"多次抽样
- Bootstrap 分布：近似抽样分布
- 百分位法：用 Bootstrap 分布的分位数做置信区间

**AI 中的应用**：
- 模型不确定性：Bootstrap 集成估计预测方差
- 特征重要性：Bootstrap 评估特征稳定性
- 随机森林：每棵树用 Bootstrap 样本训练
- 置信区间：无需正态假设的置信区间
- 小样本：传统方法不适用时的替代方案

**关键公式**：
```
Bootstrap 步骤：
1. 从原数据有放回采样 n 个样本
2. 计算统计量 T*
3. 重复 B 次 (B=1000 或更多)
4. 用 T*₁,...,T*₈ 的分布近似抽样分布

标准误估计：
SE_boot = √[Σ(T*ᵢ - T̄*)²/(B-1)]

百分位置信区间 (95%)：
[T*(2.5%), T*(97.5%)]
```

**思考题**：Bootstrap 和交叉验证有什么区别？各自适用什么场景？

## 阶段小结

**统计与推断核心思想**：
1. MLE 和 MAP 是参数估计的两种方法
2. 贝叶斯推断提供完整的不确定性量化
3. 假设检验和置信区间是统计推断的工具
4. 回归分析建模变量间关系
5. 过拟合与欠拟合是机器学习的核心挑战
6. 正则化、交叉验证、Bootstrap 是防止过拟合和评估泛化的方法
