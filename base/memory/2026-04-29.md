# 2026-04-29 日志

## 🛠️ 经验记录：Claude Code 插件安装 Git 路径问题

**场景**：Windows + Git Bash + npm 安装 Claude Code

**问题**：安装 Claude Code 插件时报错 `Failed to clone repository: Command 'git' not found`

**根因**：`~/.claude/settings.json` 中的 `env.PATH` 不包含 Git 路径。虽然系统 PATH 正常，但 Claude Code 使用自定义 PATH。

**解决**：编辑 `~/.claude/settings.json`，添加 Git 路径到 `env.PATH`：

```json
{
  "env": {
    "PATH": "/c/Users/<用户名>/AppData/Local/Programs/Git/cmd:/c/Users/<用户名>/AppData/Local/Programs/Git/bin:/mingw64/bin:/usr/bin:/bin:/cmd:$PATH"
  }
}
```

**关键教训**：
1. 问题在 Claude Code 配置，不在系统 PATH
2. 需同时添加 `cmd` 和 `bin` 目录
3. 改完配置必须完全退出 Claude Code 并重启
