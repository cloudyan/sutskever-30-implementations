## Day 11

**知识点**：导数与偏导数

**一句话**：导数度量函数的变化率，偏导数是多变量函数的"单变量导数"。

**核心定义**：
- 导数：f'(x) = lim(h→0) [f(x+h) - f(x)] / h
- 几何意义：函数曲线在某点的切线斜率
- 偏导数：∂f/∂xᵢ，固定其他变量，只对 xᵢ 求导
- 梯度向量：所有一阶偏导数组成的向量

**几何直观**：
- 单变量：导数是切线斜率，正负表示增减方向
- 多变量：固定其他维度，看某个维度方向的斜率
- 偏导数 = 0：该方向是"平坦"的（可能是极值点）
- 二阶导数：导数的导数，度量曲率（凹凸性）

**AI 中的应用**：
- 反向传播：计算损失函数对每个权重的偏导数
- 激活函数求导：ReLU、sigmoid、tanh 的导数
- 学习率：梯度乘以学习率决定更新步长
- 可微编程：整个计算图必须是可微的

**关键公式**：
```
常用导数：
d(xⁿ)/dx = nxⁿ⁻¹
d(eˣ)/dx = eˣ
d(ln x)/dx = 1/x
d(sigmoid(x))/dx = σ(x)(1-σ(x))
d(ReLU(x))/dx = 1 if x>0 else 0

链式法则 (单变量)：dy/dx = dy/du × du/dx
```

**思考题**：为什么 ReLU 比 sigmoid 更适合深度网络？从导数角度分析。

## Day 12

**知识点**：梯度

**一句话**：梯度指向函数增长最快的方向，是优化的指南针。

**核心定义**：
- 梯度：∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]ᵀ
- 梯度方向：函数值增长最快的方向
- 负梯度方向：函数值下降最快的方向
- 梯度大小：||∇f||，变化的剧烈程度

**几何直观**：
- 想象一座山：梯度指向最陡的上坡方向
- 等高线：梯度垂直于等高线
- 梯度为零：山顶、山谷或鞍点（临界点）
- 梯度下降：沿着负梯度方向一步步下山

**AI 中的应用**：
- 梯度下降：w = w - η∇L(w)，最小化损失函数
- 反向传播：高效计算神经网络梯度的算法
- 梯度裁剪：防止梯度爆炸，||g|| > threshold 时缩放
- 梯度消失：深层网络梯度趋近于 0，无法学习

**关键公式**：
```
梯度定义：∇f(x) = [∂f/∂x₁, ..., ∂f/∂xₙ]ᵀ

方向导数：Dᵥf = ∇f · v (v 是单位向量)
最大方向导数：max(Dᵥf) = ||∇f||，当 v = ∇f/||∇f||

梯度下降：wₜ₊₁ = wₜ - η∇L(wₜ)
```

**思考题**：为什么梯度方向是函数增长最快的方向？用方向导数证明。

## Day 13

**知识点**：链式法则

**一句话**：链式法则是反向传播的核心，让深层网络的梯度计算成为可能。

**核心定义**：
- 链式法则：复合函数的导数 = 各层导数的乘积
- 单变量：dy/dx = dy/du × du/dx
- 多变量：∂y/∂x = Σ(∂y/∂uᵢ × ∂uᵢ/∂x)
- 计算图：将复合函数分解为基本操作的图结构

**几何直观**：
- 复合函数 = 多层变换的叠加
- 链式法则 = 每层变化率的连乘
- 深层网络：梯度需要从输出层一路乘回输入层
- 梯度消失/爆炸：连乘导致梯度指数级变化

**AI 中的应用**：
- 反向传播算法：从输出层向输入层逐层计算梯度
- 自动微分：框架 (PyTorch/TensorFlow) 自动应用链式法则
- 计算图优化：合并操作，减少重复计算
- 自定义层：需要手动实现前向和反向传播

**关键公式**：
```
向量链式法则：
z = g(y), y = f(x)
∂z/∂x = (∂z/∂y) × (∂y/∂x)  (雅可比矩阵乘法)

神经网络反向传播：
δᴸ = ∂L/∂aᴸ (输出层误差)
δˡ = (Wˡ⁺¹)ᵀδˡ⁺¹ ⊙ σ'(zˡ) (误差反向传播)
∂L/∂Wˡ = δˡ(aˡ⁻¹)ᵀ (权重梯度)
```

**思考题**：为什么梯度消失会导致深层网络难以训练？有哪些解决方案？

## Day 14

**知识点**：泰勒展开

**一句话**：用多项式逼近复杂函数，是优化算法的理论基础。

**核心定义**：
- 泰勒展开：f(x) = Σ(f⁽ⁿ⁾(a)/n!)(x-a)ⁿ
- 一阶近似：f(x) ≈ f(a) + f'(a)(x-a)（线性近似）
- 二阶近似：f(x) ≈ f(a) + f'(a)(x-a) + (1/2)f''(a)(x-a)²
- 多变量：f(x) ≈ f(a) + ∇f(a)ᵀ(x-a) + (1/2)(x-a)ᵀH(x-a)

**几何直观**：
- 一阶：用切线近似曲线（局部线性）
- 二阶：用抛物线近似曲线（考虑曲率）
- 阶数越高：近似越精确，但计算越复杂
- 收敛半径：展开点附近才有效

**AI 中的应用**：
- 梯度下降：基于一阶泰勒展开
- 牛顿法：基于二阶泰勒展开
- 损失函数分析：理解优化 landscape
- 梯度裁剪理论：一阶近似的误差界

**关键公式**：
```
一阶泰勒展开：
f(x) ≈ f(a) + ∇f(a)ᵀ(x-a)

二阶泰勒展开：
f(x) ≈ f(a) + ∇f(a)ᵀ(x-a) + (1/2)(x-a)ᵀH(a)(x-a)

Hessian 矩阵：Hᵢⱼ = ∂²f/∂xᵢ∂xⱼ
```

**思考题**：为什么一阶方法 (SGD) 比二阶方法 (牛顿法) 在深度学习中更常用？

## Day 15

**知识点**：梯度下降法

**一句话**：最基础的优化算法，沿着负梯度方向迭代更新参数。

**核心定义**：
- 梯度下降：wₜ₊₁ = wₜ - η∇L(wₜ)
- 学习率 η：步长大小，太大发散，太小收敛慢
- 批量梯度下降 (BGD)：每次用全部数据计算梯度
- 随机梯度下降 (SGD)：每次用一个样本
- 小批量梯度下降 (Mini-batch)：折中方案

**几何直观**：
- 想象在山谷中蒙眼下山
- 用脚探出最陡方向（梯度）
- 迈一步（学习率），再探方向
- 最终到达山谷底部（局部最优）

**AI 中的应用**：
- 神经网络训练：标准配置是 Mini-batch SGD
- 学习率调度：训练过程中动态调整 η
- 初始化：影响收敛速度和最终结果
- 收敛判断：梯度接近 0 或损失不再下降

**关键公式**：
```
批量梯度下降：wₜ₊₁ = wₜ - η∇L(wₜ)
随机梯度下降：wₜ₊₁ = wₜ - η∇L(wₜ; x⁽ⁱ⁾, y⁽ⁱ⁾)
小批量：wₜ₊₁ = wₜ - η∇L(wₜ; Bₜ) (Bₜ 是 batch)

收敛条件：||∇L(w)|| < ε 或 |Lₜ₊₁ - Lₜ| < ε
```

**思考题**：为什么 Mini-batch SGD 比纯 SGD 或 BGD 更常用？

## Day 16

**知识点**：牛顿法与拟牛顿法

**一句话**：利用二阶导数信息，收敛更快但计算成本更高。

**核心定义**：
- 牛顿法：wₜ₊₁ = wₜ - H⁻¹∇L(wₜ)
- Hessian 矩阵 H：二阶偏导数矩阵，Hᵢⱼ = ∂²L/∂wᵢ∂wⱼ
- 拟牛顿法：用近似矩阵 B ≈ H⁻¹，避免直接求逆
- BFGS：最著名的拟牛顿法算法

**几何直观**：
- 梯度下降：只考虑斜率，可能走弯路
- 牛顿法：考虑曲率，直接指向极值点
- 二次函数：牛顿法一步到达最优点
- 非二次函数：迭代收敛，速度比梯度下降快

**AI 中的应用**：
- 逻辑回归：常用牛顿法或拟牛顿法 (L-BFGS)
- 二阶优化：Hessian-free 优化方法
- K-FAC：用 Kronecker 因子近似 Hessian
- 深度学习：二阶方法计算成本太高，较少使用

**关键公式**：
```
牛顿法更新：
wₜ₊₁ = wₜ - H⁻¹∇L(wₜ)

一维牛顿法求根：
xₜ₊₁ = xₜ - f(xₜ)/f'(xₜ)

拟牛顿法 (BFGS)：
wₜ₊₁ = wₜ - Bₜ∇L(wₜ)
Bₜ₊₁ 用 BFGS 公式更新
```

**思考题**：为什么深度学习中很少用牛顿法？计算复杂度是多少？

## Day 17

**知识点**：拉格朗日乘数法

**一句话**：解决带约束优化问题的强大工具。

**核心定义**：
- 约束优化：min f(x) s.t. g(x) = 0
- 拉格朗日函数：L(x,λ) = f(x) + λg(x)
- KKT 条件：最优解满足的必要条件
- 对偶问题：将约束优化转化为无约束优化

**几何直观**：
- 目标函数等高线与约束曲线相切时最优
- 切点处梯度平行：∇f = λ∇g
- 拉格朗日乘子 λ：约束的"影子价格"
- 不等式约束：g(x) ≤ 0，λ ≥ 0

**AI 中的应用**：
- SVM：最大化间隔的约束优化问题
- 带约束的回归：系数和为 1 等约束
- GAN：对抗训练的博弈均衡
- 强化学习：带约束的策略优化

**关键公式**：
```
等式约束：
L(x, λ) = f(x) + λg(x)
∇ₓL = 0, ∇λL = 0

不等式约束 (KKT 条件)：
L(x, λ) = f(x) + λg(x), λ ≥ 0
原始可行：g(x) ≤ 0
对偶可行：λ ≥ 0
互补松弛：λg(x) = 0
梯度为零：∇ₓL = 0
```

**思考题**：SVM 的对偶问题是什么？为什么用对偶问题求解？

## Day 18

**知识点**：凸优化基础

**一句话**：凸函数的局部最优就是全局最优，是优化的"理想情况"。

**核心定义**：
- 凸集：集合中任意两点的连线仍在集合内
- 凸函数：f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)
- 凸优化：min f(x) s.t. x ∈ C，f 凸，C 凸集
- 局部最优 = 全局最优（凸优化的核心性质）

**几何直观**：
- 凸函数：碗状，只有一个谷底
- 非凸函数：可能有多个局部极小值
- 凸集：没有"凹陷"的集合
- 凸函数 + 凸约束：优化问题容易求解

**AI 中的应用**：
- 逻辑回归：损失函数是凸的，保证全局最优
- 线性回归：MSE 是凸函数
- SVM：凸优化问题，有唯一解
- 深度学习：损失函数非凸，但局部最优也够用

**关键公式**：
```
凸函数判定：
一阶条件：f(y) ≥ f(x) + ∇f(x)ᵀ(y-x)
二阶条件：∇²f(x) ⪰ 0 (Hessian 半正定)

常见凸函数：
• 线性函数：ax + b
• 指数函数：eˣ
• 负对数：-log(x)
• 范数：||x||ₚ (p ≥ 1)
• 最大值函数：max(x₁, ..., xₙ)
```

**思考题**：为什么神经网络的损失函数是非凸的？这会导致什么问题？

## Day 19

**知识点**：SGD 与动量

**一句话**：动量法累积历史梯度，加速收敛并减少震荡。

**核心定义**：
- SGD：每次随机选一个样本计算梯度
- Mini-batch SGD：每次选一小批样本
- 动量法：vₜ = γvₜ₋₁ + η∇L(wₜ)，wₜ₊₁ = wₜ - vₜ
- 动量系数 γ：通常取 0.9 或 0.99

**几何直观**：
- SGD：下山时随机探索，路径曲折
- 动量：像球从山上滚下，有惯性
- 累积同方向梯度：加速收敛
- 抵消反方向梯度：减少震荡

**AI 中的应用**：
- SGD + 动量：经典配置，很多场景仍是最优选择
- 学习率 + 动量：需要调优的两个关键超参
- Nesterov 动量：提前看一步，更准确的校正
- 批归一化：与动量配合，加速训练

**关键公式**：
```
动量法：
vₜ = γvₜ₋₁ + η∇L(wₜ)
wₜ₊₁ = wₜ - vₜ

Nesterov 动量：
vₜ = γvₜ₋₁ + η∇L(wₜ - γvₜ₋₁)
wₜ₊₁ = wₜ - vₜ

SGD 收敛率：O(1/√T) (T 是迭代次数)
```

**思考题**：动量为什么能加速收敛？从指数加权平均的角度解释。

## Day 20

**知识点**：Adam 优化器

**一句话**：自适应学习率 + 动量，深度学习的默认优化器。

**核心定义**：
- Adam：Adaptive Moment Estimation
- 一阶矩估计：mₜ = β₁mₜ₋₁ + (1-β₁)∇L(wₜ)（动量）
- 二阶矩估计：vₜ = β₂vₜ₋₁ + (1-β₂)(∇L(wₜ))²（自适应学习率）
- 偏差校正：m̂ₜ = mₜ/(1-β₁ᵗ)，v̂ₜ = vₜ/(1-β₂ᵗ)

**几何直观**：
- 动量项：累积历史梯度方向
- 自适应项：梯度大的维度学习率小，梯度小的维度学习率大
- 稀疏梯度：Adam 能更快学习
- 鞍点问题：自适应学习率帮助逃离鞍点

**AI 中的应用**：
- 默认配置：β₁=0.9, β₂=0.999, ε=1e-8
- 适用场景：大多数深度学习任务
- 变体：AdamW（解耦权重衰减）、RAdam（整流器）
- 不适用：某些场景 SGD+ 动量泛化更好

**关键公式**：
```
Adam 更新规则：
mₜ = β₁mₜ₋₁ + (1-β₁)gₜ
vₜ = β₂vₜ₋₁ + (1-β₂)gₜ²
m̂ₜ = mₜ/(1-β₁ᵗ)
v̂ₜ = vₜ/(1-β₂ᵗ)
wₜ₊₁ = wₜ - η·m̂ₜ/(√v̂ₜ + ε)

AdamW (解耦权重衰减)：
wₜ₊₁ = wₜ - η·(m̂ₜ/(√v̂ₜ + ε) + λwₜ)
```

**思考题**：Adam 和 SGD 各有什么优缺点？什么时候选择哪个？

## 阶段小结

**微积分与优化核心思想**：
1. 导数度量变化率，梯度指向最陡方向
2. 链式法则让深层网络的反向传播成为可能
3. 泰勒展开是优化算法的理论基础
4. 梯度下降是最基础的优化方法
5. 动量加速收敛，Adam 自适应学习率
6. 凸优化有理论保证，但深度学习是非凸的
