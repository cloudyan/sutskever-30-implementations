## 💡 关键洞察

### 1. 线性代数是 AI 的"数据语言"

```
单词 → 词向量
图片 → 像素向量 → 特征向量
用户 → 嵌入向量
图 → 邻接矩阵
```

**没有线性代数，就没有深度学习**。

---

### 2. 矩阵乘法是核心操作

神经网络的前向传播：
```
输出 = 激活函数 (输入 @ 权重 + 偏置)
```

注意力机制：
```
Attention = softmax(QKᵀ/√d) @ V
```

全是矩阵乘法！

---

### 3. 特征值和 SVD 揭示数据结构

- 特征值大 → 该方向重要
- 奇异值大 → 该成分能量高
- 丢弃小的特征值/奇异值 → 降维、压缩、去噪

---

### 4. PCA 是无监督学习的基石

- 降维可视化
- 特征提取
- 数据去相关
- 推荐系统（矩阵分解）

```
a = [1, 2, 3]
b = [4, 5, 6]

计算：
1. a + b = ?
2. a · b = ?
3. ||a||₂ = ?
4. cos(a, b) = ?
```

<details>
<summary>点击查看答案</summary>

```
1. a + b = [5, 7, 9]
2. a · b = 1×4 + 2×5 + 3×6 = 32
3. ||a||₂ = √(1+4+9) = √14 ≈ 3.74
4. cos(a,b) = 32 / (√14 × √77) ≈ 0.975
```

### 测试题 2：矩阵乘法

```
A = | 1  2 |    B = | 5  6 |
    | 3  4 |        | 7  8 |

计算 A × B 和 B × A，验证是否相等
```

<details>
<summary>点击查看答案</summary>

```
A×B = | 19  22 |    B×A = | 23  34 |
      | 43  50 |          | 31  46 |

A×B ≠ B×A，矩阵乘法不可交换 ✓
```
</details>

---

### 测试题 3：行列式与可逆性

```
判断以下矩阵是否可逆：
A = | 1  2 |    B = | 1  2 |
    | 3  4 |        | 2  4 |
```

<details>
<summary>点击查看答案</summary>

```
det(A) = 1×4 - 2×3 = -2 ≠ 0 → 可逆 ✓
det(B) = 1×4 - 2×2 = 0 → 不可逆 ✓
```
</details>

## 🎓 实战项目

### 项目：用 PCA 分析 Iris 数据集

```python
from sklearn.datasets import load_iris
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# 加载数据
iris = load_iris()
X = iris.data
y = iris.target

# PCA 降维到 2D
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)

# 可视化
plt.figure(figsize=(8, 6))
for class_idx in range(3):
    plt.scatter(X_pca[y == class_idx, 0], 
                X_pca[y == class_idx, 1],
                label=iris.target_names[class_idx])

plt.xlabel(f'PC1 ({pca.explained_variance_ratio_[0]:.2%})')
plt.ylabel(f'PC2 ({pca.explained_variance_ratio_[1]:.2%})')
plt.legend()
plt.title('Iris 数据集 PCA 可视化')
plt.show()
```
