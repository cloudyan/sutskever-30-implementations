## 💡 核心洞察

**1. 微积分是 AI 的"学习引擎"**
```
损失函数 L(θ) → 求梯度 ∇L(θ) → 更新参数 θ = θ - α∇L(θ)
```
没有微积分，就没有梯度下降；没有梯度下降，就没有深度学习。

**2. 链式法则是反向传播的核心**
神经网络反向传播：`∂L/∂w = ∂L/∂y · ∂y/∂z · ∂z/∂w`
每一层只是链式法则的一环！

**3. 优化算法的演进**
GD → SGD → Momentum → Adam
从稳定到快速，从手动调参到自适应。
