# 007 | 主成分分析 (PCA)：高维数据的可视化

> 🎯 **一句话核心**：PCA 找到数据变化最大的方向，将高维数据投影到低维空间，同时保留最多的信息——是数据降维和可视化的核心工具。

---

## 🤔 从一个问题开始

### 问题：如何在 2D 纸上画 100 维的数据？

你有一个数据集：
- 1000 个样本
- 每个样本有 100 个特征

**问题**：如何可视化这些数据？如何理解数据的结构？

**答案**：用 PCA 找到最重要的 2 个方向，投影到 2D 平面！

---

### 直观理解 PCA

想象一群人在房间里站立（3D 空间）：

```
从某个角度看，人群" spread out"最开
从另一个角度看，人群挤在一起
```

PCA 就是找到那个"spread out"最开的角度！

---

### PCA 的核心思想

**目标**：找到一个新坐标系，使得：
1. 第一坐标轴（第一主成分）：数据投影后的方差最大
2. 第二坐标轴（第二主成分）：与第一轴正交，方差次大
3. 以此类推...

**关键**：方差大 = 信息多

---

## 📖 核心概念详解

### 1. 方差与信息

**直觉**：如果一个方向上方差为 0，说明所有点在这个方向上都一样——这个方向没有信息！

```
方差大 → 点分布广 → 区分度大 → 信息多
方差小 → 点挤在一起 → 区分度小 → 信息少
```

---

### 2. PCA 的数学推导

**问题**：找到单位向量 u，使得数据投影到 u 上的方差最大。

数据矩阵 X（n 个样本，p 个特征），已中心化。

投影：z = Xu

方差：Var(z) = (1/n) × zᵀz = (1/n) × uᵀXᵀXu

**最大化**：uᵀ(XᵀX)u，约束 uᵀu = 1

**解**：用拉格朗日乘数法，得到：

```
(XᵀX)u = λu

这正是特征方程！
```

**结论**：
- 最优投影方向 = 协方差矩阵的特征向量
- 投影后的方差 = 对应的特征值

---

### 3. PCA 算法步骤

```
输入：数据矩阵 X (n×p)
输出：降维后的数据 Z (n×k)

步骤：
1. 中心化：X = X - mean(X)
2. 计算协方差矩阵：Σ = (1/(n-1)) × XᵀX
3. 特征分解：Σ = VDVᵀ
4. 选择前 k 个特征向量：V_k = V[:, :k]
5. 投影：Z = X × V_k
```

---

### 4. 选择主成分个数 k

**方法 1：累积方差解释率**

```
选择最小的 k，使得：
(λ₁ + λ₂ + ... + λₖ) / (λ₁ + λ₂ + ... + λₚ) ≥ 阈值（如 95%）
```

**方法 2：碎石图（Scree Plot）**

画特征值曲线，找"肘部"拐点。

**方法 3：固定 k**

根据可视化需求：k=2 或 k=3。

---

### 5. PCA 的性质

| 性质 | 说明 |
|------|------|
| 正交性 | 主成分之间互相正交（无关） |
| 最大方差 | 第一主成分方差最大 |
| 最优重构 | PCA 是最优的线性降维（最小重构误差） |
| 去相关 | 降维后的数据各维度不相关 |

## 💻 代码实现

```python
import numpy as np
import matplotlib.pyplot as plt

# ==================== 从零实现 PCA ====================

print("="*50)
print("从零实现 PCA")
print("="*50)

def pca_from_scratch(X, k):
    """
    从零实现 PCA
    
    X: 数据矩阵 (n×p)，每行一个样本
    k: 降维后的维度
    返回：降维后的数据 Z (n×k)，主成分 V_k (p×k)，解释方差比
    """
    n, p = X.shape
    
    # 步骤 1: 中心化
    X_mean = X.mean(axis=0)
    X_centered = X - X_mean
    
    # 步骤 2: 协方差矩阵
    cov_matrix = np.cov(X_centered, rowvar=False)
    
    # 步骤 3: 特征分解
    eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)
    
    # 按特征值从大到小排序
    idx = np.argsort(eigenvalues)[::-1]
    eigenvalues = eigenvalues[idx]
    eigenvectors = eigenvectors[:, idx]
    
    # 步骤 4: 选择前 k 个特征向量
    V_k = eigenvectors[:, :k]
    
    # 步骤 5: 投影
    Z = X_centered @ V_k
    
    # 计算解释方差比
    explained_variance_ratio = eigenvalues / eigenvalues.sum()
    cumulative_variance_ratio = np.cumsum(explained_variance_ratio)
    
    return Z, V_k, explained_variance_ratio, cumulative_variance_ratio

# 生成测试数据
np.random.seed(42)
n = 100
# 生成有相关性的 3D 数据
X = np.random.multivariate_normal(
    mean=[0, 0, 0],
    cov=[[3, 2, 1],
         [2, 3, 1],
         [1, 1, 1]],
    size=n
)

print(f"\n原始数据形状：{X.shape}")

# 用我们的 PCA 降维到 2D
Z, V_k, exp_var, cum_var = pca_from_scratch(X, k=2)

print(f"\n降维后数据形状：{Z.shape}")
print(f"\n主成分（每列一个）：\n{V_k}")
print(f"\n解释方差比：{exp_var}")
print(f"累积解释方差比：{cum_var}")
print(f"\n前 2 个主成分解释了 {cum_var[1]*100:.2f}% 的方差")

# ==================== 用 sklearn 验证 ====================

print("\n" + "="*50)
print("用 sklearn 验证")
print("="*50)

from sklearn.decomposition import PCA

pca = PCA(n_components=2)
Z_sklearn = pca.fit_transform(X)

print(f"\n sklearn 降维后形状：{Z_sklearn.shape}")
print(f"\n sklearn 解释方差比：{pca.explained_variance_ratio_}")
print(f"\n sklearn 累积解释方差：{np.cumsum(pca.explained_variance_ratio_)}")

# 比较结果（可能符号相反，但方向一致）
print(f"\n结果一致：{np.allclose(np.abs(Z), np.abs(Z_sklearn), atol=1e-10)}")

# ==================== 可视化 PCA ====================

print("\n" + "="*50)
print("可视化：原始数据 vs PCA 降维")
print("="*50)

fig = plt.figure(figsize=(12, 5))

# 3D 原始数据
ax1 = fig.add_subplot(121, projection='3d')
ax1.scatter(X[:, 0], X[:, 1], X[:, 2], alpha=0.6)
ax1.set_xlabel('X1')
ax1.set_ylabel('X2')
ax1.set_zlabel('X3')
ax1.set_title('原始 3D 数据')

# 2D PCA 结果
ax2 = fig.add_subplot(122)
ax2.scatter(Z[:, 0], Z[:, 1], alpha=0.6)
ax2.set_xlabel(f'PC1 ({exp_var[0]*100:.1f}%)')
ax2.set_ylabel(f'PC2 ({exp_var[1]*100:.1f}%)')
ax2.set_title(f'PCA 降维到 2D\n累积解释方差：{cum_var[1]*100:.1f}%')
ax2.axhline(0, color='gray', linewidth=0.5)
ax2.axvline(0, color='gray', linewidth=0.5)

plt.tight_layout()
plt.savefig('/Users/cloudyan/.openclaw/workspace/memory/ai-math-tutorial/images/007-pca-visualization.png', dpi=150)
print("\nPCA 可视化图已保存：images/007-pca-visualization.png")

# ==================== 选择主成分个数 ====================

print("\n" + "="*50)
print("选择主成分个数：累积解释方差")
print("="*50)

# 生成高维数据
np.random.seed(42)
X_highdim = np.random.rand(100, 20)
# 添加低秩结构
X_highdim = X_highdim @ np.random.rand(20, 20)

# 完整 PCA
pca_full = PCA()
pca_full.fit(X_highdim)

exp_var = pca_full.explained_variance_ratio_
cum_var = np.cumsum(exp_var)

print(f"\n特征值数量：{len(exp_var)}")
print(f"\n前 5 个解释方差比：{exp_var[:5]}")
print(f"\n累积解释方差：")

for k in [1, 3, 5, 10, 15, 20]:
    print(f"  k={k}: {cum_var[k-1]*100:.2f}%")

# 找 95% 方差需要的 k
k_95 = np.argmax(cum_var >= 0.95) + 1
print(f"\n保留 95% 方差需要的主成分数：{k_95}")

# 绘制碎石图
plt.figure(figsize=(10, 4))

plt.subplot(1, 2, 1)
plt.plot(exp_var, 'o-')
plt.xlabel('主成分')
plt.ylabel('解释方差比')
plt.title('碎石图（Scree Plot）')
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.plot(cum_var, 'o-')
plt.axhline(0.95, color='r', linestyle='--', label='95% 阈值')
plt.xlabel('主成分')
plt.ylabel('累积解释方差')
plt.title('累积解释方差')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.savefig('/Users/cloudyan/.openclaw/workspace/memory/ai-math-tutorial/images/007-scree-plot.png', dpi=150)
print("\n碎石图已保存：images/007-scree-plot.png")

# ==================== PCA 重构误差 ====================

print("\n" + "="*50)
print("PCA 重构误差：降维 vs 信息损失")
print("="*50)

def pca_reconstruct(Z, V_k, X_mean):
    """从降维数据重构原始数据"""
    return Z @ V_k.T + X_mean

# 测试不同 k 的重构误差
for k in [1, 5, 10, 15]:
    Z_k, V_k, _, _ = pca_from_scratch(X_highdim, k)
    X_reconstructed = pca_reconstruct(Z_k, V_k, X_highdim.mean(axis=0))
    
    mse = np.mean((X_highdim - X_reconstructed) ** 2)
    
    print(f"\nk={k}:")
    print(f"  解释方差：{cum_var[k-1]*100:.2f}%")
    print(f"  重构 MSE: {mse:.4f}")

# ==================== 应用：人脸识别 ====================

print("\n" + "="*50)
print("应用示例：人脸识别（Eigenfaces）")
print("="*50)

from sklearn.datasets import fetch_olivetti_faces

# 加载人脸数据集
faces = fetch_olivetti_faces(shuffle=True, random_state=42)
X_faces = faces.data  # 400 张脸，每张 64×64 = 4096 维
y_faces = faces.target

print(f"\n人脸数据形状：{X_faces.shape}")
print(f"（400 个样本，每个 4096 维）")

# PCA 降维
pca_faces = PCA(n_components=50)
Z_faces = pca_faces.fit_transform(X_faces)

print(f"\n降维后形状：{Z_faces.shape}")
print(f"解释方差：{pca_faces.explained_variance_ratio_.sum()*100:.2f}%")

# 可视化特征脸
fig, axes = plt.subplots(2, 5, figsize=(10, 5))

for i, ax in enumerate(axes.flat):
    if i < len(pca_faces.components_):
        ax.imshow(pca_faces.components_[i].reshape(64, 64), cmap='gray')
        ax.set_title(f'PC{i+1}: {pca_faces.explained_variance_ratio_[i]*100:.1f}%')
    ax.axis('off')

plt.tight_layout()
plt.savefig('/Users/cloudyan/.openclaw/workspace/memory/ai-math-tutorial/images/007-eigenfaces.png', dpi=150)
print("\n特征脸图已保存：images/007-eigenfaces.png")

# 重构人脸
X_faces_reconstructed = pca_faces.inverse_transform(Z_faces)

fig, axes = plt.subplots(2, 5, figsize=(12, 3))

for i in range(5):
    # 原始
    axes[0, i].imshow(X_faces[i].reshape(64, 64), cmap='gray')
    axes[0, i].set_title(f'原始')
    axes[0, i].axis('off')
    
    # 重构
    axes[1, i].imshow(X_faces_reconstructed[i].reshape(64, 64), cmap='gray')
    axes[1, i].set_title(f'重构 (50 PC)')
    axes[1, i].axis('off')

plt.tight_layout()
plt.savefig('/Users/cloudyan/.openclaw/workspace/memory/ai-math-tutorial/images/007-face-reconstruction.png', dpi=150)
print("人脸重构图已保存：images/007-face-reconstruction.png")

## 🔗 与 AI 的联系

### 1. 数据可视化

PCA 是高维数据可视化的标准工具：
- 2D/3D 散点图
- 聚类分析前的探索

---

### 2. 特征降维

在训练 ML 模型前用 PCA 降维：
- 减少计算量
- 避免过拟合
- 去除噪声

---

### 3. 特征脸（Eigenfaces）

人脸识别的经典方法：
- 每张脸 = 特征脸的线性组合
- 用少量系数表示人脸

---

### 4. 去噪

PCA 可以去除噪声：
- 噪声通常在小特征值方向
- 丢弃小特征值对应的成分

---

### 5. 白化（Whitening）

PCA + 标准化 = 白化，使特征不相关且方差为 1。

---

## 🧠 常见误区

### ❌ 误区 1：PCA 适用于任何数据

**纠正**：PCA 假设：
- 线性关系
- 方差大 = 信息多
- 主成分正交

非线性数据用 t-SNE、UMAP 更好。

---

### ❌ 误区 2：PCA 前不需要标准化

**纠正**：如果特征量纲不同，**必须先标准化**！

否则大方差的特征会主导结果。

---

### ❌ 误区 3：主成分有明确含义

**纠正**：主成分是原始特征的线性组合，通常没有直观解释。

def pca_with_scaling(X, k):
    from sklearn.preprocessing import StandardScaler
    
    # 标准化
    scaler = StandardScaler()
    X_scaled = scaler.fit_transform(X)
    
    # PCA
    Z, V_k, exp_var, cum_var = pca_from_scratch(X_scaled, k)
    
    return Z, V_k, exp_var, cum_var, scaler
```
