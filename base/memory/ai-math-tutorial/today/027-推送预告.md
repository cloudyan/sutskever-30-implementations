### **027 协方差与相关性：两个变量如何"一起变化"**

---

### 🎯 核心内容摘要

**协方差（Covariance）** —— 衡量两个变量的"协同变化"
- 定义：Cov(X,Y) = E[(X - E[X])(Y - E[Y])]
- 直观理解：同向变化为正，反向变化为负
- 局限：数值大小依赖变量的单位

**相关系数（Correlation Coefficient）** —— 标准化的协方差
- 公式：ρ(X,Y) = Cov(X,Y) / (σₓ × σᵧ)
- 范围：-1 ≤ ρ ≤ 1
- 解读：
  - ρ = 1：完全正相关
  - ρ = 0：无线性相关
  - ρ = -1：完全负相关

**关键性质**：
- 独立性 ⇒ 不相关（反之不成立！）
- 相关性只度量线性关系
- 非线性关系可能相关系数为 0

**AI 中的应用**：
- 特征选择（剔除高度相关的特征）
- PCA 降维（基于协方差矩阵）
- 注意力机制（query-key 相关性）
- 多任务学习（任务间相关性建模）
