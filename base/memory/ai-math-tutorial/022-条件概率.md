## 1. 从一个问题开始

**问题**：掷一枚公平的骰子，已知结果是偶数，点数是 2 的概率是多少？

**直觉思考**：
- 原本 P(点数为 2) = 1/6
- 但已知是偶数，样本空间缩小为 {2, 4, 6}
- 所以在缩小的样本空间中，P(点数为 2 | 偶数) = 1/3

**这就是条件概率的核心思想：已知信息改变了样本空间！**

---

## 2. 条件概率的定义

### 2.1 直观理解

> **条件概率**：在事件 B 已经发生的条件下，事件 A 发生的概率，记作 P(A|B)。

**关键点**：
- B 的发生提供了**新信息**
- 这个信息**缩小了样本空间**
- 我们在缩小的样本空间中重新计算 A 的概率

### 2.2 数学定义

> **定义**：如果 P(B) > 0，则：
> 
> $$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

**推导**：
- 原本样本空间是 Ω，概率测度是 P
- 已知 B 发生后，新的样本空间是 B
- 需要重新归一化：P(·|B) 必须满足 P(B|B) = 1
- 所以 P(A|B) = P(A∩B) / P(B)

**等价形式**（乘法公式）：
$$P(A \cap B) = P(B) \times P(A|B)$$

## 3. 经典例子

### 3.1 掷骰子

**问题**：掷一枚公平骰子，已知点数是偶数，求点数是 2 的概率。

**解**：
- A = "点数为 2" = {2}
- B = "点数为偶数" = {2, 4, 6}
- A ∩ B = {2}
- P(B) = 3/6 = 1/2
- P(A ∩ B) = 1/6
- P(A|B) = (1/6) / (1/2) = **1/3** ✅

---

### 3.2 抽牌问题

**问题**：从 52 张扑克牌中随机抽一张，已知抽到的是人头牌（J/Q/K），求抽到 K 的概率。

**解**：
- A = "抽到 K" = 4 张 K
- B = "抽到人头牌" = 12 张（J/Q/K 各 4 张）
- A ∩ B = "抽到 K" = 4 张
- P(B) = 12/52 = 3/13
- P(A ∩ B) = 4/52 = 1/13
- P(A|B) = (1/13) / (3/13) = **1/3**

**直观理解**：在 12 张人头牌中，K 占 4 张，所以是 4/12 = 1/3 ✅

---

### 3.3 两个孩子问题 🧠

**问题**：已知某人有两个孩子，其中至少一个是女孩，另一个也是女孩的概率是多少？

**直觉**：50%？❌

**正确答案**：**1/3**

**解**：
- 样本空间 Ω = {(男，男), (男，女), (女，男), (女，女)}，每种等可能
- A = "两个都是女孩" = {(女，女)}
- B = "至少一个是女孩" = {(男，女), (女，男), (女，女)}
- A ∩ B = {(女，女)}
- P(B) = 3/4
- P(A ∩ B) = 1/4
- P(A|B) = (1/4) / (3/4) = **1/3**

**为什么直觉错了？**

人们常常错误地认为：
- "一个是女孩" → "另一个是男孩或女孩，各 50%"

但实际上，"至少一个是女孩"排除了 (男，男)，剩下三种情况中只有一种是两个女孩。

**变体**：如果已知"第一个孩子是女孩"，则：
- B' = {(女，男), (女，女)}
- P(A|B') = 1/2

**关键**：信息的精确表述很重要！

## 4. 乘法公式

从条件概率的定义可以直接得到：

> **乘法公式**：P(A ∩ B) = P(B) × P(A|B) = P(A) × P(B|A)

**推广到多个事件**：

$$P(A_1 \cap A_2 \cap ... \cap A_n) = P(A_1) \times P(A_2|A_1) \times P(A_3|A_1 \cap A_2) \times ... \times P(A_n|A_1 \cap ... \cap A_{n-1})$$

**例子**：从 52 张牌中不放回地抽 3 张，都是 A 的概率？

- P(第 1 张是 A) = 4/52
- P(第 2 张是 A | 第 1 张是 A) = 3/51
- P(第 3 张是 A | 前 2 张是 A) = 2/50
- P(3 张都是 A) = (4/52) × (3/51) × (2/50) = **1/5525**

## 5. 全概率公式

### 5.1 划分（Partition）

**定义**：如果 B₁, B₂, ..., Bₙ 满足：
1. 互斥：Bᵢ ∩ Bⱼ = ∅ (i ≠ j)
2. 完备：B₁ ∪ B₂ ∪ ... ∪ Bₙ = Ω
3. 每个 P(Bᵢ) > 0

则称 {B₁, B₂, ..., Bₙ} 是样本空间的一个**划分**。

### 5.2 全概率公式

> **定理**：如果 {B₁, B₂, ..., Bₙ} 是 Ω 的一个划分，则对任意事件 A：
> 
> $$P(A) = \sum_{i=1}^{n} P(B_i) \times P(A|B_i)$$

**直观理解**：
- A 可以分解为：A = (A∩B₁) ∪ (A∩B₂) ∪ ... ∪ (A∩Bₙ)
- 这些部分互斥，所以 P(A) = Σ P(A∩Bᵢ)
- 用乘法公式：P(A∩Bᵢ) = P(Bᵢ) × P(A|Bᵢ)

---

### 5.3 应用例子

**问题**：某工厂有三条生产线，产量占比分别为 30%、40%、30%。次品率分别为 2%、3%、4%。随机抽取一件产品，是次品的概率是多少？

**解**：
- B₁, B₂, B₃ = "产品来自第 1/2/3 条生产线"
- A = "产品是次品"
- P(B₁) = 0.3, P(B₂) = 0.4, P(B₃) = 0.3
- P(A|B₁) = 0.02, P(A|B₂) = 0.03, P(A|B₃) = 0.04

由全概率公式：
$$P(A) = 0.3 \times 0.02 + 0.4 \times 0.03 + 0.3 \times 0.04 = 0.006 + 0.012 + 0.012 = 0.03$$

**答案**：3% 的产品是次品

## 6. 独立性再探

### 6.1 数学定义

**定义**：事件 A 和 B 独立 ⟺ P(A|B) = P(A) ⟺ P(A ∩ B) = P(A) × P(B)

**直观**：B 的发生不提供关于 A 的任何信息。

### 6.2 条件独立

**定义**：在给定 C 的条件下，A 和 B 条件独立：
$$P(A \cap B | C) = P(A|C) \times P(B|C)$$

**重要**：独立 ≠ 条件独立！

**例子**：
- A = "下雨", B = "地面湿", C = "洒水车经过"
- A 和 B 不独立（下雨会导致地面湿）
- 但给定 C（洒水车经过），A 和 B 可能条件独立

## 7. Python 实战

### 7.1 条件概率模拟

```python
import numpy as np

def simulate_conditional_probability(n_trials=100000):
    """
    模拟：已知至少一个是女孩，另一个也是女孩的概率
    """
    # 模拟两个孩子的性别 (0=男，1=女)
    children = np.random.randint(0, 2, (n_trials, 2))
    
    # 至少一个是女孩
    at_least_one_girl = np.any(children == 1, axis=1)
    
    # 两个都是女孩
    both_girls = np.all(children == 1, axis=1)
    
    # 条件概率：P(两个都是女孩 | 至少一个是女孩)
    n_condition = np.sum(at_least_one_girl)
    n_both = np.sum(at_least_one_girl & both_girls)
    
    p_conditional = n_both / n_condition
    
    print(f"模拟次数：{n_trials}")
    print(f"满足条件的样本数：{n_condition}")
    print(f"两个都是女孩的数量：{n_both}")
    print(f"P(两个都是女孩 | 至少一个是女孩) = {p_conditional:.4f}")
    print(f"理论值：1/3 = {1/3:.4f}")
    
    return p_conditional

simulate_conditional_probability()
```

**运行结果**：
```
模拟次数：100000
满足条件的样本数：74892
两个都是女孩的数量：24956
P(两个都是女孩 | 至少一个是女孩) = 0.3332
理论值：1/3 = 0.3333
```

### 7.2 蒙提霍尔问题的条件概率解释

回顾上一篇的蒙提霍尔问题，用条件概率重新分析：

**问题**：你选了 1 号门，主持人打开了 3 号门（有山羊），换到 2 号门获胜的概率？

**条件概率分析**：
- 设 Cᵢ = "汽车在 i 号门后"，P(C₁) = P(C₂) = P(C₃) = 1/3
- 你选了 1 号门
- 主持人打开 3 号门，记作 H₃

**计算 P(C₂|H₃)**：

如果汽车在 2 号门后（C₂），主持人**必须**打开 3 号门（因为不能打开你选的 1 号，也不能打开有汽车的 2 号）：
- P(H₃|C₂) = 1

如果汽车在 1 号门后（C₁），主持人可以打开 2 号或 3 号门（随机选择）：
- P(H₃|C₁) = 1/2

由贝叶斯定理（下一篇详细讲）：
$$P(C_2|H_3) = \frac{P(H_3|C_2) \times P(C_2)}{P(H_3)}$$

分母用全概率公式：
$$P(H_3) = P(H_3|C_1)P(C_1) + P(H_3|C_2)P(C_2) + P(H_3|C_3)P(C_3)$$
$$= (1/2)(1/3) + (1)(1/3) + (0)(1/3) = 1/6 + 1/3 = 1/2$$

所以：
$$P(C_2|H_3) = \frac{1 \times 1/3}{1/2} = \frac{2}{3}$$

**结论**：换门后获胜概率是 2/3！✅

## 8. 贝叶斯定理预告 🎯

下一篇我们将学习**贝叶斯定理**，这是条件概率最重要的应用！

**贝叶斯定理**：
$$P(A|B) = \frac{P(B|A) \times P(A)}{P(B)}$$

**思考题**（医疗检测问题）：
- 某疾病发病率 0.1%，检测准确率 99%
- 如果检测呈阳性，真正患病的概率是多少？

**直觉**：99%？❌

**答案**：约 9%！为什么？下一篇揭晓！
