# 001 | 向量：AI 的通用语言

> 🎯 **一句话核心**：向量是有方向和大小的量，AI 用它表示一切——从单词到图像到用户偏好。

---

## 🤔 从一个问题开始

### 问题 1：如何让计算机理解词语的关系？

如果我说：

```
国王 - 男人 + 女人 = ？
```

人类会立刻想到"女王"。但计算机只认识数字，怎么办？

**答案**：把每个词变成一个向量（一串数字），然后做向量运算：

```
向量 (国王) - 向量 (男人) + 向量 (女人) ≈ 向量 (女王)
```

这听起来像魔法？学完这篇你就知道为什么能成立。

---

### 问题 2：抖音怎么知道你喜欢什么视频？

抖音背后有一个巨大的**用户向量**和**视频向量**数据库：

```
你的向量 = [年龄偏好，内容偏好，时长偏好，... , 第 128 维]
视频的向量 = [类别，时长，音乐，... , 第 128 维]
```

系统计算你的向量和每个视频向量的**相似度**，给你推最匹配的。

## 📖 核心概念详解

### 1. 什么是向量？

#### 代数定义
向量是一组有序的数，写在括号里：

```
v = [v₁, v₂, v₃, ..., vₙ]
```

例如：
```
v = [3, 4]           # 2 维向量
w = [1, 2, 3]        # 3 维向量
x = [0.5, -0.2, 0.8, 0.1]  # 4 维向量
```

#### 几何定义
向量是空间中的一个**箭头**，有：
- **起点**（通常是原点）
- **方向**（指向哪里）
- **长度**（也叫"模"或"范数"）

```
     ↑
     |  向量 v = [3, 4]
     |  长度 = 5
     |  方向 = 与 x 轴夹角约 53°
     |
-----+----→
    (0,0)
```

---

### 2. 向量的基本运算

#### 加法：头尾相接

```
u = [1, 2]
v = [3, 1]
u + v = [1+3, 2+1] = [4, 3]
```

**几何意义**：把 v 的起点放到 u 的终点，从 u 的起点到 v 的终点就是 u+v。

```
     ↑
     |      / v
     |     /
     |    / u+v
     |   /|
     |  / | v
     | /  |
     |/___|____→
    (0,0)  u
```

#### 数乘：拉伸或压缩

```
v = [2, 3]
2·v = [4, 6]      # 拉长 2 倍
0.5·v = [1, 1.5]  # 压缩到一半
-1·v = [-2, -3]   # 反向
```

**几何意义**：改变向量的长度（和可能的方向）。

---

#### 点积（内积）：最重要的运算

```
u = [u₁, u₂, u₃]
v = [v₁, v₂, v₃]

u · v = u₁v₁ + u₂v₂ + u₃v₃
```

**例子**：
```
u = [1, 2, 3]
v = [4, 5, 6]
u · v = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

**关键性质**：点积的结果是一个**数**（不是向量）！

---

### 3. 点积的几何意义（重点！）

点积有一个神奇的几何解释：

```
u · v = |u| × |v| × cos(θ)
```

其中：
- |u| 是 u 的长度
- |v| 是 v 的长度
- θ 是两个向量的夹角

**这意味着什么？**

| 夹角 θ | cos(θ) | 点积 | 含义 |
|--------|--------|------|------|
| 0° | 1 | 正最大 | 同方向 |
| 90° | 0 | 0 | 垂直（正交） |
| 180° | -1 | 负最大 | 反方向 |

**结论**：点积衡量两个向量的"方向相似度"！

---

### 4. 余弦相似度

基于点积，我们定义**余弦相似度**：

```
cos(θ) = (u · v) / (|u| × |v|)
```

**性质**：
- 范围：[-1, 1]
- 1：完全相同方向
- 0：垂直（无关）
- -1：完全相反

**AI 中的应用**：这就是推荐系统、搜索引擎计算相似度的核心公式！

## 💻 代码实现

### 从零实现向量运算

```python
import numpy as np
import math

# ==================== 向量的基本运算 ====================

# 创建向量
v = np.array([3, 4])
w = np.array([1, 2, 3])

print(f"向量 v: {v}")
print(f"向量 w: {w}")

# 向量加法
a = np.array([1, 2])
b = np.array([3, 1])
c = a + b
print(f"\n{a} + {b} = {c}")  # [4, 3]

# 数乘
v = np.array([2, 3])
print(f"\n2 × {v} = {2 * v}")  # [4, 6]
print(f"-1 × {v} = {-1 * v}")  # [-2, -3]

# ==================== 向量的长度（范数） ====================

def norm(v):
    """计算向量的长度（L2 范数）"""
    return math.sqrt(sum(x**2 for x in v))

# 或用 numpy
v = np.array([3, 4])
print(f"\n向量 {v} 的长度：{np.linalg.norm(v)}")  # 5.0

# 验证：3² + 4² = 9 + 16 = 25, √25 = 5 ✓

# ==================== 点积 ====================

def dot_product(u, v):
    """计算两个向量的点积"""
    if len(u) != len(v):
        raise ValueError("向量维度必须相同")
    return sum(ui * vi for ui, vi in zip(u, v))

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])
print(f"\n{u} · {v} = {np.dot(u, v)}")  # 32

# ==================== 余弦相似度 ====================

def cosine_similarity(u, v):
    """计算两个向量的余弦相似度"""
    dot = np.dot(u, v)
    norm_u = np.linalg.norm(u)
    norm_v = np.linalg.norm(v)
    return dot / (norm_u * norm_v)

# 测试
a = np.array([1, 0])
b = np.array([0, 1])
c = np.array([1, 1])

print(f"\n[1,0] 和 [0,1] 的相似度：{cosine_similarity(a, b):.4f}")  # 0.0（垂直）
print(f"[1,0] 和 [1,1] 的相似度：{cosine_similarity(a, c):.4f}")  # 0.7071（45°）
print(f"[1,0] 和 [1,0] 的相似度：{cosine_similarity(a, a):.4f}")  # 1.0（相同）

# ==================== 词向量示例 ====================

print("\n" + "="*50)
print("词向量示例：国王 - 男人 + 女人 ≈ 女王")
print("="*50)

# 这里用简化的 4 维向量演示（实际是 300 维）
king = np.array([0.8, 0.2, -0.1, 0.5])
man = np.array([0.7, 0.3, -0.2, 0.4])
woman = np.array([0.6, -0.3, 0.1, 0.3])
queen = np.array([0.7, -0.2, 0.0, 0.4])

# 计算：king - man + woman
result = king - man + woman
print(f"\nking:  {king}")
print(f"man:   {man}")
print(f"woman: {woman}")
print(f"\nking - man + woman = {result}")
print(f"queen 的真实向量    = {queen}")
print(f"\n相似度：{cosine_similarity(result, queen):.4f}")  # 应该接近 1
```

### 运行结果

```
==================================================
词向量示例：国王 - 男人 + 女人 ≈ 女王
==================================================

king:  [0.8 0.2 -0.1 0.5]
man:   [0.7 0.3 -0.2 0.4]
woman: [0.6 -0.3 0.1 0.3]

king - man + woman = [0.7 -0.2 0.  0.4]
queen 的真实向量    = [0.7 -0.2 0.  0.4]

相似度：1.0000
```

## 🔗 与 AI 的联系

### 1. 词向量（Word Embedding）

2013 年，Google 的 Word2Vec 论文展示了：

```
向量 (巴黎) - 向量 (法国) + 向量 (德国) ≈ 向量 (柏林)
向量 (跑) - 动词 + 名词 ≈ 向量 (跑步)
向量 (好) - 好 + 最好 ≈ 向量 (最好)
```

**为什么？** 因为向量空间捕捉了语义关系！

---

### 2. 图像表示

一张 224×224 的 RGB 图片可以表示为一个向量：

```
向量维度 = 224 × 224 × 3 = 150,528 维
```

CNN 的作用就是把这个巨大向量转换成有意义的**特征向量**（比如 512 维），用于分类、检测等任务。

---

### 3. 用户嵌入（User Embedding）

推荐系统中，每个用户是一个向量：

```
用户 A = [喜欢动作片，喜欢科幻，平均观看时长，活跃时间，... , 第 128 维]
```

每个物品也是一个向量，计算相似度做推荐。

---

### 4. Transformer 中的向量

在 GPT、BERT 等模型中：
- 每个词被表示为一个向量（词嵌入）
- 位置也被表示为向量（位置编码）
- 注意力机制本质是向量的加权组合

## 🧠 常见误区

### ❌ 误区 1：向量就是列表

**纠正**：向量有**几何意义**！它不只是数字的集合，而是空间中的一个箭头。始终想象它的几何含义。

---

### ❌ 误区 2：点积和叉积是一回事

**纠正**：
- **点积**：结果是数，衡量方向相似度
- **叉积**：结果是向量（仅 3D），结果向量垂直于输入的两个向量

AI 中几乎只用点积！

---

### ❌ 误区 3：高维向量和 2D/3D 一样直观

**纠正**：高维空间有很多反直觉的性质：
- 在高维空间中，随机向量几乎总是近似垂直的
- 高维球体的体积主要集中在表面

不过别担心，我们后面会讲到这些！

### 练习 2：余弦相似度

```
u = [1, 0]
v = [1, 1]

计算 u 和 v 的余弦相似度，并验证角度是否为 45°
```

<details>
<summary>点击查看答案</summary>

```
u · v = 1×1 + 0×1 = 1
|u| = 1
|v| = √2

cos(θ) = 1 / (1 × √2) = 1/√2 ≈ 0.707

θ = arccos(0.707) ≈ 45° ✓
```
</details>

```python
def find_most_similar(target, candidates):
    best_idx = -1
    best_sim = -1
    
    for i, cand in enumerate(candidates):
        sim = cosine_similarity(target, cand)
        if sim > best_sim:
            best_sim = sim
            best_idx = i
    
    return candidates[best_idx], best_idx, best_sim
```
