# 015 | 梯度下降法

> 🎯 **一句话核心**：梯度下降是优化算法的基石——沿着损失函数梯度的反方向更新参数，一步步走向最小值。这是所有深度学习算法的核心引擎。

---

## 🤔 从一个实际问题开始

### 问题：如何训练一个线性回归模型？

假设你有数据 {(x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)}，想拟合一条直线：

```
y = w·x + b
```

**如何找到最好的 w 和 b？**

定义损失函数（均方误差）：

```
L(w, b) = 1/n · Σ(yᵢ - (w·xᵢ + b))²
```

这是一个关于 w 和 b 的函数。我们的目标是：

```
min L(w, b)
 w,b
```

**怎么找最小值？**

- ❌ 求导令导数为 0？高维情况下解析解不存在或计算成本太高
- ❌ 随机搜索？效率太低，像大海捞针
- ✅ **梯度下降**：沿着最陡的方向下山！

---

### 直观理解：下山问题

想象你站在一座山上（损失函数），想走到山谷（最小值）：

```
        你在这里
          ↓
         _/ \_
        /     \
       /       \
      /         \
     /           \
    ·-------------·
        山谷（最小值）
```

**策略**：
1. 感受脚下的坡度（计算梯度）
2. 往最陡的下坡方向走一步（沿负梯度更新）
3. 重复 1-2，直到到达山谷

这就是梯度下降！

---

## 📖 核心概念详解

### 1. 梯度下降算法

#### 算法步骤

```
输入：损失函数 L(θ), 初始参数 θ₀, 学习率 η, 最大迭代次数 T
输出：最优参数 θ*

1. θ = θ₀
2. for t = 1 to T:
     a. 计算梯度：g = ∇L(θ)
     b. 更新参数：θ = θ - η·g
     c. 检查收敛：如果 ||g|| < ε，提前退出
3. return θ
```

#### 更新公式

```
θ_{new} = θ_{old} - η·∇L(θ_{old})
```

其中：
- **θ**：参数向量（w, b, ...）
- **η**：学习率（learning rate），控制步长
- **∇L**：梯度，指向函数增长最快的方向

**为什么是减号？**

梯度指向**上升最快**的方向，我们要最小化，所以走反方向！

---

### 2. 一元函数的梯度下降

#### 例子：最小化 f(x) = x²

```
f(x) = x²
f'(x) = 2x

更新公式：x_{new} = x_{old} - η·2x_{old}
```

**手动迭代**（从 x₀=4, η=0.1 开始）：

```
迭代 0: x = 4.0,    f'(x) = 8.0,     f(x) = 16.0
迭代 1: x = 4 - 0.1×8 = 3.2,    f'(x) = 6.4,     f(x) = 10.24
迭代 2: x = 3.2 - 0.1×6.4 = 2.56,   f'(x) = 5.12,    f(x) = 6.55
迭代 3: x = 2.56 - 0.1×5.12 = 2.05,   f'(x) = 4.10,    f(x) = 4.20
迭代 4: x = 2.05 - 0.1×4.10 = 1.64,   f'(x) = 3.28,    f(x) = 2.69
...
迭代 20: x ≈ 0.07,   f(x) ≈ 0.005
```

**可视化**：

```
        f(x)
         |
    16 - |*
         | \
    10 - |  \
         |   \
     6 - |    \
         |     \
     2 - |      \____
         |           \___
     0 - ·---------------·--- x
         0   1   2   3   4
         
         *→→→→→→→→→→→→→→ 山谷
```

### 3. 多元函数的梯度下降

#### 例子：线性回归

```
L(w, b) = 1/n · Σ(yᵢ - (w·xᵢ + b))²

梯度：
∂L/∂w = -2/n · Σ(yᵢ - (w·xᵢ + b))·xᵢ
∂L/∂b = -2/n · Σ(yᵢ - (w·xᵢ + b))

更新：
w = w - η·∂L/∂w
b = b - η·∂L/∂b
```

**向量化表示**：

```
令 X = [x₁, x₂, ..., xₙ]ᵀ, y = [y₁, y₂, ..., yₙ]ᵀ, θ = [w, b]ᵀ

预测：ŷ = X·w + b
损失：L(θ) = 1/n · ||y - ŷ||²
梯度：∇L(θ) = -2/n · Xᵀ(y - ŷ)

更新：θ = θ + η·2/n · Xᵀ(y - ŷ)
```

---

### 4. 学习率的选择

学习率 η 是梯度下降最重要的超参数！

#### 学习率太小

```
        _
      _/ \_
     /     \
    /       \
   ·→→→→→→→→·  走了很久才到
```

- 收敛太慢，需要很多次迭代
- 可能卡在局部极小值

#### 学习率太大

```
        _
      _/ \_
     /     \
    /       \
   ·→←→←→←→·  来回震荡，不收敛
```

- 在最小值附近震荡
- 可能发散（越走越远）

#### 学习率刚好

```
        _
      _/ \_
     /     \
    /       \
   ·→→→→→·  稳步收敛
```

#### 选择策略

1. **经验值**：从 0.01, 0.001, 0.0001 开始尝试
2. **学习率搜索**：尝试 10⁻⁵ 到 10⁰ 的对数范围
3. **学习率调度**：
   - **固定学习率**：最简单，但可能不是最优
   - **学习率衰减**：η_t = η₀ / (1 + α·t)
   - **Step decay**：每 N 轮减半
   - **Cosine annealing**：η_t = η_min + ½(η_max - η_min)(1 + cos(π·t/T))
   - **Warmup**：先从小学习率开始，逐渐增大

## 💻 Python 实现

### 基础实现：一元函数

```python
import numpy as np
import matplotlib.pyplot as plt

def gradient_descent_1d(f, df, x0, lr, max_iter=100, tol=1e-6):
    """一元函数的梯度下降"""
    x = x0
    history = {'x': [x], 'f': [f(x)], 'grad': [df(x)]}
    
    for i in range(max_iter):
        grad = df(x)
        x = x - lr * grad
        
        history['x'].append(x)
        history['f'].append(f(x))
        history['grad'].append(grad)
        
        if abs(grad) < tol:
            print(f"收敛于迭代 {i+1}")
            break
    
    return x, history

# 测试：最小化 f(x) = x²
f = lambda x: x**2
df = lambda x: 2*x

x_opt, history = gradient_descent_1d(f, df, x0=4.0, lr=0.1)

print(f"最优解：x = {x_opt:.6f}")
print(f"最小值：f(x) = {f(x_opt):.6f}")

# 可视化
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

# 1. 函数图像 + 优化路径
x = np.linspace(-4.5, 4.5, 100)
axes[0].plot(x, f(x), 'b-', linewidth=2, label='f(x) = x²')

axes[0].set_xlabel('x')
```

### 实现：多元函数（线性回归）

```python
def gradient_descent_linear_regression(X, y, lr=0.01, max_iter=1000, tol=1e-6):
    """
    用梯度下降训练线性回归
    
    参数:
        X: 特征矩阵 (n_samples, n_features)
        y: 目标向量 (n_samples,)
        lr: 学习率
        max_iter: 最大迭代次数
        tol: 收敛阈值
    
    返回:
        w: 权重 (n_features,)
        b: 偏置
        history: 训练历史
    """
    n_samples, n_features = X.shape
    
    # 初始化参数
    w = np.zeros(n_features)
    b = 0.0
    
    history = {'loss': [], 'w': [], 'b': []}
    
    for i in range(max_iter):
        # 前向传播
        y_pred = X @ w + b
        
        # 计算损失
        loss = np.mean((y - y_pred) ** 2)
        
        # 计算梯度
        dw = -2/n_samples * X.T @ (y - y_pred)
        db = -2/n_samples * np.sum(y - y_pred)
        
        # 更新参数
        w = w - lr * dw
        b = b - lr * db
        
        # 记录历史
        history['loss'].append(loss)
        history['w'].append(w.copy())
        history['b'].append(b)
        
        # 检查收敛
        if i > 0 and abs(history['loss'][-2] - loss) < tol:
            print(f"收敛于迭代 {i+1}, 损失：{loss:.6f}")
            break
    
    return w, b, history

# 生成测试数据
np.random.seed(42)
n_samples = 100
X = np.random.randn(n_samples, 1)
true_w = 2.5
true_b = 1.0
y = true_w * X.squeeze() + true_b + np.random.randn(n_samples) * 0.5

# 训练
w, b, history = gradient_descent_linear_regression(X, y, lr=0.1, max_iter=1000)

print(f"真实参数：w = {true_w:.4f}, b = {true_b:.4f}")
print(f"学习到的参数：w = {w[0]:.4f}, b = {b:.4f}")

# 可视化
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

# 1. 数据 + 拟合直线
x_test = np.linspace(X.min(), X.max(), 100)
y_test = w[0] * x_test + b

axes[0].scatter(X, y, alpha=0.6, label='数据点')
axes[0].plot(x_test, y_test, 'r-', linewidth=2, label=f'拟合：y = {w[0]:.2f}x + {b:.2f}')
axes[0].plot(x_test, true_w * x_test + true_b, 'g--', linewidth=2, label='真实直线')
axes[0].set_xlabel('x')

axes[0].set_title('线性回归拟合')

axes[1].set_title('损失函数收敛')
```

## 🧠 深度理解

### 1. 为什么梯度下降有效？

#### 泰勒展开的视角

损失函数 L(θ) 在 θ₀ 处的一阶泰勒展开：

```
L(θ) ≈ L(θ₀) + ∇L(θ₀)ᵀ(θ - θ₀)
```

令 θ = θ₀ - η·∇L(θ₀)，代入：

```
L(θ) ≈ L(θ₀) + ∇L(θ₀)ᵀ(-η·∇L(θ₀))
     = L(θ₀) - η·||∇L(θ₀)||²
```

因为 ||∇L||² ≥ 0，所以当 η > 0 时，L(θ) < L(θ₀)。

**结论**：只要学习率足够小，梯度下降保证损失下降！

---

#### 收敛性分析

**凸函数情况**：
- 如果 L 是凸函数，梯度下降保证收敛到全局最小值
- 收敛速度：O(1/ε)，需要 O(1/ε) 次迭代达到误差 ε

**非凸函数情况**（如神经网络）：
- 只能保证收敛到**稳定点**（梯度为 0 的点）
- 可能是局部最小值、鞍点
- 但实践中，SGD 往往能找到足够好的解

---

### 2. 梯度下降的变体

#### 批量梯度下降 (Batch GD)

```
每次更新使用全部训练数据

∇L(θ) = 1/n · Σ ∇Lᵢ(θ)
```

**优点**：
- 梯度估计准确，收敛稳定
- 可以并行计算

**缺点**：
- 每次迭代计算成本高（O(n)）
- 大数据集内存放不下
- 可能卡在局部最小值

---

#### 随机梯度下降 (SGD)

```
每次更新使用一个随机样本

∇L(θ) ≈ ∇Lᵢ(θ)  (i 随机选择)
```

**优点**：
- 每次迭代快（O(1)）
- 可以在线学习
- 噪声有助于逃离局部最小值

**缺点**：
- 梯度方差大，收敛不稳定
- 损失函数会震荡

---

#### 小批量梯度下降 (Mini-batch GD)

```
每次更新使用一个小批量数据（如 32, 64, 128）

∇L(θ) ≈ 1/b · Σ ∇Lᵢ(θ)  (b 个小批量)
```

**优点**：
- 平衡了 Batch GD 和 SGD
- 可以利用 GPU 并行加速
- 最常用！✅

**对比**：

```
        批量 GD      小批量      SGD
        ━━━━━━━    ━━━━      ━
        稳定        较稳定      震荡
        慢          中等        快
        内存多      内存中      内存少
```

### 3. 梯度消失与爆炸

#### 问题

在深度神经网络中，梯度可能：
- **消失**：梯度趋近于 0，参数几乎不更新
- **爆炸**：梯度非常大，参数更新过大导致发散

#### 原因

链式法则：

```
∂L/∂w₁ = ∂L/∂yₙ · ∂yₙ/∂yₙ₋₁ · ... · ∂y₂/∂y₁ · ∂y₁/∂w₁
```

如果每个 ∂yᵢ₊₁/∂yᵢ < 1，连乘后趋近于 0（消失）
如果每个 ∂yᵢ₊₁/∂yᵢ > 1，连乘后趋近于 ∞（爆炸）

#### 解决方案

1. **合适的激活函数**：ReLU 比 Sigmoid 好
2. **权重初始化**：Xavier、He 初始化
3. **Batch Normalization**：规范化每层输入
4. **梯度裁剪**：限制梯度范数 ||g|| ≤ max_norm
5. **残差连接**：ResNet 的 skip connection

---

### 4. 动量法 (Momentum)

#### 问题

标准梯度下降在以下情况表现不佳：
- 损失曲面在某些方向很平坦，某些方向很陡峭
- 容易在峡谷地形中震荡

```
        峡谷地形
        
        | | | | |  陡峭
        | | | | |
        ·→→→→→·  震荡前进
       /         \
      /           \  平坦
```

#### 动量法

引入"动量"，积累之前的更新方向：

```
v_t = γ·v_{t-1} + η·∇L(θ_t)
θ_{t+1} = θ_t - v_t
```

其中：
- **v**：速度（累积梯度）
- **γ**：动量系数（通常 0.9）

**直观理解**：
- 就像球从山上滚下，有惯性
- 在一致方向上加速
- 在震荡方向上减速

**效果**：
- 加速收敛
- 减少震荡
- 更容易冲出局部最小值

---

### 5. 自适应学习率方法

#### AdaGrad

```
累积梯度平方：G_t = G_{t-1} + (∇L(θ_t))²
更新：θ_{t+1} = θ_t - η/(√G_t + ε) · ∇L(θ_t)
```

**特点**：
- 频繁更新的参数学习率变小
- 稀疏特征的参数学习率大
- 缺点：学习率单调下降，可能过早停止

---

#### RMSProp

```
指数移动平均：E[g²]_t = α·E[g²]_{t-1} + (1-α)·(∇L(θ_t))²
更新：θ_{t+1} = θ_t - η/√(E[g²]_t + ε) · ∇L(θ_t)
```

**改进**：
- 用指数平均代替累加
- 解决了 AdaGrad 学习率过早下降的问题

---

#### Adam（最常用！）

```
一阶矩（均值）：m_t = β₁·m_{t-1} + (1-β₁)·∇L(θ_t)
二阶矩（未中心化的方差）：v_t = β₂·v_{t-1} + (1-β₂)·(∇L(θ_t))²

偏差修正：m̂_t = m_t/(1-β₁^t), v̂_t = v_t/(1-β₂^t)

更新：θ_{t+1} = θ_t - η/√(v̂_t + ε) · m̂_t
```

**默认参数**：
- β₁ = 0.9（一阶矩衰减）
- β₂ = 0.999（二阶矩衰减）
- ε = 10⁻⁸（数值稳定性）

**为什么 Adam 好用？**
- 结合了动量和自适应学习率
- 对超参数不敏感
- 默认参数就能 work well

## 🎯 与 AI 的直接连接

### 1. 神经网络训练

**标准训练流程**：

```python
for epoch in range(num_epochs):
    for batch_X, batch_y in dataloader:
        # 前向传播
        y_pred = model(batch_X)
        
        # 计算损失
        loss = criterion(y_pred, batch_y)
        
        # 反向传播（计算梯度）
        optimizer.zero_grad()
        loss.backward()
        
        # 更新参数（梯度下降）
        optimizer.step()
```

**优化器选择**：
- **SGD + Momentum**：图像分类（ResNet 等），泛化好
- **Adam**：NLP、GAN、大多数情况，收敛快
- **AdamW**：Adam + 权重衰减，Transformer 首选

### 2. 深度学习中的实践技巧

#### 学习率调度

```python
# PyTorch 示例
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer, T_max=100, eta_min=1e-6
)

for epoch in range(100):
    train()
    scheduler.step()  # 更新学习率
```

**常见策略**：
- **StepLR**：每 N 轮乘以 γ（如 0.1）
- **CosineAnnealing**：余弦退火
- **ReduceLROnPlateau**：损失不下降时降低学习率
- **Warmup**：前 N 轮线性增加学习率

---

#### 梯度裁剪

```python
# 防止梯度爆炸
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

**何时使用**：
- RNN/LSTM 训练
- 深度网络
- 梯度爆炸时

#### 批量大小选择

| 批量大小 | 适用场景 |
|---------|---------|
| 16-32 | 小数据集、显存有限 |
| 64-128 | 标准选择（图像分类） |
| 256-512 | 大数据集、分布式训练 |
| 1024+ | 需要特殊调参技巧 |

**经验法则**：
- 在显存允许范围内，尽量用大批量
- 大批量需要更大的学习率（线性缩放规则）

```python
def plot_loss_landscape(model, data, direction):
    """可视化损失曲面的一维切片"""
    w0 = model.weight.data.clone()
    alphas = np.linspace(-1, 1, 50)
    losses = []
    
    for alpha in alphas:
        model.weight.data = w0 + alpha * direction
        loss = compute_loss(model, data)
        losses.append(loss)
    
    plt.plot(alphas, losses)
    plt.xlabel('沿方向的距离')
    plt.ylabel('损失')
    plt.title('损失曲面切片')
    plt.show()
```

**观察**：
- 凸形状：优化容易
- 多谷形状：可能陷入局部最小值
- 平坦区域：梯度消失

```python
实现随机梯度下降训练线性回归
```

<summary>参考实现</summary>

```python
def sgd_linear_regression(X, y, lr=0.01, epochs=100):
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    b = 0.0
    
    for epoch in range(epochs):
        # 打乱数据
        indices = np.random.permutation(n_samples)
        
        for i in indices:
            # 单个样本
            xi, yi = X[i], y[i]
            y_pred = xi @ w + b
            error = y_pred - yi
            
            # 更新
            w = w - lr * error * xi
            b = b - lr * error
    
    return w, b
```
