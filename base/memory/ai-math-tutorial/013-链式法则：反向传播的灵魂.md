# 013 | 链式法则：反向传播的灵魂

> 🎯 **一句话核心**：链式法则是复合函数求导的"拆解术"——把复杂函数拆成简单环节，逐环求导再相乘，这是反向传播算法的数学基础。

---

## 🤔 从一个实际问题开始

### 问题：神经网络的损失函数怎么求导？

考虑一个简单的神经网络：

```
输入 x → [隐藏层 h = σ(W₁x)] → [输出 ŷ = σ(W₂h)] → 损失 L = (ŷ - y)²
```

损失函数 L 是关于 W₁ 和 W₂ 的函数，但中间经过了多层变换：

```
L = L(ŷ) = L(σ(W₂h)) = L(σ(W₂ · σ(W₁x)))
```

这是一个**复合函数**，嵌套了 3-4 层！怎么对 W₁ 求导？

```
∂L/∂W₁ = ?
```

**直接求导？ Impossible!** 表达式太复杂了。

**链式法则**：把复合函数拆成链条，逐段求导，然后相乘。

```
∂L/∂W₁ = (∂L/∂ŷ) · (∂ŷ/∂h) · (∂h/∂W₁)
         ↑        ↑         ↑
      第 3 段    第 2 段     第 1 段
```

这就是**反向传播**的核心思想！

---

### 直观理解：多米诺骨牌

想象一排多米诺骨牌：

```
W₁ → h → ŷ → L
```

推倒 W₁ 会怎样？影响会沿着链条传递：

```
W₁ 变化 → h 变化 → ŷ 变化 → L 变化
```

**链式法则**问的是：W₁ 变化一点点，L 最终变化多少？

答案是：每一段的"传递系数"相乘。

```
∂L/∂W₁ = (L 对 ŷ 的敏感度) × (ŷ 对 h 的敏感度) × (h 对 W₁ 的敏感度)
```

---

## 📖 核心概念详解

### 1. 链式法则的两种形式

#### 形式 1：一元函数的链式法则

```
y = f(u), u = g(x)  →  y = f(g(x))

dy/dx = dy/du · du/gx
```

**例子**：

```
y = sin(x²)

令 u = x², 则 y = sin(u)

dy/du = cos(u) = cos(x²)
du/dx = 2x

dy/dx = cos(x²) · 2x = 2x·cos(x²)
```

---

#### 形式 2：多元函数的链式法则（向量形式）

```
z = f(x, y), x = g(t), y = h(t)

dz/dt = (∂z/∂x)·(dx/dt) + (∂z/∂y)·(dy/dt)
```

**例子**：

```
z = x² + y², x = t², y = t³

∂z/∂x = 2x, ∂z/∂y = 2y
dx/dt = 2t, dy/dt = 3t²

dz/dt = 2x·2t + 2y·3t²
      = 2(t²)·2t + 2(t³)·3t²
      = 4t³ + 6t⁵
```

---

### 2. 链式法则的"计算图"视角

神经网络的求导用**计算图**最清晰：

```
        x
        ↓
    ┌───┴───┐
    │  W₁   │
    └───┬───┘
        ↓
        h = σ(W₁x)
        ↓
    ┌───┴───┐
    │  W₂   │
    └───┬───┘
        ↓
        ŷ = σ(W₂h)
        ↓
        L = (ŷ - y)²
```

**反向传播**：从 L 开始，沿着箭头**反向**逐层求导。

```
∂L/∂W₂ = (∂L/∂ŷ) · (∂ŷ/∂W₂)
∂L/∂W₁ = (∂L/∂ŷ) · (∂ŷ/∂h) · (∂h/∂W₁)
```

**关键洞察**：∂L/∂ŷ 被复用了！

这就是反向传播高效的原因——**中间结果可以复用**，不用重复计算。

---

### 3. 为什么叫"反向"传播？

对比两种方式：

#### 前向模式（从输入往输出）

```
∂h/∂W₁ → ∂ŷ/∂W₁ → ∂L/∂W₁
```

要对每个参数都走一遍，效率低。

#### 反向模式（从输出往输入）⭐

```
∂L/∂ŷ → ∂L/∂h → ∂L/∂W₁ 和 ∂L/∂W₂
```

**一次反向遍历**，得到所有参数的梯度！

神经网络参数百万级，反向模式效率碾压前向模式。

## 💻 Python 实现：链式法则 vs 自动微分

### 手动实现链式法则

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)  # σ'(x) = σ(x)(1-σ(x))

# 简单网络：x → W₁ → h → W₂ → ŷ → L
x = np.array([[1.0], [2.0]])  # 2×1 输入
W1 = np.array([[0.5, 0.3]])    # 1×2 权重
W2 = np.array([[0.8]])         # 1×1 权重
y = np.array([[1.0]])          # 目标输出

# === 前向传播 ===
z1 = W1 @ x           # 线性变换
h = sigmoid(z1)       # 激活
z2 = W2 @ h           # 线性变换
y_hat = sigmoid(z2)   # 预测

# 损失：MSE
L = 0.5 * (y_hat - y) ** 2

# === 反向传播（链式法则）===
# 第 3 段：L 对 ŷ 的导数
dL_dyhat = y_hat - y  # d/dŷ [0.5(ŷ-y)²] = ŷ - y

# 第 2 段：ŷ 对 z2 的导数
dyhat_dz2 = sigmoid_derivative(z2)

# 第 1 段：z2 对 W2 的导数
dz2_dW2 = h

# 组合：∂L/∂W₂
dL_dW2 = dL_dyhat * dyhat_dz2 * dz2_dW2.T

# 继续反向：ŷ 对 h 的导数
dyhat_dh = W2.T * dyhat_dz2

# h 对 z1 的导数
dh_dz1 = sigmoid_derivative(z1)

# z1 对 W1 的导数
dz1_dW1 = x.T

# 组合：∂L/∂W₁
dL_dW1 = (dL_dyhat * dyhat_dh * dh_dz1) @ dz1_dW1

print(f"损失 L = {L[0][0]:.6f}")
print(f"∂L/∂W₂ = {dL_dW2}")
print(f"∂L/∂W₁ = {dL_dW1}")
```

**输出**：
```
损失 L = 0.142857
∂L/∂W₂ = [[-0.28571429]]
∂L/∂W₁ = [[-0.05714286, -0.11428571]]
```

### 使用 PyTorch 自动微分（验证）

```python
import torch

# 同样的设置
x = torch.tensor([[1.0], [2.0]], requires_grad=False)
W1 = torch.tensor([[0.5, 0.3]], requires_grad=True)
W2 = torch.tensor([[0.8]], requires_grad=True)
y = torch.tensor([[1.0]])

# 前向
z1 = W1 @ x
h = torch.sigmoid(z1)
z2 = W2 @ h
y_hat = torch.sigmoid(z2)
L = 0.5 * (y_hat - y) ** 2

# 反向传播
L.backward()

print(f"损失 L = {L.item():.6f}")
print(f"∂L/∂W₂ (PyTorch) = {W2.grad}")
print(f"∂L/∂W₁ (PyTorch) = {W1.grad}")
```

**结果应该和手动计算一致！** ✅

## 🧠 深度理解

### 1. 链式法则的本质：**变化的传递**

```
x 变化 Δx → u 变化 Δu ≈ (du/dx)·Δx → y 变化 Δy ≈ (dy/du)·Δu
```

所以：

```
Δy ≈ (dy/du)·(du/dx)·Δx
```

当 Δx → 0 时，就是链式法则。

---

### 2. 为什么神经网络必须用链式法则？

**规模对比**：

| 方法 | 计算复杂度 | 100 万参数需要 |
|------|-----------|---------------|
| 数值微分 | O(n) 次前向 | 100 万次 ❌ |
| 符号微分 | 表达式爆炸 | 内存溢出 ❌ |
| **链式法则（反向传播）** | **O(1) 次反向** | **1 次 ✅** |

**数值微分**（有限差分）：

```
∂L/∂wᵢ ≈ (L(w+ε) - L(w-ε)) / 2ε
```

对每个参数都要扰动一次，100 万参数 = 100 万次前向传播！

**反向传播**：

```
一次前向 + 一次反向 = 所有参数的梯度
```

效率差距：**百万倍**！

---

### 3. 链式法则的"路径"视角

对于复杂函数，链式法则是**所有路径的贡献之和**：

```
      x
     / \
    u   v
     \ /
      y
```

```
dy/dx = (dy/du)·(du/dx) + (dy/dv)·(dv/dx)
         ↑ 路径 1 ↑    ↑ 路径 2 ↑
```

神经网络中，一个参数可能影响多个输出路径，梯度是所有路径贡献的**总和**。

## 🎯 与 AI 的直接连接

### 1. 反向传播算法

反向传播 = 链式法则 + 计算图 + 动态规划（缓存中间结果）

**算法步骤**：

1. **前向传播**：计算所有节点的值（缓存）
2. **初始化**：∂L/∂L = 1
3. **反向遍历**：对每个节点，用链式法则计算梯度
4. **复用**：上游梯度传递给所有输入边

```python
# 伪代码
def backward(node):
    for parent in node.parents:
        # 链式法则：父节点的梯度 += 当前节点梯度 × 当前节点对父节点的导数
        parent.grad += node.grad * node.derivative_wrt(parent)
        backward(parent)
```

---

### 2. 实际神经网络中的链式法则

#### CNN（卷积神经网络）

```
输入 → [Conv → ReLU → Pool] × N → FC → 输出
```

每一层都是一个函数，链式法则贯穿所有层：

```
∂L/∂W_conv = (∂L/∂输出) · (∂输出/∂... ) · ... · (∂.../∂W_conv)
```

#### RNN（循环神经网络）

```
x₁ → h₁ → h₂ → ... → hₜ → y
```

**BPTT（随时间反向传播）**：

```
∂L/∂W = Σₜ (∂L/∂hₜ) · (∂hₜ/∂hₜ₋₁) · ... · (∂h₁/∂W)
```

时间步越长，链式法则的链条越长 → **梯度消失/爆炸**的根源！

#### Transformer

```
输入 → Embedding → [Self-Attention + FFN] × N → 输出
```

层数更深（GPT-3 有 96 层），链式法则的链条更长。

**解决方案**：
- Residual Connection（残差连接）：提供"捷径"，缩短有效链长
- Layer Normalization：稳定梯度尺度
- 精心设计的初始化

## 📊 可视化：梯度流动

```
前向传播（计算损失）：
x → W₁ → h → W₂ → ŷ → L
    ↓    ↓    ↓    ↓
   z1   σ   z2   σ

反向传播（计算梯度）：
x ← W₁ ← h ← W₂ ← ŷ ← L
    ←    ←    ←    ←
   ∂L/∂z1 ← ∂L/∂z2 ← ∂L/∂ŷ ← 1
```

**梯度像水流一样**，从输出端流向输入端，沿途"浇灌"每个参数。

## 🧪 练习

### 练习 1：基础链式法则

```
y = ln(sin(x²))

求 dy/dx
```

<details>
<summary>点击查看答案</summary>

```
令 u = x², v = sin(u), y = ln(v)

dy/dx = (dy/dv) · (dv/du) · (du/dx)
      = (1/v) · cos(u) · 2x
      = (1/sin(x²)) · cos(x²) · 2x
      = 2x · cot(x²)
```

</details>

---

### 练习 2：神经网络单神经元

```
单个神经元：ŷ = σ(wx + b)
损失：L = (ŷ - y)²

求 ∂L/∂w 和 ∂L/∂b
```

<details>
<summary>点击查看答案</summary>

```
∂L/∂w = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂w)
      = 2(ŷ - y) · σ'(z) · x
      = 2(ŷ - y) · ŷ(1-ŷ) · x

∂L/∂b = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂b)
      = 2(ŷ - y) · σ'(z) · 1
      = 2(ŷ - y) · ŷ(1-ŷ)
```

</details>

---

### 练习 3：两层网络

```
h = ReLU(W₁x + b₁)
ŷ = W₂h + b₂
L = ½(ŷ - y)²

求 ∂L/∂W₁
```

<details>
<summary>点击查看答案</summary>

```
∂L/∂W₁ = (∂L/∂ŷ) · (∂ŷ/∂h) · (∂h/∂z₁) · (∂z₁/∂W₁)

其中：
- ∂L/∂ŷ = (ŷ - y)
- ∂ŷ/∂h = W₂
- ∂h/∂z₁ = ReLU'(z₁) = 1 if z₁>0 else 0
- ∂z₁/∂W₁ = x

所以：
∂L/∂W₁ = (ŷ - y) · W₂ · ReLU'(z₁) · x
```

</details>

## 🔑 核心要点总结

| 概念 | 要点 |
|------|------|
| **链式法则** | 复合函数求导 = 逐段求导 × 相乘 |
| **计算图** | 把函数拆成节点和边，清晰表达依赖关系 |
| **反向传播** | 从输出往输入反向计算梯度，复用中间结果 |
| **效率优势** | O(1) 次反向 = 所有参数梯度（vs O(n) 次数值微分） |
| **梯度消失** | 链式法则连乘导致梯度指数级缩小（深层网络问题） |
