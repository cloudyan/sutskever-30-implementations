# 005 | 特征值与特征向量：变换的"不变方向"

> 🎯 **一句话核心**：特征向量是线性变换中方向不变的向量，特征值是该方向的缩放倍数——它们揭示了变换的本质结构。

---

## 🤔 从一个问题开始

### 想象一个变换

你有一个矩阵 A，它把空间拉伸、旋转、挤压...

```
A = | 3  1 |
    | 1  3 |
```

**问题**：有没有一些特殊的方向，经过变换后**方向不变**，只是被拉长或缩短？

---

### 寻找"不变方向"

假设存在一个向量 v，经过变换后方向不变：

```
A × v = λ × v

其中 λ 是一个数（缩放倍数）
```

**这就是特征方程！**

- **v** 叫做**特征向量**（eigenvector）
- **λ** 叫做**特征值**（eigenvalue）
- "eigen"是德语，意思是"自己的"、"特有的"

---

### 解特征方程

对于 A = | 3  1 |
         | 1  3 |

**步骤 1**：改写方程

```
Av = λv
Av - λv = 0
(A - λI)v = 0
```

**步骤 2**：要有非零解 v，必须 det(A - λI) = 0

```
A - λI = | 3-λ  1  |
         | 1   3-λ |

det(A - λI) = (3-λ)² - 1 = 0
(3-λ)² = 1
3-λ = ±1

解得：λ₁ = 4, λ₂ = 2
```

**步骤 3**：求对应的特征向量

对于 λ₁ = 4：
```
(A - 4I)v = 0
| -1  1 |   | x |   | 0 |
| 1  -1 | × | y | = | 0 |

得到：-x + y = 0 → y = x
特征向量：v₁ = [1, 1]（或任何倍数）
```

对于 λ₂ = 2：
```
(A - 2I)v = 0
| 1  1 |   | x |   | 0 |
| 1  1 | × | y | = | 0 |

得到：x + y = 0 → y = -x
特征向量：v₂ = [1, -1]
```

---

### 验证

```
A × v₁ = | 3  1 |   | 1 |   | 4 |   = 4 × v₁ ✓
         | 1  3 | × | 1 | = | 4 |

A × v₂ = | 3  1 |   | 1  |   | 2  |   = 2 × v₂ ✓
         | 1  3 | × | -1 | = | -2 |
```

---

## 📖 核心概念详解

### 1. 特征值与特征向量的定义

**定义**：对于 n×n 矩阵 A，如果存在非零向量 v 和数 λ，使得：

```
A × v = λ × v
```

则：
- λ 是 A 的**特征值**
- v 是对应的**特征向量**

---

### 2. 特征值的几何意义

特征值表示特征向量方向的**缩放倍数**：

| 特征值 λ | 几何意义 |
|----------|----------|
| λ > 1 | 沿该方向拉伸 |
| λ = 1 | 长度不变 |
| 0 < λ < 1 | 沿该方向压缩 |
| λ = 0 | 压扁到原点（该方向消失） |
| λ < 0 | 方向翻转 + 缩放 |

---

### 3. 特征向量的性质

**重要性质**：

1. **特征向量不唯一**：v 和 kv（k≠0）都是同一特征值对应的特征向量
2. **通常归一化**：取单位特征向量（长度为 1）
3. **不同特征值的特征向量线性无关**
4. **对称矩阵的特征向量正交**（点积为 0）

---

### 4. 特征分解（对角化）

如果 n×n 矩阵 A 有 n 个线性无关的特征向量，则：

```
A = PDP⁻¹

其中：
- D 是对角矩阵，对角线是特征值
- P 的列是对应的特征向量
```

```
     | ↑   ↑       ↑ |   | λ₁  0   ...  0  |
P =  | v₁  v₂  ...  vₙ |, D = | 0   λ₂  ...  0  |
     | ↓   ↓       ↓ |   | ... ...  ... ... |
                      | 0   0   ...  λₙ |
```

---

### 5. 特征分解的应用

#### 快速计算矩阵的幂

```
A² = (PDP⁻¹)(PDP⁻¹) = PD²P⁻¹
A³ = PD³P⁻¹
...
Aᵏ = PDᵏP⁻¹

而 Dᵏ 很容易计算（对角线元素的 k 次幂）！
```

---

#### 理解变换的本质

任何线性变换都可以理解为：
1. 用 P⁻¹ 变换到特征向量坐标系
2. 用 D 沿各特征方向独立缩放
3. 用 P 变换回原坐标系

---

### 6. 特殊矩阵的特征值

| 矩阵类型 | 特征值特点 |
|----------|------------|
| 对角矩阵 | 对角线元素 |
| 三角矩阵 | 对角线元素 |
| 对称矩阵 | 全是实数，特征向量正交 |
| 正交矩阵 | 绝对值为 1 |
| 奇异矩阵 | 至少一个特征值为 0 |

## 💻 代码实现

```python
import numpy as np

# ==================== 特征值与特征向量计算 ====================

print("="*50)
print("特征值与特征向量计算")
print("="*50)

A = np.array([[3, 1],
              [1, 3]])

eigenvalues, eigenvectors = np.linalg.eig(A)

print(f"\n矩阵 A：\n{A}")
print(f"\n特征值：{eigenvalues}")
print(f"\n特征向量（列向量）：\n{eigenvectors}")

# 验证：Av = λv
print("\n" + "="*50)
print("验证特征方程 Av = λv")
print("="*50)

for i in range(len(eigenvalues)):
    λ = eigenvalues[i]
    v = eigenvectors[:, i]
    
    Av = A @ v
    λv = λ * v
    
    print(f"\n特征值 λ{i+1} = {λ:.4f}")
    print(f"特征向量 v{i+1} = {v}")
    print(f"Av = {Av}")
    print(f"λv = {λv}")
    print(f"相等：{np.allclose(Av, λv)}")  # True ✓

# ==================== 特征分解 ====================

print("\n" + "="*50)
print("特征分解：A = PDP⁻¹")
print("="*50)

P = eigenvectors  # 特征向量矩阵
D = np.diag(eigenvalues)  # 对角特征值矩阵
P_inv = np.linalg.inv(P)

print(f"\nP (特征向量矩阵)：\n{P}")
print(f"\nD (对角矩阵)：\n{D}")
print(f"\nP⁻¹：\n{P_inv}")

# 验证：PDP⁻¹ = A
A_reconstructed = P @ D @ P_inv
print(f"\nPDP⁻¹ = \n{A_reconstructed}")
print(f"\n原始 A = \n{A}")
print(f"\n相等：{np.allclose(A_reconstructed, A)}")  # True ✓

# ==================== 矩阵的幂 ====================

print("\n" + "="*50)
print("用特征分解计算矩阵的幂")
print("="*50)

# 直接计算
A_squared = A @ A
A_cubed = A @ A @ A

# 用特征分解
D_squared = D @ D
D_cubed = D @ D @ D

A_squared_eig = P @ D_squared @ P_inv
A_cubed_eig = P @ D_cubed @ P_inv

print(f"\nA²（直接计算）：\n{A_squared}")
print(f"A²（特征分解）：\n{A_squared_eig.round(10)}")
print(f"相等：{np.allclose(A_squared, A_squared_eig)}")

print(f"\nA³（直接计算）：\n{A_cubed}")
print(f"A³（特征分解）：\n{A_cubed_eig.round(10)}")
print(f"相等：{np.allclose(A_cubed, A_cubed_eig)}")

# ==================== 对称矩阵的特殊性质 ====================

print("\n" + "="*50)
print("对称矩阵：特征值为实数，特征向量正交")
print("="*50)

# 对称矩阵
S = np.array([[2, 1],
              [1, 2]])

eigenvalues_S, eigenvectors_S = np.linalg.eig(S)

print(f"\n对称矩阵 S：\n{S}")
print(f"\n特征值：{eigenvalues_S}")
print(f"（都是实数 ✓）")

# 验证特征向量正交
v1 = eigenvectors_S[:, 0]
v2 = eigenvectors_S[:, 1]

dot_product = np.dot(v1, v2)
print(f"\n特征向量 v1 = {v1}")
print(f"特征向量 v2 = {v2}")
print(f"点积 v1·v2 = {dot_product:.10f}")
print(f"（接近 0，说明正交 ✓）")

# ==================== Google PageRank 示例 ====================

print("\n" + "="*50)
print("应用示例：PageRank 算法的核心")
print("="*50)

# 简化的链接矩阵（3 个网页）
# 网页 1 → 网页 2, 网页 3
# 网页 2 → 网页 3
# 网页 3 → 网页 1

M = np.array([[0, 0, 1],    # 网页 1 从谁获得链接
              [1, 0, 0],    # 网页 2 从谁获得链接
              [1, 1, 0]])   # 网页 3 从谁获得链接

# 归一化（每列和为 1）
M = M / M.sum(axis=0)

eigenvalues, eigenvectors = np.linalg.eig(M)

print(f"\n链接矩阵：\n{M}")
print(f"\n特征值：{eigenvalues}")

# 主特征值（最接近 1 的）对应的特征向量就是 PageRank
main_idx = np.argmax(np.real(eigenvalues))
pagerank = np.real(eigenvectors[:, main_idx])
pagerank = pagerank / pagerank.sum()  # 归一化为概率

print(f"\nPageRank 向量：{pagerank}")
print(f"网页重要性排序：网页{np.argmax(pagerank)+1} > ...")

# ==================== 协方差矩阵的特征分解 ====================

print("\n" + "="*50)
print("应用示例：协方差矩阵与 PCA")
print("="*50)

# 生成一些相关数据
np.random.seed(42)
data = np.random.multivariate_normal(
    mean=[0, 0],
    cov=[[2, 1], [1, 1]],  # 协方差矩阵
    size=1000
)

# 计算协方差矩阵
cov_matrix = np.cov(data.T)
print(f"\n数据协方差矩阵：\n{cov_matrix}")

# 特征分解
eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)

print(f"\n特征值：{eigenvalues}")
print(f"特征向量：\n{eigenvectors}")

# 特征值表示各方向的方差
print(f"\n第一主成分方向方差：{eigenvalues[0]:.4f}")
print(f"第二主成分方向方差：{eigenvalues[1]:.4f}")
print(f"（特征值大的方向是数据的主要变化方向）")
```

## 🔗 与 AI 的联系

### 1. 主成分分析（PCA）

PCA 的核心就是协方差矩阵的特征分解：

```
1. 计算数据协方差矩阵 Σ
2. 特征分解：Σ = PDP⁻¹
3. 特征值大的特征向量 = 主成分方向
4. 用前 k 个特征向量做降维
```

---

### 2. 谱聚类

谱聚类使用图拉普拉斯矩阵的特征向量进行聚类：

```
1. 构建相似度图
2. 计算拉普拉斯矩阵 L
3. 求 L 的前 k 个特征向量
4. 对特征向量做 k-means 聚类
```

---

### 3. 矩阵分解推荐系统

奇异值分解（SVD）是特征分解的推广：

```
用户 - 物品矩阵 = U × Σ × Vᵀ

用前 k 个奇异值近似，实现降维和推荐
```

---

### 4. 神经网络的初始化

Xavier/He 初始化考虑了权重矩阵的特征值分布，避免梯度消失/爆炸。

---

### 5. PageRank 算法

Google 的核心算法：网页重要性 = 链接矩阵的主特征向量！

## 🧠 常见误区

### ❌ 误区 1：所有矩阵都有特征分解

**纠正**：只有 n 个线性无关特征向量的矩阵才能对角化。

有些矩阵（如 | 1  1 |
              | 0  1 |）不能对角化，需要用若尔当标准型。

---

### ❌ 误区 2：特征向量是唯一的

**纠正**：特征向量可以缩放！v 和 2v、-v 都是同一特征值的特征向量。

通常取**单位特征向量**（长度为 1）。

---

### ❌ 误区 3：特征值必须是实数

**纠正**：实矩阵的特征值可能是复数！

例如旋转矩阵：
```
R = | 0  -1 |
    | 1   0 |

特征值：λ = ±i（虚数）
```

但**对称矩阵**的特征值一定是实数。

```python
def matrix_power_eig(A, n):
    eigenvalues, eigenvectors = np.linalg.eig(A)
    P = eigenvectors
    D_n = np.diag(eigenvalues ** n)
    P_inv = np.linalg.inv(P)
    return P @ D_n @ P_inv
```
