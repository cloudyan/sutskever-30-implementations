## 📖 期望：随机变量的"中心"

### 直观理解

**期望（Expectation）** 是随机变量取值的"平均水平"。

想象你掷骰子很多次：
- 每次结果：1, 2, 3, 4, 5, 6
- 长期平均：(1+2+3+4+5+6)/6 = 3.5

**3.5 就是期望**，虽然你永远掷不出 3.5，但它是"理论平均值"。

### 数学定义

#### 离散型随机变量

```
E[X] = Σ xᵢ × P(X = xᵢ)

读作：每个取值 × 对应概率，然后求和
```

**例子**：掷骰子
```
E[X] = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
     = (1+2+3+4+5+6)/6
     = 3.5
```

#### 连续型随机变量

```
E[X] = ∫ x × f(x) dx

f(x) 是概率密度函数
```

### 期望的线性性质 ⭐ 超级重要

```
E[aX + b] = a×E[X] + b
E[X + Y] = E[X] + E[Y]  （无论 X, Y 是否独立！）
```

这个性质在 AI 中无处不在！

### Python 实现

```python
import numpy as np
from scipy.stats import bernoulli, binom, poisson

# 1. 离散型：伯努利分布
p = 0.7
expected = 0 * (1-p) + 1 * p  # 手动计算
print(f"伯努利分布期望 (p={p}): {expected}")

# 用样本估计
samples = bernoulli.rvs(p, size=10000)
print(f"样本均值：{samples.mean():.3f}")

# 2. 二项分布
n, p = 10, 0.5
expected = n * p  # 理论值
samples = binom.rvs(n, p, size=10000)
print(f"二项分布期望：理论={expected}, 样本={samples.mean():.3f}")

# 3. 泊松分布
lambda_ = 3
samples = poisson.rvs(lambda_, size=10000)
print(f"泊松分布期望：理论={lambda_}, 样本={samples.mean():.3f}")
```

## 📐 方差：随机变量的"离散程度"

### 直观理解

**方差（Variance）** 描述随机变量偏离期望的程度。

想象两个射手：
- **射手 A**：每次都射中 9 环附近（方差小）
- **射手 B**：有时 10 环，有时 5 环（方差大）

虽然平均都是 9 环，但**稳定性完全不同**！

### 数学定义

```
Var(X) = E[(X - E[X])²]

读作：偏离期望的平方 的期望
```

展开后有个更方便的公式：
```
Var(X) = E[X²] - (E[X])²

读作：平方的期望 减去 期望的平方
```

**标准差（Standard Deviation）**：
```
σ = √Var(X)

方差的平方根，和原变量同单位
```

### 为什么用平方？

1. **避免正负抵消**：(X - E[X]) 有正有负，平方后都是正的
2. **数学友好**：平方可导，方便优化
3. **放大极端值**：大的偏离会被更重视

### 方差的性质

```
Var(aX + b) = a² × Var(X)  # 常数 b 不影响方差
Var(X + Y) = Var(X) + Var(Y)  # 仅当 X, Y 独立时成立
```

### Python 实现

```python
import numpy as np
from scipy.stats import norm

# 1. 手动计算方差
data = [1, 2, 3, 4, 5]
mean = np.mean(data)
variance = np.mean((data - mean) ** 2)
std = np.sqrt(variance)

print(f"均值：{mean}")
print(f"方差：{variance}")
print(f"标准差：{std:.3f}")

# 2. 用 numpy 直接计算
print(f"np.var: {np.var(data)}")
print(f"np.std: {np.std(data):.3f}")

# 3. 正态分布
mu, sigma = 0, 2
samples = np.random.normal(mu, sigma, 10000)

print(f"\n正态分布 N({mu}, {sigma}²):")
print(f"理论方差：{sigma**2}")
print(f"样本方差：{samples.var():.3f}")
print(f"理论标准差：{sigma}")
print(f"样本标准差：{samples.std():.3f}")
```

## 📊 常见分布的期望和方差

### 离散分布

| 分布 | 期望 E[X] | 方差 Var(X) |
|------|-----------|-------------|
| 伯努利 (p) | p | p(1-p) |
| 二项 (n, p) | np | np(1-p) |
| 泊松 (λ) | λ | λ |
| 几何 (p) | 1/p | (1-p)/p² |
| 均匀 (a, b) | (a+b)/2 | ((b-a+1)²-1)/12 |

### 连续分布

| 分布 | 期望 E[X] | 方差 Var(X) |
|------|-----------|-------------|
| 均匀 (a, b) | (a+b)/2 | (b-a)²/12 |
| 正态 (μ, σ²) | μ | σ² |
| 指数 (λ) | 1/λ | 1/λ² |
| t (ν) | 0 (ν>1) | ν/(ν-2) (ν>2) |
| 卡方 (k) | k | 2k |

## 💡 期望和方差的直观理解

### 期望的"物理意义"

把概率分布想象成一个**质量分布**：
- 期望 = 重心位置
- 方差 = 转动惯量（质量离重心的距离）

```
      ▲
      │     ▓▓
      │   ▓▓▓▓▓
      │ ▓▓▓▓▓▓▓▓
──────┼─────────────► x
      │     ↑
      │   重心 = 期望
```

### 标准差的"经验法则"

对于**近似正态分布**的数据：

```
μ ± σ   包含约 68% 的数据
μ ± 2σ  包含约 95% 的数据
μ ± 3σ  包含约 99.7% 的数据
```

这就是著名的 **68-95-99.7 规则**。

## 🎯 实战应用

### 应用 1：投资组合分析

```python
import numpy as np

# 两个资产的收益率
asset_A = np.array([0.05, 0.08, -0.02, 0.10, 0.03])
asset_B = np.array([0.04, 0.04, 0.05, 0.03, 0.04])

print("资产 A:")
print(f"  期望收益：{asset_A.mean():.2%}")
print(f"  风险 (std): {asset_A.std():.2%}")

print("\n资产 B:")
print(f"  期望收益：{asset_B.mean():.2%}")
print(f"  风险 (std): {asset_B.std():.2%}")

# 结论：A 收益高但风险大，B 收益低但稳定
```

### 应用 3：A/B 测试样本量估算

```python
from scipy.stats import norm

# 假设我们想检测 5% 的提升
baseline_conversion = 0.10  # 基准转化率 10%
min_detectable_effect = 0.05  # 最小检测效应 5%

# 使用正态近似估算样本量
# 公式：n = 16 × σ² / δ²  (经验法则)
sigma = np.sqrt(baseline_conversion * (1 - baseline_conversion))
delta = baseline_conversion * min_detectable_effect

n_per_group = 16 * (sigma ** 2) / (delta ** 2)
print(f"每组需要样本量：{n_per_group:.0f}")
print(f"总样本量：{n_per_group * 2:.0f}")
```

### 练习 2：比较不同分布的方差

```python
from scipy.stats import bernoulli, binom, poisson, norm

# 生成不同分布的样本
distributions = {
    '伯努利 (p=0.5)': bernoulli.rvs(0.5, 10000),
    '二项 (n=10, p=0.5)': binom.rvs(10, 0.5, 10000),
    '泊松 (λ=5)': poisson.rvs(5, 10000),

for name, samples in distributions.items():
    print(f"{name}:")
    print(f"  期望：{samples.mean():.3f}")
    print(f"  方差：{samples.var():.3f}")
    print(f"  标准差：{samples.std():.3f}")
    print()
```

### 练习 3：切比雪夫不等式验证

切比雪夫不等式：**任意分布**都满足
```
P(|X - μ| ≥ kσ) ≤ 1/k²
```

```python
import numpy as np

# 用任意分布验证（这里用泊松分布）
lambda_ = 5
samples = np.random.poisson(lambda_, 100000)

mu = samples.mean()
sigma = samples.std()

for k in [1, 2, 3]:
    # 计算实际比例
    outlier_mask = np.abs(samples - mu) >= k * sigma
    actual_prob = outlier_mask.mean()
    
    # 切比雪夫上界
    chebyshev_bound = 1 / (k ** 2)
    
    print(f"k={k}: 实际比例={actual_prob:.4f}, 切比雪夫上界={chebyshev_bound:.4f}")
    print(f"  验证：{actual_prob:.4f} ≤ {chebyshev_bound:.4f} ✓")
```

## 🔗 与 AI 的联系

### 1. 损失函数

**均方误差 (MSE)** 本质上就是方差：
```
MSE = E[(y - ŷ)²] = 方差 + 偏差²
```

这就是著名的 **偏差 - 方差分解**！

### 2. 批归一化 (Batch Normalization)

```
x_normalized = (x - μ) / σ

减去均值，除以标准差，让数据标准化
```

### 3. 权重初始化

```
Xavier 初始化：W ~ N(0, 1/n_in)
He 初始化：W ~ N(0, 2/n_in)

方差的选择影响梯度流动！
```

### 4. 不确定性量化

```
预测 = 均值
置信区间 = 均值 ± 2×标准差
```

## ✅ 小结

### 核心要点

1. **期望** = 长期平均值，描述"中心位置"
2. **方差** = 偏离期望的平方的平均，描述"离散程度"
3. **标准差** = 方差的平方根，和原变量同单位
4. **期望的线性性质**：E[X+Y] = E[X] + E[Y]（无条件成立！）
5. **方差的性质**：Var(X+Y) = Var(X) + Var(Y)（仅当独立时）

### 常见分布的期望和方差

记住这几个最常用的：
- 伯努利：E=p, Var=p(1-p)
- 二项：E=np, Var=np(1-p)
- 泊松：E=λ, Var=λ
- 正态：E=μ, Var=σ²
