## 一、为什么凸优化如此重要？

### 1.1 优化问题的"圣杯"

**一般优化问题**：
```
minimize: f(x)

可能有很多局部最优解 ●
                    ╱│╲
                   ╱ │ ╲
              ●──╱  │  ╲──●  哪个是最优？
             ╱    ╱ │ ╲    ╲
            ●───╱──●──╲───●
           局部  全局  局部
```

**凸优化问题**：
```
minimize: f(x)  (f 是凸函数)

           ●
          ╱ ╲
         ╱   ╲
        ╱     ╲
       ●───────●
      只有一个最优解！
```

### 1.2 核心定理

> **凸优化黄金定理**：对于凸优化问题，**任何局部最优解都是全局最优解**。

**这意味着**：
- ✅ 梯度下降找到的一定是最优解
- ✅ 不用担心陷入局部最优
- ✅ 算法收敛性有保证
- ✅ 数值求解高效可靠

### 1.3 机器学习中的凸优化

| 算法 | 是否凸优化 | 说明 |
|------|-----------|------|
| **线性回归** | ✅ 凸 | 最小二乘是凸问题 |
| **逻辑回归** | ✅ 凸 | 对数损失是凸函数 |
| **SVM** | ✅ 凸 | 对偶问题是凸二次规划 |
| **Lasso/Ridge** | ✅ 凸 | 带正则化的线性模型 |
| **神经网络** | ❌ 非凸 | 多层网络是非凸的 |
| **K-Means** | ❌ 非凸 | 有多个局部最优 |

**关键洞察**：即使深度学习是非凸的，理解凸优化仍然是基础！

## 二、凸集（Convex Sets）

### 2.1 定义

**凸集**：集合 C 中任意两点的连线仍在 C 内

```
数学定义：
∀x, y ∈ C, ∀θ ∈ [0, 1],  θx + (1-θ)y ∈ C

通俗理解：
集合中任意两点之间的线段完全在集合内
```

**图示**：
```
凸集：          非凸集：
  ●────●          ●────●
  │    │          │    │
  ●────●          ●    ●
  凸四边形         凹字形（连线穿出）
```

### 2.2 常见凸集

| 集合 | 数学表示 | 是否凸 |
|------|---------|-------|
| **直线/平面** | {x | Ax = b} | ✅ |
| **半空间** | {x | aᵀx ≤ b} | ✅ |
| **超立方体** | {x | l ≤ x ≤ u} | ✅ |
| **球/椭球** | {x | ‖x‖ ≤ r} | ✅ |
| **多面体** | 有限个半空间的交集 | ✅ |
| **正定矩阵锥** | {X | X ≻ 0} | ✅ |
| **环形区域** | {x | 1 ≤ ‖x‖ ≤ 2} | ❌ |
| **L 形区域** | 两个矩形的并集 | ❌ |

### 2.3 凸集的运算性质

**凸集经过以下运算仍保持凸性**：

```python
# 1. 交集（任意多个凸集的交集仍是凸集）
C₁, C₂ 凸  →  C₁ ∩ C₂ 凸

# 2. 仿射变换
C 凸  →  {Ax + b | x ∈ C} 凸

# 3. 透视变换
C 凸  →  {(x/t, 1/t) | x ∈ C, t > 0} 凸

# 4. 线性分式变换
C 凸  →  {(Ax+b)/(cᵀx+d) | x ∈ C, cᵀx+d > 0} 凸
```

**注意**：凸集的**并集不一定是凸集**！

## 三、凸函数（Convex Functions）

### 3.1 定义

**凸函数**：函数图像上任意两点的连线在图像上方

```
数学定义：
f 是凸函数 ⟺ 
∀x, y ∈ dom(f), ∀θ ∈ [0, 1],
f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)

几何意义：
函数图像在任意弦的下方
```

**图示**：
```
凸函数：          非凸函数：
     ●               ●   ●
    ╱ ╲             ╱ ╲ ╱ ╲
   ╱   ●           ●   ●   ●
  ╱               ╱
 ●               ●
f(θx+(1-θ)y) ≤ θf(x)+(1-θ)f(y)  ✓
```

### 3.2 一阶条件（可微函数）

**定理**：可微函数 f 是凸的 ⟺

```
f(y) ≥ f(x) + ∇f(x)ᵀ(y - x),  ∀x, y

几何意义：
切线（或切平面）总是在函数图像下方
```

**图示**：
```
        函数 f(x)
       ╱
      ╱
     ●─────── 切线（始终在下方）
    ╱
   ╱
```

### 3.3 二阶条件（二阶可微函数）

**定理**：二阶可微函数 f 是凸的 ⟺

```
∇²f(x) ≽ 0,  ∀x ∈ dom(f)

即：Hessian 矩阵半正定
```

**一元函数特例**：
```
f''(x) ≥ 0  →  f 是凸函数
```

**例子**：
| 函数 | 二阶导数 | 是否凸 |
|------|---------|-------|
| f(x) = x² | f''(x) = 2 ≥ 0 | ✅ |
| f(x) = eˣ | f''(x) = eˣ > 0 | ✅ |
| f(x) = log(x) | f''(x) = -1/x² < 0 | ❌ (凹函数) |
| f(x) = |x| | 不可微，但是一阶条件满足 | ✅ |

### 3.4 常见凸函数

| 函数 | 定义域 | 说明 |
|------|-------|------|
| **仿射函数** | ℝⁿ | f(x) = aᵀx + b |
| **指数函数** | ℝ | eᵃˣ |
| **幂函数** | ℝ₊₊ | xᵅ (α ≥ 1 或 α ≤ 0) |
| **绝对值** | ℝ | |x| |
| **范数** | ℝⁿ | ‖x‖ (任何范数) |
| **最大值函数** | ℝⁿ | f(x) = max(x₁, ..., xₙ) |
| **二次函数** | ℝⁿ | f(x) = ½xᵀPx + qᵀx + r (P ≽ 0) |
| **负对数** | ℝ₊₊ | -log(x) |
| **相对熵** | ℝ₊₊² | x log(x/y) |
| **逻辑损失** | ℝ | log(1 + e⁻ˣ) |

### 3.5 凸函数的运算性质

**以下运算保持凸性**：

```python
# 1. 非负加权和
f₁, f₂ 凸，α, β ≥ 0  →  αf₁ + βf₂ 凸

# 2. 仿射复合
f 凸  →  f(Ax + b) 凸

# 3. 逐点最大值
f₁, ..., fₙ 凸  →  max(f₁, ..., fₙ) 凸

# 4. 与线性函数复合
f 凸，g 线性  →  f(g(x)) 凸

# 5. 透视函数
f 凸  →  tf(x/t) 凸 (t > 0)
```

**例子**：
```python
# 逻辑回归的损失函数
L(w) = Σ log(1 + exp(-yᵢwᵀxᵢ))

# 为什么是凸的？
# 1. log(1 + e⁻ˣ) 是凸函数
# 2. -yᵢwᵀxᵢ 是 w 的仿射函数
# 3. 凸函数 + 仿射复合 = 凸函数
# 4. 非负求和 = 凸函数 ✓
```

## 四、凸优化问题

### 4.1 标准形式

**凸优化问题**：
```
minimize:     f₀(x)
subject to:   fᵢ(x) ≤ 0,  i = 1, ..., m
              aⱼᵀx = bⱼ, j = 1, ..., p

其中：
- f₀, f₁, ..., fₘ 是凸函数
- 等式约束是仿射的
```

**关键要求**：
- ✅ 目标函数是凸的（最小化）
- ✅ 不等式约束函数是凸的（定义凸可行域）
- ✅ 等式约束必须是仿射的

### 4.2 为什么等式约束必须是仿射的？

```
等式约束 h(x) = 0 定义了一个集合 {x | h(x) = 0}

如果 h 是非线性凸函数：
  h(x) = x² - 1 = 0  →  x = ±1
  集合 {-1, 1} 不是凸集！❌

如果 h 是仿射函数：
  h(x) = ax - b = 0  →  x = b/a
  集合是单点或超平面，是凸集 ✓
```

### 4.3 可行域是凸集

**定理**：凸优化问题的可行域是凸集

```
证明：
- 不等式约束：{x | fᵢ(x) ≤ 0} 是凸集（凸函数的下水平集）
- 等式约束：{x | aⱼᵀx = bⱼ} 是凸集（仿射集合）
- 有限个凸集的交集是凸集 ✓
```

## 五、常见凸优化问题类型

### 5.1 线性规划（LP）

```
minimize:     cᵀx
subject to:   Ax ≤ b
              Aeq x = beq

特点：
- 目标和约束都是线性的
- 求解非常高效（单纯形法、内点法）
- 应用：资源分配、生产计划、运输问题
```

**例子**：生产计划
```python
# 最大化利润
maximize: 3x₁ + 5x₂

# 约束
subject to:
  x₁ + 2x₂ ≤ 100  (原材料)
  3x₁ + x₂ ≤ 90   (工时)
  x₁, x₂ ≥ 0      (非负)
```

### 5.2 二次规划（QP）

```
minimize:     ½xᵀPx + qᵀx + r
subject to:   Ax ≤ b
              Aeq x = beq

其中 P ≽ 0 (半正定)

特点：
- 目标是凸二次函数，约束是线性的
- 应用：投资组合优化、模型预测控制、SVM
```

**例子**：投资组合优化
```python
# 最小化风险（方差）
minimize: ½xᵀΣx

# 约束
subject to:
  μᵀx ≥ R_target  (期望收益)
  1ᵀx = 1         (预算约束)
  x ≥ 0           (不允许做空)
```

### 5.3 二次约束二次规划（QCQP）

```
minimize:     ½xᵀP₀x + q₀ᵀx + r₀
subject to:   ½xᵀPᵢx + qᵢᵀx + rᵢ ≤ 0,  i = 1, ..., m
              Ax = b

其中 P₀, P₁, ..., Pₘ ≽ 0

特点：
- 目标和约束都是凸二次函数
- 应用：鲁棒优化、信号处理
```

### 5.4 半定规划（SDP）

```
minimize:     cᵀx
subject to:   x₁F₁ + x₂F₂ + ... + xₙFₙ ≼ G

其中 Fᵢ, G 是对称矩阵，≼ 表示半正定序

特点：
- 变量是矩阵，约束是矩阵半正定
- 应用：控制理论、组合优化、量子信息
```

### 5.5 几何规划（GP）

```
minimize:     f₀(x)
subject to:   fᵢ(x) ≤ 1,  i = 1, ..., m
              hⱼ(x) = 1,  j = 1, ..., p

其中 fᵢ 是正项式，hⱼ 是单项式

特点：
- 通过对数变换可转化为凸优化
- 应用：电路设计、机械工程、化学平衡
```

## 六、凸优化在机器学习中的应用

### 6.1 线性回归（最小二乘）

```python
# 问题
minimize: ||Xw - y||²

# 展开
minimize: (Xw - y)ᵀ(Xw - y)
        = wᵀXᵀXw - 2yᵀXw + yᵀy

# 这是凸二次函数（XᵀX ≽ 0）
# 闭式解：w* = (XᵀX)⁻¹Xᵀy
```

### 6.2 逻辑回归

```python
# 问题
minimize: -Σ[yᵢlog(pᵢ) + (1-yᵢ)log(1-pᵢ)]
其中 pᵢ = σ(wᵀxᵢ) = 1/(1 + e^(-wᵀxᵢ))

# 等价于
minimize: Σ log(1 + e^(-yᵢwᵀxᵢ))

# 这是凸函数（对数损失是凸的）
```

### 6.3 支持向量机（SVM）

```python
# 原始问题（凸二次规划）
minimize: ½||w||²
subject to: yᵢ(wᵀxᵢ + b) ≥ 1, ∀i

# 对偶问题（也是凸二次规划）
maximize: Σαᵢ - ½ΣΣαᵢαⱼyᵢyⱼxᵢᵀxⱼ
subject to: αᵢ ≥ 0, Σαᵢyᵢ = 0
```

### 6.4 Lasso 与 Ridge 回归

```python
# Ridge 回归（L2 正则化）
minimize: ||Xw - y||² + λ||w||₂²
# 凸二次规划

# Lasso（L1 正则化）
minimize: ||Xw - y||² + λ||w||₁
# 凸优化（但不可微，需特殊算法）
```

### 6.5 软间隔 SVM（铰链损失）

```python
# 问题
minimize: ½||w||² + CΣξᵢ
subject to: yᵢ(wᵀxᵢ + b) ≥ 1 - ξᵢ
            ξᵢ ≥ 0

# 这是凸二次规划
```

## 七、如何判断问题是凸的？

### 7.1 检查清单

```
□ 1. 目标函数 f₀(x) 是凸函数吗？
   - 检查二阶导数/Hessian
   - 或用已知凸函数的运算性质

□ 2. 不等式约束 fᵢ(x) ≤ 0 中的 fᵢ 是凸函数吗？
   - 同上

□ 3. 等式约束是仿射的吗？
   - 必须是 Ax = b 形式

□ 4. 可行域是凸集吗？
   - 如果不满足上面三条，可行域可能非凸
```

### 7.2 常见陷阱

| 问题 | 是否凸 | 原因 |
|------|-------|------|
| minimize -f(x), f 凸 | ❌ | 最大化凸函数 = 最小化凹函数 |
| f(x) ≥ 0, f 凸 | ❌ | 凸函数的上水平集不一定凸 |
| h(x) = 0, h 非线性 | ❌ | 等式约束必须仿射 |
| x ∈ C₁ ∪ C₂, C₁,C₂凸 | ❌ | 凸集的并集不一定凸 |

### 7.3 转化技巧

**非凸问题 → 凸问题**：

```python
# 1. 变量替换
minimize: 1/x  (x > 0, 非凸)
令 y = 1/x → minimize: y (凸)

# 2. 对数变换（几何规划）
minimize: x₁² + x₂²  (x₁,x₂ > 0)
令 yᵢ = log(xᵢ) → 转化为凸问题

# 3. 松弛
minimize: ||x||₀  (L0 范数，非凸)
→ minimize: ||x||₁  (L1 范数，凸松弛)
```

## 八、Python 实战

### 8.1 使用 CVXPY 求解凸优化

```python
import cvxpy as cp
import numpy as np

# 例子：带约束的二次优化
# minimize: ||Ax - b||²
# subject to: x ≥ 0, sum(x) = 1

n = 10
A = np.random.randn(n, n)
b = np.random.randn(n)

# 定义变量
x = cp.Variable(n)

# 定义目标
objective = cp.Minimize(cp.sum_squares(A @ x - b))

# 定义约束
constraints = [
    x >= 0,
    cp.sum(x) == 1
]

# 构造并求解问题
problem = cp.Problem(objective, constraints)
result = problem.solve()

print(f"最优值：{result:.4f}")
print(f"最优解：{x.value}")
```

### 8.2 逻辑回归的凸优化实现

```python
import cvxpy as cp
import numpy as np

def logistic_regression_cvx(X, y, lambda_reg=0.01):
    """
    用凸优化求解逻辑回归
    X: 样本矩阵 (n_samples, n_features)
    y: 标签 (+1 或 -1)
    """
    n_samples, n_features = X.shape
    
    # 变量
    w = cp.Variable(n_features)
    b = cp.Variable()
    
    # 目标：最小化对数损失 + 正则化
    objective = cp.Minimize(
        cp.sum(cp.logistic(cp.multiply(y, X @ w + b))) +
        lambda_reg * cp.norm(w, 2)
    )
    
    # 求解
    problem = cp.Problem(objective)
    problem.solve()
    
    return w.value, b.value

# 测试
X = np.random.randn(100, 10)
y = np.random.choice([-1, 1], 100)

w, b = logistic_regression_cvx(X, y)
print(f"权重：{w}")
print(f"偏置：{b}")
```

### 8.3 投资组合优化

```python
import cvxpy as cp
import numpy as np

def portfolio_optimization(mu, Sigma, R_target, risk_free=False):
    """
    投资组合优化
    mu: 期望收益向量
    Sigma: 协方差矩阵
    R_target: 目标收益
    """
    n = len(mu)
    
    # 变量：各资产权重
    w = cp.Variable(n)
    
    # 目标：最小化风险（方差）
    risk = cp.quad_form(w, Sigma)
    objective = cp.Minimize(risk)
    
    # 约束
    constraints = [
        mu @ w >= R_target,  # 期望收益
        cp.sum(w) == 1,       # 预算约束
    ]
    
    if not risk_free:
        constraints.append(w >= 0)  # 不允许做空
    
    # 求解
    problem = cp.Problem(objective, constraints)
    problem.solve()
    
    return w.value, risk.value

# 测试数据
mu = np.array([0.10, 0.15, 0.12])  # 期望收益
Sigma = np.array([
    [0.04, 0.01, 0.02],
    [0.01, 0.09, 0.03],
    [0.02, 0.03, 0.06]
])

w, risk = portfolio_optimization(mu, Sigma, R_target=0.12)
print(f"最优权重：{w}")
print(f"最小风险：{risk:.6f}")
print(f"期望收益：{mu @ w:.4f}")
```

## 十、核心要点总结

### 📌 关键定义

```python
# 凸集
∀x, y ∈ C, ∀θ ∈ [0, 1], θx + (1-θ)y ∈ C

# 凸函数
f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)

# 凸优化标准形式
minimize: f₀(x)
subject to: fᵢ(x) ≤ 0 (fᵢ 凸)
           Ax = b (仿射)
```

### 📌 核心定理

| 定理 | 内容 |
|------|------|
| **局部最优 = 全局最优** | 凸优化问题的任何局部最优都是全局最优 |
| **一阶条件** | f 凸 ⟺ f(y) ≥ f(x) + ∇f(x)ᵀ(y-x) |
| **二阶条件** | f 凸 ⟺ ∇²f(x) ≽ 0 |
| **可行域凸性** | 凸优化问题的可行域是凸集 |

### 📌 常见凸问题

| 类型 | 目标 | 约束 |
|------|------|------|
| LP | 线性 | 线性 |
| QP | 凸二次 | 线性 |
| QCQP | 凸二次 | 凸二次 |
| SDP | 线性 | 半定矩阵 |

### 📌 实践建议

```
1. 先判断问题是否凸（用检查清单）
2. 如果是凸的，用 CVXPY 等工具直接求解
3. 如果非凸，尝试转化为凸问题（松弛、变换）
4. 机器学习模型优先选择凸损失函数
```
