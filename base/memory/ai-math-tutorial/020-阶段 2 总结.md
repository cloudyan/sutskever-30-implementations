## 💡 关键洞察

### 1. 微积分是 AI 的"学习引擎"

```
损失函数 L(θ)
  ↓
求梯度 ∇L(θ)
  ↓
更新参数 θ = θ - α∇L(θ)
  ↓
重复直到收敛
```

**没有微积分，就没有梯度下降；没有梯度下降，就没有深度学习**。

---

### 2. 链式法则是反向传播的核心

神经网络反向传播：
```
∂L/∂w = ∂L/∂y · ∂y/∂z · ∂z/∂w
```

每一层只是链式法则的一环！

---

### 3. 优化算法的演进

| 算法 | 核心思想 | 优点 | 缺点 |
|------|----------|------|------|
| GD | 全量梯度 | 稳定 | 慢 |
| SGD | 单样本梯度 | 快 | 波动大 |
| Momentum | 惯性加速 | 抑制震荡 | 需调动量参数 |
| Adam | 动量 + 自适应 | 收敛快 | 可能过拟合 |

---

### 4. 凸优化是"理想情况"

- 凸函数：任意两点连线在函数上方
- 凸优化：局部最优 = 全局最优
- 深度学习：非凸，但 SGD 能找到"足够好"的解

### 测试题 2：梯度计算

```
f(x, y) = x²y + 3xy²

求梯度 ∇f = ?
```

<details>
<summary>点击查看答案</summary>

```
∂f/∂x = 2xy + 3y²
∂f/∂y = x² + 6xy

∇f = [2xy + 3y², x² + 6xy]
```
</details>

---

### 测试题 3：链式法则

```
z = (x + y)²
x = t²
y = 2t

求 dz/dt = ?
```

<details>
<summary>点击查看答案</summary>

```
dz/dt = ∂z/∂x · dx/dt + ∂z/∂y · dy/dt
      = 2(x+y) · 2t + 2(x+y) · 2
      = 2(t² + 2t) · 2t + 2(t² + 2t) · 2
      = 4t(t² + 2t) + 4(t² + 2t)
      = 4t³ + 8t² + 4t² + 8t
      = 4t³ + 12t² + 8t
```
</details>

---

### 测试题 4：泰勒展开

```
f(x) = e^x 在 x=0 处的二阶泰勒展开是？
```

<details>
<summary>点击查看答案</summary>

```
f(x) ≈ f(0) + f'(0)x + f''(0)x²/2
     = 1 + 1·x + 1·x²/2
     = 1 + x + x²/2
```
</details>

### 测试题 5：梯度下降

```
f(x) = x²，初始 x=3，学习率α=0.1

迭代 3 次后 x = ?
```

<details>

第 1 次：x = 3 - 0.1×6 = 2.4

## 🎓 实战项目

### 项目：用梯度下降拟合多项式

```python
import numpy as np
import matplotlib.pyplot as plt

# 生成数据
np.random.seed(42)
X = np.linspace(-1, 1, 100)
y_true = 3*X**2 - 2*X + 1
y = y_true + np.random.randn(100) * 0.1

# 特征工程：多项式特征
X_poly = np.column_stack([np.ones(100), X, X**2])

# 梯度下降
def loss(w, X, y):
    return np.mean((X @ w - y)**2)

def gradient(w, X, y):
    return 2 * X.T @ (X @ w - y) / len(y)

w = np.random.randn(3)
lr = 0.01
history = []

for i in range(1000):
    w = w - lr * gradient(w, X_poly, y)
    history.append(loss(w, X_poly, y))

# 可视化
plt.figure(figsize=(12, 4))

plt.subplot(1, 2, 1)
plt.scatter(X, y, label='数据')
plt.plot(X, X_poly @ w, 'r-', label='拟合')
plt.plot(X, y_true, 'g--', label='真实')
plt.legend()
plt.title(f'拟合结果 (w={w.round(2)})')

plt.subplot(1, 2, 2)
plt.plot(history)
plt.xlabel('迭代次数')
plt.ylabel('损失')
plt.title('损失下降曲线')
plt.show()
```
