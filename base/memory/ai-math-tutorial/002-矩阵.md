# 002 | 矩阵：数据的组织与变换

> 🎯 **一句话核心**：矩阵是向量的数组，它既能组织数据，又能表示变换——是 AI 中最高效的数学工具。

---

## 🤔 从一个问题开始

### 问题 1：如何同时处理 1000 个用户的数据？

假设你有 1000 个用户，每个用户有 128 个特征（年龄、偏好、行为...）。

**笨办法**：用 1000 个向量，每个向量 128 维，然后写个循环逐个处理。

```python
# 低效的做法
users = [user_1, user_2, ..., user_1000]  # 1000 个向量
for user in users:
    result = transform(user)  # 慢！
```

**聪明的做法**：用一个矩阵，1000 行×128 列，然后一次矩阵运算搞定所有用户！

```python
# 高效的做法
users = np.array([...])  # 1000×128 矩阵
results = users @ W.T    # 一次矩阵乘法，搞定！
```

这就是矩阵的力量：**批量处理**。

---

### 问题 2：如何把一张图片旋转 30 度？

图片的每个像素是一个点 (x, y)。要旋转图片，就是旋转每个点。

**笨办法**：对每个像素用三角函数计算新位置。

```python
for each pixel (x, y):
    x_new = x * cos(30°) - y * sin(30°)
    y_new = x * sin(30°) + y * cos(30°)
```

**聪明的做法**：用一个 2×2 的**旋转矩阵**，一次乘法搞定所有点！

```python
rotation_matrix = [[cos30, -sin30],
                   [sin30,  cos30]]

all_points @ rotation_matrix = rotated_points
```

这就是矩阵的另一个超能力：**表示变换**。

## 📖 核心概念详解

### 1. 什么是矩阵？

#### 定义
矩阵是一个 rectangular array（矩形数组），由行和列组成：

```
A = | a₁₁  a₁₂  a₁₃ |
    | a₂₁  a₂₂  a₂₃ |
    | a₃₁  a₃₂  a₃₃ |

这是一个 3×3 矩阵（3 行 3 列）
```

#### 记号
- **形状**：m×n 表示 m 行 n 列
- **元素**：A[i,j] 或 aᵢⱼ 表示第 i 行第 j 列的元素
- **向量是特殊的矩阵**：n×1 矩阵就是列向量

---

### 2. 矩阵的基本运算

#### 加法：对应位置相加

```
| 1  2 |   | 5  6 |   | 6  8 |
| 3  4 | + | 7  8 | = | 10 12|
```

**要求**：两个矩阵形状必须相同！

---

#### 数乘：每个元素乘以常数

```
     | 1  2 |   | 3   6 |
3 × | 3  4 | = | 9  12 |
```

---

#### 转置：行列互换

```
        | 1  2  3 |
A = | 1  4 |    T   | 2  5 |
    | 2  5 |  → A = | 3  6 |
    | 3  6 |

(行变列，列变行)
```

**记号**：Aᵀ 或 A.T

---

### 3. 矩阵乘法（重点！）

#### 定义

```
A (m×n)  ×  B (n×p)  =  C (m×p)

注意：A 的列数必须等于 B 的行数！
```

#### 计算方法

**方法 1：行列点积**

C 的第 [i,j] 个元素 = A 的第 i 行 · B 的第 j 列

```
      | 1  2 |
A =   | 3  4 |  (2×2)
      | 5  6 |

      | 7  8 |
B =   | 9 10 |  (2×2)

C = A × B (2×2)

C[1,1] = [1,2] · [7,9] = 1×7 + 2×9 = 25
C[1,2] = [1,2] · [8,10] = 1×8 + 2×10 = 28
C[2,1] = [3,4] · [7,9] = 3×7 + 4×9 = 57
C[2,2] = [3,4] · [8,10] = 3×8 + 4×10 = 64
...以此类推

      | 25  28 |
C =   | 57  64 |
      | 89 100 |
```

---

**方法 2：列向量视角（更重要！）**

矩阵×向量 = 矩阵各列的线性组合

```
| 1  2 |   | x |       | 1 |       | 2 |
| 3  4 | × | y |  =  x·| 3 |  +  y·| 4 |
| 5  6 |               | 5 |       | 6 |

结果是一个向量，是矩阵列向量的加权组合！
```

这个视角在 AI 中极其重要！

---

### 4. 矩阵乘法的几何意义：线性变换

**核心思想**：矩阵乘法 = 空间变换

#### 例子：旋转矩阵

```
        | cosθ  -sinθ |
R(θ) = | sinθ   cosθ |

这个矩阵乘以任意向量，就是把向量旋转θ角度！
```

验证（旋转 90°）：

```
        | 0  -1 |
R(90°) =| 1   0 |

| 0  -1 |   | 1 |   | 0 |
| 1   0 | × | 0 | = | 1 |

向量 [1, 0] 被旋转成了 [0, 1] ✓
```

---

#### 例子：缩放矩阵

```
     | 2  0 |
S =  | 0  3 |

这个矩阵把 x 方向拉伸 2 倍，y 方向拉伸 3 倍！

| 2  0 |   | 1 |   | 2 |
| 0  3 | × | 1 | = | 3 |
```

---

#### 例子：剪切变换

```
     | 1  1 |
S =  | 0  1 |

这个矩阵把空间"推斜"！

| 1  1 |   | 1 |   | 2 |
| 0  1 | × | 1 | = | 1 |
```

---

### 5. 特殊矩阵

#### 单位矩阵（Identity Matrix）

```
     | 1  0  0 |
I =  | 0  1  0 |
     | 0  0  1 |

性质：I × A = A × I = A（就像数字 1）
```

---

#### 对角矩阵

```
     | 2  0  0 |
D =  | 0  3  0 |
     | 0  0  5 |

只有对角线有值，其他都是 0。
性质：对角矩阵乘法 = 对各维度独立缩放
```

---

#### 零矩阵

```
     | 0  0 |
O =  | 0  0 |

所有元素都是 0。
```

## 💻 代码实现

### 从零实现矩阵运算

```python
import numpy as np

# ==================== 创建矩阵 ====================

# 直接创建
A = np.array([[1, 2, 3],
              [4, 5, 6]])  # 2×3 矩阵

print(f"矩阵 A 的形状：{A.shape}")  # (2, 3)
print(f"A = \n{A}")

# 特殊矩阵
I = np.eye(3)  # 3×3 单位矩阵
Z = np.zeros((2, 3))  # 2×3 零矩阵
O = np.ones((2, 2))  # 2×2 全 1 矩阵
R = np.random.rand(3, 3)  # 3×3 随机矩阵

print(f"\n单位矩阵 I = \n{I}")

# ==================== 矩阵基本运算 ====================

A = np.array([[1, 2],
              [3, 4]])

B = np.array([[5, 6],
              [7, 8]])

# 加法
print(f"\nA + B = \n{A + B}")

# 数乘
print(f"\n2 × A = \n{2 * A}")

# 转置
print(f"\nA 的转置 A.T = \n{A.T}")

# ==================== 矩阵乘法 ====================

# 方法 1：@ 运算符
C = A @ B
print(f"\nA @ B = \n{C}")

# 方法 2：np.dot()
C = np.dot(A, B)
print(f"\nnp.dot(A, B) = \n{C}")

# 方法 3：.dot() 方法
C = A.dot(B)
print(f"\nA.dot(B) = \n{C}")

# 验证矩阵乘法维度要求
try:
    A = np.array([[1, 2, 3]])  # 1×3
    B = np.array([[1, 2],      # 2×2
                  [3, 4]])
    C = A @ B  # 会报错！
except ValueError as e:
    print(f"\n维度不匹配错误：{e}")

# ==================== 矩阵×向量 = 线性组合 ====================

print("\n" + "="*50)
print("矩阵×向量 = 列向量的线性组合")
print("="*50)

A = np.array([[1, 2],
              [3, 4],
              [5, 6]])  # 3×2 矩阵

x = np.array([2, 3])  # 2 维向量

# 方法 1：直接乘法
result = A @ x
print(f"\nA = \n{A}")
print(f"\nx = {x}")
print(f"\nA @ x = {result}")

# 方法 2：手动计算线性组合
col1 = A[:, 0]  # 第一列 [1, 3, 5]
col2 = A[:, 1]  # 第二列 [2, 4, 6]
manual = x[0] * col1 + x[1] * col2
print(f"\n手动计算：2×col1 + 3×col2 = {manual}")
print(f"结果一致：{np.allclose(result, manual)}")  # True ✓

# ==================== 线性变换示例 ====================

print("\n" + "="*50)
print("线性变换：旋转、缩放、剪切")
print("="*50)

import math

# 原始向量
v = np.array([1, 0])
print(f"\n原始向量：{v}")

# 旋转 90 度
theta = math.radians(90)
R = np.array([[math.cos(theta), -math.sin(theta)],
              [math.sin(theta), math.cos(theta)]])
rotated = R @ v
print(f"\n旋转 90°后：{rotated.round(4)}")  # [0, 1]

# 缩放
S = np.array([[2, 0],
              [0, 3]])
scaled = S @ v
print(f"\n缩放 (2x, 3y) 后：{scaled}")  # [2, 0]

# 剪切
SH = np.array([[1, 1],
               [0, 1]])
sheared = SH @ v
print(f"\n剪切后：{sheared}")  # [1, 0]

# ==================== 批量处理示例 ====================

print("\n" + "="*50)
print("批量处理：1000 个用户，一次矩阵乘法搞定")
print("="*50)

# 1000 个用户，每个用户 128 个特征
num_users = 1000
num_features = 128
users = np.random.rand(num_users, num_features)

# 权重矩阵：128→64 维变换
W = np.random.rand(num_features, 64)

# 一次矩阵乘法，处理所有用户！
results = users @ W  # 结果形状：(1000, 64)

print(f"\n用户矩阵形状：{users.shape}")
print(f"权重矩阵形状：{W.shape}")
print(f"输出形状：{results.shape}")
print(f"\n如果用循环需要 1000 次运算，矩阵乘法只需 1 次！")
```

## 🔗 与 AI 的联系

### 1. 神经网络 = 一堆矩阵乘法

一个全连接层：

```
输出 = 输入 @ 权重矩阵 + 偏置
y = X @ W + b
```

一个深度神经网络就是多层矩阵乘法的叠加！

```
第 1 层：h₁ = X @ W₁ + b₁
第 2 层：h₂ = h₁ @ W₂ + b₂
...
输出层：y = hₙ @ Wₒ + bₒ
```

---

### 2. 卷积神经网络（CNN）

卷积操作也可以用矩阵乘法表示（im2col 技巧）：

```
卷积 = 展开的输入矩阵 @ 展开的卷积核矩阵
```

这就是为什么 CNN 能用 GPU 加速——本质还是矩阵乘法！

---

### 3. 注意力机制（Transformer）

注意力矩阵计算：

```
Attention(Q, K, V) = softmax(Q @ K.T / √d) @ V
```

全是矩阵乘法！

---

### 4. 批量训练

训练时，我们一次处理一个 batch（比如 64 个样本）：

```
输入：X (64×784)  # 64 个样本，每个 784 特征
权重：W (784×10)  # 784 输入，10 输出
输出：Y (64×10)   # 64 个样本，每个 10 分类

Y = X @ W
```

没有矩阵，深度学习根本不可能实现！

## 🧠 常见误区

### ❌ 误区 1：矩阵乘法可交换

**纠正**：一般情况下 A×B ≠ B×A！

```
A = | 1  2 |    B = | 5  6 |
    | 3  4 |        | 7  8 |

A×B = | 19  22 |    B×A = | 23  34 |
      | 43  50 |          | 31  46 |
```

**特例**：单位矩阵、对角矩阵之间可交换。

---

### ❌ 误区 2：矩阵除法存在

**纠正**：没有"矩阵除法"，只有**逆矩阵**！

如果 A×B = C，想求 B，不能写 B = C/A，而要写：

```
B = A⁻¹ × C  （如果 A 可逆）
```

---

### ❌ 误区 3：所有矩阵都可逆

**纠正**：只有方阵（行数=列数）且行列式≠0 的矩阵才可逆！

很多 AI 中的矩阵不可逆，这时要用**伪逆**（后面会讲）。
