## 1. 为什么 AI 需要概率？

在前两个阶段，我们学习了**确定性的数学**：
- 线性代数：数据如何表示
- 微积分：如何找到最优解

但现实世界充满了**不确定性**：
- 这张图片是猫还是狗？（分类问题）
- 明天股价会涨还是跌？（预测问题）
- 用户会点击哪个广告？（推荐问题）

**概率论就是不确定性的语言。**

### AI 中的概率应用

| 领域 | 概率的作用 |
|------|-----------|
| 分类 | P(猫\|图片) vs P(狗\|图片) |
| 生成模型 | 学习数据的概率分布 P(x) |
| 强化学习 | 状态转移概率 P(s'\|s,a) |
| 贝叶斯推断 | P(参数\|数据) ∝ P(数据\|参数)×P(参数) |
| 不确定性估计 | 预测的置信区间 |

## 2. 概率的三种定义

### 2.1 古典概率（拉普拉斯，1812）

> **定义**：如果所有结果等可能，事件 A 的概率为：
> 
> $$P(A) = \frac{\text{A 包含的基本事件数}}{\text{样本空间中基本事件总数}}$$

**例子**：掷一枚公平的骰子，点数为偶数的概率？

- 样本空间：{1, 2, 3, 4, 5, 6}
- 偶数事件：{2, 4, 6}
- 概率：P(偶数) = 3/6 = 0.5

**局限性**：只适用于"等可能"的情况。但现实中很多事件不是等可能的（比如明天下雨的概率）。

---

### 2.2 频率概率（von Mises，1919）

> **定义**：在大量重复实验中，事件 A 发生的频率稳定值：
> 
> $$P(A) = \lim_{n \to \infty} \frac{\text{A 发生的次数}}{n}$$

**例子**：一枚硬币是否公平？

- 掷 10 次：7 次正面 → 频率 0.7
- 掷 100 次：52 次正面 → 频率 0.52
- 掷 10000 次：5010 次正面 → 频率 0.501

随着 n 增大，频率趋近于真实概率 0.5。

**在 AI 中的应用**：
- 用训练数据的经验分布估计真实分布
- 蒙特卡洛方法：用大量采样估计概率

---

### 2.3 主观概率（贝叶斯学派）

> **定义**：概率是**信念的度量**，表示对事件发生的信心程度。

**例子**：
- "我认为明天下雨的概率是 30%"
- "这个模型预测正确的概率是 95%"

**在 AI 中的应用**：
- 贝叶斯深度学习：参数不是固定值，而是概率分布
- 不确定性量化：模型知道自己"不知道什么"

---

## 3. 核心概念

### 3.1 随机实验（Random Experiment）

**定义**：可以在相同条件下重复进行，但结果不确定的实验。

**例子**：
- 掷硬币
- 掷骰子
- 从一副牌中抽一张
- 观察明天的天气
- 用户是否点击广告

---

### 3.2 样本空间（Sample Space）Ω

**定义**：随机实验所有可能结果的集合。

| 实验 | 样本空间 Ω |
|------|-----------|
| 掷硬币 | {正面，反面} |
| 掷骰子 | {1, 2, 3, 4, 5, 6} |
| 掷两枚硬币 | {(正，正), (正，反), (反，正), (反，反)} |
| 测量身高 | [0, 300] cm（连续） |
| 明天天气 | {晴，阴，雨，雪} |

**关键点**：
- 样本空间必须**互斥且完备**（所有可能结果都要包含）
- 可以是**离散**的（有限或可数无限）或**连续**的

---

### 3.3 事件（Event）

**定义**：样本空间的子集，用大写字母 A, B, C... 表示。

**例子**（掷骰子）：
- A = "点数为偶数" = {2, 4, 6}
- B = "点数大于 4" = {5, 6}
- C = "点数为 1" = {1}（基本事件）
- D = "点数为 7" = ∅（不可能事件）
- E = "点数为 1 到 6" = Ω（必然事件）

**事件的关系**：

| 关系 | 符号 | 含义 |
|------|------|------|
| 并集 | A ∪ B | A 或 B 发生 |
| 交集 | A ∩ B | A 且 B 同时发生 |
| 补集 | Aᶜ | A 不发生 |
| 互斥 | A ∩ B = ∅ | A 和 B 不能同时发生 |

---

### 3.4 概率测度（Probability Measure）

**定义**：给每个事件分配一个 [0, 1] 之间的数，满足：

**柯尔莫哥洛夫公理**（1933）：

1. **非负性**：P(A) ≥ 0，对任意事件 A
2. **规范性**：P(Ω) = 1（必然事件概率为 1）
3. **可列可加性**：如果 A₁, A₂, ... 互斥，则：
   $$P(A_1 \cup A_2 \cup ...) = P(A_1) + P(A_2) + ...$$

**推论**：
- P(∅) = 0（不可能事件概率为 0）
- P(Aᶜ) = 1 - P(A)
- P(A ∪ B) = P(A) + P(B) - P(A ∩ B)（容斥原理）

---

## 4. 重要性质

### 4.1 互斥事件（Mutually Exclusive）

**定义**：A ∩ B = ∅，即不能同时发生。

**性质**：P(A ∪ B) = P(A) + P(B)

**例子**：
- 掷骰子："点数为 1" 和 "点数为 2" 互斥
- 掷骰子："点数为偶数" 和 "点数为奇数" 互斥

---

### 4.2 独立事件（Independent）⚠️

**定义**：一个事件的发生不影响另一个事件的概率。

**数学定义**：A 和 B 独立 ⟺ P(A ∩ B) = P(A) × P(B)

**例子**：
- 掷两枚硬币：第一枚正面 和 第二枚正面 → **独立**
- 从一副牌中抽两张（不放回）：第一张是 A 和 第二张是 A → **不独立**

**⚠️ 互斥 ≠ 独立！**

- 互斥：A 发生则 B 一定不发生 → P(A ∩ B) = 0
- 独立：A 发生不影响 B 的概率 → P(A ∩ B) = P(A)×P(B)

如果 A 和 B 互斥且 P(A)>0, P(B)>0，则它们**一定不独立**！

## 5. Python 实战：模拟概率实验

### 5.1 掷硬币实验

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_coin_flips(n_flips):
    """模拟掷硬币实验"""
    # 1=正面，0=反面
    flips = np.random.randint(0, 2, n_flips)
    
    # 计算累积频率
    cumulative_heads = np.cumsum(flips)
    n_array = np.arange(1, n_flips + 1)
    frequencies = cumulative_heads / n_array
    
    return frequencies

# 模拟 10000 次
frequencies = simulate_coin_flips(10000)

# 绘图
plt.figure(figsize=(10, 6))
plt.plot(frequencies, alpha=0.5, label='累积频率')
plt.axhline(y=0.5, color='r', linestyle='--', label='理论概率 0.5')
plt.xlabel('实验次数 n')
plt.ylabel('正面频率')
plt.title('大数定律：频率趋近于概率')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print(f"最终频率：{frequencies[-1]:.4f}")
print(f"与理论值的差距：{abs(frequencies[-1] - 0.5):.4f}")
```

**运行结果**：
```
最终频率：0.5012
与理论值的差距：0.0012
```

### 5.2 掷骰子实验

```python
def simulate_dice(n_rolls):
    """模拟掷骰子"""
    rolls = np.random.randint(1, 7, n_rolls)
    
    # 计算各点数的频率
    outcomes = [1, 2, 3, 4, 5, 6]
    frequencies = [np.sum(rolls == i) / n_rolls for i in outcomes]
    
    return outcomes, frequencies

# 模拟 10000 次
outcomes, freqs = simulate_dice(10000)

# 绘图
plt.figure(figsize=(10, 6))
plt.bar(outcomes, freqs, alpha=0.7, label='模拟频率')
plt.axhline(y=1/6, color='r', linestyle='--', label='理论概率 1/6')
plt.xlabel('点数')
plt.ylabel('频率')
plt.title('公平骰子的概率分布')
plt.legend()
plt.grid(True, alpha=0.3, axis='y')
plt.show()

for i, f in zip(outcomes, freqs):
    print(f"点数{i}: 频率={f:.4f}, 理论={1/6:.4f}, 差距={abs(f-1/6):.4f}")
```

### 5.3 蒙提霍尔问题（三门问题）🧠

这是一个经典的反直觉概率问题！

**问题**：
- 有三扇门，一扇后面是汽车，两扇后面是山羊
- 你选择一扇门（比如 1 号）
- 主持人打开另一扇有山羊的门（比如 3 号）
- 主持人问：你要不要换到 2 号门？

**直觉**：换不换都是 50%？

**答案**：**换！换门后获胜概率是 2/3，不换是 1/3**

```python
def monty_hall_simulation(n_trials, switch=True):
    """
    蒙提霍尔问题模拟
    
    参数:
        n_trials: 模拟次数
        switch: 是否换门
    """
    wins = 0
    
    for _ in range(n_trials):
        # 随机放置汽车（0, 1, 2）
        car_door = np.random.randint(0, 3)
        
        # 参赛者随机选择一扇门
        chosen_door = np.random.randint(0, 3)
        
        # 主持人打开一扇有山羊的门
        remaining_doors = [0, 1, 2]
        remaining_doors.remove(chosen_door)
        if car_door != chosen_door:
            remaining_doors.remove(car_door)
        # 主持人从剩余门中选一个打开（都是山羊）
        opened_door = np.random.choice(remaining_doors)
        
        # 如果换门
        if switch:
            final_door = [0, 1, 2]
            final_door.remove(chosen_door)
            final_door.remove(opened_door)
            final_door = final_door[0]
        else:
            final_door = chosen_door
        
        # 判断是否获胜
        if final_door == car_door:
            wins += 1
    
    return wins / n_trials

# 模拟 100000 次
n = 100000
p_switch = monty_hall_simulation(n, switch=True)
p_stay = monty_hall_simulation(n, switch=False)

print(f"模拟次数：{n}")
print(f"换门获胜概率：{p_switch:.4f} (理论值：2/3 ≈ 0.6667)")
print(f"不换获胜概率：{p_stay:.4f} (理论值：1/3 ≈ 0.3333)")
```

**运行结果**：
```
模拟次数：100000
换门获胜概率：0.6681 (理论值：2/3 ≈ 0.6667)
不换获胜概率：0.3319 (理论值：1/3 ≈ 0.3333)
```

**为什么？**

| 策略 | 初始选择正确 (1/3) | 初始选择错误 (2/3) | 总概率 |
|------|------------------|------------------|--------|
| 不换 | 赢 ✅ | 输 ❌ | 1/3 |
| 换 | 输 ❌ | 赢 ✅ | 2/3 |
