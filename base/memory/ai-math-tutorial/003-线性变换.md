# 003 | 线性变换：矩阵如何"移动"空间

> 🎯 **一句话核心**：线性变换是保持网格线平行且等距的空间变换，每个线性变换都对应一个矩阵，反之亦然。

---

## 🤔 从一个问题开始

### 想象一个游戏

你有一个橡皮膜，上面画着网格：

```
变换前：
  ↑ y
  |
  |___|___|___|
  |___|___|___|
  |___|___|___|
  +---+---+---→ x

你用手拉伸、旋转、挤压这个橡皮膜...

变换后：
  ↑ y
  |    /
  | / / /
  |/ / /
  +/ / /→ x
```

**问题**：什么样的变换是"线性"的？什么样的不是？

---

### 线性变换的两条规则

一个变换 T 是线性的，当且仅当：

**规则 1：可加性**
```
T(u + v) = T(u) + T(v)
```
先加再变换 = 先变换再加

**规则 2：齐次性**
```
T(c·v) = c·T(v)
```
先数乘再变换 = 先变换再数乘

---

### 直观理解

**线性变换的特点**：
1. ✅ 原点保持不动（T(0) = 0）
2. ✅ 直线保持直线
3. ✅ 平行线保持平行
4. ✅ 网格线保持平行且等距

**非线性变换（对比）**：
- ❌ 弯曲
- ❌ 原点移动
- ❌ 网格线变曲线

---

## 📖 核心概念详解

### 1. 为什么线性变换如此重要？

**关键洞察**：要完全描述一个线性变换，只需要知道**基向量变换到哪里**！

在 2D 空间中：
- 基向量 î = [1, 0]
- 基向量 ĵ = [0, 1]

任何向量 v 都可以表示为：
```
v = x·î + y·ĵ
```

经过线性变换 T：
```
T(v) = T(x·î + y·ĵ)
     = x·T(î) + y·T(ĵ)  （利用线性性质）
```

**这意味着**：只要知道 T(î) 和 T(ĵ)，就能计算任何向量的变换！

---

### 2. 从线性变换到矩阵

假设我们知道：
```
T(î) = [a, c]  （î 变换后的位置）
T(ĵ) = [b, d]  （ĵ 变换后的位置）
```

那么对于任意向量 v = [x, y]：
```
T(v) = x·T(î) + y·T(ĵ)
     = x·[a, c] + y·[b, d]
     = [ax + by, cx + dy]
```

写成矩阵形式：
```
T(v) = | a  b |   | x |
       | c  d | × | y |
```

**结论**：线性变换 T 完全由矩阵表示！

```
矩阵的第一列 = T(î)  （基向量 î 的变换结果）
矩阵的第二列 = T(ĵ)  （基向量 ĵ 的变换结果）
```

---

### 3. 常见线性变换的矩阵

#### 恒等变换（什么都不变）

```
T(î) = [1, 0]
T(ĵ) = [0, 1]

矩阵 I = | 1  0 |
         | 0  1 |
```

---

#### 旋转（逆时针θ角）

```
T(î) = [cosθ, sinθ]
T(ĵ) = [-sinθ, cosθ]

矩阵 R(θ) = | cosθ  -sinθ |
           | sinθ   cosθ |
```

验证（旋转 90°）：
```
R(90°) = | 0  -1 |
         | 1   0 |

î = [1,0] → [0,1] ✓
ĵ = [0,1] → [-1,0] ✓
```

---

#### 缩放

```
x 方向缩放 sₓ 倍
y 方向缩放 sᵧ 倍

T(î) = [sₓ, 0]
T(ĵ) = [0, sᵧ]

矩阵 S = | sₓ  0 |
         | 0  sᵧ |
```

---

#### 剪切（水平）

```
保持 x 轴不动，y 越高越往右推

T(î) = [1, 0]
T(ĵ) = [k, 1]  （ĵ 被推了 k 个单位）

矩阵 SH = | 1  k |
          | 0  1 |
```

---

#### 反射（关于 x 轴）

```
T(î) = [1, 0]   （不变）
T(ĵ) = [0, -1]  （翻转）

矩阵 F = | 1   0 |
         | 0  -1 |
```

---

### 4. 复合变换 = 矩阵乘法

如果有两个变换 T₁ 和 T₂，先做 T₁ 再做 T₂：

```
复合变换：T(v) = T₂(T₁(v))

对应矩阵：M = M₂ × M₁
```

**注意顺序**：矩阵乘法的顺序和变换顺序相反！

```
v → M₁ → M₂ → 结果

写成矩阵：M₂ × (M₁ × v) = (M₂ × M₁) × v
```

---

#### 例子：先旋转 90°，再水平剪切

```
旋转 90°:    R = | 0  -1 |
                | 1   0 |

水平剪切：   SH = | 1  1 |
                  | 0  1 |

复合矩阵：   M = SH × R

M = | 1  1 |   | 0  -1 |     | 1   1 |
    | 0  1 | × | 1   0 |  =  | 1   0 |

验证：
î = [1,0] → 旋转→ [0,1] → 剪切→ [1,1]
用复合矩阵：M × [1,0] = [1,1] ✓
```

---

### 5. 行列式：变换的缩放因子

**定义**：行列式表示线性变换对面积的缩放比例。

对于 2×2 矩阵：
```
     | a  b |
A =  | c  d |

det(A) = ad - bc
```

**几何意义**：

```
原始单位正方形面积 = 1

变换后平行四边形面积 = |det(A)|
```

---

#### 行列式的含义

| det(A) | 含义 |
|--------|------|
| 2 | 面积放大 2 倍 |
| 1 | 面积不变（如旋转） |
| 0.5 | 面积缩小一半 |
| 0 | 空间被压扁（降维） |
| -1 | 面积不变，但方向翻转 |

**重要性质**：
- det(A) = 0 ⇔ A 不可逆（空间被压扁）
- det(A×B) = det(A) × det(B)

## 💻 代码实现

### 线性变换可视化

```python
import numpy as np
import matplotlib.pyplot as plt

# ==================== 基向量变换 ====================

print("="*50)
print("线性变换：追踪基向量的变换")
print("="*50)

# 原始基向量
i_hat = np.array([1, 0])
j_hat = np.array([0, 1])

print(f"\n原始基向量：")
print(f"  î = {i_hat}")
print(f"  ĵ = {j_hat}")

# 定义一个变换矩阵（旋转 90° + 剪切）
transform = np.array([[1, 1],
                      [1, 0]])

print(f"\n变换矩阵：")
print(f"  {transform}")

# 变换后的基向量
i_hat_new = transform @ i_hat
j_hat_new = transform @ j_hat

print(f"\n变换后的基向量：")
print(f"  T(î) = {i_hat_new}")
print(f"  T(ĵ) = {j_hat_new}")

# 验证任意向量的变换
v = np.array([2, 3])
v_transformed = transform @ v

# 用基向量的线性组合验证
v_manual = v[0] * i_hat_new + v[1] * j_hat_new

print(f"\n验证任意向量 v = {v}：")
print(f"  直接变换：{v_transformed}")
print(f"  基向量组合：{v_manual}")
print(f"  结果一致：{np.allclose(v_transformed, v_manual)}")  # True ✓

# ==================== 常见变换矩阵 ====================

print("\n" + "="*50)
print("常见线性变换矩阵")
print("="*50)

import math

# 旋转矩阵
def rotation_matrix(theta_degrees):
    theta = math.radians(theta_degrees)
    return np.array([
        [math.cos(theta), -math.sin(theta)],
        [math.sin(theta), math.cos(theta)]
    ])

# 缩放矩阵
def scale_matrix(sx, sy):
    return np.array([[sx, 0], [0, sy]])

# 剪切矩阵
def shear_matrix(k):
    return np.array([[1, k], [0, 1]])

# 反射矩阵（关于 x 轴）
def reflect_matrix():
    return np.array([[1, 0], [0, -1]])

# 测试
v = np.array([1, 1])
print(f"\n原始向量：{v}")

R90 = rotation_matrix(90)
print(f"\n旋转 90°矩阵：\n{R90.round(2)}")
print(f"变换结果：{R90 @ v}")

S = scale_matrix(2, 0.5)
print(f"\n缩放矩阵 (2x, 0.5y)：\n{S}")
print(f"变换结果：{S @ v}")

SH = shear_matrix(1)
print(f"\n剪切矩阵：\n{SH}")
print(f"变换结果：{SH @ v}")

# ==================== 复合变换 ====================

print("\n" + "="*50)
print("复合变换：先旋转 90°，再剪切")
print("="*50)

R = rotation_matrix(90)
SH = shear_matrix(1)

# 复合矩阵（注意顺序！）
M = SH @ R

print(f"\n旋转矩阵 R：\n{R.round(2)}")
print(f"\n剪切矩阵 SH：\n{SH}")
print(f"\n复合矩阵 M = SH × R：\n{M.round(2)}")

# 验证
v = np.array([1, 0])
step1 = R @ v  # 先旋转
step2 = SH @ step1  # 再剪切
direct = M @ v  # 直接用复合矩阵

print(f"\n向量 {v} 的变换：")
print(f"  分步：{v} → {step1} → {step2}")
print(f"  直接：{v} → {direct}")
print(f"  结果一致：{np.allclose(step2, direct)}")  # True ✓

# ==================== 行列式计算 ====================

print("\n" + "="*50)
print("行列式：面积的缩放因子")
print("="*50)

def determinant_2x2(A):
    """计算 2×2 矩阵的行列式"""
    return A[0,0] * A[1,1] - A[0,1] * A[1,0]

matrices = [
    ("单位矩阵", np.eye(2)),
    ("旋转 90°", rotation_matrix(90)),
    ("缩放 (2,3)", scale_matrix(2, 3)),
    ("剪切", shear_matrix(1)),
    ("压扁", np.array([[1, 2], [2, 4]])),  # 行列式为 0
]

for name, M in matrices:
    det = determinant_2x2(M)
    print(f"\n{name}:")
    print(f"  矩阵：\n  {M.round(2)}")
    print(f"  行列式：{det:.2f}")
    if abs(det) < 1e-10:
        print(f"  → 空间被压扁（不可逆）！")
    elif abs(det - 1) < 1e-10:
        print(f"  → 面积不变")
    else:
        print(f"  → 面积缩放 {abs(det):.2f} 倍")

# ==================== 可视化网格变换 ====================

print("\n" + "="*50)
print("可视化：绘制变换前后的网格")
print("="*50)

def plot_grid(ax, transform, title):
    """绘制变换前后的网格"""
    
    # 创建网格线
    x = np.linspace(-3, 3, 7)
    y = np.linspace(-3, 3, 7)
    X, Y = np.meshgrid(x, y)
    
    # 变换前的网格（蓝色）
    for i in range(len(x)):
        ax.plot([x[i], x[i]], [y[0], y[-1]], 'b-', alpha=0.3, linewidth=0.5)
        ax.plot([x[0], x[-1]], [y[i], y[i]], 'b-', alpha=0.3, linewidth=0.5)
    
    # 变换后的网格（红色）
    for i in range(len(x)):
        # 垂直线
        pts = np.array([[x[i], y[0]], [x[i], y[-1]]]).T
        transformed = transform @ pts
        ax.plot(transformed[0], transformed[1], 'r-', alpha=0.5, linewidth=1)
        
        # 水平线
        pts = np.array([[x[0], y[i]], [x[-1], y[i]]]).T
        transformed = transform @ pts
        ax.plot(transformed[0], transformed[1], 'r-', alpha=0.5, linewidth=1)
    
    # 绘制基向量
    i_hat = transform @ np.array([1, 0])
    j_hat = transform @ np.array([0, 1])
    
    ax.arrow(0, 0, i_hat[0], i_hat[1], head_width=0.2, 
             fc='green', ec='green', linewidth=2, label='T(î)' if i==0 else "")
    ax.arrow(0, 0, j_hat[0], j_hat[1], head_width=0.2, 
             fc='purple', ec='purple', linewidth=2, label='T(ĵ)')
    
    ax.set_xlim(-4, 4)
    ax.set_ylim(-4, 4)
    ax.set_aspect('equal')
    ax.set_title(title)
    ax.axhline(0, color='gray', linewidth=0.5)
    ax.axvline(0, color='gray', linewidth=0.5)

# 创建图形
fig, axes = plt.subplots(2, 2, figsize=(10, 10))

# 原始网格
plot_grid(axes[0,0], np.eye(2), "原始网格")

# 旋转 45°
theta = math.radians(45)
R = np.array([[math.cos(theta), -math.sin(theta)],
              [math.sin(theta), math.cos(theta)]])
plot_grid(axes[0,1], R, "旋转 45°")

# 缩放
S = np.array([[2, 0], [0, 0.5]])
plot_grid(axes[1,0], S, "缩放 (2x, 0.5y)")

# 剪切
SH = np.array([[1, 1], [0, 1]])
plot_grid(axes[1,1], SH, "剪切")

plt.tight_layout()
plt.savefig('/Users/cloudyan/.openclaw/workspace/memory/ai-math-tutorial/images/003-linear-transforms.png', dpi=150)
print("\n网格变换图已保存：images/003-linear-transforms.png")
```

## 🔗 与 AI 的联系

### 1. 神经网络层 = 线性变换 + 非线性激活

每个全连接层：
```
z = W @ x + b  # 线性变换
a = σ(z)       # 非线性激活（如 ReLU）
```

**线性部分**：W @ x 是一个线性变换，把输入空间变换到新的空间。

**非线性部分**：激活函数引入非线性，使网络能拟合复杂函数。

---

### 2. 注意力机制中的变换

在 Transformer 中，Q、K、V 都是通过线性变换得到的：

```
Q = X @ W_Q  # 查询向量
K = X @ W_K  # 键向量
V = X @ W_V  # 值向量
```

每个 W_Q、W_K、W_V 都是一个线性变换矩阵，把输入变换到不同的子空间。

---

### 3. 卷积 = 特殊的线性变换

卷积操作是线性变换！卷积核就是一个变换矩阵：

```
输出 = 卷积核 @ 输入（展开后）
```

CNN 的强大之处在于：
- 局部性（只关注邻近像素）
- 平移不变性（同一个卷积核在整张图上滑动）

---

### 4. 数据增强中的几何变换

图像数据增强常用线性变换：
- 旋转
- 缩放
- 剪切
- 反射

这些都可以用矩阵乘法高效实现！

## 🧠 常见误区

### ❌ 误区 1：所有变换都是线性的

**纠正**：很多重要变换是非线性的！

非线性变换例子：
- 平移（原点移动了）
- 投影（3D→2D 透视）
- 弯曲/扭曲
- 激活函数（ReLU、sigmoid）

---

### ❌ 误区 2：矩阵乘法顺序不重要

**纠正**：矩阵乘法不可交换！变换顺序非常重要！

```
先旋转再剪切 ≠ 先剪切再旋转
```

---

### ❌ 误区 3：行列式为负没有意义

**纠正**：行列式为负表示空间方向翻转（如镜像反射）！

```
det = -1：面积不变，但左右翻转
```

### 练习 2：复合变换

```
变换 A：旋转 90°
变换 B：水平剪切（k=1）

1. 先 A 后 B 的复合矩阵是什么？
2. 先 B 后 A 的复合矩阵是什么？
3. 两者相等吗？
```

<details>
<summary>点击查看答案</summary>

```
A = | 0  -1 |    B = | 1  1 |
    | 1   0 |        | 0  1 |

1. 先 A 后 B：B × A = | 1  1 |   | 0  -1 |   | 1   1 |
                      | 0  1 | × | 1   0 | = | 1   0 |

2. 先 B 后 A：A × B = | 0  -1 |   | 1  1 |   | 0  -1 |
                      | 1   0 | × | 0  1 | = | 1   1 |

3. 不相等！B×A ≠ A×B
```
</details>

### 练习 3：行列式计算

计算以下矩阵的行列式，并解释几何意义：

```
A = | 2  0 |    B = | 1  2 |    C = | 1  2 |
    | 0  3 |        | 3  4 |        | 2  4 |
```

<details>
<summary>点击查看答案</summary>

```
det(A) = 2×3 - 0×0 = 6
  → 面积放大 6 倍

det(B) = 1×4 - 2×3 = 4 - 6 = -2
  → 面积放大 2 倍，方向翻转

det(C) = 1×4 - 2×2 = 4 - 4 = 0
  → 空间被压扁（不可逆）！
  → 实际上 C 的两行成比例，秩为 1
```
</details>
