## 1. 从"事件"到"数字"的飞跃

### 1.1 回顾：什么是事件？

在前 3 篇中，我们讨论的是**事件**及其概率：

- 抛硬币：正面、反面
- 掷骰子：1 点、2 点、...、6 点
- 医疗检测：患病、没患病
- 天气：下雨、不下雨

**问题**：这些描述不够"数学化"，不方便计算！

### 1.2 随机变量的诞生

**随机变量**的核心思想：**把事件映射到数字**！

| 随机试验 | 事件 | 随机变量 X |
|----------|------|-----------|
| 抛 3 次硬币 | 正正正 | X = 3（正面次数） |
| 掷 2 个骰子 | (3, 4) | X = 7（点数和） |
| 抽 10 个产品 | 2 个次品 | X = 2（次品数） |
| 等公交车 | 等了 5 分钟 | X = 5（等待时间） |

**定义**：
> 随机变量是一个函数，它将样本空间的每个结果映射到一个实数。
> 
> $$X: \Omega \rightarrow \mathbb{R}$$

**关键理解**：
- 随机变量 **不是变量**，而是一个**函数**！
- "随机"指的是结果的不确定性，不是变量本身
- 用大写字母 X, Y, Z 表示随机变量
- 用小写字母 x, y, z 表示随机变量的取值

## 2. 两类随机变量

### 2.1 离散型随机变量

**定义**：取值是**有限个**或**可数无限个**。

**例子**：
- 掷骰子的点数：X ∈ {1, 2, 3, 4, 5, 6}
- 抛 10 次硬币的正面次数：X ∈ {0, 1, 2, ..., 10}
- 某网站的日访问人数：X ∈ {0, 1, 2, ...}（可数无限）
- 某路口 1 小时内经过的车辆数：X ∈ {0, 1, 2, ...}

**特点**：
- 可以一一列举所有可能取值
- 每个取值有明确的概率
- 用**概率质量函数 (PMF)** 描述

---

### 2.2 连续型随机变量

**定义**：取值是**不可数无限个**，通常是某个区间内的任意实数。

**例子**：
- 人的身高：X ∈ [150cm, 200cm] 内的任意值
- 等待公交车的时间：X ∈ [0, ∞)
- 某股票明天的价格：X ∈ (0, ∞)
- 测量误差：X ∈ (-∞, ∞)

**特点**：
- 无法一一列举（区间内有无限多个值）
- **单个值的概率为 0**！P(X = 170.000...cm) = 0
- 只能谈论**区间概率**：P(a ≤ X ≤ b)
- 用**概率密度函数 (PDF)** 描述

---

### 2.3 直观对比

```
离散型：    ●   ●   ●   ●   ●
           1   2   3   4   5
          (可以数出来)

连续型：    ━━━━━━━━━━━━━━━━
           0              10
          (区间内任意值)
```

---

## 3. 离散型随机变量的描述

### 3.1 概率质量函数 (PMF)

**定义**：离散型随机变量 X 取某个值 x 的概率。

$$p(x) = P(X = x)$$

**性质**：
1. $0 \leq p(x) \leq 1$（概率在 0 到 1 之间）
2. $\sum_{x} p(x) = 1$（所有概率之和为 1）

---

### 3.2 例子：掷骰子

设 X = 掷骰子的点数，则：

$$p(x) = P(X = x) = \begin{cases}
1/6 & \text{if } x \in \{1, 2, 3, 4, 5, 6\} \\
0 & \text{otherwise}
\end{cases}$$

**表格表示**：

| x | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| p(x) | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 |

**验证**：$\sum p(x) = 6 \times \frac{1}{6} = 1$ ✅

---

### 3.3 例子：抛 2 次硬币

设 X = 正面的次数，则：

可能结果：{正正，正反，反正，反反}
X 的取值：{0, 1, 2}

$$p(x) = P(X = x) = \begin{cases}
1/4 & \text{if } x = 0 \text{ (反反)} \\
1/2 & \text{if } x = 1 \text{ (正反或反正)} \\
1/4 & \text{if } x = 2 \text{ (正正)} \\
0 & \text{otherwise}
\end{cases}$$

**验证**：$1/4 + 1/2 + 1/4 = 1$ ✅

---

### 3.4 累积分布函数 (CDF)

**定义**：随机变量 X 小于等于某个值 x 的概率。

$$F(x) = P(X \leq x)$$

**对于离散型**：
$$F(x) = \sum_{t \leq x} p(t)$$

---

### 3.5 例子：掷骰子的 CDF

| x | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| p(x) | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 | 1/6 |
| F(x) | 1/6 | 2/6 | 3/6 | 4/6 | 5/6 | 6/6 |

**计算**：
- F(1) = P(X ≤ 1) = 1/6
- F(2) = P(X ≤ 2) = 1/6 + 1/6 = 2/6
- F(3) = P(X ≤ 3) = 1/6 + 1/6 + 1/6 = 3/6
- ...

**CDF 的图像**（阶梯函数）：
```
F(x)
 1 ┤               ╭───
   │           ╭───┤
   │       ╭───┤   │
   │   ╭───┤   │   │
   │───┤   │   │   │
 0 ┴───┴───┴───┴───┴─── x
     1   2   3   4   5   6
```

---

## 4. 连续型随机变量的描述

### 4.1 概率密度函数 (PDF)

**定义**：连续型随机变量 X 的 PDF f(x) 满足：

$$P(a \leq X \leq b) = \int_{a}^{b} f(x) dx$$

**关键理解**：
- f(x) **不是概率**！可以大于 1！
- **面积才是概率**：曲线下方的面积表示概率
- 单个点的概率：$P(X = x) = \int_{x}^{x} f(t) dt = 0$

---

### 4.2 PDF 的性质

1. $f(x) \geq 0$（非负）
2. $\int_{-\infty}^{\infty} f(x) dx = 1$（总面积为 1）

---

### 4.3 例子：均匀分布

设 X 在 [0, 10] 上均匀分布，则：

$$f(x) = \begin{cases}
1/10 & \text{if } 0 \leq x \leq 10 \\
0 & \text{otherwise}
\end{cases}$$

**计算概率**：
$$P(3 \leq X \leq 7) = \int_{3}^{7} \frac{1}{10} dx = \frac{7-3}{10} = 0.4$$

**图像**：
```
f(x)
0.1 ┤   ┌───────────────┐
    │   │               │
    │   │               │
  0 ┴───┴───────────────┴─── x
        0              10
```

**面积** = 10 × 0.1 = 1 ✅

---

### 4.4 例子：正态分布（高斯分布）

**最重要的连续分布**！

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

其中：
- μ = 均值（决定中心位置）
- σ = 标准差（决定宽度）

**图像**（钟形曲线）：
```
f(x)
    │      ╱│╲
    │    ╱  │  ╲
    │   ╱   │   ╲
    │  ╱    │    ╲
    │ ╱     │     ╲
  0 ┴───────┴───────┴── x
           μ
```

**性质**：
- 关于 x = μ 对称
- 约 68% 的数据在 [μ-σ, μ+σ] 内
- 约 95% 的数据在 [μ-2σ, μ+2σ] 内
- 约 99.7% 的数据在 [μ-3σ, μ+3σ] 内

---

### 4.5 连续型的 CDF

**定义**：
$$F(x) = P(X \leq x) = \int_{-\infty}^{x} f(t) dt$$

**性质**：
1. F(x) 是**连续递增**函数（不是阶梯）
2. F(-∞) = 0, F(+∞) = 1
3. $P(a \leq X \leq b) = F(b) - F(a)$

---

## 5. 离散 vs 连续：对比总结

| 特性 | 离散型 | 连续型 |
|------|--------|--------|
| **取值** | 有限或可数无限 | 不可数无限（区间） |
| **描述函数** | PMF: p(x) = P(X=x) | PDF: f(x) |
| **概率计算** | 求和：Σ p(x) | 积分：∫ f(x)dx |
| **单点概率** | P(X=x) 可以 > 0 | P(X=x) = 0 |
| **CDF** | 阶梯函数 | 连续函数 |
| **例子** | 骰子、硬币、计数 | 身高、时间、温度 |

## 6. Python 实战

### 6.1 离散型随机变量

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 定义离散分布：掷骰子
x = np.arange(1, 7)
pmf = np.full(6, 1/6)

# 计算 CDF
cdf = np.cumsum(pmf)

# 绘图
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

# PMF
ax1.stem(x, pmf, basefmt=" ")
ax1.set_xlabel('x (点数)')
ax1.set_ylabel('P(X = x)')
ax1.set_title('概率质量函数 (PMF)')
ax1.set_ylim(0, 0.3)
ax1.grid(alpha=0.3)

# CDF
ax2.step(x, cdf, where='post')
ax2.set_xlabel('x (点数)')
ax2.set_ylabel('P(X ≤ x)')
ax2.set_title('累积分布函数 (CDF)')
ax2.set_ylim(0, 1.1)
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.savefig('memory/ai-math-tutorial/figures/024-discrete-distribution.png', dpi=150)
print("图已保存：024-discrete-distribution.png")
plt.show()
```

### 6.2 连续型随机变量

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 定义连续分布：正态分布 N(0, 1)
x = np.linspace(-4, 4, 1000)
pdf = stats.norm.pdf(x, loc=0, scale=1)  # 标准正态分布
cdf = stats.norm.cdf(x, loc=0, scale=1)

# 绘图
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))

# PDF
ax1.plot(x, pdf)
ax1.fill_between(x, pdf, alpha=0.3)
ax1.axvline(0, color='red', linestyle='--', label='μ=0')
ax1.axvline(1, color='green', linestyle='--', label='μ+σ=1')
ax1.axvline(-1, color='green', linestyle='--', label='μ-σ=-1')
ax1.set_xlabel('x')
ax1.set_ylabel('f(x)')
ax1.set_title('概率密度函数 (PDF) - 标准正态分布')
ax1.legend()
ax1.grid(alpha=0.3)

# CDF
ax2.plot(x, cdf)
ax2.axhline(0.5, color='red', linestyle='--', alpha=0.5)
ax2.axvline(0, color='red', linestyle='--', alpha=0.5)
ax2.set_xlabel('x')
ax2.set_ylabel('F(x) = P(X ≤ x)')
ax2.set_title('累积分布函数 (CDF)')
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.savefig('memory/ai-math-tutorial/figures/024-continuous-distribution.png', dpi=150)
print("图已保存：024-continuous-distribution.png")
plt.show()

# 计算区间概率
p_between = stats.norm.cdf(1) - stats.norm.cdf(-1)
print(f"\nP(-1 ≤ X ≤ 1) = {p_between:.4f} (约 {p_between*100:.1f}%)")
```

### 6.3 模拟：大数定律的直观展示

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_random_variable(n_trials=10000):
    """
    模拟掷骰子，展示频率趋近概率
    """
    # 模拟掷骰子
    rolls = np.random.randint(1, 7, n_trials)
    
    # 计算累积频率
    cumulative_means = np.cumsum(rolls) / np.arange(1, n_trials + 1)
    
    # 绘图
    plt.figure(figsize=(10, 6))
    plt.plot(range(1, n_trials + 1), cumulative_means, alpha=0.5, label='累积平均值')
    plt.axhline(3.5, color='red', linestyle='--', linewidth=2, label='理论期望 E[X]=3.5')
    plt.xlabel('试验次数')
    plt.ylabel('累积平均值')
    plt.title('大数定律：频率趋近概率')
    plt.legend()
    plt.grid(alpha=0.3)
    plt.savefig('memory/ai-math-tutorial/figures/024-law-of-large-numbers.png', dpi=150)
    print("图已保存：024-law-of-large-numbers.png")
    plt.show()
    
    print(f"\n模拟 {n_trials:,} 次掷骰子：")
    print(f"最终累积平均值：{cumulative_means[-1]:.4f}")
    print(f"理论期望值：3.5")
    print(f"误差：{abs(cumulative_means[-1] - 3.5):.4f}")

simulate_random_variable()
```

## 7. 随机变量在 AI 中的应用

### 7.1 特征表示

**机器学习中的特征就是随机变量**！

- 图像像素值：连续型随机变量
- 文本词频：离散型随机变量
- 用户年龄：连续型（或离散化）
- 点击/不点击：伯努利随机变量（0-1）

---

### 7.2 模型输出

**分类模型**：输出是离散随机变量（类别）
- 垃圾邮件分类：X ∈ {垃圾，正常}
- 图像分类：X ∈ {猫，狗，鸟，...}

**回归模型**：输出是连续随机变量
- 房价预测：X ∈ (0, ∞)
- 温度预测：X ∈ (-∞, ∞)

---

### 7.3 不确定性量化

**贝叶斯深度学习**：
- 模型参数是随机变量（有分布）
- 输出也是随机变量（有不确定性）
- 可以给出"置信区间"

---

### 7.4 生成模型

**GAN、VAE、扩散模型**：
- 学习数据的概率分布 p(x)
- 从分布中采样生成新数据
- 本质是学习随机变量的分布

---

## 8. 常见误区

### ❌ 误区 1：随机变量是"变量"

**纠正**：随机变量是**函数**，不是变量！
- 它把样本空间映射到实数
- "随机"指的是输入（试验结果）的随机性

---

### ❌ 误区 2：PDF 的值是概率

**纠正**：PDF 的值**可以大于 1**！
- 概率 = 面积（积分），不是高度
- 只有 PMF 的值才是概率

---

### ❌ 误区 3：连续型随机变量可以取某个精确值的概率

**纠正**：$P(X = x) = 0$ 对于连续型！
- 只能说 P(a ≤ X ≤ b)
- 实际测量总有精度限制，所以谈论区间
