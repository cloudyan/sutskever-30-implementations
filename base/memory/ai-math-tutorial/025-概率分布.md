## 📖 什么是概率分布？

### 直观理解

**概率分布**描述了随机变量取各个值的可能性。

想象你掷骰子：
- 每个面 (1-6) 出现的概率都是 1/6
- 这个"1/6, 1/6, 1/6, 1/6, 1/6, 1/6"就是概率分布

### 数学定义

对于随机变量 X，概率分布给出了：
- **离散型**：P(X = x) = ?（概率质量函数 PMF）
- **连续型**：概率密度函数 PDF，P(a ≤ X ≤ b) = ∫ₐᵇ f(x)dx

### 为什么重要？

```
现实世界 → 随机现象 → 用分布建模 → 预测和分析
```

AI 中的分布应用：
- 🎯 **正态分布**：误差建模、初始化权重
- 🎯 **伯努利分布**：二分类问题
- 🎯 **泊松分布**：稀有事件（如服务器请求）
- 🎯 **多项分布**：多分类问题

## 📐 离散概率分布

### 1. 伯努利分布 (Bernoulli Distribution)

**最简单的分布**——只有两种结果。

#### 定义
```
X ~ Bernoulli(p)

P(X = 1) = p    # 成功
P(X = 0) = 1-p  # 失败
```

#### 关键参数
- `p`：成功的概率 (0 ≤ p ≤ 1)

#### 期望和方差
```
E[X] = p
Var(X) = p(1-p)
```

#### 应用场景
- 抛硬币（正面/反面）
- 点击预测（点击/不点击）
- 疾病检测（阳性/阴性）
- 二分类标签

#### Python 实现

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import bernoulli

# 参数
p = 0.7  # 70% 成功率

# 生成样本
samples = bernoulli.rvs(p, size=1000)
print(f"样本均值：{samples.mean():.3f} (理论值：{p})")

# 概率质量函数
x = [0, 1]
pmf = bernoulli.pmf(x, p)

plt.bar(x, pmf, color=['red', 'green'], alpha=0.7)
plt.xlabel('结果 (0=失败，1=成功)')
plt.ylabel('概率')
plt.title(f'伯努利分布 (p={p})')
plt.xticks(x)
plt.show()
```

### 2. 二项分布 (Binomial Distribution)

**多次伯努利试验**——n 次独立试验中成功的次数。

#### 定义
```
X ~ Binomial(n, p)

P(X = k) = C(n,k) × p^k × (1-p)^(n-k)

其中 C(n,k) = n! / (k! × (n-k)!) 是组合数
```

#### 关键参数
- `n`：试验次数
- `p`：每次成功的概率

#### 期望和方差
```
E[X] = n × p
Var(X) = n × p × (1-p)
```

#### 应用场景
- n 次抛硬币，正面朝上的次数
- 100 个用户中，点击广告的人数
- 10 次射击，命中的次数
- A/B 测试中的转化次数

#### Python 实现

```python
from scipy.stats import binom

# 参数
n = 10  # 10 次试验
p = 0.5  # 50% 成功率

# 生成样本
samples = binom.rvs(n, p, size=10000)
print(f"样本均值：{samples.mean():.3f} (理论值：{n*p})")

# 概率质量函数
x = range(n + 1)
pmf = binom.pmf(x, n, p)

plt.figure(figsize=(10, 5))
plt.bar(x, pmf, alpha=0.7)
plt.xlabel('成功次数 k')
plt.ylabel('P(X = k)')
plt.title(f'二项分布 (n={n}, p={p})')
plt.grid(axis='y', alpha=0.3)
plt.show()

# 不同 p 值的对比
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for i, p in enumerate([0.2, 0.5, 0.8]):
    pmf = binom.pmf(x, n, p)
    axes[i].bar(x, pmf, alpha=0.7)
    axes[i].set_title(f'p = {p}')
    axes[i].set_xlabel('成功次数')
plt.suptitle(f'二项分布对比 (n={n})')
plt.show()
```

### 3. 泊松分布 (Poisson Distribution)

**稀有事件**——单位时间内发生 k 次的概率。

#### 定义
```
X ~ Poisson(λ)

P(X = k) = (λ^k × e^(-λ)) / k!
```

#### 关键参数
- `λ` (lambda)：单位时间内的平均发生次数 (λ > 0)

#### 期望和方差
```
E[X] = λ
Var(X) = λ  # 有趣：期望=方差
```

#### 与二项分布的关系
当 n 很大，p 很小，且 n×p = λ 时：
```
Binomial(n, p) ≈ Poisson(λ)
```

#### 应用场景
- 单位时间内的网站访问量
- 呼叫中心接到的电话数
- 放射性物质的衰变次数
- 交通事故发生次数
- DNA 序列的突变次数

#### Python 实现

```python
from scipy.stats import poisson

# 参数
lambda_ = 3  # 平均每小时 3 次

# 生成样本
samples = poisson.rvs(lambda_, size=10000)
print(f"样本均值：{samples.mean():.3f} (理论值：{lambda_})")

# 概率质量函数
x = range(0, 10)
pmf = poisson.pmf(x, lambda_)

plt.figure(figsize=(10, 5))
plt.bar(x, pmf, alpha=0.7)
plt.xlabel('发生次数 k')
plt.ylabel('P(X = k)')
plt.title(f'泊松分布 (λ={lambda_})')
plt.grid(axis='y', alpha=0.3)
plt.show()

# 不同 λ 值的对比
fig, axes = plt.subplots(1, 3, figsize=(15, 4))
for i, lam in enumerate([1, 3, 7]):
    x = range(0, 15)
    pmf = poisson.pmf(x, lam)
    axes[i].bar(x, pmf, alpha=0.7)
    axes[i].set_title(f'λ = {lam}')
    axes[i].set_xlabel('发生次数')
plt.suptitle('泊松分布对比')
plt.show()
```

### 4. 几何分布 (Geometric Distribution)

**首次成功**——需要多少次试验才能第一次成功。

#### 定义
```
X ~ Geometric(p)

P(X = k) = (1-p)^(k-1) × p

k = 1, 2, 3, ...
```

#### 关键参数
- `p`：每次成功的概率

#### 期望和方差
```
E[X] = 1/p
Var(X) = (1-p)/p²
```

#### 无记忆性
几何分布具有**无记忆性**：
```
P(X > m + n | X > m) = P(X > n)
```
已经失败了 m 次，接下来还需要失败 n 次的概率，和从一开始就需要失败 n 次的概率相同。

#### 应用场景
- 抛硬币，第一次正面朝上需要抛几次
- 产品检测，第一个次品出现在第几个
- 游戏抽卡，第一次抽到 SSR 需要多少次
- 用户注册，第一次转化需要多少次访问

#### Python 实现

```python
from scipy.stats import geom

# 参数
p = 0.2  # 20% 成功率

# 生成样本
samples = geom.rvs(p, size=10000)
print(f"样本均值：{samples.mean():.3f} (理论值：{1/p})")

# 概率质量函数
x = range(1, 11)
pmf = geom.pmf(x, p)

plt.figure(figsize=(10, 5))
plt.bar(x, pmf, alpha=0.7)
plt.xlabel('首次成功所需的试验次数')
plt.ylabel('P(X = k)')
plt.title(f'几何分布 (p={p})')
plt.grid(axis='y', alpha=0.3)
plt.show()
```

### 5. 离散均匀分布 (Discrete Uniform Distribution)

**等可能性**——每个结果概率相同。

#### 定义
```
X ~ Uniform(a, b)

P(X = k) = 1 / (b - a + 1)

k = a, a+1, ..., b
```

#### 期望和方差
```
E[X] = (a + b) / 2
Var(X) = (b - a + 1)² - 1 / 12
```

#### 应用场景
- 掷骰子（1-6 等概率）
- 抽奖（每个号码等概率）
- 随机数生成

#### Python 实现

```python
from scipy.stats import randint

# 参数
a, b = 1, 6  # 骰子

# 概率质量函数
x = range(a, b + 1)
pmf = randint.pmf(x, a, b + 1)

plt.figure(figsize=(10, 5))
plt.bar(x, pmf, alpha=0.7)
plt.xlabel('结果')
plt.ylabel('概率')
plt.title(f'离散均匀分布 ({a} 到 {b})')
plt.xticks(x)
plt.show()
```

## 📈 连续概率分布

### 1. 连续均匀分布 (Continuous Uniform Distribution)

**区间内等密度**。

#### 定义
```
X ~ Uniform(a, b)

f(x) = 1/(b-a)  当 a ≤ x ≤ b
f(x) = 0        其他
```

#### 期望和方差
```
E[X] = (a + b) / 2
Var(X) = (b - a)² / 12
```

#### Python 实现

```python
from scipy.stats import uniform

# 参数
a, b = 0, 10

# 概率密度函数
x = np.linspace(-2, 12, 1000)
pdf = uniform.pdf(x, a, b - a)

plt.figure(figsize=(10, 5))
plt.plot(x, pdf, linewidth=2)
plt.fill_between(x, pdf, alpha=0.3)
plt.xlabel('x')
plt.ylabel('f(x)')
plt.title(f'连续均匀分布 ({a} 到 {b})')
plt.grid(alpha=0.3)
plt.show()
```

### 2. 正态分布 (Normal Distribution) ⭐ 最重要

**高斯分布**——自然界最常见的分布。

#### 定义
```
X ~ Normal(μ, σ²)

f(x) = (1 / (σ√(2π))) × e^(-(x-μ)²/(2σ²))
```

#### 关键参数
- `μ` (mu)：均值，决定中心位置
- `σ` (sigma)：标准差，决定宽度

#### 期望和方差
```
E[X] = μ
Var(X) = σ²
```

#### 68-95-99.7 规则
```
μ ± σ   包含 68.27% 的数据
μ ± 2σ  包含 95.45% 的数据
μ ± 3σ  包含 99.73% 的数据
```

#### 为什么重要？
1. **中心极限定理**：大量独立随机变量的和趋近正态分布
2. **最大熵**：给定期望和方差，正态分布熵最大
3. **数学友好**：很多公式有解析解
4. **AI 应用**：权重初始化、误差建模、贝叶斯推断

#### Python 实现

```python
from scipy.stats import norm

# 标准正态分布
mu, sigma = 0, 1

x = np.linspace(-4, 4, 1000)
pdf = norm.pdf(x, mu, sigma)
cdf = norm.cdf(x, mu, sigma)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# PDF
ax1.plot(x, pdf, linewidth=2, label=f'μ={mu}, σ={sigma}')
ax1.fill_between(x, pdf, alpha=0.3)
ax1.axvline(mu, color='red', linestyle='--', label='均值')
ax1.axvline(mu - sigma, color='green', linestyle=':', label='±1σ')
ax1.axvline(mu + sigma, color='green', linestyle=':')
ax1.set_xlabel('x')
ax1.set_ylabel('f(x)')
ax1.set_title('正态分布 - 概率密度函数')
ax1.legend()
ax1.grid(alpha=0.3)

# CDF
ax2.plot(x, cdf, linewidth=2)
ax2.axhline(0.5, color='red', linestyle='--', label='中位数')
ax2.set_xlabel('x')
ax2.set_ylabel('F(x)')
ax2.set_title('正态分布 - 累积分布函数')
ax2.legend()
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()

# 不同参数的对比
fig, axes = plt.subplots(2, 2, figsize=(12, 10))
params = [
    (0, 1, '标准正态'),
    (0, 2, 'σ 更大（更宽）'),
    (2, 1, 'μ 更大（右移）'),
    (-2, 0.5, 'μ 更小，σ 更小')
]

for i, (mu, sigma, title) in enumerate(params):
    ax = axes[i // 2, i % 2]
    x = np.linspace(-6, 6, 1000)
    pdf = norm.pdf(x, mu, sigma)
    ax.plot(x, pdf, linewidth=2)
    ax.fill_between(x, pdf, alpha=0.3)
    ax.axvline(mu, color='red', linestyle='--')
    ax.set_title(title)
    ax.grid(alpha=0.3)

plt.tight_layout()
plt.show()
```

### 3. 指数分布 (Exponential Distribution)

**等待时间**——事件发生的时间间隔。

#### 定义
```
X ~ Exponential(λ)

f(x) = λ × e^(-λx)  当 x ≥ 0
f(x) = 0            当 x < 0
```

#### 关键参数
- `λ` (lambda)：速率参数 (λ > 0)

#### 期望和方差
```
E[X] = 1/λ
Var(X) = 1/λ²
```

#### 无记忆性
```
P(X > s + t | X > s) = P(X > t)
```
已经等了 s 时间，接下来还需要等 t 时间的概率，和从一开始就需要等 t 时间的概率相同。

#### 与泊松分布的关系
- 泊松：单位时间内事件发生的**次数**
- 指数：两次事件之间的**时间间隔**

#### 应用场景
- 放射性衰变的时间间隔
- 顾客到达的时间间隔
- 电子元件的寿命
- 电话通话时长

#### Python 实现

```python
from scipy.stats import expon

# 参数
lambda_ = 0.5  # 速率
scale = 1 / lambda_  # scipy 使用 scale = 1/λ

x = np.linspace(0, 10, 1000)
pdf = expon.pdf(x, scale=scale)
cdf = expon.cdf(x, scale=scale)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# PDF
ax1.plot(x, pdf, linewidth=2, label=f'λ={lambda_}')
ax1.fill_between(x, pdf, alpha=0.3)
ax1.axvline(1/lambda_, color='red', linestyle='--', label=f'期望={1/lambda_}')
ax1.set_xlabel('时间')
ax1.set_ylabel('f(x)')
ax1.set_title('指数分布 - 概率密度函数')
ax1.legend()
ax1.grid(alpha=0.3)

# CDF
ax2.plot(x, cdf, linewidth=2)
ax2.set_xlabel('时间')
ax2.set_ylabel('F(x)')
ax2.set_title('指数分布 - 累积分布函数')
ax2.grid(alpha=0.3)

plt.tight_layout()
plt.show()
```

### 4. t 分布 (Student's t-Distribution)

**小样本推断**——样本量小时的"加厚版"正态分布。

#### 定义
```
X ~ t(ν)

ν 是自由度参数
```

#### 特点
- 形状类似正态分布，但尾部更厚
- ν 越小，尾部越厚（极端值概率更大）
- ν → ∞ 时，趋近标准正态分布

#### 应用场景
- 小样本的假设检验（t 检验）
- 置信区间估计
- 金融建模（厚尾现象）

#### Python 实现

```python
from scipy.stats import t

# 不同自由度
df_values = [1, 3, 10, 30]

x = np.linspace(-4, 4, 1000)

plt.figure(figsize=(12, 6))
for df in df_values:
    pdf = t.pdf(x, df)
    plt.plot(x, pdf, linewidth=2, label=f'ν={df}')

# 标准正态分布对比
plt.plot(x, norm.pdf(x), 'k--', linewidth=2, label='标准正态')

plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('t 分布对比（自由度越小，尾部越厚）')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

### 5. 卡方分布 (Chi-Squared Distribution)

**平方和**——标准正态变量的平方和。

#### 定义
```
X ~ χ²(k)

如果 Z₁, Z₂, ..., Zk ~ N(0,1) 且独立
则 X = Z₁² + Z₂² + ... + Zk² ~ χ²(k)

k 是自由度
```

#### 期望和方差
```
E[X] = k
Var(X) = 2k
```

#### 应用场景
- 假设检验（卡方检验）
- 拟合优度检验
- 方差分析
- 置信区间估计

#### Python 实现

```python
from scipy.stats import chi2

# 不同自由度
df_values = [1, 3, 5, 10]

x = np.linspace(0, 20, 1000)

plt.figure(figsize=(12, 6))
for df in df_values:
    pdf = chi2.pdf(x, df)
    plt.plot(x, pdf, linewidth=2, label=f'k={df}')

plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('卡方分布对比')
plt.legend()
plt.grid(alpha=0.3)
plt.show()
```

## 🎯 分布速查表

### 离散分布

| 分布 | 参数 | 期望 | 方差 | 应用场景 |
|------|------|------|------|----------|
| 伯努利 | p | p | p(1-p) | 二分类 |
| 二项 | n, p | np | np(1-p) | n 次试验成功次数 |
| 泊松 | λ | λ | λ | 稀有事件计数 |
| 几何 | p | 1/p | (1-p)/p² | 首次成功所需次数 |
| 均匀 | a, b | (a+b)/2 | - | 等概率选择 |

### 连续分布

| 分布 | 参数 | 期望 | 方差 | 应用场景 |
|------|------|------|------|----------|
| 均匀 | a, b | (a+b)/2 | (b-a)²/12 | 区间内等概率 |
| 正态 | μ, σ | μ | σ² | 自然现象、误差 |
| 指数 | λ | 1/λ | 1/λ² | 等待时间 |
| t | ν | 0 (ν>1) | ν/(ν-2) | 小样本推断 |
| 卡方 | k | k | 2k | 假设检验 |

## 💻 实战练习

### 练习 1：模拟抛硬币

```python
import numpy as np

# 抛 1000 次硬币
n_flips = 1000
p_head = 0.5

flips = np.random.binomial(1, p_head, n_flips)
heads = flips.sum()

print(f"正面次数：{heads}")
print(f"正面比例：{heads/n_flips:.3f}")
print(f"理论概率：{p_head}")
```

### 练习 2：网站流量建模

```python
from scipy.stats import poisson

# 某网站平均每小时 100 次访问
lambda_ = 100

# 问：一小时内访问量超过 120 的概率是多少？
prob = 1 - poisson.cdf(120, lambda_)
print(f"P(X > 120) = {prob:.4f}")

# 问：95% 的情况下，访问量不会超过多少？
threshold = poisson.ppf(0.95, lambda_)
print(f"95% 分位数：{threshold}")
```

### 练习 3：产品质量检测

```python
from scipy.stats import norm

# 某零件长度服从正态分布 N(10, 0.1²)
mu, sigma = 10, 0.1

# 问：零件长度在 9.9 到 10.1 之间的概率？
prob = norm.cdf(10.1, mu, sigma) - norm.cdf(9.9, mu, sigma)
print(f"P(9.9 < X < 10.1) = {prob:.4f}")

# 问：99% 的零件长度在什么范围内？
lower = norm.ppf(0.005, mu, sigma)
upper = norm.ppf(0.995, mu, sigma)
print(f"99% 范围：[{lower:.3f}, {upper:.3f}]")
```

## 🔗 与其他知识的联系

### 与机器学习的联系

1. **逻辑回归**：输出服从伯努利分布
2. **线性回归**：假设误差服从正态分布
3. **朴素贝叶斯**：特征服从某种分布
4. **生成模型**：直接学习数据的概率分布
5. **变分自编码器**：潜在空间用正态分布建模

### 与统计推断的联系

1. **参数估计**：用样本估计分布参数
2. **假设检验**：检验数据是否来自某分布
3. **置信区间**：基于分布构造区间估计
