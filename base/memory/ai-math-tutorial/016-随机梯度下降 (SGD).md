# 016 | 随机梯度下降 (SGD)

> 🎯 **一句话核心**：SGD 每次只用一个样本来估计梯度——牺牲准确性换取速度，噪声反而帮助模型逃离局部最优，这是深度学习能训练的关键。

---

## 🤔 为什么需要 SGD？

### 问题：大数据集上的梯度下降太慢了！

回顾标准梯度下降（Batch GD）：

```
∇L(θ) = 1/n · Σ ∇Lᵢ(θ)
         i=1
```

**每次更新需要**：
- 遍历全部 n 个样本
- 计算 n 次梯度
- 求平均

**当 n = 100 万时**：
- 每次更新都要处理 100 万个样本
- 训练一个 epoch 可能需要几小时
- 收敛需要几十个 epoch...
- **太慢了！** ❌

---

### 一个极端想法

**能不能只用一个样本来估计梯度？**

```
∇L(θ) ≈ ∇Lᵢ(θ)  (随机选一个样本 i)
```

这就是**随机梯度下降 (Stochastic Gradient Descent, SGD)**！

---

### 直观对比

```
Batch GD:                    SGD:
━━━━━━━━━                  ━

▓▓▓▓▓▓▓▓▓▓  (100%)         ▓  (1%)
  ↓                          ↓
准确但慢                     快但有噪声
```

---

## 📖 SGD 算法详解

### 1. 算法流程

#### Batch GD（回顾）

```
for epoch in range(epochs):
    # 计算全部样本的梯度
    grad = 0
    for i in range(n):
        grad += ∇Lᵢ(θ)
    grad = grad / n
    
    # 更新一次
    θ = θ - η·grad
```

**特点**：
- 每个 epoch 更新 **1 次**
- 梯度估计准确（方差小）
- 计算成本高

---

#### SGD

```
for epoch in range(epochs):
    # 打乱数据
    indices = random_permutation(n)
    
    for i in indices:
        # 每个样本更新一次
        grad = ∇Lᵢ(θ)
        θ = θ - η·grad
```

**特点**：
- 每个 epoch 更新 **n 次**
- 梯度估计有噪声（方差大）
- 计算成本低

---

#### Mini-batch SGD（折中方案）

```
batch_size = 32  # 或 64, 128, 256

for epoch in range(epochs):
    indices = random_permutation(n)
    
    for start in range(0, n, batch_size):
        batch = indices[start:start+batch_size]
        
        # 用小批量估计梯度
        grad = 0
        for i in batch:
            grad += ∇Lᵢ(θ)
        grad = grad / len(batch)
        
        θ = θ - η·grad
```

**特点**：
- 每个 epoch 更新 **n/batch_size 次**
- 平衡了准确性和速度
- **最常用！** ✅

---

### 2. 收敛轨迹对比

```
损失函数等高线图：

          Batch GD              SGD              Mini-batch
          ━━━━━━━━━          ━━━              ━━━━
          
              ·                  ·  ·              ·
             /                  /    ·            / ·
            ·                  ·      ·          ·   ·
           ·                  ·        ·        ·     ·
          ·                  ·          ·      ·       ·
         ·                  ·            ·    ·         ·
        ·                  ·              ·  ·           ·
       ·                  ·                ·             ·
      ·                  ·                                ·
     ·                  ·                                  ·
    
    平滑、稳定            震荡、但有进展      较平滑、较快
    可能卡在局部          能跳出局部          最佳平衡
```

**观察**：
- **Batch GD**：路径平滑，但可能陷入局部最小值
- **SGD**：路径震荡，但噪声帮助跳出局部最优
- **Mini-batch**：折中，兼顾稳定性和探索能力

---

### 3. 为什么 SGD 的噪声有帮助？

#### 逃离局部最小值

```
损失函数：

      _       _
     / \     / \
    /   \___/   \
   ·             ·
   
   Batch GD → 卡在这里 ❌
   SGD → 噪声帮助跳出来 ✅
```

**直观理解**：
- SGD 的梯度噪声相当于给优化过程加了"随机扰动"
- 类似于**模拟退火**中的温度
- 帮助探索更大的参数空间

---

#### 泛化能力更好

**研究发现**：
- SGD 找到的解往往比 Batch GD **泛化更好**
- 原因：SGD 倾向于找到**平坦的极小值**（flat minima）

```
        尖锐极小值          平坦极小值
        (Batch GD)          (SGD)
        
           _                   ___
         _/ \_               _/   \_
        /     \             /       \
       ·       ·           ·         ·
       
       泛化差 ❌             泛化好 ✅
```

**解释**：
- 尖锐极小值：参数稍微变化，损失就大幅增加（过拟合）
- 平坦极小值：参数变化对损失影响小（鲁棒性强）

### 实现：三种梯度下降对比

```python
import numpy as np
import matplotlib.pyplot as plt

def batch_gd(X, y, lr=0.01, epochs=100):
    """批量梯度下降"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    losses = []
    
    for epoch in range(epochs):
        # 全部样本计算梯度
        y_pred = X @ w
        grad = -2/n_samples * X.T @ (y - y_pred)
        w = w - lr * grad
        
        loss = np.mean((y - y_pred) ** 2)
        losses.append(loss)
    
    return w, losses

def sgd(X, y, lr=0.01, epochs=100):
    """随机梯度下降"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    losses = []
    
    for epoch in range(epochs):
        # 打乱数据
        indices = np.random.permutation(n_samples)
        epoch_loss = 0
        
        for i in indices:
            xi, yi = X[i], y[i]
            y_pred = xi @ w
            grad = -2 * xi * (yi - y_pred)
            w = w - lr * grad
            epoch_loss += (yi - y_pred) ** 2
        
        losses.append(epoch_loss / n_samples)
    
    return w, losses

def mini_batch_gd(X, y, lr=0.01, epochs=100, batch_size=32):
    """小批量梯度下降"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    losses = []
    
    for epoch in range(epochs):
        indices = np.random.permutation(n_samples)
        epoch_loss = 0
        
        for start in range(0, n_samples, batch_size):
            batch_idx = indices[start:start+batch_size]
            X_batch, y_batch = X[batch_idx], y[batch_idx]
            
            y_pred = X_batch @ w
            grad = -2/len(batch_idx) * X_batch.T @ (y_batch - y_pred)
            w = w - lr * grad
            
            epoch_loss += np.sum((y_batch - y_pred) ** 2)
        
        losses.append(epoch_loss / n_samples)
    
    return w, losses

# 生成数据

w_sgd, losses_sgd = sgd(X, y, lr, epochs)
w_mb, losses_mb = mini_batch_gd(X, y, lr, epochs, batch_size=32)

# 可视化

# 1. 损失收敛对比

axes[0].set_xlabel('Epoch')
```

## 🧠 深度理解

### 1. 收敛性分析

#### Batch GD 的收敛

```
对于凸函数：
- 收敛速度：O(1/ε)
- 需要 O(1/ε) 次迭代达到误差 ε
- 每次迭代成本：O(n)
- 总成本：O(n/ε)
```

#### SGD 的收敛

```
对于凸函数：
- 收敛速度：O(1/ε²)
- 需要 O(1/ε²) 次迭代
- 每次迭代成本：O(1)
- 总成本：O(1/ε²)
```

**对比**：
- 要达到**高精度**（ε 很小），Batch GD 更好
- 要达到**中等精度**，SGD 更快（因为每次迭代便宜）

**深度学习中**：
- 我们不需要极高精度
- 训练数据量巨大（n 很大）
- **SGD 完胜！** ✅

### 2. 学习率调度对 SGD 至关重要

#### 问题

SGD 的学习率选择更敏感：
- 太大：震荡严重，不收敛
- 太小：进展太慢

#### 解决方案：学习率衰减

```
η_t = η₀ / (1 + decay · t)
```

或者：

```
η_t = η₀ · γ^(t/step_size)  # 每 step_size 轮乘以 γ
```

---

#### 代码实现

```python
def sgd_with_lr_schedule(X, y, epochs=100, lr_init=0.1, schedule='step'):
    """SGD with learning rate scheduling"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    history = {'loss': [], 'lr': [], 'w': []}
    
    for epoch in range(epochs):
        # 学习率调度
        if schedule == 'step':
            lr = lr_init * (0.5 ** (epoch // 20))  # 每 20 轮减半
        elif schedule == 'exponential':
            lr = lr_init * (0.95 ** epoch)
        elif schedule == 'cosine':
            lr = lr_init * 0.5 * (1 + np.cos(np.pi * epoch / epochs))
        else:
            lr = lr_init
        
        indices = np.random.permutation(n_samples)
        epoch_loss = 0
        
        for i in indices:
            xi, yi = X[i], y[i]
            y_pred = xi @ w
            grad = -2 * xi * (yi - y_pred)
            w = w - lr * grad
            epoch_loss += (yi - y_pred) ** 2
        
        history['loss'].append(epoch_loss / n_samples)
        history['lr'].append(lr)
        history['w'].append(w.copy())
    
    return w, history

# 对比不同调度
w_const, h_const = sgd(X, y, lr=0.1, epochs=100)
w_step, h_step = sgd_with_lr_schedule(X, y, lr_init=0.1, schedule='step')
w_cosine, h_cosine = sgd_with_lr_schedule(X, y, lr_init=0.1, schedule='cosine')

fig, axes = plt.subplots(1, 2, figsize=(14, 5))

# 损失对比
axes[0].plot(h_const['loss'], 'b-', linewidth=2, label='固定学习率')

axes[0].set_xlabel('Epoch')
axes[0].set_ylabel('损失')
axes[0].set_title('不同学习率调度的对比')
axes[0].legend()

axes[0].set_yscale('log')

# 学习率变化
```

### 3. SGD vs Adam：如何选择？

#### 对比表

| 特性 | SGD + Momentum | Adam |
|------|---------------|------|
| **收敛速度** | 较慢 | 快 |
| **最终精度** | 往往更好 | 稍差 |
| **超参数敏感** | 是 | 否 |
| **内存占用** | 低 | 中 |
| **适用场景** | 图像分类 | NLP、GAN、通用 |

---

#### 实践建议

**用 SGD + Momentum**：
- 图像分类（ResNet、EfficientNet）
- 需要最佳泛化性能
- 有时间仔细调参

**用 Adam/AdamW**：
- NLP 任务（Transformer、BERT）
- GAN 训练
- 快速原型验证
- 不想调太多超参数

### 4. 小批量大小的选择

#### 经验法则

| 批量大小 | 适用场景 |
|---------|---------|
| **16-32** | 小数据集、显存有限、RNN |
| **64** | 默认起点 |
| **128** | 图像分类（ResNet） |
| **256-512** | 大数据集、分布式训练 |
| **1024+** | 需要学习率 warmup |

---

#### 批量大小与学习率的关系

**线性缩放规则**：
```
如果批量大小 ×k，学习率也 ×k
```

**例子**：
- batch=32, lr=0.1 ✅
- batch=128 (×4), lr=0.4 ✅
- batch=256 (×8), lr=0.8 ✅

**原因**：
- 大批量梯度估计更准确（方差小）
- 可以承受更大的学习率

---

#### 代码实现

```python
def scale_lr_with_batch(base_lr, base_batch, new_batch):
    """根据批量大小缩放学习率"""
    return base_lr * (new_batch / base_batch)

# 例子
base_lr = 0.1
base_batch = 32

for new_batch in [64, 128, 256, 512]:
    new_lr = scale_lr_with_batch(base_lr, base_batch, new_batch)
    print(f"Batch {new_batch:4d} → LR = {new_lr:.4f}")
```

```python
import torch

    momentum=0.9,
    weight_decay=1e-4

scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer, step_size=30, gamma=0.1
)

# 训练循环
for epoch in range(100):
    for batch_X, batch_y in dataloader:
        # 前向传播
        y_pred = model(batch_X)
        loss = nn.MSELoss()(y_pred, batch_y)
        
        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    
    scheduler.step()  # 更新学习率
    
    if epoch % 10 == 0:
        print(f"Epoch {epoch}, Loss: {loss.item():.4f}")
```

```python
def sgd_with_momentum(X, y, lr=0.01, momentum=0.9, epochs=100):
    """实现带动量的 SGD"""
    n_samples, n_features = X.shape
    w = np.zeros(n_features)
    v = np.zeros(n_features)  # 速度
    
    for epoch in range(epochs):
        indices = np.random.permutation(n_samples)
        
        for i in indices:
            xi, yi = X[i], y[i]
            y_pred = xi @ w
            grad = -2 * xi * (yi - y_pred)
            
            # 动量更新
            v = momentum * v + lr * grad
            w = w - v
    
    return w
```

## 🔑 核心要点总结

| 概念 | 要点 |
|------|------|
| **SGD** | 单样本估计梯度，快但有噪声 |
| **Mini-batch** | 折中方案，batch_size=32~128 |
| **噪声的益处** | 帮助跳出局部最优，泛化更好 |
| **学习率调度** | 对 SGD 至关重要，必须衰减 |
| **SGD vs Adam** | SGD 泛化好，Adam 收敛快 |
| **批量缩放** | batch×k → lr×k |
| **Momentum** | 加速收敛，减少震荡 |
