## 📖 大数定律：直觉先行

### 一个经典实验

想象你抛一枚公平的硬币：

```
抛 10 次：可能 7 次正面，3 次反面 → 正面频率 = 0.7
抛 100 次：可能 53 次正面，47 次反面 → 正面频率 = 0.53
抛 1000 次：可能 508 次正面，492 次反面 → 正面频率 = 0.508
抛 10000 次：可能 5012 次正面，4988 次反面 → 正面频率 = 0.5012
```

**观察**：随着实验次数增加，频率越来越接近真实概率 0.5。

这就是**大数定律**的核心思想！

### 生活中的例子

| 场景 | 少量样本 | 大量样本 |
|------|----------|----------|
| 抛硬币 | 可能连续 5 次正面 | 正面比例趋近 50% |
| 掷骰子 | 平均值可能是 2 或 5 | 平均值趋近 3.5 |
| 网站转化率 | 10 个访客可能 0 个转化 | 10000 个访客转化率稳定 |
| 模型准确率 | 10 个样本可能 100% | 10000 个样本趋于真实水平 |

## 📐 数学表述

### 设有一组独立同分布随机变量

```
X₁, X₂, X₃, ..., Xₙ  独立同分布 (i.i.d.)

E[Xᵢ] = μ    (期望值)
Var(Xᵢ) = σ²  (方差，有限)
```

### 样本均值

```
X̄ₙ = (X₁ + X₂ + ... + Xₙ) / n

读作：n 个样本的平均值
```

### 弱大数定律 (WLLN) ⭐

```
对于任意 ε > 0：

lim (n→∞) P(|X̄ₙ - μ| ≥ ε) = 0

解读：
当样本量 n 趋向无穷时，
样本均值偏离真实期望超过 ε 的概率趋向于 0。

通俗说：样本越多，平均值越接近真实期望。
```

### 强大数定律 (SLLN) ⭐⭐

```
P(lim (n→∞) X̄ₙ = μ) = 1

解读：
以概率 1，样本均值几乎必然收敛到真实期望。

"几乎必然"比"依概率"更强：
- 弱大数定律：偏离的概率趋于 0
- 强大数定律：偏离的事件几乎不可能发生
```

### 两种定律的区别

```
弱大数定律：P(|X̄ₙ - μ| > ε) → 0
            （偏离的可能性越来越小）

强大数定律：P(X̄ₙ → μ) = 1
            （几乎一定会收敛）

强大数定律 ⇒ 弱大数定律
但反过来不一定成立
```

## 🔍 切比雪夫不等式：大数定律的基石

### 切比雪夫不等式

```
对于任意随机变量 X（期望 μ，方差 σ²）和任意 ε > 0：

P(|X - μ| ≥ ε) ≤ σ² / ε²

读作：偏离期望超过 ε 的概率，不超过方差除以 ε²
```

### 直观理解

```
方差 σ² 越小 → 概率上界越小 → 数据越集中在期望附近
ε 越大 → 概率上界越小 → 大幅偏离的概率越小
```

### 可视化

```
切比雪夫不等式给出了一个"保守估计"：

        σ²/ε²
    ┌─────────┐
    │         │
    │  实际概率 │  ≤  ──────
    │   往往    │       ε²
    │  小得多   │
    └─────────┘

切比雪夫给出的是上界，实际概率通常远小于上界
```

### 用切比雪夫证明弱大数定律

```
证明思路：

1. X̄ₙ = (X₁ + ... + Xₙ) / n

2. E[X̄ₙ] = μ
   （样本均值的期望 = 真实期望）

3. Var(X̄ₙ) = Var(X₁ + ... + Xₙ) / n²
           = n × σ² / n²       （独立性！）
           = σ² / n

4. 应用切比雪夫不等式：
   P(|X̄ₙ - μ| ≥ ε) ≤ Var(X̄ₙ) / ε²
                    = σ² / (n × ε²)

5. 当 n → ∞ 时：
   σ² / (n × ε²) → 0

   ∴ P(|X̄ₙ - μ| ≥ ε) → 0  ∎
```

**关键洞察**：方差以 1/n 的速度衰减！样本越多，样本均值越集中。

## 🎯 蒙特卡洛方法：大数定律的工程应用

### 什么是蒙特卡洛方法？

```
蒙特卡洛方法 = 用随机抽样来估计数值

核心原理：大数定律
  → 样本越多，估计越精确
```

### 应用 1：估算 π

```python
import numpy as np
import matplotlib.pyplot as plt

def estimate_pi(n_samples):
    """用蒙特卡洛方法估算 π"""
    # 在 [-1, 1] × [-1, 1] 正方形内随机撒点
    x = np.random.uniform(-1, 1, n_samples)
    y = np.random.uniform(-1, 1, n_samples)
    
    # 计算到原点的距离
    distance = np.sqrt(x**2 + y**2)
    
    # 落在单位圆内的点数
    inside_circle = np.sum(distance <= 1)
    
    # π ≈ 4 × (圆内点数 / 总点数)
    pi_estimate = 4 * inside_circle / n_samples
    
    return pi_estimate

# 不同样本量的估计
for n in [100, 1000, 10000, 100000, 1000000]:
    pi_est = estimate_pi(n)
    error = abs(pi_est - np.pi)
    print(f"样本量 {n:7d}: π ≈ {pi_est:.6f}, 误差 = {error:.6f}")

# 可视化收敛过程

n_max = 100000
```

### 应用 2：计算积分

```python
import numpy as np

def monte_carlo_integral(f, a, b, n_samples):
    """用蒙特卡洛方法计算定积分 ∫[a,b] f(x)dx"""
    # 在 [a, b] 内随机抽样
    x = np.random.uniform(a, b, n_samples)
    
    # 大数定律：积分 ≈ 区间长度 × 函数值的平均
    integral_estimate = (b - a) * np.mean(f(x))
    
    return integral_estimate

# 例子：计算 ∫[0,1] x² dx = 1/3
f = lambda x: x**2
exact = 1/3

for n in [100, 1000, 10000, 100000, 1000000]:
    est = monte_carlo_integral(f, 0, 1, n)
    error = abs(est - exact)
    print(f"样本量 {n:7d}: 积分 ≈ {est:.6f}, 误差 = {error:.6f}")

# 复杂积分：∫[0,π] sin(x)dx = 2
import math
f2 = lambda x: np.sin(x)
exact2 = 2.0

print(f"\n∫[0,π] sin(x)dx = {exact2}")
for n in [1000, 10000, 100000, 1000000]:
    est = monte_carlo_integral(f2, 0, math.pi, n)
    error = abs(est - exact2)
    print(f"样本量 {n:7d}: 积分 ≈ {est:.6f}, 误差 = {error:.6f}")
```

### 应用 3：AI 中的蒙特卡洛方法

```python
import numpy as np

# 1. 蒙特卡洛 Dropout（模型不确定性估计）
def monte_carlo_dropout_predict(model, X, n_dropouts=50):
    """
    在推理时保持 Dropout 开启，多次预测
    利用大数定律：多次预测的平均 = 更好的估计
    """
    predictions = []
    for _ in range(n_dropouts):
        pred = model.predict(X)  # Dropout 仍在随机失活
        predictions.append(pred)
    
    predictions = np.array(predictions)  # shape: (50, n_samples, ...)
    
    # 平均预测（大数定律保证收敛）
    mean_pred = np.mean(predictions, axis=0)
    
    # 预测不确定性（标准差）
    uncertainty = np.std(predictions, axis=0)
    
    return mean_pred, uncertainty

# 2. 蒙特卡洛树搜索 (MCTS)
# AlphaGo 的核心算法之一
# 通过大量随机对弈（模拟）来评估棋局价值
# 模拟次数越多，评估越准确（大数定律）

# 3. 强化学习中的蒙特卡洛方法
# 通过大量 episode 采样来估计状态价值
def monte_carlo_policy_evaluation(episodes, n_samples=10000):
    """
    蒙特卡洛策略评估
    用大量 episode 的平均回报来估计状态价值
    """
    state_returns = {}  # state → list of returns
    
    for _ in range(n_samples):
        # 执行一个 episode
        episode = np.random.choice(episodes)
        for state, reward in episode:
            if state not in state_returns:
                state_returns[state] = []
            state_returns[state].append(reward)
    
    # 大数定律：平均回报 → 真实状态价值
    state_values = {
        state: np.mean(returns) 
        for state, returns in state_returns.items()
    }
    
    return state_values
```

## 💡 大数定律的直觉理解

### 为什么样本越多越准确？

```
关键：方差的衰减

单个样本 Xᵢ：Var(Xᵢ) = σ²
n 个样本的平均 X̄ₙ：Var(X̄ₙ) = σ²/n

随着 n 增大：
- 方差以 1/n 的速度减小
- 标准差以 1/√n 的速度减小

这意味着：
- 样本量增加 100 倍 → 标准差缩小 10 倍
- 样本量增加 10000 倍 → 标准差缩小 100 倍
```

### 直观比喻

```
🎯  dartboard（飞镖靶）

1 次投掷：可能偏离靶心很远
10 次投掷：平均位置更接近靶心
100 次投掷：平均位置非常接近靶心
1000 次投掷：平均位置几乎就在靶心

每次投掷是随机的（有方差）
但平均位置是确定的（收敛到期望）
```

### 收敛速度的现实含义

```
精度提升需要"平方级"的样本量：

想要精度提升 10 倍 → 需要 100 倍样本
想要精度提升 100 倍 → 需要 10000 倍样本

这就是为什么深度学习需要海量数据！
```

## ⚠️ 常见误区

### 误区 1：赌徒谬误 ❌

```
❌ "已经连续 5 次正面了，下次一定是反面！"
✅ 每次抛硬币是独立的，概率始终是 0.5

大数定律说的是"大量样本的平均"，
不是"下一次的结果会补偿之前的偏差"。
```

### 误区 2：小样本代表性 ❌

```
❌ "我试了 10 次，模型准确率 90%，所以它很好"
✅ 10 个样本太小，结果可能只是运气

大数定律要求"大量样本"，
小样本的波动可能很大。
```

### 误区 3：期望值一定可达 ❌

```
❌ "期望收益是正的，所以我应该一直玩"

例子：圣彼得堡悖论
- 抛硬币，第一次正面得 2 元，第二次得 4 元，...
- 期望收益 = 2 + 2 + 2 + ... = ∞
- 但实际很少有人愿意花很多钱玩这个游戏

期望值 ≠ 实际能拿到的钱
```

### 应用 1：A/B 测试中的样本量计算

```python
import numpy as np
from scipy import stats

def calculate_sample_size(base_rate, min_detectable_effect, alpha=0.05, power=0.8):
    """
    计算 A/B 测试所需的最小样本量
    基于大数定律：样本越大，检测效果越可靠
    """
    # 控制组转化率
    p1 = base_rate
    
    # 实验组转化率
    p2 = base_rate * (1 + min_detectable_effect)
    
    # 合并比例
    p_pool = (p1 + p2) / 2
    
    # 效应量（Cohen's h）
    h = 2 * np.arcsin(np.sqrt(p2)) - 2 * np.arcsin(np.sqrt(p1))
    
    # 所需样本量（每组）
    z_alpha = stats.norm.ppf(1 - alpha/2)
    z_beta = stats.norm.ppf(power)
    
    n = 2 * ((z_alpha + z_beta) / h) ** 2
    
    return int(np.ceil(n))

# 例子：基础转化率 5%，想检测 10% 的相对提升
n = calculate_sample_size(0.05, 0.10)
print(f"每组需要 {n} 个样本")
print(f"总计需要 {2*n} 个样本")

# 如果只想检测 20% 的相对提升（更容易检测）
n2 = calculate_sample_size(0.05, 0.20)
print(f"\n检测 20% 提升：每组需要 {n2} 个样本")
```

### 应用 2：模型评估的置信区间

```python
import numpy as np

def bootstrap_confidence_interval(predictions, true_labels, n_bootstrap=1000):
    """
    用 Bootstrap（基于大数定律）计算模型准确率的置信区间
    """
    n = len(predictions)
    accuracies = []
    
    for _ in range(n_bootstrap):
        # 有放回抽样
        indices = np.random.choice(n, n, replace=True)
        boot_preds = predictions[indices]
        boot_true = true_labels[indices]
        
        # 计算 bootstrap 样本的准确率
        acc = np.mean(boot_preds == boot_true)
        accuracies.append(acc)
    
    accuracies = np.sort(accuracies)
    
    # 95% 置信区间
    lower = accuracies[int(0.025 * n_bootstrap)]
    upper = accuracies[int(0.975 * n_bootstrap)]
    
    return np.mean(accuracies), lower, upper

# 例子
np.random.seed(42)
n_test = 1000
true_labels = np.random.randint(0, 2, n_test)
# 假设模型有 85% 的准确率
predictions = true_labels.copy()
flip_indices = np.random.choice(n_test, int(n_test * 0.15), replace=False)
predictions[flip_indices] = 1 - predictions[flip_indices]

mean_acc, lower, upper = bootstrap_confidence_interval(predictions, true_labels)
print(f"准确率：{mean_acc:.3f}")
print(f"95% 置信区间：[{lower:.3f}, {upper:.3f}]")
```

### 应用 3：蒙特卡洛积分在贝叶斯推断中的应用

```python
import numpy as np

def monte_carlo_expectation(f, distribution_sampler, n_samples=100000):
    """
    用蒙特卡洛方法估计 E[f(X)]
    
    大数定律保证：
    (1/n) Σ f(Xᵢ) → E[f(X)]  当 n → ∞
    """
    samples = distribution_sampler(n_samples)
    return np.mean(f(samples))

# 例子：估计 E[sin(X)]，其中 X ~ N(0, 1)
from scipy import integrate

# 精确值（数值积分）
exact, _ = integrate.quad(
    lambda x: np.sin(x) * (1/np.sqrt(2*np.pi)) * np.exp(-x**2/2),
    -10, 10
)

# 蒙特卡洛估计
np.random.seed(42)
mc_estimate = monte_carlo_expectation(
    np.sin,
    lambda n: np.random.normal(0, 1, n),
    n_samples=100000
)

print(f"精确值：{exact:.6f}")
print(f"蒙特卡洛估计：{mc_estimate:.6f}")
print(f"误差：{abs(mc_estimate - exact):.6f}")
```

### 1. 训练集与测试集

```
大数定律保证了：
- 训练集越大，经验风险越接近真实风险
- 测试集越大，评估结果越可靠

E[经验风险] = E[真实风险]

但要注意：这要求训练集和测试集来自同一分布 (i.i.d.)！
```

### 2. 蒙特卡洛 Dropout

```
推理时多次前向传播（Dropout 随机失活不同神经元）
取平均作为最终预测

大数定律保证：多次预测的平均 → 更好的估计
```

### 3. 强化学习

```
Q(s, a) 的估计 = 大量 episode 的平均回报
样本越多，Q 值估计越准确
```

### 4. 集成学习

```
随机森林 = 大量决策树的平均
Bagging = 多次抽样训练，取平均

大数定律：平均的结果比单个模型更稳定、更准确
```

### 5. 蒙特卡洛树搜索 (MCTS)

```
AlphaGo 的核心算法
通过大量随机对弈模拟来评估棋局
模拟次数越多，评估越准确
```

### 6. 变分推断中的蒙特卡洛估计

```
ELBO 中的期望项用蒙特卡洛采样估计：

L 越大，估计越精确（大数定律）
```

```python
for eps in epsilons:
    # 实际概率
    actual_prob = np.mean(np.abs(samples) >= eps)
    
    # 切比雪夫上界：σ²/ε² = 1/ε²
    chebyshev_bound = 1 / eps**2
    
    print(f"{eps:.1f}    | {actual_prob:.4f}     | {chebyshev_bound:.4f}      | {chebyshev_bound/actual_prob:.1f}x")

# 注意：切比雪夫上界总是 ≥ 实际概率，但通常宽松很多
```

### 练习 3：蒙特卡洛估算高维球体积

```python
import numpy as np

def monte_carlo_sphere_volume(dimension, n_samples):
    """
    用蒙特卡洛方法估算 d 维单位球的体积
    
    在 [-1,1]^d 超立方体内随机撒点
    统计落在单位球内的比例
    """
    # 在超立方体内随机抽样
    samples = np.random.uniform(-1, 1, (n_samples, dimension))
    
    # 计算到原点的距离
    distances = np.sqrt(np.sum(samples**2, axis=1))
    
    # 落在单位球内的比例
    inside_ratio = np.mean(distances <= 1)
    
    # 超立方体体积 = 2^d
    hypercube_volume = 2 ** dimension
    
    # 球体积 = 比例 × 超立方体体积
    sphere_volume = inside_ratio * hypercube_volume
    
    return sphere_volume

# 不同维度的体积
print("维度 | 蒙特卡洛估计 | 理论值")
print("-" * 45)

theoretical_volumes = {
    1: 2,                          # 线段
    2: np.pi,                      # 圆
    3: 4/3 * np.pi,                # 球
    4: np.pi**2 / 2,               # 4D
    5: 8/15 * np.pi**2,            # 5D
}

for d in range(1, 6):
    est = monte_carlo_sphere_volume(d, 1000000)
    theo = theoretical_volumes[d]
    print(f"  {d}  | {est:.6f}      | {theo:.6f}")

# 观察：维度越高，蒙特卡洛估计越不准确
# 这就是"维度灾难"！
```

## ✅ 小结

### 核心要点

1. **大数定律**：样本均值依概率收敛到期望值
2. **弱大数定律**：P(|X̄ₙ - μ| ≥ ε) → 0
3. **强大数定律**：P(X̄ₙ → μ) = 1（几乎必然收敛）
4. **切比雪夫不等式**：P(|X - μ| ≥ ε) ≤ σ²/ε²（证明工具）
5. **收敛速度**：标准差以 1/√n 衰减
6. **蒙特卡洛方法**：大数定律的工程应用
7. **赌徒谬误**：大数定律不适用于"下一次"的结果

### 公式速查

```
弱大数定律：lim P(|X̄ₙ - μ| ≥ ε) = 0
强大数定律：P(lim X̄ₙ = μ) = 1
切比雪夫：P(|X - μ| ≥ ε) ≤ σ²/ε²
收敛速度：Std(X̄ₙ) = σ/√n
```
