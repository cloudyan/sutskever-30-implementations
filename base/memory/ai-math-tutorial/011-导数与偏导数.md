# 011 | 导数与偏导数

> 🎯 **一句话核心**：导数衡量函数在某一点的变化率，是优化的基础——没有导数就没有梯度下降，没有深度学习。

---

## 🤔 从一个问题开始

### 问题 1：如何让 AI"知道"往哪个方向走能变得更好？

想象你在山上，想走到最低点（山谷）。你看不见全貌，只能看到脚下：

```
        你在这里
          ↓
         /|\
        / | \
       /  |  \
      /   |   \
     /    |    \
    /     |     \
   /      |      \
  /       |       \
 /        |        \
/         |         \
----------+----------
         山谷（最低点）
```

**你怎么知道该往哪边走？**

答案：用脚试探一下，哪个方向**下坡最陡**就往哪边走。

**导数**就是那个"试探"——它告诉你函数在某一点的**变化趋势和速率**。

---

### 问题 2：神经网络怎么"学习"？

神经网络训练的本质是**最小化损失函数**：

```
损失 (Loss) = 预测值与真实值的差距
```

我们需要找到一组参数，让损失最小。怎么找？

**答案**：计算损失函数对每个参数的导数，然后沿着导数的反方向更新参数。

这就是**反向传播**的核心！

## 📖 核心概念详解

### 1. 什么是导数？

#### 直观理解

导数 = **瞬时变化率** = 函数图像在某点的**切线斜率**

```
函数 f(x) = x²

在 x=2 处：
     |
     |           /
     |         /
     |       /  ← 切线斜率 = 4
     |     /|
     |   /  |
     | /    |
-----+------+-----
     2
```

#### 正式定义

函数 f(x) 在点 x 处的导数定义为：

```
f'(x) = lim(h→0) [f(x+h) - f(x)] / h
```

**解读**：
- h 是一个很小的增量
- [f(x+h) - f(x)] / h 是平均变化率
- 当 h 趋近于 0 时，得到**瞬时**变化率

---

### 2. 常见函数的导数

| 函数 f(x) | 导数 f'(x) | 说明 |
|-----------|------------|------|
| c (常数) | 0 | 常数不变化 |
| x | 1 | 线性函数斜率为 1 |
| x² | 2x | 幂函数 |
| xⁿ | n·xⁿ⁻¹ | 幂函数通用公式 |
| √x | 1/(2√x) | 根号 |
| eˣ | eˣ | 指数函数（特殊！） |
| ln(x) | 1/x | 自然对数 |
| sin(x) | cos(x) | 正弦 |
| cos(x) | -sin(x) | 余弦 |

---

### 3. 求导法则

#### 线性法则
```
f(x) = a·g(x) + b·h(x)
f'(x) = a·g'(x) + b·h'(x)
```

#### 乘积法则
```
f(x) = g(x) · h(x)
f'(x) = g'(x)·h(x) + g(x)·h'(x)
```

#### 商法则
```
f(x) = g(x) / h(x)
f'(x) = [g'(x)·h(x) - g(x)·h'(x)] / [h(x)]²
```

#### 链式法则（最重要！）
```
f(x) = g(h(x))  # 复合函数
f'(x) = g'(h(x)) · h'(x)
```

**链式法则是反向传播的灵魂**！后面会单独详细讲。

---

### 4. 偏导数：多变量函数的导数

AI 中的函数通常有**多个输入**（参数）：

```
f(x, y) = x² + 2xy + y²
```

**偏导数**：固定其他变量，只对其中一个变量求导。

#### 对 x 求偏导（把 y 当常数）
```
∂f/∂x = 2x + 2y
```

#### 对 y 求偏导（把 x 当常数）
```
∂f/∂y = 2x + 2y
```

**符号**：
- `∂f/∂x` 或 `f_x` 表示对 x 的偏导
- `∂` 读作 "partial" 或 "del"

---

### 5. 梯度：所有偏导数的向量

对于多变量函数 f(x₁, x₂, ..., xₙ)，**梯度**定义为：

```
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

**梯度的几何意义**：
- 梯度是一个**向量**
- 指向函数**增长最快**的方向
- 梯度的模（长度）表示增长的速率

```
        梯度方向（最陡上升）
            ↑
            |
            |
    · · · · · · · · ·  等高线
            |
            |
            · 你在这里
```

**关键结论**：
- 沿梯度方向走 → 函数值增加最快
- 沿梯度反方向走 → 函数值减小最快（梯度下降）

## 💻 代码实现

### 从零实现导数和梯度

```python
import numpy as np
import matplotlib.pyplot as plt

# ==================== 数值微分 ====================

def numerical_derivative(f, x, h=1e-5):
    """
    用数值方法近似计算导数
    f: 函数
    x: 求导点
    h: 很小的增量
    """
    return (f(x + h) - f(x - h)) / (2 * h)  # 中心差分，更精确

# 测试
def f1(x):
    return x ** 2

x = 2
print(f"f(x) = x² 在 x={x} 处的导数：{numerical_derivative(f1, x)}")
print(f"理论值：{2 * x}")  # 4

# ==================== 偏导数 ====================

def numerical_partial_derivative(f, x, i, h=1e-5):
    """
    计算多变量函数的偏导数
    f: 函数（输入为 numpy 数组）
    x: 求导点（数组）
    i: 对第 i 个变量求导
    """
    x_plus = x.copy()
    x_minus = x.copy()
    x_plus[i] += h
    x_minus[i] -= h
    return (f(x_plus) - f(x_minus)) / (2 * h)

# 测试
def f2(vars):
    x, y = vars
    return x ** 2 + 2 * x * y + y ** 2

point = np.array([1.0, 2.0])
print(f"\nf(x,y) = x² + 2xy + y² 在 (1, 2) 处：")
print(f"∂f/∂x = {numerical_partial_derivative(f2, point, 0)}")  # 理论：2x + 2y = 6
print(f"∂f/∂y = {numerical_partial_derivative(f2, point, 1)}")  # 理论：2x + 2y = 6

# ==================== 梯度 ====================

def numerical_gradient(f, x, h=1e-5):
    """
    计算多变量函数的梯度
    """
    grad = np.zeros_like(x)
    for i in range(len(x)):
        grad[i] = numerical_partial_derivative(f, x, i, h)
    return grad

# 测试
print(f"\n在 (1, 2) 处的梯度：{numerical_gradient(f2, point)}")
# 理论：[6, 6]

# ==================== 可视化：导数的几何意义 ====================

def plot_derivative():
    """可视化函数和它的导数"""
    x = np.linspace(-3, 3, 100)
    y = x ** 2  # f(x) = x²
    dy = 2 * x  # f'(x) = 2x
    
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))
    
    # 原函数
    ax1.plot(x, y, 'b-', label='f(x) = x²')
    ax1.set_title('原函数')
    ax1.set_xlabel('x')
    ax1.set_ylabel('f(x)')
    ax1.grid(True)
    ax1.legend()
    
    # 导数
    ax2.plot(x, dy, 'r-', label="f'(x) = 2x")
    ax2.set_title('导数函数')
    ax2.set_xlabel('x')
    ax2.set_ylabel("f'(x)")
    ax2.grid(True)
    ax2.legend()
    
    plt.tight_layout()
    plt.savefig('derivative_visualization.png')
    print("\n已保存可视化图像：derivative_visualization.png")

plot_derivative()

# ==================== 可视化：梯度和等高线 ====================

def plot_gradient_field():
    """可视化梯度场和等高线"""
    x = np.linspace(-3, 3, 20)
    y = np.linspace(-3, 3, 20)
    X, Y = np.meshgrid(x, y)
    
    # 函数：f(x,y) = x² + y²
    Z = X ** 2 + Y ** 2
    
    # 梯度：∇f = [2x, 2y]
    dZ_dx = 2 * X
    dZ_dy = 2 * Y
    
    fig, ax = plt.subplots(figsize=(8, 8))
    
    # 等高线
    contour = ax.contour(X, Y, Z, levels=10, cmap='Blues')
    ax.clabel(contour, inline=True, fontsize=8)
    
    # 梯度场（箭头）
    ax.quiver(X, Y, dZ_dx, dZ_dy, color='red', alpha=0.6)
    
    ax.set_title('梯度场与等高线\nf(x,y) = x² + y²')
    ax.set_xlabel('x')
    ax.set_ylabel('y')
    ax.set_aspect('equal')
    ax.grid(True, alpha=0.3)
    
    plt.savefig('gradient_field.png')
    print("已保存梯度场图像：gradient_field.png")

plot_gradient_field()

# ==================== 梯度下降演示 ====================

def gradient_descent_demo():
    """演示梯度下降找最小值"""
    
    def f(x):
        return x ** 2 + 2 * x + 1  # 最小值在 x = -1
    
    def df(x):
        return 2 * x + 2
    
    # 梯度下降
    x = 3.0  # 初始点
    learning_rate = 0.1
    history = [x]
    
    for i in range(20):
        grad = df(x)
        x = x - learning_rate * grad  # 沿梯度反方向走
        history.append(x)
    
    print(f"\n梯度下降演示：")
    print(f"初始点：x = {history[0]:.4f}")
    print(f"最终点：x = {history[-1]:.4f}")
    print(f"理论最小值点：x = -1")
    print(f"迭代路径：{[f'{h:.2f}' for h in history[:10]]}...")
    
    # 可视化
    x_range = np.linspace(-3, 5, 100)
    y_range = f(x_range)
    
    plt.figure(figsize=(10, 5))
    plt.plot(x_range, y_range, 'b-', label='f(x) = x² + 2x + 1')
    plt.plot(history, [f(x) for x in history], 'ro-', label='梯度下降路径')
    plt.axvline(x=-1, color='g', linestyle='--', label='最小值点')
    plt.title('梯度下降法找最小值')
    plt.xlabel('x')
    plt.ylabel('f(x)')
    plt.legend()
    plt.grid(True)
    plt.savefig('gradient_descent.png')
    print("已保存梯度下降演示图像：gradient_descent.png")

gradient_descent_demo()
```

## 🔗 与 AI 的联系

### 1. 梯度下降：AI 训练的核心

神经网络训练的本质：

```
1. 定义损失函数 L(θ)，θ 是所有参数
2. 计算梯度 ∇L(θ) = [∂L/∂θ₁, ∂L/∂θ₂, ...]
3. 更新参数：θ = θ - η · ∇L(θ)
4. 重复直到收敛
```

其中 η 是学习率。

---

### 2. 反向传播：链式法则的应用

神经网络的复合结构：

```
输入 → 层 1 → 激活 → 层 2 → 激活 → ... → 输出 → 损失
```

反向传播用**链式法则**高效计算梯度：

```
∂L/∂w₁ = ∂L/∂a₂ · ∂a₂/∂z₂ · ∂z₂/∂w₁
```

没有链式法则，就没有深度学习！

---

### 3. 激活函数的导数

常见激活函数的导数：

| 激活函数 | 导数 |
|---------|------|
| Sigmoid: σ(x) = 1/(1+e⁻ˣ) | σ'(x) = σ(x)(1-σ(x)) |
| Tanh: tanh(x) | tanh'(x) = 1 - tanh²(x) |
| ReLU: max(0, x) | 1 (x>0), 0 (x<0) |

**为什么 ReLU 最常用？** 导数简单，计算快，避免梯度消失！

---

### 4. 优化器：改进梯度下降

基础梯度下降的改进：

| 优化器 | 核心思想 |
|--------|---------|
| SGD | 随机小批量，更快 |
| Momentum | 累积历史梯度，加速 |
| Adam | 自适应学习率，最常用 |

所有这些都基于**梯度**的概念！

## 🧠 常见误区

### ❌ 误区 1：导数就是斜率

**纠正**：导数是**瞬时**变化率，是切线的斜率。平均斜率是割线的斜率，两者不同。

---

### ❌ 误区 2：梯度总是指向最小值

**纠正**：梯度指向**增长最快**的方向。要找最小值，需要沿**梯度反方向**走（梯度下降）。

---

### ❌ 误区 3：导数为 0 就是最小值

**纠正**：导数为 0 是**驻点**，可能是：
- 最小值 ✓
- 最大值 ✗
- 鞍点（某些方向上升，某些方向下降）⚠️

需要二阶导数或更多信息判断。

---

### ❌ 误区 4：数值微分和符号微分一样好

**纠正**：
- **数值微分**：简单但有精度问题，计算慢
- **符号微分**：精确但表达式可能爆炸
- **自动微分**（PyTorch/TensorFlow 用的）：结合两者优点，精确且高效
