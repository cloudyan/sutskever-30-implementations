# 008 | 范数：如何衡量"大小"

> 🎯 **一句话核心**：范数是向量或矩阵"大小"的度量，不同范数强调不同特性——L1 产生稀疏性，L2 防止过拟合，是正则化和优化的基础。

---

## 🤔 从一个问题开始

### 问题：如何衡量向量的"长度"？

给定向量 v = [3, 4]，它的长度是多少？

**答案 1**：用勾股定理，长度 = √(3² + 4²) = 5（这是 L2 范数）

**答案 2**：用曼哈顿距离，长度 = |3| + |4| = 7（这是 L1 范数）

**答案 3**：用最大值，长度 = max(|3|, |4|) = 4（这是 L∞ 范数）

**哪个对**？都对！取决于你想衡量什么。

---

### 不同范数的直观

想象从 (0,0) 走到 (3,4)：

```
L1 范数（出租车距离）：
  沿街道走，先 3 格再 4 格，总共 7 格
  
L2 范数（欧几里得距离）：
  直线穿过街区，5 格
  
L∞ 范数（切比雪夫距离）：
  国际象棋国王走法，max(3,4) = 4 步
```

---

## 📖 核心概念详解

### 1. 范数的定义

**范数**是一个函数 ||·||，满足：

1. **非负性**：||x|| ≥ 0，且 ||x|| = 0 ⇔ x = 0
2. **齐次性**：||αx|| = |α|·||x||
3. **三角不等式**：||x + y|| ≤ ||x|| + ||y||

---

### 2. Lp 范数族

对于向量 x = [x₁, x₂, ..., xₙ]：

```
||x||_p = (|x₁|^p + |x₂|^p + ... + |xₙ|^p)^(1/p)
```

**常见特例**：

| 范数 | p 值 | 公式 | 名称 |
|------|------|------|------|
| L0 | 0 | 非零元素个数 | "伪范数" |
| L1 | 1 | Σ|xᵢ| | 曼哈顿范数 |
| L2 | 2 | √(Σxᵢ²) | 欧几里得范数 |
| L∞ | ∞ | max|xᵢ| | 最大范数 |

---

### 3. L1 vs L2：关键区别

#### 几何形状

```
L1 单位圆（||x||₁ = 1）：
    菱形
      ♦
    
L2 单位圆（||x||₂ = 1）：
    圆形
      ○
```

#### 稀疏性

**L1 范数倾向于产生稀疏解**（很多系数为 0）

原因：L1 的等高线有"角"，最优解容易落在坐标轴上。

**应用**：Lasso 回归、特征选择、压缩感知。

---

### 4. 正则化中的范数

#### L2 正则化（Ridge）

```
损失函数 + λ·||w||₂²

作用：
- 防止过拟合
- 权重衰减
- 解稳定（可导）
```

#### L1 正则化（Lasso）

```
损失函数 + λ·||w||₁

作用：
- 防止过拟合
- 特征选择（产生稀疏解）
- 不可导，需要特殊优化
```

#### Elastic Net

```
损失函数 + λ₁·||w||₁ + λ₂·||w||₂²

结合 L1 和 L2 的优点
```

---

### 5. 矩阵范数

对于矩阵 A：

| 范数 | 公式 | 说明 |
|------|------|------|
| Frobenius | √(Σaᵢⱼ²) | 类似向量的 L2 |
| 谱范数 | σ₁(A) | 最大奇异值 |
| 核范数 | Σσᵢ | 奇异值之和，用于低秩近似 |

```python
def clip_gradient(grad, max_norm):
    """
    梯度裁剪：如果梯度 L2 范数超过阈值，就缩放
    """
    grad_norm = np.linalg.norm(grad)
    if grad_norm > max_norm:
        grad = grad * (max_norm / grad_norm)
    return grad

# 模拟梯度
```

## 🔗 与 AI 的联系

### 1. 正则化

- **L2 正则化**：权重衰减，防止过拟合
- **L1 正则化**：特征选择，产生稀疏模型
- **Elastic Net**：两者结合

---

### 2. 损失函数

- **MSE**：L2 损失，对异常值敏感
- **MAE**：L1 损失，鲁棒性强
- **Huber**：L1+L2 结合

---

### 3. 梯度裁剪

用 L2 范数限制梯度大小，防止梯度爆炸。

---

### 4. 归一化

- **BatchNorm**：用 L2 范数归一化
- **LayerNorm**：类似

---

### 5. 稀疏编码

L1 正则化用于学习稀疏表示。

---

## 🧠 常见误区

### ❌ 误区 1：L0 范数是真正的范数

**纠正**：L0"范数"不满足齐次性，只是伪范数。

它计算非零元素个数，用于衡量稀疏性。

---

### ❌ 误区 2：L2 范数总是比 L1 好

**纠正**：取决于应用：
- 需要稀疏解 → L1
- 需要可导、稳定 → L2
- 有异常值 → L1 更鲁棒

---

### ❌ 误区 3：范数只用于向量

**纠正**：矩阵也有范数（Frobenius、谱范数、核范数）。

```python
def gradient_descent_l1(X, y, alpha=0.01, l1_lambda=0.1, n_iter=1000):
    n, p = X.shape
    w = np.zeros(p)
    
    for _ in range(n_iter):
        # 预测
        y_pred = X @ w
        
        # 梯度（MSE + L1 次梯度）
        gradient = (2/n) * X.T @ (y_pred - y)
        
        # L1 次梯度（符号函数）
        l1_subgradient = l1_lambda * np.sign(w)
        
        # 更新
        w = w - alpha * (gradient + l1_subgradient)
    
    return w
```
