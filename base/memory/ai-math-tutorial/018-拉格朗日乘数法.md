## 一、为什么需要约束优化？

### 1.1 现实世界的问题都有约束

**无约束优化**（我们已经学过）：
```python
minimize: f(x)  # 随便找 x，让 f(x) 最小
```

**约束优化**（现实问题）：
```python
minimize: f(x)
subject to: g(x) = 0  # 必须满足的约束
           h(x) ≤ 0   # 不等式约束
```

### 1.2 机器学习中的约束优化

| 应用场景 | 目标函数 | 约束条件 |
|----------|----------|----------|
| **SVM** | 最大化间隔 | 所有样本正确分类 |
| **投资组合** | 最大化收益 | 预算固定、风险上限 |
| **资源分配** | 最小化成本 | 满足需求、容量限制 |
| **模型压缩** | 最小化误差 | 参数量/计算量上限 |
| **公平性约束** | 最小化损失 | 不同群体公平性要求 |

### 1.3 一个直观例子

**问题**：在圆 `x² + y² = 1` 上找一点，使 `f(x,y) = x + y` 最大

```
        y
        ↑
    ╱""""╲
   ╱      ╲  圆：x² + y² = 1
  ╱   ●    ╲ ← 最优点（在圆上）
 ╱          ╲
─┼────────────→ x
 ╲          ╱
  ╲        ╱
   ╲______╱

目标：最大化 x + y（等高线是斜线）
约束：必须在圆上
```

**直觉**：
- 无约束时，x+y 可以无限大
- 有约束时，最优解在"等高线与圆相切"的地方

## 二、拉格朗日乘数法（等式约束）

### 2.1 核心思想

**关键洞察**：在最优解处，目标函数的梯度与约束函数的梯度**平行**

```
在最优解处：
∇f(x*) = λ · ∇g(x*)

λ 就是"拉格朗日乘数"
```

**为什么？**
- 如果不平行，说明还能沿着约束曲面移动，让 f 更小
- 只有平行时，才"无路可走"，达到最优

### 2.2 拉格朗日函数

**构造技巧**：把约束优化转化为无约束优化

```python
# 原问题
minimize: f(x)
subject to: g(x) = 0

# 拉格朗日函数
L(x, λ) = f(x) + λ · g(x)
```

**神奇之处**：
- 对 `x` 求导：`∇ₓL = ∇f(x) + λ·∇g(x) = 0` → 梯度平行条件
- 对 `λ` 求导：`∂L/∂λ = g(x) = 0` → 约束条件

### 2.3 求解步骤

```
步骤 1：构造拉格朗日函数
  L(x, λ) = f(x) + λ · g(x)

步骤 2：对所有变量求偏导，令其为零
  ∂L/∂x = 0
  ∂L/∂λ = 0

步骤 3：解方程组，得到候选解

步骤 4：验证哪个是最优解
```

### 2.4 具体例子

**问题**：在圆 `x² + y² = 1` 上最大化 `f(x,y) = x + y`

**步骤 1**：写成标准形式
```
minimize: -x - y  (最大化转最小化)
subject to: x² + y² - 1 = 0
```

**步骤 2**：构造拉格朗日函数
```
L(x, y, λ) = -x - y + λ(x² + y² - 1)
```

**步骤 3**：求偏导
```
∂L/∂x = -1 + 2λx = 0  →  x = 1/(2λ)
∂L/∂y = -1 + 2λy = 0  →  y = 1/(2λ)
∂L/∂λ = x² + y² - 1 = 0
```

**步骤 4**：解方程
```
x = y (从前面两个方程)
x² + x² = 1  →  2x² = 1  →  x = ±1/√2

候选解：
  (1/√2, 1/√2)  →  f = √2  (最大值) ✓
  (-1/√2, -1/√2) → f = -√2 (最小值)
```

### 2.5 Python 验证

```python
import numpy as np
from scipy.optimize import minimize

# 目标函数：最大化 x + y（最小化 -x-y）
def objective(x):
    return -x[0] - x[1]

# 约束：x² + y² = 1
def constraint(x):
    return x[0]**2 + x[1]**2 - 1

# 使用 scipy 求解
cons = {'type': 'eq', 'fun': constraint}
x0 = [0.5, 0.5]  # 初始猜测

result = minimize(objective, x0, constraints=cons)
print(f"最优解：x = {result.x[0]:.4f}, y = {result.x[1]:.4f}")
print(f"最大值：f = {-result.fun:.4f}")
```

**输出**：
```
最优解：x = 0.7071, y = 0.7071
最大值：f = 1.4142  (≈ √2) ✓
```

## 三、多个等式约束

### 3.1 推广

如果有多个等式约束：
```
minimize: f(x)
subject to: g₁(x) = 0
           g₂(x) = 0
           ...
           gₘ(x) = 0
```

**拉格朗日函数**：
```
L(x, λ₁, λ₂, ..., λₘ) = f(x) + λ₁·g₁(x) + λ₂·g₂(x) + ... + λₘ·gₘ(x)
```

**求解**：
```
∇ₓL = 0  →  ∇f(x) + Σλᵢ·∇gᵢ(x) = 0
∂L/∂λᵢ = 0  →  gᵢ(x) = 0  (所有约束)
```

### 3.2 例子：最大熵分布

**问题**：在均值为 μ、方差为 σ² 的条件下，找熵最大的概率分布

```
maximize: H(p) = -∫p(x)log(p(x))dx
subject to: ∫p(x)dx = 1         (概率和为 1)
           ∫x·p(x)dx = μ        (均值约束)
           ∫(x-μ)²·p(x)dx = σ²  (方差约束)
```

**解**：高斯分布！这就是为什么高斯分布如此常见——它是给定均值和方差下"最不确定"的分布。

## 四、不等式约束与 KKT 条件

### 4.1 不等式约束

**问题**：
```
minimize: f(x)
subject to: h(x) ≤ 0
```

**拉格朗日函数**：
```
L(x, λ) = f(x) + λ·h(x)
```

**关键区别**：
- λ ≥ 0（乘数非负）
- 互补松弛条件：λ·h(x) = 0

### 4.2 互补松弛条件的直觉

```
两种情况：

情况 1：约束不起作用（h(x) < 0）
  - 最优解在可行域内部
  - λ = 0（乘数为零）
  - 退化为无约束优化

情况 2：约束起作用（h(x) = 0）
  - 最优解在边界上
  - λ ≥ 0（乘数非负）
  - 约束影响最优解
```

**直观理解**：
- 如果约束"不紧"，λ=0，约束不影响结果
- 如果约束"紧"，λ>0，约束把解"推"向可行域

### 4.3 KKT 条件（Karush-Kuhn-Tucker）

**完整问题**：
```
minimize: f(x)
subject to: gᵢ(x) = 0  (等式约束，i=1,...,m)
           hⱼ(x) ≤ 0  (不等式约束，j=1,...,p)
```

**KKT 条件**（最优解必须满足）：

```
1. 平稳性：∇f(x) + Σλᵢ·∇gᵢ(x) + Σμⱼ·∇hⱼ(x) = 0
2. 原始可行：gᵢ(x) = 0,  hⱼ(x) ≤ 0
3. 对偶可行：μⱼ ≥ 0
4. 互补松弛：μⱼ·hⱼ(x) = 0
```

**记忆口诀**：
- 梯度平衡（平稳性）
- 满足约束（可行性）
- 乘数非负（对偶可行）
- 要么约束紧，要么乘数零（互补松弛）

## 五、应用：支持向量机（SVM）

### 5.1 SVM 的优化问题

**目标**：找到最大间隔的超平面

```
minimize: (1/2)||w||²
subject to: yᵢ(w·xᵢ + b) ≥ 1,  ∀i
```

写成标准形式：
```
minimize: (1/2)||w||²
subject to: 1 - yᵢ(w·xᵢ + b) ≤ 0
```

### 5.2 构造拉格朗日函数

```
L(w, b, α) = (1/2)||w||² + Σαᵢ[1 - yᵢ(w·xᵢ + b)]
```

其中 αᵢ ≥ 0 是拉格朗日乘数。

### 5.3 求导

```
∂L/∂w = 0  →  w = Σαᵢyᵢxᵢ
∂L/∂b = 0  →  Σαᵢyᵢ = 0
```

### 5.4 对偶问题

代入后得到**对偶问题**：
```
maximize: Σαᵢ - (1/2)ΣΣαᵢαⱼyᵢyⱼ(xᵢ·xⱼ)
subject to: αᵢ ≥ 0,  Σαᵢyᵢ = 0
```

**关键洞察**：
- 只依赖样本的内积 `xᵢ·xⱼ`
- 可以用核函数替换内积 → 核技巧！
- 只有支持向量的 αᵢ > 0（互补松弛）

### 5.5 Python 实现（简化版）

```python
import numpy as np
from cvxopt import matrix, solvers

def svm_primal_to_dual(X, y):
    """
    SVM 对偶问题求解
    X: 样本矩阵 (n_samples, n_features)
    y: 标签向量 (+1 或 -1)
    """
    n_samples = X.shape[0]
    
    # 计算 Gram 矩阵（内积矩阵）
    K = X @ X.T
    
    # 对偶问题：maximize Σαᵢ - (1/2)ΣΣαᵢαⱼyᵢyⱼKᵢⱼ
    # 转化为最小化：(1/2)αᵀ(Q)α - pᵀα
    Q = matrix(np.outer(y, y) * K)
    p = matrix(-np.ones(n_samples))
    
    # 约束：αᵢ ≥ 0
    G = matrix(-np.eye(n_samples))
    h = matrix(np.zeros(n_samples))
    
    # 约束：Σαᵢyᵢ = 0
    A = matrix(y.reshape(1, -1), tc='d')
    b = matrix(np.zeros(1))
    
    # 求解
    solvers.options['show_progress'] = False
    solution = solvers.qp(Q, p, G, h, A, b)
    alpha = np.array(solution['x']).flatten()
    
    return alpha

# 测试
X = np.array([[1, 2], [2, 3], [3, 3], [8, 9], [9, 8], [10, 10]])
y = np.array([-1, -1, -1, 1, 1, 1])

alpha = svm_primal_to_dual(X, y)
print("拉格朗日乘数：", alpha)
print("支持向量：", np.where(alpha > 1e-5)[0])
```

## 六、应用：资源分配问题

### 6.1 问题描述

**场景**：公司有 100 万预算，要分配给 3 个项目

```
项目 1：预期回报率 10%，风险系数 0.5
项目 2：预期回报率 15%，风险系数 0.8
项目 3：预期回报率 12%，风险系数 0.6

目标：最大化总回报
约束：
  - 总预算 ≤ 100 万
  - 每个项目至少投 10 万
  - 总风险 ≤ 0.7
```

### 6.2 数学建模

```
maximize: 0.10x₁ + 0.15x₂ + 0.12x₃
subject to: x₁ + x₂ + x₃ ≤ 100
           x₁ ≥ 10, x₂ ≥ 10, x₃ ≥ 10
           (0.5x₁ + 0.8x₂ + 0.6x₃) / (x₁ + x₂ + x₃) ≤ 0.7
```

### 6.3 Python 求解

```python
from scipy.optimize import minimize

# 目标函数（最小化负回报）
def objective(x):
    return -(0.10*x[0] + 0.15*x[1] + 0.12*x[2])

# 约束
constraints = [
    # 总预算 ≤ 100
    {'type': 'ineq', 'fun': lambda x: 100 - sum(x)},
    # 风险 ≤ 0.7
    {'type': 'ineq', 'fun': lambda x: 0.7*sum(x) - (0.5*x[0] + 0.8*x[1] + 0.6*x[2])},
]

# 边界：每个项目 ≥ 10
bounds = [(10, None), (10, None), (10, None)]

# 求解
x0 = [30, 30, 40]
result = minimize(objective, x0, bounds=bounds, constraints=constraints)

print(f"最优分配：项目 1={result.x[0]:.1f}万，项目 2={result.x[1]:.1f}万，项目 3={result.x[2]:.1f}万")
print(f"最大回报：{-result.fun:.2f}万")
```

## 七、对偶性与强对偶

### 7.1 拉格朗日对偶函数

**定义**：
```
g(λ, μ) = minₓ L(x, λ, μ)
```

**性质**：
- g(λ, μ) 总是原问题最优值的**下界**
- 即使原问题非凸，对偶函数也是凹的

### 7.2 弱对偶与强对偶

```
弱对偶：d* ≤ p*  (对偶最优 ≤ 原问题最优)  [总是成立]
强对偶：d* = p*  (对偶最优 = 原问题最优)  [需要条件]
```

**强对偶成立的条件**：
- 原问题是凸优化问题
- 满足 Slater 条件（存在严格可行点）

### 7.3 为什么对偶重要？

1. **更容易求解**：对偶问题可能是凸的，即使原问题非凸
2. **核技巧**：SVM 对偶形式天然支持核函数
3. **分布式优化**：对偶分解可以并行求解
4. **理论分析**：对偶间隙给出最优性保证

### 练习 3：实现投影梯度下降

**思路**：每步梯度下降后，投影回可行域

```python
def projected_gradient_descent(f, grad_f, project, x0, lr=0.1, iterations=100):
    """
    投影梯度下降
    project: 投影函数，把任意点投影到可行域
    """
    x = x0
    for i in range(iterations):
        # 梯度步
        x = x - lr * grad_f(x)
        # 投影回可行域
        x = project(x)
    return x
```

## 九、核心要点总结

### 📌 关键公式

```python
# 等式约束
L(x, λ) = f(x) + λ·g(x)
∇ₓL = 0,  ∂L/∂λ = 0

# 不等式约束（KKT 条件）
∇f(x) + Σλᵢ·∇gᵢ(x) + Σμⱼ·∇hⱼ(x) = 0  (平稳性)
gᵢ(x) = 0,  hⱼ(x) ≤ 0                 (原始可行)
μⱼ ≥ 0                                 (对偶可行)
μⱼ·hⱼ(x) = 0                          (互补松弛)
```

### 📌 直觉理解

| 概念 | 物理直觉 |
|------|----------|
| 拉格朗日乘数 | 约束的"价格"或"压力" |
| 互补松弛 | 要么约束紧，要么价格为零 |
| 对偶性 | 从另一个角度看问题 |

### 📌 实践建议

```
1. 等式约束 → 直接构造拉格朗日函数
2. 不等式约束 → 用 KKT 条件
3. 凸优化问题 → 强对偶成立，可解对偶
4. 机器学习应用 → SVM、正则化、约束学习
```
