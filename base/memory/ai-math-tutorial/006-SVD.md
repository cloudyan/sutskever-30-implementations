# 006 | 奇异值分解 (SVD)：AI 最重要的矩阵分解

> 🎯 **一句话核心**：SVD 将任意矩阵分解为三个简单矩阵的乘积，揭示了数据的内在结构——是 PCA、推荐系统、图像压缩的核心。

---

## 🤔 从一个问题开始

### 特征分解的局限

特征分解很强大，但有两个限制：
1. 只能用于**方阵**（n×n）
2. 有些方阵也不能对角化

**问题**：如果不是方阵怎么办？比如：
- 用户 - 物品矩阵（1000 用户 × 500 物品）
- 图像矩阵（256×512）
- 数据矩阵（10000 样本 × 100 特征）

**答案**：用 SVD（奇异值分解）！

---

### SVD 的神奇之处

**SVD 定理**：任何 m×n 矩阵 A 都可以分解为：

```
A = U × Σ × Vᵀ

其中：
- U 是 m×m 正交矩阵（左奇异向量）
- Σ 是 m×n 对角矩阵（奇异值）
- Vᵀ 是 n×n 正交矩阵的转置（右奇异向量）
```

```
     m×n     m×m   m×n   n×n
    
      A    =   U  ×  Σ  ×  Vᵀ
```

---

### 直观理解

任何线性变换都可以理解为三个简单变换的组合：

```
1. Vᵀ：旋转/反射（在输入空间）
2. Σ：沿坐标轴缩放（奇异值决定缩放倍数）
3. U：旋转/反射（在输出空间）
```

```
输入 → [Vᵀ 旋转] → [Σ 缩放] → [U 旋转] → 输出
```

---

## 📖 核心概念详解

### 1. SVD 的定义

对于任意 m×n 矩阵 A，存在分解：

```
A = UΣVᵀ

详细结构：

     | ↑   ↑       ↑ |   | σ₁  0   ...   0  |   | — v₁ᵀ — |
A =  | u₁  u₂  ...  uₘ | × | 0   σ₂  ...   0  | × | — v₂ᵀ — |
     | ↓   ↓       ↓ |   | ... ...  ...  ... |   |    ...  |
                      | 0   0   ...  σᵣ |   | — vₙᵀ — |

其中：
- σ₁ ≥ σ₂ ≥ ... ≥ σᵣ > 0 是奇异值
- uᵢ 是左奇异向量（U 的列）
- vᵢ 是右奇异向量（V 的列）
- r = rank(A) 是矩阵的秩
```

---

### 2. 奇异值的含义

**关键洞察**：奇异值表示矩阵的"能量"或"重要性"分布。

- σ₁ 最大，表示最重要的方向
- 后面的奇异值越来越小
- 很多奇异值可能接近 0

**低秩近似**：只保留前 k 个奇异值：

```
A ≈ U[:, :k] × Σ[:k, :k] × V[:, :k].T

这叫做秩-k 近似，是最佳近似（Eckart-Young 定理）！
```

---

### 3. SVD 与特征分解的关系

**重要关系**：

```
A 的左奇异向量 = AAᵀ 的特征向量
A 的右奇异向量 = AᵀA 的特征向量
A 的奇异值 = √(AᵀA 的特征值)
```

---

### 4. 精简 SVD vs 完整 SVD

**完整 SVD**：
- U 是 m×m
- Σ 是 m×n
- Vᵀ 是 n×n

**精简 SVD**（更常用）：
- U 是 m×r
- Σ 是 r×r（只保留非零奇异值）
- Vᵀ 是 r×n

其中 r = rank(A)

---

### 5. SVD 的计算

对于小矩阵，可以用特征分解计算：

```
1. 计算 AᵀA
2. 特征分解 AᵀA = VDVᵀ
3. 奇异值 σᵢ = √λᵢ
4. 计算 U = AVΣ⁻¹
```

实际中用更稳定的数值算法（如 Golub-Kahan 双对角化）。

## 💻 代码实现

```python
import numpy as np

# ==================== SVD 基础 ====================

print("="*50)
print("SVD 基础：任意矩阵分解")
print("="*50)

# 创建一个非方阵
A = np.array([[3, 2, 2],
              [2, 3, -2]])

print(f"\n矩阵 A ({A.shape[0]}×{A.shape[1]}):")
print(A)

# SVD 分解
U, sigma, Vt = np.linalg.svd(A)

print(f"\nSVD 分解结果：")
print(f"U 的形状：{U.shape}")
print(f"奇异值：{sigma}")
print(f"Vᵀ 的形状：{Vt.shape}")

# 重建矩阵
Sigma = np.zeros(A.shape)
np.fill_diagonal(Sigma, sigma)
A_reconstructed = U @ Sigma @ Vt

print(f"\n重建矩阵：")
print(A_reconstructed.round(10))
print(f"\n重建误差：{np.max(np.abs(A - A_reconstructed)):.2e}")

# ==================== 奇异值的能量分布 ====================

print("\n" + "="*50)
print("奇异值的能量分布")
print("="*50)

# 能量比例
energy_ratio = sigma**2 / np.sum(sigma**2)
cumulative_energy = np.cumsum(energy_ratio)

print(f"\n奇异值：{sigma}")
print(f"能量比例：{energy_ratio}")
print(f"累积能量：{cumulative_energy}")

for i in range(len(sigma)):
    print(f"前{i+1}个奇异值保留 {cumulative_energy[i]*100:.2f}% 能量")

# ==================== 低秩近似 ====================

print("\n" + "="*50)
print("低秩近似：用更少的数据近似原矩阵")
print("="*50)

def low_rank_approx(A, k):
    """计算矩阵 A 的秩-k 近似"""
    U, sigma, Vt = np.linalg.svd(A, full_matrices=False)
    return U[:, :k] @ np.diag(sigma[:k]) @ Vt[:k, :]

# 创建测试矩阵
np.random.seed(42)
A = np.random.rand(10, 10)

# 添加低秩结构
A = A @ A.T  # 使其接近低秩

print(f"\n原始矩阵形状：{A.shape}")
print(f"原始矩阵秩：{np.linalg.matrix_rank(A)}")

# 不同 k 值的近似
for k in [1, 3, 5, 10]:
    A_k = low_rank_approx(A, k)
    error = np.linalg.norm(A - A_k, 'fro')
    print(f"\nk={k}:")
    print(f"  近似矩阵秩：{np.linalg.matrix_rank(A_k)}")
    print(f"  Frobenius 误差：{error:.4f}")

# ==================== 图像压缩示例 ====================

print("\n" + "="*50)
print("应用：图像压缩")
print("="*50)

# 创建一个简单的"图像"（渐变矩阵）
image = np.zeros((50, 50))
for i in range(50):
    for j in range(50):
        image[i, j] = np.sin(i/10) * np.cos(j/10)

print(f"\n原始图像形状：{image.shape}")
print(f"原始数据量：{image.size} 个数值")

# SVD 分解
U, sigma, Vt = np.linalg.svd(image)

# 用不同数量的奇异值重建
for k in [1, 5, 10, 20]:
    image_k = U[:, :k] @ np.diag(sigma[:k]) @ Vt[:k, :]
    
    # 压缩率
    original_size = image.size
    compressed_size = k * (U.shape[0] + Vt.shape[0] + 1)  # 只存储前 k 个奇异向量和值
    compression_ratio = original_size / compressed_size
    
    # 重建误差
    error = np.mean((image - image_k) ** 2)
    
    print(f"\nk={k}:")
    print(f"  压缩后大小：{compressed_size} 个数值")
    print(f"  压缩率：{compression_ratio:.1f}x")
    print(f"  均方误差：{error:.6f}")

# ==================== 推荐系统示例 ====================

print("\n" + "="*50)
print("应用：推荐系统（矩阵分解）")
print("="*50)

# 用户 - 物品评分矩阵（5 用户 × 4 物品）
# 0 表示未评分
R = np.array([
    [5, 3, 0, 4],
    [4, 0, 0, 3],
    [0, 2, 5, 0],
    [3, 0, 4, 5],
    [0, 4, 3, 0]
])

print(f"\n评分矩阵：\n{R}")

# 用 SVD 做矩阵分解
# 注意：实际推荐系统需要处理缺失值，这里简化演示
R_filled = np.nan_to_num(R, nan=np.mean(R))  # 用均值填充
U, sigma, Vt = np.linalg.svd(R_filled, full_matrices=False)

# 用前 2 个奇异值近似
k = 2
R_pred = U[:, :k] @ np.diag(sigma[:k]) @ Vt[:k, :]

print(f"\n预测评分（k={k}）：\n{R_pred.round(2)}")

# ==================== PCA 与 SVD ====================

print("\n" + "="*50)
print("SVD 与 PCA 的关系")
print("="*50)

# 生成数据
np.random.seed(42)
data = np.random.multivariate_normal(
    mean=[0, 0],
    cov=[[3, 2], [2, 2]],
    size=100
)

# 中心化
data_centered = data - data.mean(axis=0)

# 方法 1：用协方差矩阵的特征分解做 PCA
cov_matrix = np.cov(data_centered.T)
eigenvalues, eigenvectors = np.linalg.eig(cov_matrix)

# 方法 2：用 SVD 做 PCA
U, sigma, Vt = np.linalg.svd(data_centered)

print(f"\n数据形状：{data.shape}")
print(f"\n协方差矩阵特征值：{eigenvalues}")
print(f"SVD 奇异值的平方/n: {sigma**2 / (len(data) - 1)}")
print(f"\n（两者成比例 ✓）")

print(f"\n特征向量（主成分）：\n{eigenvectors}")
print(f"\n右奇异向量：\n{Vt}")
print(f"\n（相同 ✓）")

# ==================== 伪逆与最小二乘 ====================

print("\n" + "="*50)
print("SVD 与伪逆：解决不可逆问题")
print("="*50)

# 奇异矩阵（不可逆）
A = np.array([[1, 2],
              [2, 4]])

print(f"\n矩阵 A：\n{A}")
print(f"行列式：{np.linalg.det(A)}")
print(f"（不可逆！）")

# 用 SVD 计算伪逆
U, sigma, Vt = np.linalg.svd(A)

# 伪逆：Σ⁺ 对非零奇异值取倒数
sigma_pinv = np.zeros_like(sigma)
nonzero = sigma > 1e-10
sigma_pinv[nonzero] = 1 / sigma[nonzero]

A_pinv = Vt.T @ np.diag(sigma_pinv) @ U.T

print(f"\n伪逆 A⁺：\n{A_pinv.round(4)}")

# 验证伪逆性质
print(f"\n验证：A × A⁺ × A ≈ A")
print(f"A × A⁺ × A = \n{(A @ A_pinv @ A).round(4)}")
```

## 🔗 与 AI 的联系

### 1. PCA（主成分分析）

PCA 本质上就是 SVD：

```
数据中心化 → SVD → 右奇异向量 = 主成分方向
```

---

### 2. 推荐系统

矩阵分解推荐：

```
用户 - 物品矩阵 R ≈ U × Σ × Vᵀ

用户隐向量 = U
物品隐向量 = V
```

Netflix Prize 的核心技术！

---

### 3. 图像压缩

保留前 k 个奇异值：

```
原始：m×n 个数值
压缩：k×(m+n+1) 个数值

通常 k << min(m,n)，压缩率很高！
```

---

### 4. 潜在语义分析（LSA）

NLP 中的文档 - 词矩阵用 SVD 降维，捕捉语义关系。

---

### 5. 神经网络权重初始化

SVD 初始化可以保持梯度稳定流动。

## 🧠 常见误区

### ❌ 误区 1：SVD 和特征分解是一回事

**纠正**：
- SVD 适用于**任意矩阵**
- 特征分解只适用于**方阵**
- 即使对方阵，两者结果也不同

关系：SVD 的奇异值 = √(特征值的绝对值)

---

### ❌ 误区 2：奇异值可以是负数

**纠正**：奇异值**总是非负**的！

奇异值定义为 Σ 矩阵对角线上的非负数。

---

### ❌ 误区 3：SVD 是唯一的

**纠正**：SVD 不唯一！
- 奇异向量可以变号（u 和 -u 都可以）
- 重复奇异值对应的奇异向量可以旋转

但奇异值是唯一的。
