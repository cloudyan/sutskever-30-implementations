# 012 | 梯度：最陡的方向

> 🎯 **一句话核心**：梯度是多元函数的"指南针"，指向函数增长最快的方向——梯度下降沿着它的反方向走，找到损失函数的最小值。

---

## 🤔 从一个问题开始

### 问题 1：你在雾中登山，如何找到下山的路？

想象你在浓雾弥漫的山上，能见度只有脚下几米：

```
        🌫️🌫️🌫️ 你在这里 🌫️🌫️🌫️
              ↓
             /|\
            / | \    看不见山顶也看不见山谷
           /  |  \   只能感受脚下的坡度
          /   |   \
         /    |    \
        /     |     \
       /      |      \
      /       |       \
     /        |        \
    /         |         \
   🌫️🌫️🌫️🌫️🌫️🌫️山谷🌫️🌫️🌫️🌫️🌫️🌫️
```

**你怎么知道该往哪边走？**

答案：用脚试探四周，找到**下坡最陡**的方向，迈一步。然后重复。

**梯度**就是那个"四周的坡度信息"——它是一个向量，告诉你：
- 哪个方向最陡
- 陡到什么程度

---

### 问题 2：神经网络有百万个参数，怎么一起调整？

神经网络损失函数：

```
L(w₁, w₂, ..., w₁₀₀₀₀₀₀) = 预测误差
```

这是一个**100 万维**的函数！怎么找到让 L 最小的参数组合？

**答案**：计算梯度 ∇L，它告诉你每个参数应该增加还是减少，以及变化的"紧迫程度"。

```
∇L = [∂L/∂w₁, ∂L/∂w₂, ..., ∂L/∂w₁₀₀₀₀₀₀]
     ↑        ↑              ↑
   w₁的坡度  w₂的坡度     w₁₀₀₀₀₀₀的坡度
```

然后所有参数一起沿着梯度反方向更新：

```
wᵢ = wᵢ - η · ∂L/∂wᵢ
```

这就是**梯度下降**！

---

## 📖 核心概念详解

### 1. 从导数到梯度

#### 一元函数：导数

```
f(x) = x²
f'(x) = 2x

在 x=2 处，f'(2) = 4
```

**含义**：x 增加一点，f(x) 大约增加 4 倍那么多。

---

#### 多元函数：梯度

```
f(x, y) = x² + y²

梯度 ∇f = [∂f/∂x, ∂f/∂y] = [2x, 2y]

在点 (3, 4) 处，∇f = [6, 8]
```

**含义**：
- x 方向的变化率是 6
- y 方向的变化率是 8
- **合起来**，最陡的方向是向量 [6, 8] 的方向

---

### 2. 梯度的几何意义

#### 二维情况：等高线与梯度

```
         y
         ↑
         │     ╭───╮  等高线（高度相同）
         │   ╭─┤   ├─╮
         │  │  │ · │  │  · = 你在这里
         │  │  │ ↑ │  │  ↑ = 梯度方向（垂直于等高线）
         │   ╰─┤   ├─╯
         │     ╰───╯
         └────────────→ x
```

**关键性质**：
1. 梯度**垂直于**等高线
2. 梯度指向**高度增加最快**的方向
3. 梯度的模（长度）= 最大变化率

---

#### 三维情况：地形图

```
        高度
          ↑
          │
     山顶 │    ╱│╲
          │  ╱  │  ╲
          │╱────┼───╲
          │     │    ╲
          │     │     ╲
          └─────────────→ 位置
```

梯度告诉你："往这边走，爬升最快！"

---

### 3. 梯度的计算

#### 定义

对于函数 f(x₁, x₂, ..., xₙ)，梯度为：

```
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

也可以写成向量形式：

```
∇f = ∂f/∂x₁ · e₁ + ∂f/∂x₂ · e₂ + ... + ∂f/∂xₙ · eₙ
```

其中 eᵢ 是单位向量。

---

#### 示例 1：二次函数

```
f(x, y) = x² + 2y²

∂f/∂x = 2x
∂f/∂y = 4y

∇f = [2x, 4y]

在点 (1, 1) 处：∇f = [2, 4]
```

---

#### 示例 2：神经网络中的常见函数

```
f(x, y, z) = σ(wx + by + c)  # σ 是 sigmoid

令 u = wx + by + c，则 f = σ(u)

用链式法则：
∂f/∂w = σ'(u) · x
∂f/∂b = σ'(u) · y
∂f/∂c = σ'(u) · 1

∇f = [σ'(u)·x, σ'(u)·y, σ'(u)]
```

这就是反向传播中梯度计算的基本模式！

---

### 4. 梯度下降法

#### 算法流程

```
输入：函数 f(x)，初始点 x₀，学习率 η，迭代次数 T
输出：近似最小值点 x*

x = x₀
for t = 1 to T:
    grad = ∇f(x)          # 计算梯度
    x = x - η · grad      # 沿梯度反方向走一步
    if |grad| < ε:        # 梯度足够小，收敛
        break
return x
```

---

#### 可视化：下山的过程

```
迭代 0:  x = 3.0      损失 = 9.0
            ↓ 梯度 = 6.0，往左走
迭代 1:  x = 1.5      损失 = 2.25
            ↓ 梯度 = 3.0，继续往左
迭代 2:  x = 0.75     损失 = 0.56
            ↓ 梯度 = 1.5
迭代 3:  x = 0.375    损失 = 0.14
            ↓ ...
...
迭代∞: x ≈ 0         损失 ≈ 0  ✅
```

---

### 5. 学习率：走多大步？

学习率 η 是梯度下降中**最重要的超参数**：

```
x = x - η · ∇f(x)
        ↑
      学习率
```

#### 学习率太大

```
         ╱╲
        ╱  ╲
       ╱    ╲
      ╱      ╲
     ╱        ╲
    ╱          ╲
   ╱            ╲
  ╱              ╲
 ╱                ╲
╱──────────────────╲
  ↖️  跳过了最小值！
```

**后果**：在最优点附近震荡，甚至发散。

---

#### 学习率太小

```
起点 → · → · → · → · → · → · → · → · → · → · → · → · → · → · → 终点
                    （走了很久还没到）
```

**后果**：收敛太慢，训练时间长，可能卡在局部最优。

---

#### 合适的学习率

```
起点
  ↓
  ↓
   ↘
    ↘
     ↘
      ↘
       ↘
        · ← 最小值
```

**经验值**：
- 常用：0.1, 0.01, 0.001
- 现代优化器（Adam）：默认 0.001
- 技巧：学习率衰减（训练过程中逐渐减小）

## 💻 代码实现

### 从零实现梯度下降

```python
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# ==================== 梯度计算 ====================

def gradient_2d(f, x, y, h=1e-5):
    """
    计算二元函数的数值梯度
    """
    grad_x = (f(x + h, y) - f(x - h, y)) / (2 * h)
    grad_y = (f(x, y + h) - f(x, y - h)) / (2 * h)
    return np.array([grad_x, grad_y])

# 测试函数
def f1(x, y):
    return x ** 2 + y ** 2

print("f(x,y) = x² + y² 在 (1, 2) 处的梯度：")
print(gradient_2d(f1, 1, 2))  # 理论：[2, 4]

# ==================== 梯度下降 ====================

def gradient_descent(f, grad_f, start, learning_rate=0.1, iterations=100):
    """
    梯度下降优化
    f: 目标函数
    grad_f: 梯度函数
    start: 初始点
    learning_rate: 学习率
    iterations: 迭代次数
    """
    x = np.array(start, dtype=float)
    history = [x.copy()]
    
    for i in range(iterations):
        grad = grad_f(x)
        x = x - learning_rate * grad
        history.append(x.copy())
        
        # 检查收敛
        if np.linalg.norm(grad) < 1e-6:
            print(f"第 {i+1} 次迭代收敛")
            break
    
    return x, np.array(history)

# 测试：f(x, y) = x² + y²，最小值在 (0, 0)
def f2(vars):
    x, y = vars
    return x ** 2 + y ** 2

def grad_f2(vars):
    x, y = vars
    return np.array([2 * x, 2 * y])

start = [3.0, 4.0]
optimal, history = gradient_descent(f2, grad_f2, start, learning_rate=0.1, iterations=50)

print(f"\n初始点：{start}")
print(f"最优点：{optimal}")
print(f"理论最优点：[0, 0]")
print(f"迭代路径（前 5 步）：{history[:5]}")

# ==================== 可视化：2D 梯度下降 ====================

def plot_2d_gradient_descent():
    """可视化 2D 梯度下降"""
    
    # 生成网格
    x = np.linspace(-3, 3, 100)
    y = np.linspace(-3, 3, 100)
    X, Y = np.meshgrid(x, y)
    Z = X ** 2 + Y ** 2
    
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))
    
    # 左图：等高线 + 路径
    contour = ax1.contour(X, Y, Z, levels=20, cmap='Blues')
    ax1.clabel(contour, inline=True, fontsize=8)
    ax1.plot(history[:, 0], history[:, 1], 'ro-', linewidth=2, markersize=4, label='梯度下降路径')
    ax1.plot(history[0, 0], history[0, 1], 'go', markersize=10, label='起点')
    ax1.plot(optimal[0], optimal[1], 'y*', markersize=15, label='最优点')
    ax1.set_title('2D 梯度下降路径')
    ax1.set_xlabel('x')
    ax1.set_ylabel('y')
    ax1.legend()
    ax1.grid(True, alpha=0.3)
    ax1.set_aspect('equal')
    
    # 右图：3D 表面 + 路径
    ax2 = fig.add_subplot(122, projection='3d')
    ax2.plot_surface(X, Y, Z, cmap='Blues', alpha=0.7)
    ax2.plot(history[:, 0], history[:, 1], [f2(h) for h in history], 'ro-', linewidth=2, markersize=4)
    ax2.set_title('3D 视角下的梯度下降')
    ax2.set_xlabel('x')
    ax2.set_ylabel('y')
    ax2.set_zlabel('f(x,y)')
    
    plt.tight_layout()
    plt.savefig('gradient_descent_2d.png', dpi=150)
    print("\n已保存可视化：gradient_descent_2d.png")

plot_2d_gradient_descent()

# ==================== 不同学习率的对比 ====================

def compare_learning_rates():
    """对比不同学习率的效果"""
    
    learning_rates = [0.01, 0.1, 0.3, 0.5]
    colors = ['blue', 'green', 'orange', 'red']
    
    plt.figure(figsize=(10, 8))
    
    # 等高线背景
    x = np.linspace(-3, 3, 100)
    y = np.linspace(-3, 3, 100)
    X, Y = np.meshgrid(x, y)
    Z = X ** 2 + Y ** 2
    contour = plt.contour(X, Y, Z, levels=20, cmap='Blues', alpha=0.5)
    
    for lr, color in zip(learning_rates, colors):
        _, hist = gradient_descent(f2, grad_f2, [2.5, 2.5], learning_rate=lr, iterations=20)
        plt.plot(hist[:, 0], hist[:, 1], 'o-', color=color, label=f'η={lr}', linewidth=2, markersize=3)
    
    plt.title('不同学习率的梯度下降路径对比')
    plt.xlabel('x')
    plt.ylabel('y')
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.axis('equal')
    plt.savefig('learning_rate_comparison.png', dpi=150)
    print("已保存学习率对比图：learning_rate_comparison.png")
    
    # 打印收敛情况
    print("\n学习率对比（20 次迭代后的位置）：")
    for lr, color in zip(learning_rates, colors):
        _, hist = gradient_descent(f2, grad_f2, [2.5, 2.5], learning_rate=lr, iterations=20)
        final_pos = hist[-1]
        distance = np.linalg.norm(final_pos)
        print(f"  η={lr:.2f}: 距离原点 {distance:.4f}")

compare_learning_rates()

# ==================== 非凸函数：多个局部最优 ====================

def non_convex_demo():
    """演示非凸函数的梯度下降"""
    
    # 一个有多个局部最优的函数
    def f3(vars):
        x, y = vars
        return (x ** 2 + y - 11) ** 2 + (x + y ** 2 - 7) ** 2  # Himmelblau 函数
    
    def grad_f3(vars):
        x, y = vars
        dx = 2 * (x ** 2 + y - 11) * 2 * x + 2 * (x + y ** 2 - 7)
        dy = 2 * (x ** 2 + y - 11) + 2 * (x + y ** 2 - 7) * 2 * y
        return np.array([dx, dy])
    
    # 从不同起点开始
    starts = [[3, 2], [-3, -2], [3, -2], [-3, 2]]
    colors = ['red', 'blue', 'green', 'orange']
    
    plt.figure(figsize=(10, 8))
    
    x = np.linspace(-4, 4, 200)
    y = np.linspace(-4, 4, 200)
    X, Y = np.meshgrid(x, y)
    Z = f3([X, Y])
    
    contour = plt.contour(X, Y, Z, levels=30, cmap='viridis')
    plt.clabel(contour, inline=True, fontsize=6)
    
    for start, color in zip(starts, colors):
        opt, hist = gradient_descent(f3, grad_f3, start, learning_rate=0.01, iterations=100)
        plt.plot(hist[:, 0], hist[:, 1], 'o-', color=color, linewidth=1.5, markersize=3, label=f'起点{start}')
        plt.plot(opt[0], opt[1], 'x', color=color, markersize=15, markeredgewidth=2)
    
    plt.title('非凸函数：不同起点收敛到不同局部最优')
    plt.xlabel('x')
    plt.ylabel('y')
    plt.legend()
    plt.grid(True, alpha=0.3)
    plt.savefig('non_convex_gradient_descent.png', dpi=150)
    print("\n已保存非凸函数演示：non_convex_gradient_descent.png")

non_convex_demo()

# ==================== 实际应用：线性回归 ====================

def linear_regression_gd():
    """用梯度下降实现线性回归"""
    
    # 生成数据
    np.random.seed(42)
    X = np.random.randn(100, 1) * 2
    y = 3 * X + 5 + np.random.randn(100, 1) * 0.5  # y = 3x + 5 + 噪声
    
    # 添加截距项
    X_b = np.c_[np.ones((100, 1)), X]  # [1, x]
    
    # 损失函数：MSE
    def mse_loss(theta):
        predictions = X_b @ theta
        errors = predictions - y
        return np.mean(errors ** 2)
    
    # 梯度
    def mse_gradient(theta):
        predictions = X_b @ theta
        errors = predictions - y
        return 2 * X_b.T @ errors / len(y)
    
    # 梯度下降
    theta = np.random.randn(2, 1)  # 随机初始化参数
    history = [mse_loss(theta)]
    
    learning_rate = 0.1
    for i in range(100):
        grad = mse_gradient(theta)
        theta = theta - learning_rate * grad
        history.append(mse_loss(theta))
    
    print(f"\n线性回归结果：")
    print(f"真实参数：截距=5, 斜率=3")
    print(f"学习到的参数：截距={theta[0,0]:.3f}, 斜率={theta[1,0]:.3f}")
    
    # 可视化
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 4))
    
    # 数据 + 拟合线
    ax1.scatter(X, y, alpha=0.6, label='数据点')
    x_line = np.linspace(-4, 4, 100)
    y_line = theta[0] + theta[1] * x_line
    ax1.plot(x_line, y_line, 'r-', linewidth=2, label=f'拟合：y={theta[1,0]:.2f}x+{theta[0,0]:.2f}')
    ax1.set_title('梯度下降线性回归')
    ax1.set_xlabel('x')
    ax1.set_ylabel('y')
    ax1.legend()
    ax1.grid(True, alpha=0.3)
    
    # 损失下降曲线
    ax2.plot(history, 'b-', linewidth=2)
    ax2.set_title('损失函数下降曲线')
    ax2.set_xlabel('迭代次数')
    ax2.set_ylabel('MSE 损失')
    ax2.grid(True, alpha=0.3)
    
    plt.tight_layout()
    plt.savefig('linear_regression_gd.png', dpi=150)
    print("已保存线性回归演示：linear_regression_gd.png")

linear_regression_gd()
```

## 🔗 与 AI 的联系

### 1. 神经网络训练 = 高维梯度下降

神经网络损失函数：

```
L(θ) = 1/N Σ (预测ᵢ - 真实ᵢ)²
```

其中 θ 包含所有权重和偏置，可能有百万维！

**训练过程**：
```
1. 前向传播：计算预测
2. 计算损失：L(θ)
3. 反向传播：计算梯度 ∇L(θ)
4. 更新参数：θ = θ - η · ∇L(θ)
5. 重复直到收敛
```

---

### 2. 批量梯度下降 vs 随机梯度下降

| 类型 | 每次更新的样本 | 优点 | 缺点 |
|------|---------------|------|------|
| **BGD** | 全部数据 | 稳定，收敛平滑 | 慢，内存占用大 |
| **SGD** | 1 个样本 | 快，可在线学习 | 波动大 |
| **Mini-batch SGD** | 小批量（32-512） | 平衡速度与稳定 | 需要调 batch size |

**现代深度学习**：几乎都用 Mini-batch SGD + Adam 优化器。

---

### 3. 梯度问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| **梯度消失** | 深层网络，连乘导致梯度趋近 0 | ReLU、残差连接、BatchNorm |
| **梯度爆炸** | 连乘导致梯度巨大 | 梯度裁剪、权重初始化 |
| **局部最优** | 非凸函数 | 动量、随机性、更好的优化器 |
| **鞍点** | 高维空间中常见 | 动量、自适应学习率 |

---

### 4. 现代优化器

基于梯度下降的改进：

| 优化器 | 核心改进 | 适用场景 |
|--------|---------|----------|
| **SGD + Momentum** | 累积历史梯度，加速 | 通用 |
| **AdaGrad** | 自适应学习率 | 稀疏数据 |
| **RMSprop** | 指数加权平均 | RNN |
| **Adam** | 动量 + 自适应 | **默认首选** |

**Adam 更新公式**：
```
m = β₁·m + (1-β₁)·grad      # 一阶矩（动量）
v = β₂·v + (1-β₂)·grad²     # 二阶矩（自适应）
θ = θ - η·m̂/(√v̂ + ε)        # 更新
```

## 🧠 常见误区

### ❌ 误区 1：梯度指向最小值

**纠正**：梯度指向**增长最快**的方向！要找最小值，需要沿**梯度反方向**走。

```
梯度 ↑     你在这里
      |
      ·
     / \
    /   \
   /     \
  ·───────· 最小值在这边！
```

---

### ❌ 误区 2：梯度为 0 就是找到最小值

**纠正**：梯度为 0 是**驻点**，可能是：
- ✅ 局部最小值
- ❌ 局部最大值
- ⚠️ 鞍点（某些方向上升，某些方向下降）

**高维空间中，鞍点比局部最优更常见！**

---

### ❌ 误区 3：学习率固定最好

**纠正**：学习率衰减通常更好：
```
η(t) = η₀ / (1 + decay·t)
```

或者用**学习率预热**（warmup）：先小后大再小。

---

### ❌ 误区 4：梯度下降一定能找到全局最优

**纠正**：对于非凸函数（如神经网络），梯度下降只能找到**局部最优**。

**但好消息**：在高维空间中，局部最优通常也"足够好"，而且有很多技巧帮助逃离差的局部最优。

### 练习 2：梯度下降实践

用梯度下降找到 f(x, y) = (x-1)² + (y-2)² 的最小值：

```python
def f(vars):
    x, y = vars
    return (x - 1) ** 2 + (y - 2) ** 2

def grad_f(vars):
    x, y = vars
    return ______  # 填写梯度

# 从 (0, 0) 开始，学习率 0.1，迭代 50 次
optimal, history = gradient_descent(f, grad_f, [0, 0], 0.1, 50)
print(f"最优点：{optimal}")  # 应该接近 [1, 2]
```

<details>
<summary>点击查看答案</summary>

```python
def grad_f(vars):
    x, y = vars
    return np.array([2 * (x - 1), 2 * (y - 2)])
```
</details>
