## Day 46

**知识点**：softmax 与交叉熵

**一句话**：softmax 将 logits 转为概率分布，交叉熵衡量预测与真实的差距。

**前置知识**：Day 42（熵）、Day 43（交叉熵定义）、Day 11-13（导数与链式法则）
**后续应用**：Day 56（注意力机制）、Day 57（位置编码）
**关联回顾**：Day 31（MLE - 交叉熵=负对数似然）、Day 48（sigmoid 二分类推广）

**核心定义**：
- softmax：σ(z)ᵢ = exp(zᵢ)/Σⱼexp(zⱼ)
- 性质 1：输出和为 1，可解释为概率
- 性质 2：保持大小关系，zᵢ 越大输出越大
- 数值稳定：减去最大值防止溢出
- 交叉熵梯度：∂L/∂zᵢ = ŷᵢ - yᵢ（简洁！）

**几何直观**：
- softmax：将实数向量"拉伸"为概率分布
- 温度参数：除以 T>1 使分布更平坦
- 最大值主导：最大 logit 对应概率接近 1
- 梯度：预测越错，梯度越大

**AI 中的应用**：
- 多分类输出层：标准配置
- 注意力机制：softmax 注意力权重
- 语言模型：下一个词的概率分布
- 强化学习：策略网络的输出
- 知识蒸馏：用软化标签（高温度）

**关键公式**：
```
softmax：
σ(z)ᵢ = exp(zᵢ)/Σⱼexp(zⱼ)

数值稳定版本：
σ(z)ᵢ = exp(zᵢ - max(z))/Σⱼexp(zⱼ - max(z))

交叉熵损失：
L = -Σₖ yₖ log ŷₖ (ŷ = softmax(z))

梯度（关键！）：
∂L/∂zᵢ = ŷᵢ - yᵢ

带温度参数：
σ(z/T)ᵢ = exp(zᵢ/T)/Σⱼexp(zⱼ/T)
```

**思考题**：为什么 softmax+ 交叉熵的梯度如此简洁？推导这个结果。

## Day 47

**知识点**：高斯分布与最小二乘

**一句话**：假设误差服从高斯分布时，MLE 等价于最小二乘。

**前置知识**：Day 24（高斯分布）、Day 31（MLE）、Day 5（伪逆与最小二乘）
**后续应用**：Day 58（归一化 - 假设数据近似高斯）
**关联回顾**：Day 36（回归分析）、Day 46（交叉熵是分类的 MLE，此处是回归的 MLE）
**重要**：这是 Day 31 MLE 的直接应用，建议学完 Day 31 后立即回顾

**核心定义**：
- 线性回归模型：y = wᵀx + ε
- 误差假设：ε ~ N(0, σ²)
- 似然函数：P(y|x,w) = N(wᵀx, σ²)
- MLE：最大化对数似然
- 结论：MLE = 最小化 Σ(yᵢ - wᵀxᵀxᵢ)²

**几何直观**：
- 高斯误差：预测值周围对称分布
- 最大似然：找到让数据最"可能"的直线
- 最小二乘：最小化垂直距离平方和
- 等价性：两种视角得到相同结果

**AI 中的应用**：
- 线性回归：标准解法
- 神经网络回归：MSE 损失的理论基础
- 卡尔曼滤波：高斯假设下的最优估计
- 高斯过程：贝叶斯非参数回归
- 异常检测：大残差可能是异常值

**关键公式**：
```
模型假设：
y = wᵀx + ε, ε ~ N(0, σ²)

似然函数：
P(D|w) = Πᵢ N(yᵢ|wᵀxᵢ, σ²)
= Πᵢ (1/√(2πσ²))exp(-(yᵢ-wᵀxᵢ)²/(2σ²))

对数似然：
ℓ(w) = -n/2·log(2πσ²) - (1/(2σ²))Σ(yᵢ-wᵀxᵢ)²

最大化ℓ(w) ⇔ 最小化 Σ(yᵢ-wᵀxᵢ)²
```

## Day 48

**知识点**：sigmoid 与逻辑回归

**一句话**：sigmoid 将实数映射到 (0,1)，逻辑回归用 sigmoid 做二分类。

**核心定义**：
- sigmoid：σ(z) = 1/(1+exp(-z))
- 导数：σ'(z) = σ(z)(1-σ(z))
- 逻辑回归：P(y=1|x) = σ(wᵀx)
- 决策边界：wᵀx = 0（线性）
- 几率比：log(P/(1-P)) = wᵀx（对数几率）

**几何直观**：
- sigmoid：S 形曲线，中心对称
- z→+∞：σ(z)→1；z→-∞：σ(z)→0
- z=0：σ(z)=0.5（决策边界）
- 梯度：在 0 附近最大，两端饱和

**AI 中的应用**：
- 二分类输出：标准配置
- 多标签分类：每个类别独立 sigmoid
- 门控机制：LSTM/GRU 中的遗忘门、输入门
- 注意力：sigmoid 用于某些注意力变体
- 校准：将分数转为概率

**关键公式**：
```
sigmoid 函数：
σ(z) = 1/(1+exp(-z))

导数：
σ'(z) = σ(z)(1-σ(z))

逻辑回归：
P(y=1|x) = σ(wᵀx)
P(y=0|x) = 1 - σ(wᵀx)

对数几率：
log(P(y=1|x)/P(y=0|x)) = wᵀx

损失函数（交叉熵）：
L = -[y log ŷ + (1-y)log(1-ŷ)]
```

**思考题**：为什么逻辑回归叫"回归"却用于分类？与线性回归有什么区别？

## Day 49

**知识点**：拉普拉斯平滑

**一句话**：拉普拉斯平滑加一个小常数，避免零概率问题。

**核心定义**：
- 问题：某事件未在训练集出现，P=0
- 平滑：P(x) = (count(x)+α)/(N+αK)
- 拉普拉斯平滑：α=1
- 本质：均匀分布的先验（贝叶斯解释）
- 效果：零概率变很小但不为零

**几何直观**：
- 原始：经验分布，未出现的概率为 0
- 平滑：从均匀分布"借"一点概率
- α越大：分布越接近均匀
- α→0：接近原始经验分布

**AI 中的应用**：
- 朴素贝叶斯：避免零概率导致整个乘积为 0
- 语言模型：n-gram 平滑
- 推荐系统：避免未交互物品概率为 0
- 决策树：叶子节点概率估计
- 强化学习：避免未访问状态概率为 0

**关键公式**：
```
拉普拉斯平滑：
P(xᵢ) = (count(xᵢ) + α) / (N + αK)

其中：
- count(xᵢ)：xᵢ 出现次数
- N：总样本数
- K：类别数
- α：平滑参数（通常α=1）

朴素贝叶斯中的应用：
P(xᵢ|y) = (count(xᵢ,y) + 1) / (count(y) + K)

加一平滑后：
未见过的特征 P > 0，不会导致连乘为 0
```

**思考题**：拉普拉斯平滑的贝叶斯解释是什么？先验分布是什么？

## Day 50

**知识点**：EM 算法

**一句话**：EM 算法用于含隐变量的概率模型参数估计，交替优化 E 步和 M 步。

**前置知识**：Day 31（MLE）、Day 29（联合分布与边缘分布）、Day 52（HMM）
**后续应用**：Day 52（HMM 的 Baum-Welch 算法）、Day 55（变分推断 - EM 的推广）
**关联回顾**：Day 33（贝叶斯推断）、Day 54（MCMC - 另一种推断方法）
**注意**：变分推断 (Day 55) 是 EM 的推广，建议对比学习

**核心定义**：
- E 步 (Expectation)：计算隐变量的后验期望
- M 步 (Maximization)：基于期望最大化似然
- 收敛：每次迭代似然不减，收敛到局部最优
- 应用：高斯混合模型、隐马尔可夫模型

**几何直观**：
- 鸡生蛋问题：知道隐变量好估计参数，知道参数好估计隐变量
- E 步：猜隐变量（软分配）
- M 步：用猜的隐变量更新参数
- 交替：直到稳定

**AI 中的应用**：
- 高斯混合模型 (GMM)：聚类
- 隐马尔可夫模型 (HMM)：Baum-Welch 算法
- 潜在狄利克雷分配 (LDA)：主题模型
- 变分自编码器 (VAE)：EM 的变体
- 期望传播：近似推断

**关键公式**：
```
EM 算法框架：
1. 初始化参数θ⁰
2. 重复直到收敛：
   E 步：Q(θ|θᵗ) = E[log P(X,Z|θ)|X,θᵗ]
   M 步：θᵗ⁺¹ = argmax Q(θ|θᵗ)

高斯混合模型：
E 步：γᵢₖ = P(zᵢ=k|xᵢ,θᵗ)
M 步：
μₖ = Σᵢγᵢₖxᵢ / Σᵢγᵢₖ
Σₖ = Σᵢγᵢₖ(xᵢ-μₖ)(xᵢ-μₖ)ᵀ / Σᵢγᵢₖ
πₖ = Σᵢγᵢₖ / n

ELBO (变分 EM)：
log P(X|θ) ≥ E_q[log P(X,Z|θ)] - E_q[log q(Z)]
```

**思考题**：EM 算法为什么能保证收敛？为什么只能保证局部最优？

## Day 51

**知识点**：马尔可夫链

**一句话**：马尔可夫链是"无记忆"的随机过程，未来只依赖现在。

**核心定义**：
- 马尔可夫性：P(Xₜ₊₁|X₁,...,Xₜ) = P(Xₜ₊₁|Xₜ)
- 转移矩阵：Pᵢⱼ = P(Xₜ₊₁=j|Xₜ=i)
- 平稳分布：πP = π，长期分布不再变化
- 遍历性：从任意状态可达任意状态，有唯一平稳分布

**几何直观**：
- 状态转移图：节点是状态，边是转移概率
- 随机游走：在图上随机跳转
- 平稳分布：长期来看在每个状态的时间比例
- 收敛：无论从哪里开始，最终分布相同

**AI 中的应用**：
- PageRank：网页重要性 = 平稳分布
- MCMC 采样：构造马尔可夫链采样复杂分布
- 强化学习：MDP 是马尔可夫链的扩展
- 语言模型：n-gram 是马尔可夫近似
- 扩散模型：前向过程是马尔可夫链

**关键公式**：
```
马尔可夫性：
P(Xₜ₊₁|X₁,...,Xₜ) = P(Xₜ₊₁|Xₜ)

转移矩阵：
Pᵢⱼ = P(Xₜ₊₁=j|Xₜ=i)
ΣⱼPᵢⱼ = 1 (每行和为 1)

平稳分布：
πP = π
Σᵢπᵢ = 1

n 步转移：
P(Xₜ₊ₙ=j|Xₜ=i) = (Pⁿ)ᵢⱼ
```

**思考题**：PageRank 如何用马尔可夫链建模？平稳分布的含义是什么？

## Day 52

**知识点**：隐马尔可夫模型 (HMM)

**一句话**：HMM 是含隐变量的马尔可夫链，隐状态序列不可观测，只能看到观测序列。

**核心定义**：
- 隐状态：不可观测的马尔可夫链
- 观测：每个状态产生一个观测
- 三要素：初始分布π、转移矩阵 A、发射矩阵 B
- 三问题：
  1. 概率计算：P(O|λ)
  2. 解码：argmax P(Q|O,λ)
  3. 学习：argmax P(O|λ)

**几何直观**：
- 双层随机过程：隐状态链 + 观测生成
- 隐状态：天气（晴/雨），不可直接观测
- 观测：带伞/不带伞，可观测
- 推断：从观测反推隐状态

**AI 中的应用**：
- 语音识别：隐状态=音素，观测=声学特征
- 词性标注：隐状态=词性，观测=词语
- 生物信息：基因序列分析
- 时间序列：状态空间模型
- CRF：HMM 的判别式变体

**关键公式**：
```
HMM 三要素：λ = (π, A, B)

前向算法（问题 1）：
αₜ(i) = P(o₁,...,oₜ, qₜ=i|λ)
αₜ₊₁(j) = [Σᵢαₜ(i)Aᵢⱼ]Bⱼ(oₜ₊₁)

后向算法：
βₜ(i) = P(oₜ₊₁,...,oₜ|qₜ=i,λ)

Viterbi 算法（问题 2）：
δₜ(i) = max P(q₁,...,qₜ=i, o₁,...,oₜ|λ)
δₜ₊₁(j) = maxᵢ[δₜ(i)Aᵢⱼ]Bⱼ(oₜ₊₁)

Baum-Welch（问题 3）：
EM 算法在 HMM 上的应用
```

**思考题**：HMM 的独立性假设是什么？这个假设在实际中合理吗？

## Day 53

**知识点**：蒙特卡洛方法

**一句话**：蒙特卡洛方法用随机采样近似计算期望和积分。

**核心定义**：
- 基本思想：用样本均值近似期望
- 大数定律：样本越多，近似越精确
- 收敛速度：O(1/√N)，与维度无关
- 方差缩减：重要性采样、控制变量等

**几何直观**：
- 积分：曲线下面积
- 蒙特卡洛：随机撒点，数落在曲线下的比例
- 高维：传统网格方法指数爆炸，蒙特卡洛依然有效
- 误差：随机波动，但随样本量减小

**AI 中的应用**：
- 强化学习：蒙特卡洛树搜索 (MCTS)
- 贝叶斯推断：MCMC 采样
- 变分推断：用采样估计 ELBO
- 策略梯度：用采样估计期望梯度
- 不确定性估计：蒙特卡洛 Dropout

**关键公式**：
```
蒙特卡洛积分：
I = ∫f(x)p(x)dx ≈ (1/N)Σᵢf(x⁽ⁱ⁾), x⁽ⁱ⁾~p(x)

期望估计：
Eₓ~p[f(x)] ≈ (1/N)Σᵢf(x⁽ⁱ⁾)

方差：
Var[Î] = Var[f(x)]/N

重要性采样：
Eₓ~p[f(x)] = Eₓ~q[f(x)p(x)/q(x)]
≈ (1/N)Σᵢf(x⁽ⁱ⁾)p(x⁽ⁱ⁾)/q(x⁽ⁱ⁾), x⁽ⁱ⁾~q(x)
```

**思考题**：蒙特卡洛方法的收敛速度为什么与维度无关？这是什么意思？

## Day 54

**知识点**：MCMC 采样

**一句话**：MCMC 构造一个马尔可夫链，使其平稳分布等于目标分布，从而采样。

**核心定义**：
- MCMC：Markov Chain Monte Carlo
- Metropolis-Hastings：接受 - 拒绝采样
- Gibbs 采样：逐个变量条件采样
- burn-in：丢弃初始样本（未收敛）
- 自相关：连续样本相关，需稀释

**几何直观**：
- 目标：从高维复杂分布采样
- MCMC：在状态空间随机游走
- 平稳分布：游走的长期分布 = 目标分布
- 收敛：需要足够步数达到平稳

**AI 中的应用**：
- 贝叶斯推断：采样后验分布
- 玻尔兹曼机：训练时的采样
- 对比散度：近似的 MCMC
- 汉密尔顿蒙特卡洛 (HMC)：用梯度信息加速
- 变分推断的替代方案

**关键公式**：
```
Metropolis-Hastings：
1. 从 q(x'|xₜ) 提议新状态 x'
2. 计算接受率：α = min(1, P(x')q(xₜ|x')/(P(xₜ)q(x'|xₜ)))
3. 以概率α接受 x'，否则保持 xₜ

Gibbs 采样：
xᵢ⁽ᵗ⁺¹⁾ ~ P(xᵢ|x₁⁽ᵗ⁺¹⁾,...,xᵢ₋₁⁽ᵗ⁺¹⁾,xᵢ₊₁⁽ᵗ⁾,...,xₙ⁽ᵗ⁾)
逐个变量从条件分布采样

细致平衡条件：
P(x)T(x'|x) = P(x')T(x|x')
```

**思考题**：MCMC 和变分推断各有什么优缺点？什么时候选择哪个？

## Day 55

**知识点**：变分推断

**一句话**：变分推断用优化代替采样，用简单分布近似复杂后验。

**前置知识**：Day 44（KL 散度）、Day 33（贝叶斯推断）、Day 50（EM 算法）
**后续应用**：Day 56-60（Transformer 各组件不直接使用，但 VAE 等生成模型依赖）
**关联回顾**：Day 54（MCMC - 变分推断的替代方案）、Day 42（熵 - ELBO 包含熵项）
**重要**：建议在 Day 50 EM 算法之后立即学习，两者对比理解

**核心定义**：
- 核心思想：将推断转化为优化问题
- 变分分布 q(z)：近似真实后验 p(z|x)
- ELBO：Evidence Lower Bound
- 优化目标：max ELBO = min KL(q||p)
- 平均场假设：q(z) = Πq(zᵢ)，变量独立

**几何直观**：
- 真实后验：复杂、难计算
- 变分分布：简单分布族（如高斯）
- 优化：在简单分布族中找最接近的
- 近似：计算高效，但有近似误差

**AI 中的应用**：
- 变分自编码器 (VAE)：神经变分推断
- 主题模型：LDA 的变分推断
- 贝叶斯神经网络：变分近似后验
- 概率编程：自动变分推断
- 黑盒变分推断：通用框架

**关键公式**：
```
ELBO 推导：
log p(x) = ELBO + D_KL(q||p)
ELBO = E_q[log p(x,z)] - E_q[log q(z)]
= E_q[log p(x|z)] - D_KL(q(z)||p(z))

变分推断：
q*(z) = argmax ELBO

VAE 损失：
L = E_q[log p(x|z)] - D_KL(q(z|x)||p(z))
重构项 - KL 正则项

重参数化技巧：
z = μ + σ⊙ε, ε~N(0,I)
```

**思考题**：变分推断和 MCMC 的区别是什么？各适用什么场景？

## Day 56

**知识点**：注意力机制的数学

**一句话**：注意力是加权平均，权重由 Query-Key 相似度决定。

**核心定义**：
- Attention(Q,K,V) = softmax(QKᵀ/√d)V
- Query：当前需要关注的"问题"
- Key：每个位置的"索引"
- Value：每个位置的实际内容
- 缩放因子 1/√d：防止点积过大，softmax 饱和

**几何直观**：
- 相似度：Q·K 越大，注意力权重越大
- softmax：归一化为概率分布
- 加权平均：按注意力权重聚合 Value
- 并行：所有位置同时计算注意力

**AI 中的应用**：
- Transformer：自注意力是核心
- 编码器 - 解码器：跨注意力
- 视觉 Transformer：图像块之间的注意力
- 长序列：稀疏注意力、线性注意力
- 多模态：图文交叉注意力

**关键公式**：
```
缩放点积注意力：
Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V

单头注意力：
Aᵢ = softmax(q·Kᵀ/√d)
output = ΣᵢAᵢVᵢ

多头注意力：
MultiHead(Q,K,V) = Concat(head₁,...,headₕ)Wᴼ
headᵢ = Attention(QWᵢQ, KWᵢK, VWᵢV)

自注意力复杂度：
时间：O(n²d)
空间：O(n²) (注意力矩阵)
```

**思考题**：为什么需要缩放因子 1/√d？不缩放会有什么问题？

## Day 57

**知识点**：位置编码的数学

**一句话**：位置编码给序列注入顺序信息，让 Transformer 能感知位置。

**核心定义**：
- 正弦位置编码：PE(pos,2i) = sin(pos/10000^(2i/d))
- PE(pos,2i+1) = cos(pos/10000^(2i/d))
- 可学习位置编码：直接学习嵌入向量
- RoPE (旋转位置编码)：用旋转矩阵编码相对位置
- 目标：让模型能利用位置信息

**几何直观**：
- 正弦编码：每个维度是不同频率的正弦波
- 相对位置：PE(pos+k) 可由 PE(pos) 线性变换得到
- 旋转：RoPE 将位置编码为旋转角度
- 外推：正弦编码可外推到更长序列

**AI 中的应用**：
- Transformer：标准位置编码
- RoPE：LLaMA 等模型使用
- ALiBi：用注意力偏置编码位置
- 长上下文：位置编码外推
- 视觉 Transformer：2D 位置编码

**关键公式**：
```
正弦位置编码：
PE(pos,2i) = sin(pos/10000^(2i/d_model))
PE(pos,2i+1) = cos(pos/10000^(2i/d_model))

相对位置性质：
PE(pos+k) 可由 PE(pos) 线性表示

RoPE (2D 旋转)：
R(θ) = [[cosθ, -sinθ], [sinθ, cosθ]]
f_q(x_m) = R(θ_m)q, f_k(x_n) = R(θ_n)k
注意力 = f_q(x_m)·f_k(x_n) = q·R(θ_n-θ_m)k
```

**思考题**：正弦位置编码相比可学习位置编码有什么优势？为什么能外推？

## Day 58

**知识点**：归一化技术

**一句话**：归一化稳定训练，加速收敛，是深度网络的标配。

**核心定义**：
- BatchNorm：对 batch 维度归一化
- LayerNorm：对特征维度归一化
- InstanceNorm：对单个样本归一化
- GroupNorm：对通道分组归一化
- 公式：x̂ = (x-μ)/σ, y = γx̂ + β

**几何直观**：
- 归一化：将数据拉回到均值为 0、方差为 1
- 缩放平移：γ和β学习最优的缩放和平移
- 稳定：防止激活值过大或过小
- 平滑：归一化使 loss landscape 更平滑

**AI 中的应用**：
- CNN：BatchNorm 是标准配置
- Transformer：LayerNorm 是标准配置
- 生成模型：InstanceNorm 用于风格迁移
- 小 batch：GroupNorm 替代 BatchNorm
- 归一化位置：Pre-Norm vs Post-Norm

**关键公式**：
```
BatchNorm：
μ_B = (1/m)Σxᵢ
σ²_B = (1/m)Σ(xᵢ-μ_B)²
x̂ᵢ = (xᵢ-μ_B)/√(σ²_B+ε)
yᵢ = γx̂ᵢ + β

LayerNorm：
对单个样本的所有特征归一化
μ = (1/d)Σxⱼ
σ² = (1/d)Σ(xⱼ-μ)²

推理时 (BatchNorm)：
用训练时的移动平均μ和σ
```

**思考题**：为什么 Transformer 用 LayerNorm 而不用 BatchNorm？

## Day 59

**知识点**：初始化方法

**一句话**：好的初始化让信号在前向和反向传播中保持稳定。

**核心定义**：
- Xavier 初始化：适用于 tanh/sigmoid
- He 初始化：适用于 ReLU 及其变体
- 目标：保持前向信号方差和反向梯度方差稳定
- 原则：权重方差 = 2/(fan_in + fan_out) 或 2/fan_in
- 避免：梯度消失或爆炸

**几何直观**：
- 太小：信号逐层衰减，梯度消失
- 太大：信号逐层放大，梯度爆炸
- 刚好：信号稳定传播
- ReLU：一半神经元失活，方差需×2

**AI 中的应用**：
- 全连接层：Xavier 或 He 初始化
- 卷积层：He 初始化更常用
- Transformer：小模型用 He，大模型用特殊初始化
- 残差网络：残差分支初始化为 0 或小值
- 预训练：随机初始化替代方案

**关键公式**：
```
Xavier 初始化 (Glorot)：
W ~ N(0, 2/(fan_in + fan_out))  (正态)
W ~ U[-√(6/(fan_in+fan_out)), √(6/(fan_in+fan_out))]  (均匀)

He 初始化 (Kaiming)：
W ~ N(0, 2/fan_in)  (适用于 ReLU)
W ~ N(0, 1/fan_in)  (适用于线性)

方差保持：
Var(y) = Var(x) (前向)
Var(∂L/∂x) = Var(∂L/∂y) (反向)
```

**思考题**：为什么 ReLU 要用 He 初始化而不是 Xavier？推导方差变化。

## Day 60

**知识点**：学习率调度

**一句话**：学习率调度动态调整学习率，平衡收敛速度和最终性能。

**核心定义**：
- 学习率衰减：随训练逐渐减小学习率
- Warmup：先从小学习率开始，逐渐增大
- 余弦退火：按余弦函数衰减
- 阶梯衰减：在特定 epoch 乘以衰减因子
- 自适应：根据梯度动态调整 (Adam 等)

**几何直观**：
- 大学习率：快速下降，但可能在最优解附近震荡
- 小学习率：精确收敛，但速度慢
- Warmup：避免初期梯度不稳定
- 退火：后期精细调整

**AI 中的应用**：
- Transformer：Warmup + 逆平方根衰减
- 图像分类：余弦退火或阶梯衰减
- 大模型：Warmup 必不可少
- 微调：小学习率精细调整
- 学习率查找：找到最大可用学习率

**关键公式**：
```
Warmup：
η = η_max × t/T_warmup (线性增长)

逆平方根衰减 (Transformer)：
η = d_model^(-0.5) × min(t^(-0.5), t×T_warmup^(-1.5))

余弦退火：
ηₜ = η_min + (η_max - η_min) × (1+cos(πt/T))/2

阶梯衰减：
η = η₀ × γ^⌊t/step⌋

OneCycle：
先升后降的三角或余弦形状
```

**思考题**：为什么 Warmup 对大模型训练如此重要？有什么理论解释？
