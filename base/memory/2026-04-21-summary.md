## 1. Windows Git Bash 安装 Claude Code CLI

### 核心要点

| 问题 | 解决方案 |
|------|---------|
| pnpm v10+ 阻止 build scripts | 加 `--allow-build=@anthropic-ai/claude-code` |
| Git Bash 路径识别失败 | 用 `cygpath -w /usr/bin/bash` 获取真实路径 |
| 国内无法访问 Anthropic | 配置代理端点（如 DashScope 兼容模式） |

### 推荐安装命令

```bash
# 方案一：pnpm（需授权）
pnpm add -g @anthropic-ai/claude-code --allow-build=@anthropic-ai/claude-code

# 方案二：npm（更省心，推荐）
npm install -g @anthropic-ai/claude-code

# 配置环境变量
export CLAUDE_CODE_GIT_BASH_PATH="C:\Users\...\Git\usr\bin\bash.exe"
export ANTHROPIC_API_KEY="your-api-key"
```

## 2. SSH Host Key 类型不匹配故障

### 问题
```
Unable to negotiate with 10.1.17.2 port xxxx: no matching host key type found. Their offer: ssh-rsa
```

### 原因
OpenSSH 8.8+ 默认禁用 `ssh-rsa`（安全问题），但老旧 Git 服务器仍在使用。

### 解决方案
在 `~/.ssh/config` 中添加：
```ssh
Host coding.xxx.com          # 必须匹配 git remote 中的 hostname
    HostName 10.1.17.2       # 实际 IP
    HostKeyAlgorithms +ssh-rsa
    PubkeyAcceptedAlgorithms +ssh-rsa
```

### ⚠️ 关键细节
- `Host` 匹配的是 **hostname** 不是 IP
- `+ssh-rsa` 是追加到默认列表，不是替换

## 3. 大模型记忆机制

| 类型 | 类比 | 实现 | 特点 |
|------|------|------|------|
| 参数记忆 | 长期记忆 | 神经网络权重 | 静态、截止训练日 |
| 上下文记忆 | 短期记忆 | Attention 机制 | 即时生效、窗口限制 |
| RAG | 查资料 | 向量检索 | 外部知识库注入 |
| 微调 | 重新学习 | 梯度更新/LoRA | 可能灾难性遗忘 |

**本质**：知识以统计关联模式存储在权重矩阵中，而非显式数据库。

## 4. Prompt 影响回答的原理

### 核心原因
模型存储的是**概率关联模式**，Prompt 引导模型在概率空间中找到正确路径。

### 三种影响机制

1. **激活正确知识区域**
   - 好 Prompt 精准激活相关路径

2. **设定概率分布偏向**
   - "深思熟虑"→结构化推理
   - "快速回答"→简洁直接

3. **引导输出格式**
   - "列举 3 点"→结构化
   - "逐步推理"→CoT 模式

### 本质
> Prompt 不增加模型知识，但决定它能多准确地调用已有知识。

## 5. 注意力机制详解

### Q-K-V 机制

```
Query (Q): 我要找什么信息？
Key (K):   我有什么信息？
Value (V): 信息的具体内容

注意力分数 = Q × K (点积)
↓
Softmax 归一化 → 放大差异
```

### Softmax 放大效应
```
原始分数：[8, 7, 2, 1]    →  Softmax: [0.46, 0.34, 0.12, 0.08]
原始分数：[20, 2, 1, 1]   →  Softmax: [0.999, 0.0004, ...] 极端聚焦
```

### 形象类比
- 模型知识 = 黑暗图书馆
- 差 Prompt = 手电筒散射（杂乱）
- 好 Prompt = 手电筒聚焦（精准）

### 一句话总结
> Prompt 通过提供高权重 Query 向量，让注意力层计算偏向特定知识区域的分布，在参数空间中"照亮"正确路径。
