# 技术文档编写指南

> **核心原则**：以学科体系为骨架，以学习者认知为脉络，主动补充学习者"不知道自己不知道"的知识点

---

## 一、核心理念

### 不是"不按学科体系"，而是：

> **以学科体系为骨架，以学习者认知为脉络，主动暴露"你不知道的"**

### 三个关键认知

| 误区           | 正确理解                             |
| -------------- | ------------------------------------ |
| 抛弃学科体系   | 学科体系是地图，文档是导航路线       |
| 只回答提问     | 主动预判认知盲区，补充重要知识点     |
| 教会=讲完      | 教会=能回答What+How+Why              |

---

## 二、文档结构模型

```
1. 【为什么学】动机与目标
   ↓
2. 【是什么】核心概念（简明定义）
   ↓
3. 【怎么用】实践应用（代码/示例）
   ↓
4. 【易错点】常见误区与纠正（学科重要，学习者易误解）
   ↓
5. 【深入理解】原理与本质（学科重要，学习者未知）
   ↓
6. 【概念网络】关系与辨析（建立知识体系）
   ↓
7. 【记忆辅助】口诀、表格、图（降低认知负荷）
   ↓
8. 【延伸资源】工具、链接、进阶（按需深入）
```

---

## 三、关键原则

### 原则1：学科体系是地图，不是路线

- **地图**：展示所有重要地点（知识点）
- **路线**：根据学习者当前位置定制
- **关键**：不能因为"绕路"而跳过学科体系中的重要地点

### 原则2：主动暴露"你不知道的"

- 不是等学习者问，而是预判
- "你可能觉得X和Y一样，其实..."
- "这里有个坑，很多人踩过..."
- "学科体系中还有一个重要概念，你可能没想到..."

### 原则3：真正的懂 = 能回答三个问题

| 问题   | 层次   | 检验标准           |
| ------ | ------ | ------------------ |
| What？ | 认知   | 能用自己的话解释   |
| How？  | 应用   | 能动手实践         |
| Why？  | 原理   | 能推导、能举一反三 |

---

## 四、知识点补充策略

### 四维分类法

| 学科重要性 | 学习者认知 | 处理方式           | 示例              |
| ---------- | ---------- | ------------------ | ----------------- |
| 重要       | 已知       | 快速复习，建立连接 | 单变量导数        |
| 重要       | 未知       | **必须补充，详细讲解** | 全微分、Hessian |
| 重要       | 误解       | **纠正误区，澄清概念** | 梯度方向          |
| 次要       | 好奇       | 附录延伸，按需阅读 | 牛顿法推导        |

### 补充时机

```
基础概念讲解时
      ↓
"这里有个重要的区别..."（微分vs导数）
      ↓
实践应用演示时
      ↓
"你可能想问，为什么这样能工作..."（极值原理）
      ↓
深入理解拓展时
      ↓
"学科体系中还有一个相关概念..."（二阶导数）
```

## 六、自检清单

### 内容完整性

- [ ] 读者看完能回答"这是什么"（What）
- [ ] 读者看完能回答"这有什么用"（Why）
- [ ] 读者看完能回答"怎么用"（How）
- [ ] 列出了至少3个常见误区
- [ ] 提供了实践代码/示例
- [ ] 概念间的关系清晰
- [ ] 有记忆辅助（口诀/表格/图）
- [ ] 提供了延伸学习资源

### 学科体系覆盖

- [ ] 检查了学科体系中的重要知识点
- [ ] 补充了学习者可能忽略的重要概念
- [ ] 纠正了学习者可能的误解
- [ ] 建立了概念间的逻辑联系

### 教学效果

- [ ] 从学习者已知出发
- [ ] 多层次呈现（公式+几何+代码+类比）
- [ ] 主动暴露"你不知道的"
- [ ] 渐进式深入，按需阅读

## 七、案例：偏导数文档的知识点补充

### 学习者没想到，但学科体系中重要的知识点

| 知识点 | 学习者通常的想法 | 为什么必须教 |
|--------|------------------|--------------|
| 全微分 vs 偏微分 | "导数和微分差不多吧" | 理解线性近似的本质 |
| 二阶导数/Hessian | "梯度下降就够了" | 理解收敛速度、曲率 |
| 条件数 | "学习率调小就行" | 理解为什么有些问题难优化 |
| 牛顿法 | "深度学习只用SGD" | 理解二阶信息的威力与代价 |
| 导数找极值的原理 | "令导数=0就行" | 理解为什么这样能找到最值 |

### 文档结构逻辑

```
【学科体系骨架】          【学习者认知脉络】
     ↓                        ↓
微积分基础 ─────────────→ 从单变量到多变量
     ↓                        ↓
偏导数定义 ─────────────→ 怎么计算？
     ↓                        ↓
链式法则 ──────────────→ 神经网络怎么用？
     ↓                        ↓
梯度与优化 ────────────→ 为什么能下降？
     ↓                        ↓
二阶理论（Hessian）────→ 还能做得更好吗？
     ↓                        ↓
数值优化方法 ──────────→ 实际应用的选择
```

## 八、一句话总结

> **好的技术文档 = 学科体系的完整地图 + 学习者的最优路径 + 沿途的重要提示 + 你不知道的我知道**

不是抛弃学科体系，而是**以学科体系为底气，以学习者为中心，主动补全认知缺口，教会真正的懂**。
