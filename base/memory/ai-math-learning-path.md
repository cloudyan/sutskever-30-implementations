按照 Day 1-60 顺序学习，适合：

## 💡 学习建议

### ✅ 应该做的
1. **理解优先**：不要死记硬背公式，理解几何直观
2. **动手推导**：关键公式手动推导至少一遍
3. **联系 AI**：时刻思考这个知识点在 AI 中哪里用到
4. **间隔复习**：利用遗忘曲线，定期回顾
5. **讨论交流**：和别人讨论能加深理解

### ❌ 应该避免的
1. **跳跃学习**：前面没理解就往后看
2. **只看不练**：不推导公式，不写代码实现
3. **追求完美**：某些细节可以先跳过，后续会理解
4. **孤立学习**：不联系 AI 应用，纯学数学
5. **急于求成**：数学需要时间沉淀，不要贪快
