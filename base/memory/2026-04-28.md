## 🐛 踩坑记录：GitHub Pages + Docsify 的 sidebar 404 问题

### 问题现象
- Docsify 项目部署到 GitHub Pages 后，页面能打开，但 **sidebar 不显示**
- 直接访问 `https://xxx.github.io/xxx/_sidebar.md` 返回 **404**
- 文件在仓库里确实存在，但 Pages 就是访问不到

### 根本原因
GitHub Pages 默认使用 **Jekyll** 构建，Jekyll 会**忽略 `_` 开头的文件和目录**（如 `_sidebar.md`、`_navbar.md`），认为它们是内部文件。

### 解决方案
在仓库**根目录**添加一个空文件 **`.nojekyll`**：
```bash
touch .nojekyll
git add .nojekyll
git commit -m "添加 .nojekyll 修复 sidebar 404"
git push
```

### 经验教训
> **⚠️ 使用 Docsify 部署 GitHub Pages 时，必须在仓库根目录添加 `.nojekyll` 文件，否则 `_sidebar.md`、`_navbar.md` 等 `_` 开头的文件会被 Jekyll 忽略，导致 sidebar/navbar 无法加载。**
