## Day 41

**知识点**：信息量与自信息

**一句话**：信息量度量事件的" surprise 程度"，越不可能的事件信息量越大。

**核心定义**：
- 自信息：I(x) = -log P(x) = log(1/P(x))
- 单位：bit (以 2 为底) 或 nat (以 e 为底)
- 性质 1：P(x)=1 时，I(x)=0（确定事件无信息）
- 性质 2：P(x)→0 时，I(x)→∞（罕见事件信息量大）
- 可加性：独立事件的联合信息 = 信息之和

**几何直观**：
- 高概率事件：发生了也不意外，信息量少
- 低概率事件：发生了很惊讶，信息量大
- 对数函数：单调递减，P 越大 I 越小
- 直觉："太阳从东边升起"信息量≈0；"太阳从西边升起"信息量巨大

**AI 中的应用**：
- 决策树：用信息增益选择分裂特征
- 异常检测：低概率事件可能是异常
- 课程学习：从高概率（简单）样本开始
- 主动学习：选择信息量大的未标注样本
- 压缩编码：高频符号用短编码，低频用长编码

**关键公式**：
```
自信息定义：
I(x) = -log₂ P(x)  (单位：bit)
I(x) = -ln P(x)    (单位：nat)

独立事件的联合信息：
I(x,y) = I(x) + I(y)  (当 P(x,y)=P(x)P(y))

期望信息（熵，见 Day 42）：
H(X) = E[I(X)] = Σ P(x)I(x)
```

**思考题**：为什么用对数定义信息量？加法性质有什么实际意义？

## Day 42

**知识点**：熵 (Entropy)

**一句话**：熵是随机变量的平均信息量，度量不确定性。

**核心定义**：
- 熵：H(X) = -Σ P(x)log P(x) = E[I(X)]
- 连续熵（微分熵）：h(X) = -∫ p(x)log p(x)dx
- 最大熵：均匀分布时熵最大
- 最小熵：确定性分布（某个 P(x)=1）时熵为 0
- 单位：bit 或 nat

**几何直观**：
- 高熵：分布平坦，不确定性大
- 低熵：分布集中，不确定性小
- 二元分布：P=0.5 时熵最大 (=1 bit)
- 熵是"惊喜度的期望"

**AI 中的应用**：
- 决策树：ID3/C4.5 用信息增益（熵的减少）选择特征
- 分类损失：交叉熵损失是最小化真实分布与预测分布的差距
- 正则化：最大熵正则化鼓励探索
- 强化学习：策略熵正则化防止过早收敛
- 聚类：用熵评估聚类质量

**关键公式**：
```
离散熵：
H(X) = -Σᵢ P(xᵢ)log₂ P(xᵢ)

二元分布熵（二元熵函数）：
H(p) = -p log₂ p - (1-p)log₂(1-p)
最大值：p=0.5 时 H=1 bit

连续熵（微分熵）：
h(X) = -∫ p(x)log p(x)dx

高斯分布的微分熵：
h(N(μ,σ²)) = (1/2)log₂(2πeσ²)

联合熵：
H(X,Y) = -Σ P(x,y)log P(x,y)
```

**思考题**：为什么均匀分布的熵最大？证明这个结论。

## Day 43

**知识点**：交叉熵

**一句话**：交叉熵度量用错误分布 q 编码真实分布 p 的平均编码长度。

**核心定义**：
- 交叉熵：H(p,q) = -Σ p(x)log q(x)
- 含义：用分布 q 的编码方案编码分布 p 的样本
- 与熵的关系：H(p,q) = H(p) + D_KL(p||q)
- 最小化交叉熵 = 最小化 KL 散度（因为 H(p) 是常数）

**几何直观**：
- 真实分布 p：固定的"目标"
- 预测分布 q：我们学习的分布
- 交叉熵：q 离 p 越远，值越大
- 最小值：当 q=p 时，H(p,q)=H(p)

**AI 中的应用**：
- 分类损失函数：交叉熵是标准配置
- softmax + 交叉熵：神经网络分类的标准组合
- 语言模型：最小化预测分布与真实分布的交叉熵
- 生成模型：VAE、GAN 都涉及分布匹配
- 知识蒸馏：学生模型拟合教师模型的分布

**关键公式**：
```
交叉熵定义：
H(p,q) = -Σₓ p(x)log q(x)

与熵和 KL 的关系：
H(p,q) = H(p) + D_KL(p||q)

分类问题（one-hot 标签）：
p = [0,...,1,...,0] (真实类别为 1)
H(p,q) = -log q(y_true)
= -log q̂ (预测概率的对数)

多分类交叉熵：
L = -Σᵢ Σₖ yᵢₖ log ŷᵢₖ
(对样本 i 和类别 k 求和)
```

**思考题**：为什么分类问题用交叉熵而不用 MSE？从梯度和概率角度分析。

## Day 44

**知识点**：KL 散度

**一句话**：KL 散度度量两个概率分布的"距离"，但不是真正的距离。

**核心定义**：
- KL 散度：D_KL(p||q) = Σ p(x)log(p(x)/q(x))
- 性质 1：D_KL(p||q) ≥ 0（Gibbs 不等式）
- 性质 2：D_KL(p||q) = 0 当且仅当 p=q
- 非对称：D_KL(p||q) ≠ D_KL(q||p)
- 不满足三角不等式：不是度量 (metric)

**几何直观**：
- p||q：用 q 近似 p 的"信息损失"
- 非对称：p 是"真实"，q 是"近似"
- D_KL(p||q) 大：q 在 p 概率大的地方概率小
- 零强制：p(x)>0 时 q(x) 必须>0，否则 KL→∞

**AI 中的应用**：
- 变分推断：最小化近似后验与真实后验的 KL
- VAE：ELBO = 重构误差 - KL 散度正则项
- 强化学习：TRPO/PPO 用 KL 约束策略更新幅度
- 知识蒸馏：最小化学生与教师分布的 KL
- 期望传播：用简单分布近似复杂分布

**关键公式**：
```
KL 散度定义：
D_KL(p||q) = Σₓ p(x)log(p(x)/q(x))
= Eₓ~p[log p(x) - log q(x)]

与交叉熵的关系：
D_KL(p||q) = H(p,q) - H(p)

连续形式：
D_KL(p||q) = ∫ p(x)log(p(x)/q(x))dx

高斯分布间的 KL：
D_KL(N₀||N₁) = (1/2)[log(σ₁²/σ₀²) + (σ₀²+(μ₀-μ₁)²)/σ₁² - 1]
```

**思考题**：为什么 KL 散度不对称？D_KL(p||q) 和 D_KL(q||p) 各有什么含义？

## Day 45

**知识点**：互信息

**一句话**：互信息度量两个变量"共享"的信息量，即知道一个变量后对另一个变量不确定性的减少。

**核心定义**：
- 互信息：I(X;Y) = ΣΣ P(x,y)log(P(x,y)/(P(x)P(y)))
- 等价形式：I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)
- 对称：I(X;Y) = I(Y;X)
- 范围：0 ≤ I(X;Y) ≤ min(H(X), H(Y))
- 独立：X,Y 独立时 I(X;Y)=0

**几何直观**：
- 文氏图：H(X) 和 H(Y) 是两个圆
- 互信息：两个圆的重叠部分
- H(X|Y)：H(X) 中不与 H(Y) 重叠的部分
- 完全相关：I(X;Y) = H(X) = H(Y)

**AI 中的应用**：
- 特征选择：选择与目标互信息大的特征
- 表示学习：最大化输入与表示的互信息
- 对比学习：InfoNCE 损失最大化互信息下界
- 信息瓶颈：压缩输入同时保留与目标相关的信息
- 因果发现：用互信息发现变量间依赖

**关键公式**：
```
互信息定义：
I(X;Y) = Σₓ Σᵧ P(x,y)log(P(x,y)/(P(x)P(y)))

与熵的关系：
I(X;Y) = H(X) - H(X|Y)
= H(Y) - H(Y|X)
= H(X) + H(Y) - H(X,Y)
= D_KL(P(X,Y) || P(X)P(Y))

条件互信息：
I(X;Y|Z) = H(X|Z) - H(X|Y,Z)

点互信息 (PMI)：
PMI(x,y) = log(P(x,y)/(P(x)P(y)))
```

**思考题**：互信息和相关系数有什么区别？互信息能捕捉非线性关系吗？

## 阶段小结

**信息论核心思想**：
1. 信息量度量事件的"surprise 程度"
2. 熵是随机变量的平均不确定性
3. 交叉熵是用错误分布编码的平均长度
4. KL 散度度量两个分布的差异（非对称）
5. 互信息度量两个变量的共享信息
6. 信息论是深度学习损失函数的理论基础
