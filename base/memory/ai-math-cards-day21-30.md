## Day 21

**知识点**：概率与条件概率

**一句话**：概率度量事件发生的可能性，条件概率是"已知某信息后"的概率。

**核心定义**：
- 概率：P(A) ∈ [0,1]，事件 A 发生的可能性
- 样本空间：所有可能结果的集合 Ω
- 条件概率：P(A|B) = P(A∩B)/P(B)，已知 B 发生后 A 的概率
- 联合概率：P(A,B) = P(A∩B)，A 和 B 同时发生

**几何直观**：
- 文氏图：概率是面积，条件概率是"缩小样本空间"
- P(A|B)：在 B 的区域内，A 占的比例
- 独立性：P(A|B) = P(A)，B 的发生不影响 A
- 互斥：P(A∩B) = 0，A 和 B 不能同时发生

**AI 中的应用**：
- 分类问题：P(y|x) 是给定输入 x 后类别 y 的概率
- 贝叶斯网络：用条件概率表示变量间依赖关系
- 语言模型：P(下一个词 | 上文)
- 决策树：每个节点的条件概率分布

**关键公式**：
```
概率公理：
1. P(A) ≥ 0
2. P(Ω) = 1
3. 互斥事件：P(A∪B) = P(A) + P(B)

条件概率：P(A|B) = P(A∩B)/P(B), P(B) > 0
乘法法则：P(A∩B) = P(A|B)P(B) = P(B|A)P(A)
全概率公式：P(A) = ΣᵢP(A|Bᵢ)P(Bᵢ)
```

## Day 22

**知识点**：贝叶斯定理

**一句话**：贝叶斯定理是"逆向概率"，从结果反推原因。

**核心定义**：
- 贝叶斯定理：P(A|B) = P(B|A)P(A)/P(B)
- 先验概率 P(A)：看到证据前的信念
- 后验概率 P(A|B)：看到证据后的信念
- 似然 P(B|A)：在 A 条件下观察到 B 的可能性
- 证据 P(B)：归一化常数

**几何直观**：
- 先验：初始信念
- 似然：证据对假设的支持程度
- 后验：更新后的信念
- 贝叶斯更新：不断用新证据修正信念

**AI 中的应用**：
- 朴素贝叶斯分类：P(y|x) ∝ P(x|y)P(y)
- 贝叶斯推断：从数据推断参数分布
- 贝叶斯优化：超参数调优
- 变分自编码器 (VAE)：变分贝叶斯推断
- 贝叶斯神经网络：权重是概率分布而非确定值

**关键公式**：
```
贝叶斯定理：
P(A|B) = P(B|A)P(A)/P(B)

多假设形式：
P(Hᵢ|D) = P(D|Hᵢ)P(Hᵢ) / ΣⱼP(D|Hⱼ)P(Hⱼ)

连续形式：
p(θ|D) = p(D|θ)p(θ) / p(D)
```

**思考题**：为什么朴素贝叶斯叫"朴素"？这个假设在实际中合理吗？

## Day 23

**知识点**：随机变量

**一句话**：随机变量是将随机结果映射为数字的函数。

**核心定义**：
- 随机变量 X：样本空间→实数的函数
- 离散随机变量：取值可数（如掷骰子）
- 连续随机变量：取值不可数（如身高）
- 概率质量函数 (PMF)：P(X=x)，离散变量
- 概率密度函数 (PDF)：p(x)，连续变量

**几何直观**：
- 离散：概率分布是"柱状图"
- 连续：概率密度是"曲线"，概率是曲线下面积
- 累积分布 (CDF)：F(x) = P(X ≤ x)，单调递增
- 随机变量是"随机"的，但分布是确定的

**AI 中的应用**：
- 分类输出：离散随机变量（类别）
- 回归输出：连续随机变量（数值）
- 生成模型：学习数据的概率分布
- Dropout：伯努利随机变量决定神经元是否激活
- 采样：从分布中生成随机样本

**关键公式**：
```
离散随机变量：
PMF: P(X=xᵢ) = pᵢ, Σpᵢ = 1
CDF: F(x) = P(X ≤ x) = Σₓᵢ≤ₓ pᵢ

连续随机变量：
PDF: p(x) ≥ 0, ∫p(x)dx = 1
CDF: F(x) = P(X ≤ x) = ∫₋∞ˣ p(t)dt
P(a ≤ X ≤ b) = ∫ₐᵇ p(x)dx = F(b) - F(a)
```

**思考题**：为什么连续随机变量取某个具体值的概率是 0？

## Day 24

**知识点**：概率分布

**一句话**：常见概率分布是 AI 建模的基础构件。

**核心定义**：
- 伯努利分布：单次试验，成功概率 p
- 二项分布：n 次伯努利试验，成功次数
- 多项式分布：k 个结果，n 次试验
- 高斯分布：正态分布，最连续的分布
- 均匀分布：等概率分布

**几何直观**：
- 伯努利：两点分布，0 或 1
- 高斯：钟形曲线，对称，均值处最高
- 指数分布：衰减曲线，等待时间
- 分布形状：由参数决定（均值、方差等）

**AI 中的应用**：
- 二分类：伯努利分布（sigmoid 输出）
- 多分类：多项式分布（softmax 输出）
- 回归：假设误差服从高斯分布
- 初始化：权重用高斯或均匀分布初始化
- 贝叶斯方法：用共轭先验简化计算

**关键公式**：
```
伯努利分布：P(X=1) = p, P(X=0) = 1-p
均值：E[X] = p, 方差：Var(X) = p(1-p)

二项分布：P(X=k) = C(n,k)pᵏ(1-p)ⁿ⁻ᵏ
均值：np, 方差：np(1-p)

高斯分布：
p(x) = (1/√(2πσ²))exp(-(x-μ)²/(2σ²))
均值：μ, 方差：σ²

多项式分布：
P(X₁=k₁,...,Xₖ=kₖ) = n!/(k₁!...kₖ!) × p₁ᵏ¹...pₖᵏᵏ
```

**思考题**：为什么高斯分布如此常见？中心极限定理说明了什么？

## Day 25

**知识点**：期望与方差

**一句话**：期望是随机变量的"平均值"，方差度量"波动程度"。

**核心定义**：
- 期望 E[X]：随机变量的加权平均
- 离散：E[X] = ΣxᵢP(X=xᵢ)
- 连续：E[X] = ∫x·p(x)dx
- 方差 Var(X)：E[(X-E[X])²]，度量离散程度
- 标准差：√Var(X)，与 X 同量纲

**几何直观**：
- 期望：分布的"重心"或"平衡点"
- 方差：分布的"宽度"或"分散程度"
- 大方差：数据分散；小方差：数据集中
- 期望线性：E[aX+b] = aE[X]+b

**AI 中的应用**：
- 损失函数：期望损失（风险最小化）
- 强化学习：期望回报最大化
- 批归一化：计算 batch 的均值和方差
- 权重初始化：保持方差稳定（Xavier/He）
- 蒙特卡洛：用样本均值近似期望

**关键公式**：
```
期望性质：
E[aX+b] = aE[X] + b
E[X+Y] = E[X] + E[Y] (线性性，不要求独立)
E[XY] = E[X]E[Y] (仅当 X,Y 独立)

方差性质：
Var(X) = E[X²] - (E[X])²
Var(aX+b) = a²Var(X)
Var(X+Y) = Var(X) + Var(Y) (仅当 X,Y 独立)

常用分布的期望和方差：
伯努利：E=p, Var=p(1-p)
高斯：E=μ, Var=σ²
```

**思考题**：为什么 Var(X) = E[X²] - (E[X])²？证明这个公式。

## Day 26

**知识点**：协方差与相关系数

**一句话**：协方差度量两个变量的"协同变化"，相关系数是标准化的协方差。

**核心定义**：
- 协方差：Cov(X,Y) = E[(X-E[X])(Y-E[Y])]
- 协方差 > 0：X 和 Y 同向变化
- 协方差 < 0：X 和 Y 反向变化
- 相关系数：ρ = Cov(X,Y)/(σₓσᵧ) ∈ [-1,1]
- 不相关：Cov(X,Y) = 0（但不一定独立）

**几何直观**：
- 正相关：散点图呈上升趋势
- 负相关：散点图呈下降趋势
- 不相关：散点图无规律
- 相关系数：线性关系的强度

**AI 中的应用**：
- 特征选择：高度相关的特征冗余
- PCA：基于协方差矩阵的特征分解
- 注意力机制：Query-Key 的相似度可看作协方差
- 时间序列：自相关分析
- 因果推断：相关性≠因果性

**关键公式**：
```
协方差：
Cov(X,Y) = E[XY] - E[X]E[Y]
Cov(X,X) = Var(X)

相关系数：
ρₓᵧ = Cov(X,Y) / (σₓσᵧ)
-1 ≤ ρ ≤ 1
|ρ|=1：完全线性相关；ρ=0：无线性相关

协方差矩阵：
Σᵢⱼ = Cov(Xᵢ,Xⱼ)
对称半正定矩阵
```

**思考题**：独立一定不相关，但不相关不一定独立。举例说明。

## Day 27

**知识点**：大数定律

**一句话**：样本越多，样本均值越接近期望值。

**核心定义**：
- 大数定律 (LLN)：n→∞时，样本均值→期望
- 弱大数定律：依概率收敛
- 强大数定律：几乎必然收敛
- 直观：抛硬币次数越多，正面比例越接近 0.5

**几何直观**：
- 单次试验：随机波动大
- 多次试验：波动相互抵消
- 大量试验：稳定在期望值附近
- 收敛速度：O(1/√n)

**AI 中的应用**：
- Mini-batch：用 batch 梯度近似全量梯度
- 蒙特卡洛方法：用大量采样近似期望
- 强化学习：用多次 rollout 估计期望回报
- 交叉验证：多次平均减少方差
- Dropout 训练：期望多个子网络的平均

**关键公式**：
```
弱大数定律：
lim(n→∞) P(|(1/n)ΣXᵢ - μ| ≥ ε) = 0

样本均值：
X̄ₙ = (1/n)Σᵢ₌₁ⁿ Xᵢ
E[X̄ₙ] = μ
Var(X̄ₙ) = σ²/n

收敛速度：
P(|X̄ₙ - μ| ≥ ε) ≤ σ²/(nε²) (切比雪夫不等式)
```

**思考题**：为什么 Mini-batch 大小不是越大越好？从梯度和计算效率角度分析。

## Day 28

**知识点**：中心极限定理

**一句话**：独立随机变量之和趋近于高斯分布，解释了高斯分布的普遍性。

**核心定义**：
- 中心极限定理 (CLT)：n→∞时，标准化和→标准正态分布
- 条件：独立同分布，有限方差
- 标准化：Zₙ = (ΣXᵢ - nμ)/(σ√n) → N(0,1)
- 无论原分布是什么，和的分布趋近高斯

**几何直观**：
- 单个变量：任意分布
- 多个变量求和：分布越来越"光滑"
- 标准化后：趋近标准正态分布
- n≥30：通常认为近似足够好

**AI 中的应用**：
- 权重初始化：和的分布趋近高斯
- 梯度噪声：大量样本梯度的和近似高斯
- 置信区间：基于正态近似
- 假设检验：t 检验、z 检验的理论基础
- 贝叶斯推断：后验分布的渐近正态性

**关键公式**：
```
中心极限定理：
设 X₁,...,Xₙ 独立同分布，E[Xᵢ]=μ, Var(Xᵢ)=σ²
则 Zₙ = (ΣXᵢ - nμ)/(σ√n) → N(0,1) (n→∞)

等价形式：
X̄ₙ ≈ N(μ, σ²/n) (n 足够大)

应用：
ΣXᵢ ≈ N(nμ, nσ²)
X̄ₙ ≈ N(μ, σ²/n)
```

**思考题**：中心极限定理和大数定律有什么区别和联系？

## Day 29

**知识点**：联合分布与边缘分布

**一句话**：联合分布描述多个变量的整体，边缘分布是"投影"到单个变量。

**核心定义**：
- 联合分布：P(X,Y)，多个变量同时的概率
- 边缘分布：P(X) = ΣᵧP(X,Y) 或 ∫P(X,Y)dy
- 条件分布：P(X|Y) = P(X,Y)/P(Y)
- 独立性：P(X,Y) = P(X)P(Y)

**几何直观**：
- 联合分布：多维空间中的"概率云"
- 边缘分布：投影到低维（求和或积分）
- 条件分布：切片（固定某些变量）
- 独立：联合分布可分解为边缘分布的乘积

**AI 中的应用**：
- 生成模型：学习数据的联合分布 P(X,Y)
- 判别模型：学习条件分布 P(Y|X)
- 贝叶斯网络：用条件独立性简化联合分布
- 隐变量模型：P(X) = ∫P(X,Z)dZ（边缘化隐变量）
- 注意力：联合注意力分布

**关键公式**：
```
离散联合分布：
P(X=xᵢ) = ΣⱼP(X=xᵢ, Y=yⱼ) (边缘化)

连续联合分布：
p(x) = ∫p(x,y)dy

条件分布：
p(x|y) = p(x,y)/p(y)

链式法则：
p(x₁,...,xₙ) = p(x₁)p(x₂|x₁)...p(xₙ|x₁,...,xₙ₋₁)
```

**思考题**：为什么边缘化隐变量通常很难？有什么近似方法？

## Day 30

**知识点**：条件独立性

**一句话**：条件独立性是贝叶斯网络和朴素贝叶斯的核心假设。

**核心定义**：
- 条件独立：X⊥Y|Z ⇔ P(X,Y|Z) = P(X|Z)P(Y|Z)
- 等价形式：P(X|Y,Z) = P(X|Z)
- 含义：已知 Z 后，Y 对 X 没有额外信息
- 图模型：用图结构表示条件独立性

**几何直观**：
- 无向图：分离=条件独立
- 有向图：d-分离=条件独立
- 链式结构：X→Z→Y，X⊥Y|Z
- 共同原因：X←Z→Y，X⊥Y|Z
- 共同结果：X→Z←Y，X 和 Y 不独立，但给定 Z 后独立

**AI 中的应用**：
- 朴素贝叶斯：假设特征在给定类别下条件独立
- 贝叶斯网络：用有向无环图表示条件独立结构
- 马尔可夫随机场：无向图的条件独立模型
- 隐马尔可夫模型：马尔可夫性（未来只依赖现在）
- Transformer：自注意力打破条件独立假设

**关键公式**：
```
条件独立：
X⊥Y|Z ⇔ P(X,Y|Z) = P(X|Z)P(Y|Z)
⇔ P(X|Y,Z) = P(X|Z)

朴素贝叶斯：
P(y|x₁,...,xₙ) ∝ P(y)ΠᵢP(xᵢ|y)
(假设 xᵢ 在给定 y 下条件独立)

马尔可夫性：
P(Xₜ₊₁|X₁,...,Xₜ) = P(Xₜ₊₁|Xₜ)
```

**思考题**：朴素贝叶斯的条件独立假设明显不成立，为什么在实际中仍然有效？

4. 协方差和相关系数度量变量间的关系
