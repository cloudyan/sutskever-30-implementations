## 1️⃣ 从标量求导 → 向量求导

### 回顾：标量对 scalar 求导

**函数**：`y = f(x) = x²`

**导数**：`dy/dx = 2x`

**结果**：一个数（标量）

---

### 升级：标量对向量求导

**函数**：`y = f(x₁, x₂, ..., xₙ) = x₁² + x₂² + ... + xₙ²`

用向量表示：`y = f(**x**) = ||**x**||²`（向量长度的平方）

**问题**：`∂y/∂**x**` = ？

**答案**：**梯度向量**！

```
∂y/∂**x** = ∇y = [∂y/∂x₁, ∂y/∂x₂, ..., ∂y/∂xₙ]
```

---

### 🔢 具体例子

**函数**：`y = x₁² + x₂² + x₃²`

**向量形式**：`y = **x**ᵀ**x**`（**x** 与自己的点积）

**求导**：
```
∂y/∂x₁ = 2x₁
∂y/∂x₂ = 2x₂
∂y/∂x₃ = 2x₃

∇y = [2x₁, 2x₂, 2x₃] = 2**x**
```

**结论**：
```
∂(**x**ᵀ**x**)/∂**x** = 2**x**
```

---

### 📐 几何意义

**标量导数**：
```
dy/dx = 斜率（一个数）
```

**向量导数（梯度）**：
```
∇y = [∂y/∂x₁, ∂y/∂x₂, ...]
    = 指向函数增长最快方向的向量
```

**每个分量**：
```
∂y/∂x₁ = x₁ 变化时，y 的变化率
∂y/∂x₂ = x₂ 变化时，y 的变化率
...
```

## 2️⃣ 标量对矩阵求导

### 定义

**函数**：`y = f(W)`，W 是 m×n 矩阵

**导数**：`∂y/∂W` 也是 m×n 矩阵

**每个元素**：
```
[∂y/∂W]ᵢⱼ = ∂y/∂Wᵢⱼ
```

**通俗**：
> 对 W 中每个元素分别求偏导，保持原形状

---

### 🔢 例子 1：线性函数

**函数**：`y = **w**ᵀ**x**`（点积，**w** 和 **x** 都是 n 维向量）

展开：`y = w₁x₁ + w₂x₂ + ... + wₙxₙ`

**求 ∂y/∂**w**：**

```
∂y/∂w₁ = x₁
∂y/∂w₂ = x₂
...
∂y/∂wₙ = xₙ

∂y/∂**w** = [x₁, x₂, ..., xₙ] = **x**
```

**结论**：
```
∂(**w**ᵀ**x**)/∂**w** = **x**
```

---

### 🔢 例子 2：二次函数

**函数**：`y = (**w**ᵀ**x** - t)²`（线性回归的损失）

其中：
- **w**: 权重向量（n 维）
- **x**: 输入向量（n 维）
- t: 目标值（标量）

**求 ∂y/∂**w**：**

用链式法则：
```
令 z = **w**ᵀ**x** - t，则 y = z²

∂y/∂**w** = ∂y/∂z × ∂z/∂**w**
          = 2z × **x**
          = 2(**w**ᵀ**x** - t) × **x**
```

**结果形状**：
```
2(**w**ᵀ**x** - t) 是标量
**x** 是 n 维向量
结果 = n 维向量 ✓
```

## 3️⃣ 神经网络中的矩阵求导

### 单层神经网络

**前向传播**：
```
**z** = W**x** + **b**      # 加权和
**a** = σ(**z**)            # 激活函数
L = (a - y)²               # 损失（简化为单输出）
```

**形状**：
```
W: (m, n)   # m 个输出神经元，n 个输入
x: (n,)     # 输入向量
b: (m,)     # 偏置
z: (m,)     # 加权和
a: (m,)     # 激活输出
y: (m,)     # 真实标签
L: ()       # 标量损失
```

---

### 反向传播：求 ∂L/∂W

**目标**：计算损失 L 对权重 W 的梯度

**用链式法则**：
```
∂L/∂W = ∂L/∂**a** × ∂**a**/∂**z** × ∂**z**/∂W
```

---

#### Step 1: ∂L/∂**a**

```
L = (a - y)²

∂L/∂**a** = 2(**a** - **y**)  # 向量，形状 (m,)
```

---

#### Step 2: ∂**a**/∂**z**

```
**a** = σ(**z**)  （逐元素应用 sigmoid）

∂**a**/∂**z** = σ(**z**) ⊙ (1 - σ(**z**))
             = **a** ⊙ (1 - **a**)  # ⊙ 是逐元素乘法

# 形状：(m,)
```

**注意**：这里是**逐元素**的导数，不是矩阵导数

---

#### Step 3: ∂**z**/∂W

```
**z** = W**x** + **b**

zᵢ = Σⱼ Wᵢⱼxⱼ + bᵢ

∂zᵢ/∂Wᵢⱼ = xⱼ

所以：∂**z**/∂W 是一个... 呃，三维张量？
```

**问题**：直接求 ∂**z**/∂W 很麻烦！

---

### 🎯 更聪明的方法：分量法

**不求** ∂**z**/∂W，而是直接求 **∂L/∂Wᵢⱼ**

**链式法则**：
```
∂L/∂Wᵢⱼ = Σₖ (∂L/∂zₖ × ∂zₖ/∂Wᵢⱼ)
```

**但** `zₖ` 只依赖于 `Wₖ*`（第 k 行），所以：
```
∂L/∂Wᵢⱼ = ∂L/∂zᵢ × ∂zᵢ/∂Wᵢⱼ
        = ∂L/∂zᵢ × xⱼ
```

---

#### 定义：误差项 δ

```
δᵢ = ∂L/∂zᵢ = ∂L/∂aᵢ × ∂aᵢ/∂zᵢ
             = 2(aᵢ - yᵢ) × aᵢ(1 - aᵢ)

向量形式：**δ** = 2(**a** - **y**) ⊙ **a** ⊙ (1 - **a**)
```

---

#### 最终结果

```
∂L/∂Wᵢⱼ = δᵢ × xⱼ

矩阵形式：∂L/∂W = **δ** × **x**ᵀ
```

**形状验证**：
```
**δ**: (m,)
**x**ᵀ: (1, n)
**δ** × **x**ᵀ: (m, n) ✓ 和 W 同形状！
```

---

### 🔢 具体数值例子

**前向**：
```python
W = [[0.1, 0.2],      # 2×2 矩阵
     [0.3, 0.4]]

x = [1, 2]             # 输入
b = [0.1, 0.2]         # 偏置
y = [0, 1]             # 真实标签

# Step 1: z = Wx + b
z = [[0.1×1 + 0.2×2 + 0.1],    [[0.6],
     [0.3×1 + 0.4×2 + 0.2]]  =  [1.3]]

# Step 2: a = sigmoid(z)
a = [1/(1+e^-0.6), 1/(1+e^-1.3)]
  ≈ [0.646, 0.785]

# Step 3: L = (a-y)²
L = (0.646-0)² + (0.785-1)²
  ≈ 0.417 + 0.046 = 0.463
```

---

**反向**：
```python
# Step 1: ∂L/∂a = 2(a - y)
∂L/∂a = [2×(0.646-0), 2×(0.785-1)]
      = [1.292, -0.430]

# Step 2: ∂a/∂z = a ⊙ (1-a)
∂a/∂z = [0.646×(1-0.646), 0.785×(1-0.785)]
      = [0.229, 0.169]

# Step 3: δ = ∂L/∂a ⊙ ∂a/∂z
δ = [1.292×0.229, -0.430×0.169]
  = [0.296, -0.073]

# Step 4: ∂L/∂W = δ × xᵀ
∂L/∂W = [[0.296],    ×  [[1, 2]]
         [-0.073]]
       
       = [[0.296×1, 0.296×2],
          [-0.073×1, -0.073×2]]
       
       = [[0.296, 0.592],
          [-0.073, -0.146]]
```

**形状验证**：`(2, 2)` ✓

---

**权重更新**：
```python
lr = 0.1

W_new = W - lr × ∂L/∂W
      = [[0.1, 0.2],    [[0.0296, 0.0592],
         [0.3, 0.4]]  -  [-0.0073, -0.0146]]
      
      = [[0.0704, 0.1408],
         [0.3073, 0.4146]]
```

## 4️⃣ 常用矩阵求导公式

### 必备公式表

| 函数 | 导数 | 形状 |
|------|------|------|
| `**w**ᵀ**x**` | `**x**` | 同 **w** |
| `**x**ᵀ**x**` | `2**x**` | 同 **x** |
| `**w**ᵀA**w**` | `(A + Aᵀ)**w**` | 同 **w** |
| `W**x**`（对 W） | `**δ**×**x**ᵀ`（**δ**=上游梯度） | 同 W |
| `**a**ᵀ**b**`（对 **a**） | `**b**` | 同 **a** |

---

### 记忆技巧

**1. 线性函数**：`y = **w**ᵀ**x**`
```
∂y/∂**w** = **x**
# 记忆："对谁求导，结果就是另一个向量"
```

**2. 二次函数**：`y = **x**ᵀ**x**`
```
∂y/∂**x** = 2**x**
# 记忆：类似 x² 的导数是 2x
```

**3. 矩阵 - 向量乘法**：`**z** = W**x**`
```
∂L/∂W = **δ** × **x**ᵀ
# 记忆：误差 × 输入的转置
```

## 5️⃣ 为什么反向传播高效？

### 计算图视角

**前向计算图**：
```
x ──→ [W] ──→ z ──→ [σ] ──→ a ──→ [损失] ──→ L
```

**反向梯度流**：
```
x ←── [W] ←── z ←── [σ] ←── a ←── [损失] ←── L
     ↑
∂L/∂W
```

---

### 梯度计算规则

**每个节点**：
1. 接收"上游梯度"（从后面传来的 ∂L/∂输出）
2. 计算"局部梯度"（输出对输入的导数）
3. 相乘得到"下游梯度"（∂L/∂输入）

**公式**：
```
下游梯度 = 上游梯度 × 局部梯度
```

---

### 例子：线性层 `z = Wx + b`

**局部梯度**：
```
∂z/∂W = ?  （z 对 W 的导数）
∂z/∂x = ?  （z 对 x 的导数）
∂z/∂b = ?  （z 对 b 的导数）
```

**答案**：
```
∂z/∂W = **δ** × **x**ᵀ  （外积）
∂z/∂x = Wᵀ × **δ**      （矩阵×向量）
∂z/∂b = **δ**           （直接传递）
```

**其中** `**δ** = ∂L/∂z` 是上游梯度

---

## 6️⃣ 回到注意力机制

### Q/K/V 的梯度

**前向**：
```
Q = W_Q · x
K = W_K · x
V = W_V · x
score = Q · Kᵀ / √d
weight = softmax(score)
output = weight · V
```

**反向**（求 ∂L/∂W_Q）：

```
∂L/∂W_Q = ∂L/∂Q × ∂Q/∂W_Q
        = **δ**_Q × **x**ᵀ
```

**其中** `**δ**_Q = ∂L/∂Q` 是从后面传回来的梯度

---

### 完整反向传播链

```
L
↑
∂L/∂output
↑
∂L/∂weight = Vᵀ × ∂L/∂output
↑
∂L/∂score = weight ⊙ (∂L/∂weight - Σ(...))  （softmax 反向）
↑
∂L/∂Q = (∂L/∂score) × K / √d
↑
∂L/∂W_Q = ∂L/∂Q × xᵀ
```

## 📊 总结表

| 求导类型 | 函数 | 结果 | 结果形状 |
|----------|------|------|----------|
| 标量→标量 | y = x² | dy/dx = 2x | 标量 |
| 标量→向量 | y = **x**ᵀ**x** | ∂y/∂**x** = 2**x** | 向量 |
| 标量→矩阵 | L = f(W) | ∂L/∂W | 矩阵（同 W） |
| 向量→向量 | **y** = W**x** | ∂**y**/∂W | 三维张量* |

*注：实际中用分量法或链式法则避免直接计算

> 线性层反向，误差乘输入。

## 📝 练习题

**1. 向量求导**：
```
y = 3x₁ + 2x₂ - x₃

∂y/∂**x** = ?
```

**2. 二次型求导**：
```
y = **w**ᵀ**w** = w₁² + w₂² + ... + wₙ²

∂y/∂**w** = ?
```

**3. 线性层梯度**：
```
**z** = W**x**
L = ||**z** - **y**||²

∂L/∂W = ?
```

---

**答案**：
```
1. ∂y/∂**x** = [3, 2, -1]

2. ∂y/∂**w** = 2**w**

3. 令 **δ** = ∂L/∂**z** = 2(**z** - **y**)
   ∂L/∂W = **δ** × **x**ᵀ = 2(**z** - **y**) × **x**ᵀ
```
