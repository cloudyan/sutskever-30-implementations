## 🎯 核心问题

**为什么要拆这么散？**
**反向时怎么知道哪步到哪步？**

**答案**：**计算图（Computational Graph）**！

---

## 1️⃣ 什么是计算图？

### 定义

**计算图**：把计算过程画成图

- **节点**：变量或运算
- **边**：数据流向（依赖关系）

---

### 例子：简单神经网络

**计算公式**：
```
z = w·x + b
a = σ(z)
L = (a - y)²
```

**计算图**：
```
     w ──┐
         × ──→ + ──→ σ ──→ (·)² ──→ L
     x ──┘    ↑                ↑
              b                y
```

**更清晰的画法**（分层）：
```
输入层      隐藏层      输出层      损失

  w ─────────→ z ─────────→ a ─────────→ L
  x ────→ × ──→ + ────→ σ ────→ (·)²
  b ────────────→
                          y ────→
```

---

## 2️⃣ 前向传播：顺着箭头算

### 步骤

```
Step 1: 输入已知值
  x = 2, w = 3, b = 1, y = 7

Step 2: 计算 z
  z = w·x + b = 3×2 + 1 = 7

Step 3: 计算 a
  a = σ(z) = σ(7) ≈ 0.999

Step 4: 计算 L
  L = (a - y)² = (0.999 - 7)² ≈ 36
```

**计算图标注**：
```
     w=3 ──┐
           × ──→ z=7 ──→ σ ──→ a=0.999 ──→ (·)² ──→ L=36
     x=2 ──┘        ↑                        ↑
                    b=1                      y=7
```

---

## 3️⃣ 反向传播：逆着箭头传

### 核心思想

**从损失 L 开始，逆向计算每个变量的梯度**

**规则**：
> 每个节点接收"上游梯度"，乘以"局部梯度"，传给"下游"

---

### 局部梯度表

**每个运算的导数公式**（提前背好）：

| 运算 | 前向 | 局部梯度 |
|------|------|----------|
| **加法** | `z = x + y` | `∂z/∂x = 1`, `∂z/∂y = 1` |
| **乘法** | `z = x × y` | `∂z/∂x = y`, `∂z/∂y = x` |
| **幂次** | `z = x²` | `∂z/∂x = 2x` |
| **Sigmoid** | `z = σ(x)` | `∂z/∂x = z(1-z)` |
| **ReLU** | `z = max(0,x)` | `∂z/∂x = 1 if x>0 else 0` |

---

### 🔢 完整反向传播示例

**前向**（已知）：
```
x = 2, w = 3, b = 1, y = 7
z = 7, a = 0.999, L = 36
```

**反向**：

---

#### Step 1: L 对 a 的梯度

```
L = (a - y)²
∂L/∂a = 2(a - y) = 2(0.999 - 7) = -12.002

计算图标注：
  a ──→ (·)² ──→ L
        ↑
   ∂L/∂a = -12.002
```

---

#### Step 2: a 对 z 的梯度

```
a = σ(z)
∂a/∂z = a(1 - a) = 0.999 × (1 - 0.999) = 0.001

链式法则：
∂L/∂z = ∂L/∂a × ∂a/∂z
      = -12.002 × 0.001
      = -0.012
```

---

#### Step 3: z 对 w/b/x 的梯度

```
z = w·x + b

局部梯度：
∂z/∂w = x = 2
∂z/∂x = w = 3
∂z/∂b = 1

链式法则：
∂L/∂w = ∂L/∂z × ∂z/∂w = -0.012 × 2 = -0.024
∂L/∂x = ∂L/∂z × ∂z/∂x = -0.012 × 3 = -0.036
∂L/∂b = ∂L/∂z × ∂z/∂b = -0.012 × 1 = -0.012
```

---

### 📊 完整计算图（带梯度）

```
前向值（绿色） / 梯度（红色）

       w=3 ────────→ z=7 ────────→ a=0.999 ────────→ L=36
       │  ↘+3        │  ↗+1        │  ↗-12.0         │
       │    ×        │  σ          │  (·)²           │
       │  ↙×2        │             │                 │
       x=2 ──────────┘             │                 │
                                   │                 │
       b=1 ────────────────────────┘                 │
                                                     │
       y=7 ──────────────────────────────────────────┘

反向梯度流：
  ∂L/∂L = 1
  ↓
  ∂L/∂a = -12.0
  ↓
  ∂L/∂z = -0.012
  ↓
  ∂L/∂w = -0.024,  ∂L/∂x = -0.036,  ∂L/∂b = -0.012
```

## 4️⃣ 为什么反向传播高效？

### 对比：数值微分 vs 反向传播

**问题**：求 `∂L/∂w`, `∂L/∂b`, `∂L/∂x`

---

#### 方法 1：数值微分（暴力）

```python
# 原始前向
L0 = forward(w, b, x, y)  # 1 次

# 对 w 求导
L1 = forward(w+0.0001, b, x, y)  # 1 次
∂L/∂w = (L1 - L0) / 0.0001

# 对 b 求导
L2 = forward(w, b+0.0001, x, y)  # 1 次
∂L/∂b = (L2 - L0) / 0.0001

# 对 x 求导
L3 = forward(w, b, x+0.0001, y)  # 1 次
∂L/∂x = (L3 - L0) / 0.0001

# 总计：4 次前向传播
```

**参数越多越慢**：
- 3 个参数 → 4 次前向
- 100 万个参数 → 100 万零 1 次前向！

---

#### 方法 2：反向传播（聪明）

```python
# 1 次前向：计算并缓存所有中间值
z = w*x + b
a = σ(z)
L = (a - y)²
# 缓存：x, w, b, z, a

# 1 次反向：用链式法则一次算出所有梯度
∂L/∂a = 2(a - y)
∂L/∂z = ∂L/∂a × σ'(z)
∂L/∂w = ∂L/∂z × x
∂L/∂b = ∂L/∂z × 1
∂L/∂x = ∂L/∂z × w

# 总计：2 次（1 前 1 后）
```

**无论多少参数，都是 2 次**！

---

### 🎯 关键洞察

**反向传播为什么快？**

1. **缓存复用**：前向的中间结果（z, a）反向时直接用
2. **链式法则**：避免重复计算
3. **动态规划**：每个梯度只算一次

## 5️⃣ 注意力机制的计算图

### 前向计算图

```
Q = W_Q · x
K = W_K · x
V = W_V · x
score = Q · Kᵀ / √d
weight = softmax(score)
output = weight · V
L = loss(output, y)
```

**计算图**：
```
     W_Q ──→ × ──→ Q ──→ · ──→ score ──→ softmax ──→ weight ──→ × ──→ output ──→ loss ──→ L
     x ──→ ↑            ↑                                                    ↑
                    K ──┘                                                    │
     W_K ──→ × ──→ │                                                        │
     x ──→ ↑       │                                                        │
                                                                                 │
     W_V ──→ × ──→ V ────────────────────────────────────────────────────────────┘
     x ──→ ↑
```

---

### 反向传播链

**从 L 开始，逆向传递**：

```
∂L/∂L = 1
  ↓
∂L/∂output = ∂loss/∂output
  ↓
∂L/∂weight = Vᵀ × ∂L/∂output
∂L/∂V = weight × ∂L/∂output
  ↓
∂L/∂score = softmax_backward(weight, ∂L/∂weight)
  ↓
∂L/∂Q = (∂L/∂score) × K / √d
∂L/∂K = (∂L/∂score)ᵀ × Q / √d
  ↓
∂L/∂W_Q = ∂L/∂Q × xᵀ
∂L/∂W_K = ∂L/∂K × xᵀ
∂L/∂W_V = ∂L/∂V × xᵀ
```

---

### 关键节点的局部梯度

| 节点 | 前向 | 局部梯度 |
|------|------|----------|
| **矩阵×向量** | `Q = W_Q·x` | `∂L/∂W_Q = ∂L/∂Q × xᵀ` |
| **点积** | `s = Q·K` | `∂L/∂Q = ∂L/∂s × K`, `∂L/∂K = ∂L/∂s × Q` |
| **缩放** | `s = s/√d` | `∂L/∂s = ∂L/∂s / √d` |
| **Softmax** | `w = softmax(s)` | `∂L/∂s = w ⊙ (∂L/∂w - Σ(w×∂L/∂w))` |
| **矩阵×向量** | `o = w·V` | `∂L/∂w = Vᵀ×∂L/∂o`, `∂L/∂V = o×∂L/∂wᵀ` |

## 6️⃣ 实战：手把手走一遍

### 简化版注意力（单头、单 token）

**前向**：
```python
# 输入
x = [1, 2]              # 2 维
W_Q = [[0.5, 0.3],      # 2×2
       [0.2, 0.1]]
W_K = [[0.4, 0.2],
       [0.1, 0.3]]
W_V = [[1.0, 0.0],
       [0.0, 1.0]]
y = [0, 1]              # 真实标签

# Step 1: Q, K, V
Q = W_Q · x = [0.5×1+0.3×2, 0.2×1+0.1×2] = [1.1, 0.4]
K = W_K · x = [0.4×1+0.2×2, 0.1×1+0.3×2] = [0.8, 0.7]
V = W_V · x = [1.0×1+0.0×2, 0.0×1+1.0×2] = [1.0, 2.0]

# Step 2: score
score = Q · K / √2 = (1.1×0.8 + 0.4×0.7) / 1.41 = 1.16 / 1.41 = 0.82

# Step 3: weight (softmax)
weight = [0.695, 0.305]  # 假设有 2 个 key，简化计算

# Step 4: output
output = weight · V = 0.695×[1.0, 2.0] + 0.305×[V₂...]
# 简化：假设只有一个 key
output = 0.695 × [1.0, 2.0] = [0.695, 1.39]

# Step 5: loss (MSE)
L = ||output - y||² = (0.695-0)² + (1.39-1)² = 0.483 + 0.152 = 0.635
```

---

**反向**：

```python
# Step 1: ∂L/∂output
∂L/∂output = 2(output - y) = 2([0.695, 1.39] - [0, 1]) = [1.39, 0.78]

# Step 2: ∂L/∂weight
∂L/∂weight = Vᵀ × ∂L/∂output = [[1.0, 0.0], [0.0, 1.0]] × [1.39, 0.78] = [1.39, 0.78]

# Step 3: ∂L/∂score (softmax 反向)
# 简化：假设 ∂L/∂score ≈ ∂L/∂weight = [1.39, 0.78]

# Step 4: ∂L/∂Q
∂L/∂Q = ∂L/∂score × K / √2 = 1.39 × [0.8, 0.7] / 1.41 = [0.79, 0.69]

# Step 5: ∂L/∂W_Q
∂L/∂W_Q = ∂L/∂Q × xᵀ = [0.79, 0.69] × [1, 2] = [[0.79, 1.58], [0.69, 1.38]]
```

---

**更新权重**：
```python
lr = 0.01

W_Q_new = W_Q - lr × ∂L/∂W_Q
        = [[0.5, 0.3],    [[0.0079, 0.0158],
           [0.2, 0.1]]  -  [0.0069, 0.0138]]

        = [[0.4921, 0.2842],
           [0.1931, 0.0862]]
```

## 📊 总结：反向传播的套路

### 通用流程

```
1. 画计算图（明确依赖关系）
2. 前向传播（计算并缓存所有中间值）
3. 从损失开始，逆向计算：
   a. 查局部梯度表
   b. 乘以上游梯度
   c. 传给下游
4. 得到所有参数的梯度
5. 更新参数：W = W - lr × ∂L/∂W
```

---

### 局部梯度表（背诵！）

| 运算 | 前向 | ∂输出/∂输入 |
|------|------|-----------|
| 加法 | `z = x + y` | 1 |
| 乘法 | `z = x × y` | y 或 x |
| 线性 | `z = Wx` | Wᵀ 或 xᵀ |
| Sigmoid | `z = σ(x)` | z(1-z) |
| ReLU | `z = max(0,x)` | 1 if x>0 else 0 |
| Softmax | `z = softmax(x)` | z ⊙ (1 - z) |
| MSE | `L = (a-y)²` | 2(a-y) |

## 🧠 记忆口诀

> 计算图，画清楚，前向缓存中间值。
> 反向传，逆着走，上游乘局部梯度。
> 加为 1，乘为反，线性外积要记住。
> S 型，z 乘一减 z，softmax 略复杂。
> 链式法，逐段乘，一次前向一次反。

## 📝 练习题

**1. 画计算图**：
```
y = (wx + b - t)²
```

**2. 反向传播**：
```
前向：x=2, w=3, b=1, t=7
求：∂L/∂w, ∂L/∂b, ∂L/∂x
```

**3. 多变量链式法则**：
```
z = x + y
L = z²

∂L/∂x = ?
∂L/∂y = ?
```

---

**答案**：
```
1. 计算图：
   w ──→ × ──→ + ──→ (·)² ──→ L
   x ──→ ↑    ↑         ↑
         b    └──────── t

2.
   z = 3×2 + 1 - 7 = 0
   L = 0² = 0

   ∂L/∂z = 2z = 0
   ∂L/∂w = ∂L/∂z × x = 0 × 2 = 0
   ∂L/∂b = ∂L/∂z × 1 = 0
   ∂L/∂x = ∂L/∂z × w = 0 × 3 = 0

   （恰好在最优点，梯度都是 0）

3.
   ∂L/∂z = 2z
   ∂L/∂x = ∂L/∂z × ∂z/∂x = 2z × 1 = 2z
   ∂L/∂y = ∂L/∂z × ∂z/∂y = 2z × 1 = 2z
```
