## 1️⃣ 偏导数：多变量的"导数"

### 回顾：单变量导数

**函数**：`y = f(x) = x²`

**导数**：`dy/dx = 2x`

**含义**：
> x 增加一点点，y 会增加多少？

**例子**：
```
x = 3 时，dy/dx = 6
# 意思：x 增加 0.1，y 大约增加 0.6
```

---

### 偏导数：多变量函数

**函数**：`z = f(x, y) = x² + xy + y²`

现在有两个自变量 x 和 y，怎么求导？

**方法**：**每次只对一个变量求导，其他变量视为常数**

---

#### 对 x 求偏导

```
z = x² + xy + y²

∂z/∂x = 2x + y + 0
      = 2x + y

# 解释：
# - x² 对 x 求导 = 2x
# - xy 对 x 求导 = y（y 视为常数）
# - y² 对 x 求导 = 0（y 是常数，y² 也是常数）
```

---

#### 对 y 求偏导

```
z = x² + xy + y²

∂z/∂y = 0 + x + 2y
      = x + 2y

# 解释：
# - x² 对 y 求导 = 0（x 是常数）
# - xy 对 y 求导 = x（x 视为常数）
# - y² 对 y 求导 = 2y
```

---

### 📐 几何意义

**单变量导数**：
```
y = f(x) 是一条曲线
dy/dx = 曲线在某点的切线斜率
```

**多变量偏导数**：
```
z = f(x, y) 是一个曲面

∂z/∂x = 固定 y，沿 x 方向的切线斜率
∂z/∂y = 固定 x，沿 y 方向的切线斜率
```

**可视化**：
```
        z
        ↑
       /|\
      / | \
     /  |  \    ← 曲面
    /   |   \
   /____|____\___ y
  /     |     /
 /      |    /
x       |

∂z/∂x：沿 x 方向切一刀，看切线斜率
∂z/∂y：沿 y 方向切一刀，看切线斜率
```

---

### 🔢 计算练习

**例题 1**：
```
f(x, y) = 3x²y + 2xy²

∂f/∂x = ?
∂f/∂y = ?
```

**答案**：
```
∂f/∂x = 6xy + 2y²  （y 视为常数）
∂f/∂y = 3x² + 4xy  （x 视为常数）
```

---

**例题 2**（神经网络相关）：
```
L = (w·x + b - y)²

∂L/∂w = ?
∂L/∂b = ?
```

**答案**（用链式法则）：
```
令 z = w·x + b - y，则 L = z²

∂L/∂w = ∂L/∂z × ∂z/∂w
      = 2z × x
      = 2(w·x + b - y) × x

∂L/∂b = ∂L/∂z × ∂z/∂b
      = 2z × 1
      = 2(w·x + b - y)
```

## 2️⃣ 链式法则：复合函数求导

### 单变量链式法则

**函数**：
```
y = f(x) = x²
z = g(y) = sin(y)

复合：z = g(f(x)) = sin(x²)
```

**求导**：
```
dz/dx = dz/dy × dy/dx
      = cos(y) × 2x
      = cos(x²) × 2x
```

---

### 多变量链式法则

**函数**：
```
z = f(x, y) = x² + y²
x = g(t) = t²
y = h(t) = t³

复合：z = f(g(t), h(t)) = (t²)² + (t³)² = t⁴ + t⁶
```

**求导**（两种方法）：

**方法 1：直接求导**
```
dz/dt = 4t³ + 6t⁵
```

**方法 2：链式法则**
```
dz/dt = ∂z/∂x × dx/dt + ∂z/∂y × dy/dt
      = (2x) × (2t) + (2y) × (3t²)
      = 2(t²) × 2t + 2(t³) × 3t²
      = 4t³ + 6t⁵  ✓
```

---

### 🎯 神经网络中的链式法则

**网络结构**：
```
x → [×w] → z → [sigmoid] → a → [损失] → L
```

**具体函数**：
```
z = w·x
a = σ(z) = 1/(1 + e^(-z))
L = (a - y)²
```

**求 ∂L/∂w**：

```
∂L/∂w = ∂L/∂a × ∂a/∂z × ∂z/∂w

Step 1: ∂L/∂a = 2(a - y)
Step 2: ∂a/∂z = σ(z) × (1 - σ(z)) = a(1-a)  （sigmoid 导数）
Step 3: ∂z/∂w = x

结果：∂L/∂w = 2(a - y) × a(1-a) × x
```

## 3️⃣ 梯度：偏导数的向量形式

### 梯度定义

**函数**：`f(x₁, x₂, ..., xₙ)`

**梯度**：把所有偏导数打包成一个向量
```
∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

**读作**："del f" 或 "gradient f"

---

### 梯度的几何意义

**关键性质**：
> 梯度方向是函数**增长最快**的方向

**类比**：
```
想象你站在一座山上（函数 f 是海拔）

梯度 ∇f 指向：
- 方向：最陡的上坡方向
- 大小：陡峭程度

负梯度 -∇f 指向：
- 方向：最陡的下坡方向
```

---

### 梯度下降法

**目标**：最小化函数 f(x)

**算法**：
```python
# 初始化
x = 随机值

# 迭代更新
while 未收敛:
    grad = ∇f(x)  # 计算梯度
    x = x - lr × grad  # 往坡下走

# 最终 x 会到达局部最小值
```

**为什么有效？**
- 梯度指向坡上
- 负梯度指向坡下
- 每次走一小步，最终到谷底

---

### 🔢 例子：梯度下降

**函数**：`f(x) = x²`（简单抛物线）

**梯度**：`∇f = df/dx = 2x` 山坡的陡峭程度和方向（指向上坡）

**更新**：`x_new = x - lr × 2x`

**迭代过程**（lr = 0.1，初始 x = 5）：
```
迭代 0: x = 5,    grad = 10,   x_new = 5 - 0.1×10 = 4
迭代 1: x = 4,    grad = 8,    x_new = 4 - 0.1×8  = 3.2
迭代 2: x = 3.2,  grad = 6.4,  x_new = 3.2 - 0.1×6.4 = 2.56
迭代 3: x = 2.56, grad = 5.12, x_new = 2.56 - 0.1×5.12 = 2.048
...
迭代∞: x → 0（最小值点）
```

> 梯度下降法用局部信息（梯度）做局部改进，重复多次后，局部改进累积成全局最优。

- 是调学习率 lr 的重要性：太小→慢；太大→震荡/发散。

## 4️⃣ 回到神经网络：为什么 `w_new = w - lr × ∂L/∂w`？

### 问题重述

**损失函数**：`L = f(w, b, x, y)`

**目标**：找到 w 和 b，使得 L 最小

**方法**：梯度下降

---

### 推导过程

**1. 计算梯度**：
```
∂L/∂w = ?  （w 增加一点点，L 增加多少）
```

**2. 判断方向**：
```
如果 ∂L/∂w > 0：
  - w 增加 → L 增加
  - w 减小 → L 减小
  → 应该减小 w

如果 ∂L/∂w < 0：
  - w 增加 → L 减小
  - w 减小 → L 增加
  → 应该增大 w
```

**3. 更新公式**：
```
w_new = w - lr × ∂L/∂w

# 验证：
# ∂L/∂w > 0 时：w_new = w - 正数 → w 减小 ✓
# ∂L/∂w < 0 时：w_new = w - 负数 → w 增大 ✓
```

---

### 🎯 学习率 lr 的作用

**公式**：`w_new = w - lr × ∂L/∂w`

**lr 控制步长**：

```
lr = 0.001（太小）：
  w_new = w - 0.001 × ∂L/∂w
  # 每次只挪一点点，要走很久

lr = 0.1（适中）：
  w_new = w - 0.1 × ∂L/∂w
  # 稳步前进

lr = 1.0（太大）：
  w_new = w - 1.0 × ∂L/∂w
  # 可能一步跨过谷底，到对面山上
```

**可视化**：
```
        L
        ↑
       ╱│╲
      ╱ │ ╲
     ╱  │  ╲
    ╱   │   ╲
   ╱    │    ╲
  ╱     │     ╲
 ───────┴───────→ w
        │
        最小值点

lr 太小：·········（走很久）
lr 适中：→ → → →（稳步）
lr 太大：→→→→→→→（冲过头）
```

## 📊 总结表

| 概念 | 符号 | 含义 | 几何意义 |
|------|------|------|----------|
| **导数** | dy/dx | x 变化时 y 的变化率 | 切线斜率 |
| **偏导数** | ∂f/∂x | 多变量中，x 变化时 f 的变化率 | 沿 x 方向的切线斜率 |
| **梯度** | ∇f | 所有偏导数组成的向量 | 最陡上坡方向 |
| **链式法则** | dz/dx = dz/dy × dy/dx | 复合函数求导 | 逐段相乘 |
| **梯度下降** | w = w - lr × ∇L | 最小化函数 | 往坡下走 |

## ⚠️ 常见误区与易错点

### 误区 1：偏导数 vs 全微分

```
❌ 错误理解：∂z/∂x 就是 dz/dx
✅ 正确理解：
   - ∂z/∂x：固定 y，只看 x 变化的影响（偏导数）
   - dz/dx：如果 x 变化导致 y 也变化，需要考虑总影响（全导数）

例子：
z = x² + y²，且 y = x²

∂z/∂x = 2x                    （y 视为常数）
dz/dx = ∂z/∂x + ∂z/∂y × dy/dx  （考虑 y 随 x 变化）
      = 2x + 2y × 2x
      = 2x + 4x³
```

---

### 误区 2：链式法则漏项

```
❌ 错误：dz/dt = ∂z/∂x × dx/dt   （漏了 y 的贡献）
✅ 正确：dz/dt = ∂z/∂x × dx/dt + ∂z/∂y × dy/dt

记忆技巧：有几个中间变量，就加几项！
```

---

### 误区 3：梯度方向理解反了

```
❌ 错误：梯度指向函数减小的方向
✅ 正确：梯度指向函数【增长最快】的方向
       负梯度才指向减小方向（所以梯度下降用 -∇f）

类比：
- 梯度 ∇f = 最陡的上坡方向
- 负梯度 -∇f = 最陡的下坡方向
- 梯度下降 = 沿着下坡方向走
```

---

### 误区 4：学习率调参困惑

```
❌ 错误：学习率越大收敛越快
✅ 正确：
   - 学习率太小 → 收敛慢，可能陷入局部最优
   - 学习率适中 → 稳定收敛
   - 学习率太大 → 震荡不收敛，甚至发散

调参策略：
1. 先用较大学习率（如 0.1）快速接近
2. 逐渐减小学习率（学习率衰减）
3. 使用自适应优化器（Adam、RMSprop）自动调整
```

## 🔗 从数学到代码：PyTorch 中的对应

| 数学概念 | PyTorch 代码 | 含义 |
|----------|--------------|------|
| ∂L/∂w | `loss.backward()` | 自动计算所有梯度 |
| 梯度向量 ∇L | `w.grad` | 存储计算好的梯度 |
| 参数更新 | `w -= lr * w.grad` | 梯度下降步骤 |
| 清零梯度 | `optimizer.zero_grad()` | 防止梯度累加 |

```python
# 一个完整的训练步骤
import torch

# 假设：单神经元，输入 x=2，目标输出 y=1
x = torch.tensor(2.0, requires_grad=False)
y_true = torch.tensor(1.0)
w = torch.tensor(0.5, requires_grad=True)  # 权重
b = torch.tensor(0.0, requires_grad=True)  # 偏置
lr = 0.1

# 前向传播：计算预测
z = w * x + b        # 线性变换
a = torch.sigmoid(z) # 激活函数
loss = (a - y_true) ** 2  # 损失函数 L

print(f"前向：z={z.item():.4f}, a={a.item():.4f}, L={loss.item():.4f}")

# 反向传播：自动计算 ∂L/∂w 和 ∂L/∂b
loss.backward()

print(f"梯度：∂L/∂w={w.grad.item():.4f}, ∂L/∂b={b.grad.item():.4f}")

# 手动验证（对应文档中的公式）
# ∂L/∂w = 2(a-y) × a(1-a) × x
manual_grad_w = 2 * (a.item() - 1.0) * a.item() * (1 - a.item()) * x.item()
print(f"手动验证：∂L/∂w={manual_grad_w:.4f}")

# 参数更新：w = w - lr × ∂L/∂w
with torch.no_grad():
    w -= lr * w.grad
    b -= lr * b.grad

print(f"更新后：w={w.item():.4f}, b={b.item():.4f}")
```

**输出示例**：
```
前向：z=1.0000, a=0.7311, L=0.5343
梯度：∂L/∂w=0.7862, ∂L/∂b=0.3931
手动验证：∂L/∂w=0.7862
更新后：w=0.4214, b=-0.0393
```

## 🎓 进阶：二阶偏导数（Hessian 矩阵基础）

对于 f(x, y)，可以求二阶偏导：

```
∂²f/∂x²      # 对 x 求两次偏导（沿 x 方向的曲率）
∂²f/∂y²      # 对 y 求两次偏导（沿 y 方向的曲率）
∂²f/∂x∂y     # 先对 y 求偏导，再对 x 求偏导（混合偏导）
```

**Schwarz 定理**：如果 f 连续可微，混合偏导与求导顺序无关
```
∂²f/∂x∂y = ∂²f/∂y∂x
```

**Hessian 矩阵**：把所有二阶偏导打包成矩阵
```
H = [ ∂²f/∂x²    ∂²f/∂x∂y ]
    [ ∂²f/∂y∂x   ∂²f/∂y²  ]

性质：H 是对称矩阵（因为混合偏导相等）
```

**几何意义**：
- 一阶导数（梯度）→ 斜率，告诉你往哪走
- 二阶导数（Hessian）→ 曲率，告诉你走多快

**在优化中的应用**：
```
梯度下降：    x_new = x - lr × ∇f          （只用一阶信息）
牛顿法：      x_new = x - H^(-1) × ∇f      （用二阶信息，更快收敛）

💡 深度学习通常只用一阶（梯度），因为：
   - Hessian 计算成本太高（参数可能百万级）
   - 随机梯度下降 + 动量已经够用了
```

## 🎯 附录：导数的深层理解

### 偏导数与导数的关系

#### 核心关系

```
单变量导数  →  多变量偏导数
    ↓               ↓
y = f(x)      z = f(x, y)
    ↓               ↓
dy/dx         ∂z/∂x, ∂z/∂y
```

**本质相同**：都是"变化率"
**区别**：偏导数每次只变一个变量，其他固定

---

#### 对比表

| 维度 | 单变量导数 | 多变量偏导数 |
|------|------------|--------------|
| **函数** | y = f(x) | z = f(x, y, ...) |
| **变量数** | 1个自变量 | 多个自变量 |
| **求导方式** | 直接求导 | 固定其他变量，对一个变量求导 |
| **结果** | 一个数值 | 多个偏导数（每个变量一个） |
| **几何意义** | 切线斜率 | 沿某坐标轴方向的切线斜率 |
| **符号** | dy/dx | ∂z/∂x（用 ∂ 代替 d） |

---

#### 为什么用不同的符号？

```
d → 表示"全变化"（total derivative）
∂ → 表示"偏变化"（partial derivative）

dy/dx：y 随 x 的总变化（x 是唯一变量）
∂z/∂x：z 随 x 的偏变化（只考虑 x 的变化，y 固定）
```

---

#### 符号读音

| 符号 | 名称 | 英语读法 | 中文读法 |
|------|------|----------|----------|
| **d** | 微分符号 | "d" / "dee" | "d" |
| **∂** | 偏微分符号 | "partial" / "del" / "curly d" | **"偏"** / "round d" |

**常见读法示例**：
```
∂z/∂x 读作：
- 英语："partial z over partial x" 或 "del z del x"
- 中文："偏 z 偏 x"

∂L/∂w 读作：
- 英语："partial L partial w"
- 中文："偏 L 偏 w"
```

**记忆技巧**：
```
d 是直的 → 全导数（total derivative）
∂ 是弯的 → 偏导数（partial derivative）

"弯" → "偏" → 只考虑部分变化
```

---

#### 统一到梯度

```
单变量：dy/dx 就是一个数值

多变量：把所有偏导数打包成向量
       ∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]

       这个向量就是"梯度"
```

**关键理解**：
> 偏导数是导数在多维空间的"分量形式"，梯度是它们的向量组合。

---

#### 一句话总结

```
导数（单变量）：一条路，一个斜率
偏导数（多变量）：多方向，每个方向一个斜率
梯度：把所有方向的斜率打包成向量
```

---

### 导数的本质：多维度视角

#### 1️⃣ 核心定义：变化率

> **导数 = 瞬时变化率 = "此刻的变化速度"**

```
平均变化率：Δy/Δx = (y₂-y₁)/(x₂-x₁)  →  一段时间内的平均速度
瞬时变化率：dy/dx = lim(Δx→0) Δy/Δx  →  某一时刻的瞬时速度
```

**类比**：
- 汽车仪表盘上的 **速度表** 显示的就是瞬时速度（导数）
- 导航显示的 **平均速度** = 总路程/总时间

---

#### 2️⃣ 几何意义：切线斜率

```
        y
        ↑
       /|
      / |
     /  |    ← 曲线 y = f(x)
    /   |
   /____|________
  /  ↑  |       → x
     |
   切线斜率 = dy/dx
```

**关键洞察**：
- 导数是曲线在某点的"倾斜程度"
- 导数为正 → 函数在增长 ↗
- 导数为负 → 函数在减少 ↘
- 导数为零 → 可能是极值点（山顶或谷底）→

---

#### 3️⃣ 物理意义：各种"率"

| 物理量 | 数学表达 | 含义 |
|--------|----------|------|
| **速度** | v = dx/dt | 位置对时间的变化率 |
| **加速度** | a = dv/dt | 速度对时间的变化率 |
| **力** | F = dp/dt | 动量对时间的变化率（牛顿第二定律） |
| **电流** | I = dQ/dt | 电荷对时间的变化率 |
| **功率** | P = dW/dt | 功对时间的变化率 |

> 💡 **统一规律**：物理学中，"XX率"往往就是导数！

---

#### 4️⃣ 神经网络中的本质：敏感度

```
∂L/∂w = 损失对权重的敏感度
       = w 变化一点点，L 会变化多少
```

**意义**：
- 导数大 → 权重对损失影响大（需要重点调整）
- 导数小 → 权重对损失影响小（已经比较好了）
- 导数为 0 → 可能陷入局部最优或鞍点

---

#### 5️⃣ 哲学意义：局部与整体

```
导数的本质：用【局部线性】逼近【非线性】

        曲线（非线性）
           ↓
    在某点取切线（线性）
           ↓
    切线斜率 = 导数
```

**核心思想**：
> 再复杂的非线性函数，在足够小的范围内，都可以近似为直线。

这就是微积分的威力：**把复杂问题分解为无穷多个简单问题**。

### 导数与微分的关系

#### 概念辨析

| 概念 | 符号 | 本质 | 直观理解 |
|------|------|------|----------|
| **导数** | dy/dx 或 f'(x) | 一个数值（变化率） | 切线斜率 |
| **微分** | dy 或 df | 一个线性函数 | 变化量的线性近似 |

#### 数学关系

```
导数：dy/dx = f'(x)           ← 比值，表示变化率

微分：dy = f'(x) · dx         ← 线性近似，表示变化量

关系：微分 = 导数 × 自变量的微小变化
```

#### 几何解释

```
        y
        ↑
       /|
      / |  ___← 切线（线性近似）
     /  | /  |
    /   |/   | Δy（真实变化）
   /____|____|________
  /     |↑   |      → x
       /|dy  |
      / |    |
     dx  Δx

Δy = f(x+Δx) - f(x)    ← 真实变化（曲线上）
dy = f'(x) · dx        ← 线性近似（切线上）

当 Δx → 0 时：Δy ≈ dy
```

#### 在机器学习中的应用

```
梯度下降更新：w_new = w - lr × ∂L/∂w

理解方式：
- 导数视角：沿着负梯度方向走 lr 步
- 微分视角：让损失函数的微分 dL = (∂L/∂w)·dw 尽可能减小

本质相同，只是表述角度不同！
```

### 为什么导数能找极值？

#### 极值的必要条件

**费马定理**：如果 f(x) 在 x₀ 处可导且取得极值，则 f'(x₀) = 0

```
直观理解：

最大值点：     最小值点：
    ╱╲              ╲╱
   ╱  ╲            ╱  ╲
  ╱    ╲          ╱    ╲
        ↑              ↑
      导数=0          导数=0

在山顶/谷底，切线是水平的（斜率为0）
```

#### 判断极值类型

```
用二阶导数判断：

f'(x₀) = 0 且 f''(x₀) > 0  →  极小值（谷底，向上凸）
f'(x₀) = 0 且 f''(x₀) < 0  →  极大值（山顶，向下凸）
f'(x₀) = 0 且 f''(x₀) = 0  →  可能是拐点，需进一步判断
```

```
        ↓ 极大值              ↑ 极小值
       ╱╲                    ╲╱
      ╱  ╲                  ╱  ╲
     ╱    ╲                ╱    ╲
    ╱      ╲              ╱      ╲
   ╱   向下凸             ╱   向上凸
  f''(x) < 0            f''(x) > 0
```

#### 多维推广

```
对于 f(x₁, x₂, ..., xₙ)：

极值必要条件：∇f = 0（所有偏导数为0）

几何意义：在极值点，所有方向的切线都是水平的
         （就像站在山顶，往任何方向走都是下坡）
```

### 导数在优化算法中的更深层作用

#### 1️⃣ 一阶优化：梯度下降家族

```
核心思想：f(x_new) ≈ f(x) + ∇f · (x_new - x)

要让 f 减小，需要 ∇f · Δx < 0

最优选择：Δx = -∇f（负梯度方向）
         因为 ∇f · (-∇f) = -||∇f||² < 0

这就是梯度下降的数学基础！
```

**各种变体**：

| 算法 | 更新公式 | 特点 |
|------|----------|------|
| **SGD** | x = x - lr·∇f | 最基础，可能震荡 |
| **Momentum** | v = βv + ∇f<br>x = x - lr·v | 积累动量，加速收敛 |
| **AdaGrad** | 自适应学习率 | 对稀疏梯度友好 |
| **Adam** | Momentum + RMSprop | 最常用，自适应+动量 |

---

#### 2️⃣ 二阶优化：牛顿法

```
泰勒展开到二阶：
f(x+Δx) ≈ f(x) + ∇f·Δx + ½ Δxᵀ·H·Δx

令导数为0求最优 Δx：
∇f + H·Δx = 0
→ Δx = -H^(-1)·∇f

牛顿法更新：x_new = x - H^(-1)·∇f
```

**对比**：

```
梯度下降：x_new = x - lr·∇f
         ↓
         只考虑"往哪走"（方向）

牛顿法：  x_new = x - H^(-1)·∇f
         ↓
         同时考虑"往哪走"和"走多远"（方向+步长）

H^(-1) 自动调整步长：
- 曲率大（H大）→ 步长小（小心走）
- 曲率小（H小）→ 步长大（放心走）
```

**为什么深度学习不用牛顿法？**
```
1. 计算成本：Hessian 矩阵是 n×n，n 可能百万级
2. 存储成本：需要存储巨大的矩阵
3. 求逆困难：H^(-1) 计算复杂度 O(n³)

折中方案：
- L-BFGS：近似 Hessian，内存友好
- 自然梯度：利用概率分布的几何结构
```

---

#### 3️⃣ 更高阶的作用

**曲率信息**：
```
一阶导数（梯度）：告诉你"往哪走"
二阶导数（Hessian）：告诉你"路有多弯"

在损失函数中：
- 曲率大 = 峡谷地形 → 需要小步长，小心走
- 曲率小 = 平原地形 → 可以大步走
```

**条件数**：
```
条件数 = λ_max / λ_min  （Hessian 最大/最小特征值之比）

条件数大 → 地形狭长（一个方向很陡，一个方向很平）
         → 梯度下降收敛慢，呈锯齿形
         → 需要预处理或自适应方法

条件数小 → 地形圆润 → 梯度下降收敛快
```
