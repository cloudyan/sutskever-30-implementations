## 【一句话核心】

向量是 AI 表示一切的基本单位，点积是衡量向量相似性的核心运算。

---

## 【核心定义】

### 1. 向量 (Vector)

**定义**：既有大小又有方向的量

**表示方式**：
- 几何：箭头（长度 = 大小，方向 = 方向）
- 代数：有序数组 `v = [v₁, v₂, ..., vₙ]`
- AI 中：词向量、图像特征、用户偏好...

**示例**：
```python
# 词向量示例（简化为 3 维）
"国王" = [0.8, 0.6, 0.2]
"王后" = [0.7, 0.8, 0.1]
"苹果" = [0.1, 0.2, 0.9]
```

---

### 2. 点积 (Dot Product)

**代数定义**：
```
a · b = a₁b₁ + a₂b₂ + ... + aₙbₙ
```

**几何定义**：
```
a · b = |a| × |b| × cos(θ)
```

**其中**：
- `|a|` = 向量 a 的长度（模长）
- `θ` = 两向量之间的夹角

---

## 【几何直观】

### 点积的三种情况

```
        θ < 90°                    θ = 90°                    θ > 90°
        a →↗                       a →                        a ↖
           /                        |                          \
          /                         | b →                       \
         b →                        |                            \ b →
                                    |
    点积 > 0                    点积 = 0                    点积 < 0
    （方向相似）                （正交/垂直）                （方向相反）
```

### 为什么点积本身"无意义"？

**问题**：点积的值依赖于向量长度

**例子**：
```python
a = [1, 2, 3]
b = [1, 2, 3]
a · b = 14

# 把向量拉长 100 倍
a_scaled = [100, 200, 300]
b_scaled = [100, 200, 300]
a_scaled · b_scaled = 140000  # ← 点积变大，但方向没变！
```

**结论**：点积的绝对值不能直接比较相似性，需要归一化。

---

## 【关键推导：从点积到余弦相似度】

### 问题：如何消除长度影响？

从几何定义出发：
```
a · b = |a| × |b| × cos(θ)
```

移项得到：
```
cos(θ) = (a · b) / (|a| × |b|)
```

**这就是余弦相似度公式！**

---

### 为什么余弦相似度更好？

| 指标 | 公式 | 受长度影响 | 值域 | 可解释性 |
|------|------|-----------|------|----------|
| **点积** | `a·b` | ✅ 是 | (-∞, +∞) | ❌ 差 |
| **余弦相似度** | `(a·b)/(|a||b|)` | ❌ 否 | [-1, 1] | ✅ 好 |

**余弦相似度的值域解释**：
- `1` → 方向完全相同
- `0` → 正交（无关）
- `-1` → 方向完全相反

---

### 🔢 计算示例

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([2, 4, 6])  # a 的 2 倍，方向相同

# 点积
dot_product = np.dot(a, b)  # 28

# 模长
norm_a = np.linalg.norm(a)  # √14 ≈ 3.74
norm_b = np.linalg.norm(b)  # √56 ≈ 7.48

# 余弦相似度
cos_sim = dot_product / (norm_a * norm_b)  # 28 / 28 = 1.0 ✅
```

## 【AI 中的应用】

### 1️⃣ 神经网络：加权求和

**单个神经元**：
```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

**向量形式**：
```
z = w · x + b
```

**生物学解释**：
```
        输入 x₁ ────× w₁ ──┐
        输入 x₂ ────× w₂ ──┼── Σ ──> 激活函数 ──> 输出
        输入 x₃ ────× w₃ ──┤
                          │
        偏置 b ───────────┘
```

**为什么这样设计？**
1. 线性组合是最基础的函数形式
2. 可微分 → 可用梯度下降优化
3. 参数高效 → n 个输入只需 n+1 个参数

**偏置 b 的作用**：
- 没有 b：决策边界必须过原点
- 有 b：决策边界可任意平移，拟合能力更强

---

### 2️⃣ 注意力机制 (Attention)

**核心公式**：
```
Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V
```

**计算步骤**：

```
Step 1: 计算注意力分数
        分数 = Q · Kᵀ  （点积衡量匹配度）

Step 2: 缩放
        分数 / √dₖ  （防止高维点积过大）

Step 3: Softmax 归一化
        权重 = softmax(分数)  （变成概率分布）

Step 4: 加权求和
        输出 = Σ(权重 × V)
```

---

### 🎯 注意力权重是如何学习的？

**关键**：权重不是设定的，是模型从数据中学到的！

**训练过程**：
```python
# 1. 初始化可学习的权重矩阵
W_Q, W_K, W_V  # 随机初始化

# 2. 计算 Q, K, V
Q = W_Q · x
K = W_K · x
V = W_V · x

# 3. 前向传播：计算注意力输出
输出 = softmax(Q·Kᵀ/√d) · V

# 4. 计算损失
loss = 损失函数 (预测，真实标签)

# 5. 反向传播：调整 W_Q, W_K, W_V
W_Q = W_Q - lr × ∂loss/∂W_Q
W_K = W_K - lr × ∂loss/∂W_K
W_V = W_V - lr × ∂loss/∂W_V

# 6. 重复亿万次 → 模型学会合理的注意力权重
```

### 📊 注意力示例

**句子**："我 爱 AI"

**处理"我"时的注意力**：
```python
# "我" 的 Query
Q_我 = [0.5, 0.3, -0.2, ...]

# 所有词的 Key
K_我 = [0.4, 0.2, -0.1, ...]
K_爱 = [0.6, 0.4, -0.3, ...]  # ← 和 Q_我 最匹配！
K_AI = [0.1, -0.5, 0.8, ...]

# 注意力分数（点积）
分数_我 = 0.35
分数_爱 = 0.52  # ← 最高
分数_AI = -0.18

# Softmax 归一化
权重 = [0.30, 0.45, 0.25]  # "爱"的权重最高
```

**为什么"爱"权重最高？**
- 训练数据中，"我"后面常跟"爱"、"喜欢"等动词
- 模型通过反向传播学到：关注"爱"能帮助预测
- `W_Q` 和 `W_K` 被调整，使得 `Q_我 · K_爱` 变大

## 【延伸思考】

### ❓ 为什么不用欧氏距离而用余弦相似度？

**欧氏距离**：
```
distance = √[(a₁-b₁)² + (a₂-b₂)² + ...]
```

**问题**：
- 受向量长度影响大
- 高维空间中"距离膨胀"（维度灾难）

**余弦相似度优势**：
- 只看方向，不受长度影响
- 高维空间更稳定
- 值域固定 [-1, 1]，可解释性强

---

### ❓ 为什么注意力要用 Q/K/V 三个向量？

**解耦三个功能**：
- **Query**：我想找什么？（主动查询）
- **Key**：我有什么特征？（被匹配的特征）
- **Value**：我的实际内容是什么？（传递的信息）

**好处**：
- 让模型能学习不同的表示空间
- 增强表达能力（三个独立权重矩阵）

---

### ❓ 偏置 b 能不能不要？

**理论上**：可以，但...

**实际问题**：
- 决策边界强制过原点，拟合能力受限
- 优化更困难，收敛更慢

**现代架构**：
- Transformer 用 LayerNorm 部分替代偏置
- 但大多数网络仍保留偏置

## 【代码实战】

### 1. 计算余弦相似度

```python
import numpy as np

def cosine_similarity(a, b):
    """计算两个向量的余弦相似度"""
    dot_product = np.dot(a, b)
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    return dot_product / (norm_a * norm_b)

# 测试
a = np.array([1, 2, 3])
b = np.array([2, 4, 6])
print(cosine_similarity(a, b))  # 输出：1.0
```

---

### 2. 实现简单的注意力

```python
def simple_attention(Q, K, V):
    """简化版注意力机制"""
    # 计算注意力分数
    scores = np.dot(Q, K.T)
    
    # Softmax 归一化
    exp_scores = np.exp(scores - np.max(scores))
    weights = exp_scores / np.sum(exp_scores)
    
    # 加权求和
    output = np.dot(weights, V)
    return output, weights

# 测试
Q = np.array([[0.5, 0.3, -0.2]])  # 1 个查询
K = np.array([[0.4, 0.2, -0.1],   # 3 个键
              [0.6, 0.4, -0.3],
              [0.1, -0.5, 0.8]])
V = np.array([[1.0, 0.0],         # 3 个值
              [0.0, 1.0],
              [0.5, 0.5]])

output, weights = simple_attention(Q, K, V)
print(f"注意力权重：{weights}")
print(f"输出：{output}")
```
