## 🎯 核心问题

### 论文要解决什么问题？

**背景**：2017 年之前，序列建模（机器翻译、文本生成等）的主流架构是：

1. **RNN/LSTM/GRU** - 按时间步顺序处理，无法并行
2. **Attention 机制** - 作为 RNN 的辅助组件，增强长程依赖

**核心痛点**：

| 问题 | RNN/LSTM | 影响 |
|------|----------|------|
| **顺序计算** | 必须按时间步依次处理 | 无法充分利用 GPU 并行 |
| **长程依赖** | 即使有 LSTM/GRU，长序列仍有信息损失 | 翻译长句子效果差 |
| **路径长度** | O(n) - 相距 n 的词需要 n 步传递 | 梯度消失/爆炸 |

**论文目标**：
> 提出一个**完全基于注意力机制**的新架构，**不再需要 RNN 或 CNN**，实现：
> - 高度并行化训练
> - 更短的路径长度学习长程依赖
> - 在机器翻译任务上达到 SOTA

## 🔑 核心创新 1：Self-Attention（自注意力机制）

### 核心思想

每个位置的词都可以**直接关注序列中任意其他位置**，无论距离多远。

### Scaled Dot-Product Attention

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

**三个关键矩阵**：
- **Q (Query)**: 当前词"查询"什么
- **K (Key)**: 每个词被"匹配"的特征
- **V (Value)**: 每个词的实际"内容"

**计算步骤**：
```
1. Q × K^T  →  计算注意力分数（相似度）
2. ÷ √d_k   →  缩放，防止梯度消失
3. Softmax  →  归一化为概率分布
4. × V      →  加权求和，得到输出
```

### 为什么需要缩放 (÷ √d_k)？

当 d_k 较大时，点积结果会很大，导致 softmax 进入饱和区（梯度接近 0）：

```python
# 示例：d_k = 64
Q = [0.5, -0.3, 0.8, ...]  # 64 维
K = [0.2, 0.1, -0.5, ...]  # 64 维

# 不缩放：点积可能达到 ±64 范围
Q·K = 32.5  →  softmax(32.5) ≈ 1 (梯度≈0) ❌

# 缩放后：点积控制在合理范围
Q·K / √64 = 32.5 / 8 = 4.06  →  softmax(4.06) 梯度正常 ✅
```

## 🔑 核心创新 2：Multi-Head Attention（多头注意力）

### 核心思想

并行运行**多个注意力头**，每个头学习不同的表示子空间，最后拼接。

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) W^O

where head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)
```

### 参数配置（Base 模型）

| 参数 | 值 | 说明 |
|------|-----|------|
| d_model | 512 | 词向量维度 |
| h (heads) | 8 | 注意力头数 |
| d_k | 64 | 每个头的 Q/K 维度 (512/8) |
| d_v | 64 | 每个头的 V 维度 (512/8) |

### 为什么需要多头？

**单头注意力**：只能学习一种注意力模式

**多头注意力**：
- Head 1: 可能关注**语法关系**（主谓宾）
- Head 2: 可能关注**指代关系**（代词→名词）
- Head 3: 可能关注**语义相似**（同义词）
- ...

**类比**：CNN 中的多个卷积核，每个核提取不同特征

## 🔑 核心创新 3：Positional Encoding（位置编码）

### 问题

Transformer 没有 RNN 的顺序性，如何知道词的**位置信息**？

### 解决方案

使用**正弦和余弦函数**生成位置编码：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

**pos**: 词的位置 (0, 1, 2, ...)
**i**: 维度索引 (0, 1, 2, ..., d_model/2)

### 为什么用三角函数？

1. **周期性**：可以学习相对位置关系
2. **线性关系**：PE(pos+k) 可以表示为 PE(pos) 的线性函数
3. **外推能力**：可以处理比训练时更长的序列

### 位置编码可视化

```
位置 0: [sin(0), cos(0), sin(0/100), cos(0/100), ...]
位置 1: [sin(1), cos(1), sin(1/100), cos(1/100), ...]
位置 2: [sin(2), cos(2), sin(2/100), cos(2/100), ...]
```

## 🔑 核心创新 4：残差连接 & LayerNorm

### Add & Norm 结构

每个子层（Attention / Feed Forward）后都使用：

```
Output = LayerNorm(x + Sublayer(x))
```

**作用**：
- **残差连接 (x + Sublayer(x))**: 解决梯度消失，允许信息直接流动
- **LayerNorm**: 稳定训练，加速收敛

### 与 BatchNorm 对比

| 特性 | BatchNorm | LayerNorm |
|------|-----------|-----------|
| 归一化维度 | 批量维度 | 特征维度 |
| NLP 适用性 | 差（句子长度不一） | 好（逐样本归一化） |
| 训练/测试差异 | 需要移动平均 | 一致 |

---

## 🔑 核心创新 5：Position-wise Feed-Forward Networks

### 结构

每个位置独立的 FFN：

```
FFN(x) = max(0, xW_1 + b_1)W_2 + b_2
```

**参数配置**：
- W_1: 512 → 2048 (扩展 4 倍)
- W_2: 2048 → 512 (压缩回原维度)
- ReLU 激活

**本质**：两个线性变换中间加 ReLU，等价于 1x1 卷积

## 💻 代码实践

### 自注意力实现（NumPy 简化版）

```python
import numpy as np

def softmax(x, axis=-1):
    e_x = np.exp(x - np.max(x, axis=axis, keepdims=True))
    return e_x / e_x.sum(axis=axis, keepdims=True)

def scaled_dot_product_attention(Q, K, V):
    """
    Q, K, V: (batch, seq_len, d_k)
    """
    d_k = Q.shape[-1]
    
    # 1. Q × K^T
    scores = np.matmul(Q, K.transpose(0, 2, 1))  # (batch, seq_len, seq_len)
    
    # 2. 缩放
    scores = scores / np.sqrt(d_k)
    
    # 3. Softmax
    attention_weights = softmax(scores)  # (batch, seq_len, seq_len)
    
    # 4. × V
    output = np.matmul(attention_weights, V)  # (batch, seq_len, d_k)
    
    return output, attention_weights

# 示例
batch_size = 2
seq_len = 10
d_k = 64

Q = np.random.randn(batch_size, seq_len, d_k)
K = np.random.randn(batch_size, seq_len, d_k)
V = np.random.randn(batch_size, seq_len, d_k)

output, attn_weights = scaled_dot_product_attention(Q, K, V)
print(f"Output shape: {output.shape}")  # (2, 10, 64)
```

### 多头注意力实现

```python
def multi_head_attention(Q, K, V, h=8):
    """
    Q, K, V: (batch, seq_len, d_model)
    h: 头数
    """
    batch_size, seq_len, d_model = Q.shape
    d_k = d_model // h
    
    # 分割成 h 个头
    Q_heads = Q.reshape(batch_size, seq_len, h, d_k).transpose(0, 2, 1, 3)
    K_heads = K.reshape(batch_size, seq_len, h, d_k).transpose(0, 2, 1, 3)
    V_heads = V.reshape(batch_size, seq_len, h, d_k).transpose(0, 2, 1, 3)
    
    # 并行计算所有头
    outputs = []
    for i in range(h):
        out, _ = scaled_dot_product_attention(
            Q_heads[:, i], K_heads[:, i], V_heads[:, i]
        )
        outputs.append(out)
    
    # 拼接
    output = np.concatenate(outputs, axis=-1)  # (batch, seq_len, d_model)
    
    return output
```
