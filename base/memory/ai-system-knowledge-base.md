### 2.2 SSH Host Key 故障处理

#### 问题现象
```
Unable to negotiate with 10.1.17.2 port xxxx: no matching host key type found. Their offer: ssh-rsa
```

#### 根本原因
- OpenSSH 8.8+ 默认禁用 `ssh-rsa`（安全问题）
- 老旧 Git 服务器仍使用 `ssh-rsa`

#### 解决方案
```ssh
# ~/.ssh/config
Host coding.xxx.com          # 必须匹配 git remote 的 hostname
    HostName 10.1.17.2       # 实际 IP
    HostKeyAlgorithms +ssh-rsa
    PubkeyAcceptedAlgorithms +ssh-rsa
```

#### ⚠️ 关键细节
- `Host` 匹配 **hostname** 不是 IP
- `+ssh-rsa` 是追加，不是替换

## 3. 原理层：大模型核心机制

### 3.1 大模型如何"记住"知识

| 记忆类型 | 类比人类 | 技术实现 | 特点 | 应用场景 |
|---------|---------|---------|------|---------|
| **参数记忆** | 长期记忆 | 神经网络权重 | 静态、截止训练日、可能幻觉 | 通用知识 |
| **上下文记忆** | 短期记忆 | Attention 机制 | 即时生效、窗口限制 | 对话历史 |
| **RAG** | 查资料 | 向量检索 | 外部知识库、实时更新 | 企业知识 |
| **微调** | 重新学习 | 梯度更新/LoRA | 可能灾难性遗忘 | 领域适配 |

**本质**：知识以统计关联模式存储在权重矩阵中，而非显式数据库。

### 3.2 注意力机制详解

#### Q-K-V 三要素

```
┌─────────────────────────────────────────────────────────┐
│  Query (Q): "我要找什么信息？"                           │
│  Key   (K): "我有什么信息？"                             │
│  Value (V): "信息的具体内容是什么？"                      │
└─────────────────────────────────────────────────────────┘
                      ↓
         注意力分数 = Q × K (点积)
                      ↓
         Softmax 归一化 → 放大差异
                      ↓
         输出 = Softmax(Q×K) × V
```

#### Softmax 放大效应

```
原始分数：[8, 7, 2, 1]
Softmax 后：[0.46, 0.34, 0.12, 0.08]  ← 差异被放大

原始分数：[20, 2, 1, 1]
Softmax 后：[0.999, 0.0004, ...]  ← 极端聚焦
```

#### 形象类比

> 模型知识 = 一片黑暗的图书馆
> 
> 差 Prompt = 手电筒散射，照亮一大片区域（杂乱）
> 
> 好 Prompt = 手电筒聚焦，精准照亮某一排书架

### 3.3 自进化 Agent 实现

#### 核心机制

```python
class SelfEvolvingAgent:
    def run_with_evolution(self, task):
        # 1. 执行
        result = self.execute(task)
        
        # 2. 反射：分析成功/失败
        reflection = self.llm.generate(
            f"Task: {task}\nResult: {result}\n"
            "Analyze what went wrong and how to improve."
        )
        
        # 3. 进化：更新提示词或策略
        self.system_prompt = self.evolve_prompt(reflection)
        
        return result
```

#### 四种自进化方式

| 方式 | 机制 | 案例 |
|------|------|------|
| **反射循环** | 执行→分析→改进 | 自我批评 |
| **技能库积累** | 保存成功策略为可复用技能 | Voyager |
| **提示词进化** | LLM 生成并评分多个变体 | APE/OPRO |
| **元学习层** | 元 Agent 监控优化主 Agent | 系统提示词优化 |

### 4.2 注意力机制的数学拆解

#### 步骤 1：向量点积计算相似度

```
【数学】
向量点积：a·b = Σ(aᵢ × bᵢ)

【AI 应用】
"首都"·"北京" = 高分数（方向接近）
"首都"·"烤鸭" = 低分数（方向远离）

【本质】
点积 = 语义相似度的数值化
```

#### 步骤 2：矩阵乘法批量处理

```
【数学】
Q 是 seq_len×d_model 矩阵
K 是 seq_len×d_model 矩阵
注意力矩阵 = Q × Kᵀ (seq_len×seq_len)

【AI 应用】
一次矩阵运算完成所有词对的相似度计算
从 O(n²) 次单独计算 → 1 次矩阵乘法

【本质】
并行化 = 高效计算的关键
```

#### 步骤 3：Softmax 归一化

```
【数学】
softmax(xᵢ) = exp(xᵢ) / Σexp(xⱼ)

【AI 应用】
[8, 7, 2, 1] → [0.46, 0.34, 0.12, 0.08]

【本质】
- 转为概率分布（和为 1）
- 放大差异（高分更高，低分更低）
- 可解释为"注意力权重"
```

#### 步骤 4：加权求和聚合

```
【数学】
输出 = Σ(权重ᵢ × Valueᵢ)

【AI 应用】
根据注意力权重，从上下文中提取相关信息

【本质】
上下文相关的信息选择
```

## 5. 串联：从数学到智能

### 5.1 完整知识串联链

```
向量点积（简单数学运算）
    ↓ 语义化
注意力分数（词与词的相关性）
    ↓ 归一化
注意力权重（概率分布）
    ↓ 加权
上下文表示（信息聚合）
    ↓ 多层堆叠
复杂推理能力（涌现）
    ↓ 训练优化
参数记忆（知识存储）
    ↓ Prompt 引导
精准输出（应用）
```

### 5.2 关键顿悟

#### 顿悟 1：注意力 = 可学习的加权平均

```
传统加权平均：权重是人工预设的
注意力机制：权重是动态计算的（Q-K 点积 + Softmax）
关键创新：权重是输入相关的（input-dependent）

"首都"在不同上下文中关注不同的词
```

#### 顿悟 2：Prompt 为什么有效

```
模型知识 = 固定的概率分布（参数记忆）
Prompt = 改变条件概率 P(输出 | 输入)
好 Prompt = 把概率质量集中在正确答案区域
注意力机制 = 实现"聚焦"的技术手段

本质：Prompt 不增加知识，但决定知识的调用精度
```

#### 顿悟 3：从数学到智能的涌现

```
向量点积（简单数学）
    ↓
注意力权重（语义相关）
    ↓
多层注意力（复杂推理）
    ↓
涌现能力（模型表现"理解"）

本质：简单操作的堆叠 → 复杂行为的涌现
```

### 5.3 一句话串联

> **向量点积**计算相似度 → **矩阵乘法**批量处理 → **Softmax**归一化权重 → **加权求和**聚合信息 → **反向传播**学习参数 → **概率采样**生成文本 → **Prompt**引导路径

## 6. 应用层：Prompt 工程与 Agent

### 6.1 Prompt 影响回答的三种机制

| 机制 | 原理 | 示例 |
|------|------|------|
| **激活正确知识区域** | 注意力精准聚焦 | "作为首都，北京..."vs"说一下北京" |
| **设定概率分布偏向** | 改变 token 选择概率 | "深思熟虑"→结构化，"快速回答"→简洁 |
| **引导输出格式** | 激活特定模式 | "列举 3 点"→结构化，"逐步推理"→CoT |

### 6.2 优质 Prompt 设计原则

```
❌ 差 Prompt: "说一下北京"
   → 激活混杂信息，输出杂乱

✅ 好 Prompt: "作为中国首都，北京在政治职能上有哪些特点？请分 3 点说明"
   → 精准激活"首都职能"知识
   → 结构化输出
   → 概率质量集中在正确答案
```

### 6.3 自进化 Agent 实践

```python
# 反射循环实现
class ReflectiveAgent:
    def __init__(self):
        self.skill_library = []
        self.prompt_history = []
    
    def execute_with_reflection(self, task):
        # 执行
        result = self.run(task)
        
        # 反思
        reflection = self.analyze(task, result)
        
        # 进化
        if reflection.success:
            self.save_skill(result.strategy)
        else:
            self.update_prompt(reflection.improvement)
        
        return result
```
